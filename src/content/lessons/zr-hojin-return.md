## 所得から税額へ進む前に、法人と年度の条件を確認します

税務調整と欠損金控除等を終えたら、所得金額へ該当する法人税率を適用します。普通法人か、一定の中小法人等か、対象の事業年度がいつ始まったか等により、適用する税率や特例が異なります。資本金が小さいという一つの事実だけで軽減税率を決めず、資本関係や所得額等の除外条件も確認します。

法人税のほかに、地方法人税、法人住民税、法人事業税、防衛特別法人税等を区別します。「地方法人税」は名称に地方とあっても国税です。各税の課税標準は必ずしも同じ所得金額ではないため、税率を全部足して一度だけ所得へ掛ける計算では、それぞれの関係を正しく表せません。

## 軽減税率は、対象と所得の区分から使います

独自の例として、2026年4月1日開始の12か月事業年度、所定の中小法人等の軽減税率の全条件を満たし、年800万円以下の所得へ15％、それを超える所得へ23.2％を適用できる法人とします。課税所得が1,000万円なら、800万円×15％＋200万円×23.2％＝120万円＋46.4万円＝166.4万円です。

この例では所得全額へ15％を掛けた150万円にも、全額へ23.2％を掛けた232万円にもなりません。所得の区分ごとに税率を適用するためです。所得が年10億円を超える一定の年度の17％の規定や、大法人の完全子法人等の除外条件、短期事業年度の月数調整等は別に確認します。上の15％を全中小法人の永久的な税率と覚えないようにします。

税率表では、「開始事業年度」と「終了事業年度」のどちらで適用を分けるかも読みます。例えば3月末に決算を迎えたという情報だけでは、改正後の開始年度の条件を満たすかが分かりません。事業年度の始期と終期を一本の線に書いてから、規定の適用日を重ねます。

## 税額控除と中間納付は、役割が違います

所得税額控除、外国税額控除、一定の投資等の税額控除には、それぞれ限度や明細等の条件があります。中間納付は、年度の途中で税を納め、確定した年間税額と精算する仕組みです。中間納付を所得から差し引く経費として扱うのではなく、税額から既納付額として精算します。

上の算出税額166.4万円について、全額適用できる税額控除10万円、中間納付60万円、他の調整なしと与えれば、確定の差引納付額は96.4万円です。166.4－10＝156.4万円が控除後の年間税額で、そこから60万円を引きます。中間納付が180万円なら、同じ条件で23.6万円の過納額となります。

| 計算段階       | この例の金額 | 読み取る内容     |
| -------------- | -----------: | ---------------- |
| 所得           |    1,000万円 | 税務調整等の後   |
| 算出法人税額   |    166.4万円 | 区分別税率を適用 |
| 税額控除後     |    156.4万円 | 年間の税額       |
| 中間納付精算後 |     96.4万円 | この例の追加納付 |

## 防衛特別法人税は、法人税額を基礎とする別の国税です

防衛特別法人税は、2026年4月1日以後開始事業年度から適用されます。基本として、一定の調整をした基準法人税額から年500万円の基礎控除を差し引いた課税標準へ4％を掛けます。所得に4％を掛ける税ではありません。基準法人税額は、各税額控除等の調整を含む法定の額であり、単に確定申告で今回振り込む額とも異なります。

独自の例で、2026年4月1日から2027年3月31日までの12か月事業年度、通算法人でなく、基準法人税額800万円と与えます。基礎控除500万円を差し引くと300万円となり、税額控除等がないなら防衛特別法人税は300×4％＝12万円です。所得800万円と指定した例ではない点を確かめます。

条件を変えて基準法人税額400万円なら、課税標準は0円となり、この基本例の税額も0円です。控除し切れない100万円を使ってマイナス税額を計算するものではありません。基礎控除には短期事業年度の月数調整、通算法人の配分等があるので、すべての法人に必ず500万円をそのまま使えるとは限りません。

## 税額がゼロでも、申告の確認が必要です

防衛特別法人税については、税額が生じない場合でも申告が必要となる扱いがあります。また、中間申告の開始時期は2027年4月1日以後開始事業年度と区別します。制度の適用開始と、中間申告の適用開始を同じ日付として覚えないでください。最新の様式や提出方法は公式資料で確認します。

法人税の通常の確定申告は原則として事業年度終了の日の翌日から2か月以内ですが、申告期限延長等の条件があります。延長を受けた場合の納付や利子税等も別に確認します。申告する期限が動けば、無条件に無利息で納税も後へ移せると考えないことが必要です。

青色申告の承認や各種届出、帳簿書類の保存は、税率計算とは別に適用の前提になります。決算書、別表四、欠損金の明細、税額控除の明細、既納付額をつなぎ、一つの数字を複数の欄で二重に使わないように照合します。

## 複数の税を、一つの税率にまとめず順につなげます

税額計算の資料には、法人税額を基礎とする税と、所得を基礎とする税が混在します。防衛特別法人税では基準法人税額、法人住民税では法定の法人税額等、法人事業税では所得・付加価値・資本等を確認します。同じ「法人が払う税」でも、税額計算の基礎となる金額が違うため、単純に表面税率を足す方法では計算過程を示せません。

控除額の月数調整も、制度ごとに確かめます。防衛特別法人税で、通算法人ではない六か月事業年度について基礎控除を年500万円の月数割合で250万円とする条件なら、基準法人税額400万円に対して課税標準150万円、4％で6万円です。12か月の例の500万円をそのまま引けばゼロとなり、事業年度の条件を失います。端数月等がある場合は法定の月数計算を確認します。

提出資料を点検するときは、算出税額、税額控除後の税額、中間納付額、今回の納付額を別々に読み上げます。今回の納付額だけから基準法人税額を逆算すると、控除等の調整を取り違えます。申告と納付の期限や延長条件も別欄へ記録し、税額ゼロの場合を含め必要な申告を確認してください。

中間納付だけが200万円から300万円へ増えても、法定の基準法人税額が同じなら、それだけを理由に防衛特別法人税の課税標準を100万円減らすものではありません。中間納付は既納付の精算に関わる数字です。基準額を求める調整と、今回いくら納めるかという資金の計算を別の表へ分けると、数字の役割を保てます。

科目の復習では、会計利益から所得への調整と、所得から税額への計算を別の表へまとめます。基準法人税額と所得、中間納付と損金の違いを説明できれば、税の名前が増えても判断の順を保てます。120分の独自基礎模試では、与えられた条件に即した計算と記述を行います。
