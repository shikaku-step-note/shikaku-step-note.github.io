## アイデアと表現を区別する

知的財産は創作や事業活動で生まれる価値です。著作権は文章、画像、プログラムなどの創作的な表現を保護します。単なる事実、一般的なアイデア、計算の手順そのものと、具体的な表現は区別します。原則として創作時に権利が生じ、登録しなければ著作権がないという考えは誤りです。

| 権利       | 主な対象                     | 学習上の区別                         |
| ---------- | ---------------------------- | ------------------------------------ |
| 特許権     | 技術的な発明                 | 登録による保護を考える               |
| 実用新案権 | 物品の形状・構造などの考案   | 方法そのものとの違いに注意           |
| 意匠権     | 物品などのデザイン           | 外観の創作を守る                     |
| 商標権     | 商品・サービスを識別する標識 | 名前やマークによる出所の識別         |
| 著作権     | 創作的な表現                 | 公開されていても自由利用とは限らない |

## ライセンスは使い方の条件

ソフトウェアは購入しても著作権そのものを得るとは限りません。同時利用人数、複製、改変、再配布などの許諾条件を確認します。OSSも無条件ではなく、著作権表示やライセンス文の添付、改変物を配布する際の条件が定められていることがあります。フリーウェアの「無料」と、改変や再配布の自由は別です。

## 例：社内資料へ画像を載せる

検索結果の画像をそのまま貼る前に、権利者、許諾、適用される例外、必要な表示を確認します。出典を書けば常に転載できるわけではありません。引用には必要性や主従関係、明確な区別などの要件があり、個別に判断します。営業秘密も、不正競争防止法の保護を考える際は秘密管理性などの要件が重要です。

## まとめ

保護対象、権利の成立、利用の許諾を分けて確認します。ここでは学習上の基本を扱い、個別の権利判断は専門家や公的な案内で確認してください。

## 製品公開前に、守るものと借りるものを仕分ける

新しい温度計を販売する会社には、測定を安定させる発明、外装のデザイン、製品名、説明書の図があります。同じ製品に関係していても、測定原理は特許、外観は意匠、出所を示す名称は商標、具体的な図は著作権というように対象が異なります。試験では「新製品だから特許」と決めず、何を守りたいのかを見ます。物品の形状や構造に関する考案は実用新案の候補ですが、方法そのものは対象の違いに注意します。

### 画像とコードは利用の段階ごとに確認する

説明書を作るために、取引先の写真を社内で確認することと、その写真を一般公開することは同じ利用ではありません。写真の権利者と許諾範囲を調べ、公開、改変、配布まで許されているかを確認します。引用として扱う場合も、解説に必要か、引用部分と自分の説明を区別できるかなどの条件を確かめます。写真に人物が写るなら、写真の著作権に加えて肖像の扱いも別に考えます。

生成AIについても、学習データに使う段階と、生成物を配布・公開する段階を分けます。学習に関する権利制限の条件があることは、出力を無条件で使えることを意味しません。既存作品との類似性や依拠性など、実際の使い方と事実を見ます。[文化庁の整理](https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html)と[特許庁の制度案内](https://www.jpo.go.jp/news/shinchaku/event/seminer/text/2025_nyumon.html)を参照してください。

### 料金、利用権、秘密管理は別の話

端末にソフトを導入する場合、料金を払ったことだけでは、端末の台数や同時利用者数を増やせません。契約が利用者単位か端末単位か、サーバへのアクセスに別のCALが必要かを確認します。社外へOSSを配布する場合は、部品と版を特定し、再配布時の表示やソース提供条件を調べます。一方、非公開の製造条件を守るなら、閲覧者を限定し秘密と分かる形で管理することが論点です。特許のような公開・登録を前提とする制度と同じではありません。

## 一つの製品に関わる権利を対象ごとに見分ける

### 仕組み、外観、名前、説明文を別々に見る

教材用の小型タイマーを発売する会社を考えます。タイマーには、消費電力を減らす制御方法、外側の特徴的な形、商品名、写真付き説明書があります。考案の対象が方法なら、物品の形状・構造・組合せを対象とする実用新案の説明だけでは判断できません。新しい技術的な発明について特許の可能性を調べます。一方、物品を固定する部品の形状の考案なら実用新案の対象になり得ます。どちらも、対象に当たることと、個々の登録要件を満たすことは別の判断です。

外観を守りたいなら意匠、顧客が商品やサービスの出所を見分ける目印なら商標を検討します。自社で撮った写真や自社で書いた説明文は、創作的な表現であれば著作権の対象となり得ます。説明書を読んで同じ仕組みを独立して作れるかは、著作権だけでは決まりません。特許などの権利が別に関わることがあるためです。出願・登録が必要な制度と、登録手続によらず創作により権利が生じる著作権を分けて覚えます。

### 社内で買ったソフトを取引先に使わせられるか

会社で購入したソフトに『利用者10名まで』と条件があるとします。10台に入れたことだけでは、何人が使えるかも、社外の共同作業者が使えるかも決まりません。契約書や規約で、数える単位、利用主体、対象となる事業所や設備、配布・再許諾の可否を確認します。利用者単位のライセンスなら、一人が二台を使う場合と、二人で一台を共有する場合では数え方が変わり得ます。『購入した』という事実だけで複製や再配布まで許されるとは判断しません。

別のケースでは、説明資料へ他人の図を引用したいとします。出所を書くだけでどんな利用も引用になるわけではありません。公表された著作物か、引用の目的に照らして必要な範囲か、引用部分を区別できるかなど、利用の実態を確かめます。許諾に基づいて使う場合は、改変や公開先の条件も照らし合わせます。登録や制度の概要は[特許庁の産業財産権の解説](https://www.jpo.go.jp/system/patent/gaiyo/seidogaiyo/chizai01.html)、著作権の制度は[文化庁の著作権案内](https://www.bunka.go.jp/seisaku/chosakuken/)を参照できます。

### 営業秘密と公開された技術を見分ける

加工の温度と時間を記した条件表が、製品不良を減らすために役立っているとします。社内ではその表に秘密表示を付け、担当者の権限に応じて閲覧を制限しています。一般には公開されていないので、この条件表は営業秘密の三要件である秘密管理性、有用性、非公知性を検討する対象です。秘密表示は、扱う人が秘密だと認識できる管理を考える手掛かりです。役立つ情報か、一般に知られていないかも別々に確認します。

一方、同じ内容が既に会社の公開説明書に載っているとします。社内版に秘密表示があっても、同じ情報を誰でも公開資料で読めるため、非公知性の評価は変わります。公開された文書をそのまま複製できるかは著作権など別の問題です。また、営業秘密に該当することと、ある行為が法にいう不正な取得・使用・開示に当たることも別々に判断します。要件の概要は[e-Gov法令検索の不正競争防止法第2条](https://laws.e-gov.go.jp/law/405AC0000000047)を参照できます。

出題範囲の参照：[IPA ITパスポート試験シラバス Ver.6.5（本文9ページ）](https://www.ipa.go.jp/shiken/syllabus/omgdg50000005kn1-att/syllabus_ip_ver6_5.pdf)。

## 一つの製品から、守りたい対象を取り出す

入力ミスを減らす端末を考えます。押した位置を判定する新しい技術、筐体の見た目、商品名、利用マニュアルには、それぞれ異なる保護の考え方があります。技術的な発明を保護したいなら特許を検討し、物品の形状などの考案なら実用新案も候補になります。商品の外観には意匠、商品やサービスを識別する名称・ロゴには商標、創作性のあるマニュアルの文章や図には著作権が関係します。実際に登録できるかは制度ごとの条件を確認します。

### 例題：自社で買った資料を研修へ転用する

外部の解説図を社内研修に入れたいとします。まず権利者、ライセンス、利用場所と配布範囲を確認します。無料で閲覧できることと、転載が許されていることは別の条件です。引用を検討する場合は、公表済みか、説明上の必要があるか、自分の説明と引用部分を区別できるか、必要な分量か、出所を示せるかを確認します。図が研修の中心になり、自分の説明が添え物になっているなら、引用として扱えると即断できません。許諾を得るか、事実関係を確認して自作の図で説明します。

設計図を秘密にして競争力を保つ方法では、不正競争防止法上の営業秘密として、秘密として管理されていること、事業活動に有用であること、公然と知られていないことを確認します。共有フォルダに全員が自由にアクセスでき、秘密の表示もないなら、管理方法の検討が必要です。

| 新製品の要素 | 主な保護の入口 |
| --- | --- |
| 位置を判定する技術 | 特許 |
| 筐体の外観 | 意匠 |
| 名前とロゴ | 商標 |
| 手順を表現した文と図 | 著作権 |

### 利用目的から権利と条件を選び直す

社内で購入した画像を宣伝に転用する案では、購入した素材のライセンスに広告利用と改変が含まれるかを見ます。実際の画像には撮影者の著作権に加え、写った人物や第三者の商標など別の論点もあり得ます。反対に、競合の装置と同じ性能を目指す場合は、機能の説明を読めることと、特許で保護された技術を自由に実施できることは同じではありません。何を利用し、誰に見せ、どこで配布するかを明確にします。
