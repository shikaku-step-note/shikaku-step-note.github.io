<span id="first-reading"></span>

製造で使った材料の量は、材料がどこからどこへ移ったかを順にたどると求められます。倉庫から製造現場へ出すのが<a class="lesson-term" data-lesson-term href="#lesson-term-issue">払出し</a>です。払出しの記録は倉庫を出た量を示すので、現場に使い残しがあれば、払い出した全量が消費されたわけではありません。未使用分の<a class="lesson-term" data-lesson-term href="#lesson-term-warehouse-return">倉庫への返却</a>は、この払出しの一部を戻す移動です。

これに対して<a class="lesson-term" data-lesson-term href="#lesson-term-supplier-return">仕入先への返品</a>は、納入元へ材料を返す手続です。返品した量は会社全体の材料から減ります。倉庫への返却では会社の中で保管場所が変わるだけなので、同じ「返した」という記録でも、数量を直す場所は異なります。

<span id="objective-1"></span>

## 材料の記録と、代金の記録を読み分ける

材料を注文した時点では、予定の数量が分かります。月末までに注文した分の一部しか届いていなければ、受入れとして記録するのは、その月に実際に受け取った分です。製造に使った量を求めるには、その受入記録に加えて、製造へ材料を渡した記録と、使わずに戻した記録も必要になります。

代金を払った日から分かるのは、現金をいつ支出したかです。翌月払いの約束で材料を受け取り、その日のうちに一部を使ったときは、支払いの前でも受入れと消費が生じています。資料を読む際には、「倉庫に何個入ったか」「製造で何個使ったか」「現金はいくら出たか」を別々の欄に置くと、月をまたぐ取引を扱いやすくなります。

### 四つの日付がそろわない場合の資料の選び方

注文書の数量は、後でどの注文の荷物を受け取ったか照合するために使います。月末時点で倉庫に入った数量は、受入票で確かめます。受入票に注文番号が記載されていれば、同じ注文に対して一部だけ届いたのか、別の注文の材料が届いたのかを見分けられます。先に注文金額を計算するより、どの記録が、どの出来事を証明しているかを揃える方が確実です。

材料代を先に支払っていた場合も、到着前の材料が倉庫に加わることはありません。月末の原価資料を読むとき、支払記録に金額があり、受入票に該当する行がなければ、支払いだけが先に行われた可能性を考えます。受入れの確認ができてから、手元の材料を数量表へ記入し、その中で製造に使用した分を調べます。

<span id="worked-1"></span>

### 例題1　注文した数量の一部だけ、月内に届いた

5月29日に同じ金具を15箱注文し、6月に12箱を受け取りました。残り3箱は7月の受入予定です。6月中には6箱を製造に使い、代金は7月に支払います。価格は1箱2,000円、6月初めの在庫と他の入出庫はありません。

| 月と資料 | どこに反映するか |
| --- | --- |
| 5月の注文書に15箱 | 購入の予定。6月に使える量は受入票で確かめる |
| 6月の受入票に12箱 | 6月に12箱が倉庫に入る |
| 6月の製造記録に6箱 | 6月に6箱を消費する |
| 残り3箱は7月に到着予定 | 6月の利用可能数量には含まれない |
| 7月に支払い | 6月には現金の支払いがない |

6月に受け入れた12箱から、消費した6箱を引くと、6月末の材料は6箱残ります。1箱2,000円なので、消費額は12,000円、残存額も12,000円です。どちらの額も6月の受入分24,000円の内訳であり、6月の支払額は0円です。

注文書の15箱と当月の受入れ12箱の差は、翌月に到着する3箱です。6月分の消費と残高を計算する出発点は、当月に受け取った12箱になります。

## 倉庫へ戻った材料を、行き先ごとに扱う

倉庫から製造現場へ材料を渡すことを**払出し**といいます。払い出したものを現場ですべて使う場合は、払出量と消費量が一致します。余った分をすべて倉庫へ戻した場合、消費したのは払出量からその返却量を引いた分です。この差を、ここでは正味消費量と呼びます。

材料の受入れ・払出し・残高などを種類ごとに記録する帳簿が**材料元帳**です。倉庫だけの記録では、他の増減がなければ「倉庫の月初残高＋正味受入量＝正味払出量＋倉庫の月末残高」です。仕入先への返品は正味受入量、現場からの未使用返却は正味払出量から引きます。倉庫と現場を一緒に集計すれば、二つの場所の月初残高と正味受入量の合計は、実際の消費量と二つの場所の月末残高の合計に一致します。

### 例題2　製造から戻した場合と仕入先へ戻した場合

材料の月初残高は26kg、当月受入れは70kgです。製造へ54kgを払い出しましたが、そのうち9kgが未使用のまま倉庫へ戻りました。現場に月初・月末の未使用材料はなく、他に増減はありません。

月初26kgと受入れ70kgの合計は96kgです。製造の正味消費量は54−9＝45kgなので、月末の帳簿残高は96−45＝51kgとなります。倉庫の動きを一件ずつ追う場合も、26＋70−54＋9＝51kgです。

<details id="try-material-recipient">
  <summary>返した相手を変える　9kgを仕入先へ返品したとき、月末には何kg残りますか。</summary>
  <p>この場合、製造へ払い出した54kgはすべて使用したものとします。仕入先への返品9kgは受入れ側で差し引くので、利用できた数量は26＋70−9＝87kg。これから54kgを消費し、月末残高は33kgです。「9kgを戻した」という動詞だけでは足し引きが決まりません。相手と倉庫の位置関係を読むと、返却の意味を区別できます。</p>
</details>

### 例題　倉庫と製造現場の両方に、未使用の材料がある

製造現場へ渡した材料の一部を翌月まで現場に置く場合、倉庫から出た量と製造で使った量を別々に数えます。この例では、現場にある未使用分も材料として残し、仕掛品や製品の原価へ入れるのは実際に使った分とします。

月初の倉庫残高は12kgです。当月に30kgを受け入れ、品質条件に合わない2kgを仕入先に返品しました。倉庫から製造へ24kgを払い出し、使わなかった4kgを倉庫へ戻しています。製造現場で当月に使ったのは15kgです。月初の現場在庫はなく、他に増減はありません。すべて800円/kgとすると、倉庫と製造現場にそれぞれ何kg残り、当月の材料消費額はいくらになるでしょうか。

### 例題　現場に前月から残っていた材料も、当月の消費に含める

月初の現場に4kgあり、今月は倉庫から20kgを受け取り、そのうち未使用の3kgを倉庫へ戻しました。月末の現場には6kg残っています。払出し20kgから返却3kgを引いた17kgは、この月に倉庫から現場へ移った正味の量です。このまま消費量にすると、現場に最初からあった4kgと最後の6kgが計算に入りません。

| 現場にあった材料 | kg | 消費の式での扱い |
| --- | ---: | --- |
| 月初から使える分 | 4 | 足す |
| 当月に倉庫から受け取った分 | 20 | 足す |
| 未使用のまま倉庫に戻した分 | 3 | 引く |
| 現場に残っている分 | 6 | 引く |

現場で使えた24kgから、使用せず倉庫に戻した3kgと現場に残る6kgを引くと、消費量は15kgです。現場と倉庫を含む会社全体で計算する場合は、倉庫からの払出しと倉庫への返却を数量の増減から外します。その二つは保管場所を変えただけだからです。仕入先へ返品した分は会社の外へ出るので、会社全体の計算でも引きます。

月初の現場は2kg、今月の払出しは14kgでした。1kgを倉庫へ戻し、現場に4kg残った場合の消費量を求めてください。

<p>消費量は2＋14−1−4＝11kgです。倉庫の正味払出量13kgとの差2kgは、現場の残量が2kgから4kgに増えたためです。</p>
</details>

## 数量を確かめてから、消費と残高を金額に直す

材料1単位分の金額が一定のときは、消費量と月末に残った量に同じ単価を掛けます。たとえば700円/kgの材料なら、1kgの消費も1kgの残高も700円に対応します。数量の両側を同じ単価で換算するため、利用可能額は消費額と残存額に分かれるはずです。単価が異なる場合の評価は、[材料元帳を金額まで追うレッスン](../cb2-materials/)で扱います。

月末の実物を数えると、帳簿と異なることがあります。数量差が見つかっても、何に使ったかは、払出記録や紛失の記録などを調べて判断する必要があります。設問に原因と処理が示されていれば、その条件に従います。以下の例では、資料で確かめられる製造消費と、原因が分からない不足を分けます。

<span id="worked-3"></span>

### 例題3　製品別の消費、帳簿残高、現物の差を分ける

工場では700円/kgの材料を使います。月初に16kgあり、当月に32kgを受け入れ、そのうち4kgを仕入先へ返品しました。Aに25kgを払い出しましたが、使わなかった3kgが倉庫へ戻っています。Bへ払い出した12kgはすべて使用しました。ほかに帳簿に記録された動きはありません。

まず利用可能量は16＋32−4＝44kgです。Aの使用量は25−3＝22kg、Bは12kgで、製造消費は34kg。月末の帳簿残高は44−34＝10kgです。金額に直すと、Aの消費額は15,400円、Bは8,400円、帳簿残高は7,000円となります。44kg×700円/kg＝30,800円は、消費23,800円と残存7,000円に分かれました。

月末に現物を数えると9kgだった場合、帳簿との差は1kg、資料の単価に当てると700円です。Aへ払い出した量とAから戻した量が記録されているので、Aの消費22kgは説明できます。一方、不足した1kgをA・Bのいずれかが使ったという資料はありません。製品別消費額を変えるには、不足の原因と処理を確かめる必要があります。

### 確認　同じ材料でも、問いによって記録を選ぶ

設問が聞くのが「倉庫の月末数量」なら、倉庫を出入りした数量から求めます。「今月の製品に使った材料費」であれば、現場へ渡した後の返却や保管を除き、実際の消費量を単価に結び付けます。この区別をしておくと、受入量、払出量、消費量のすべてが異なる資料でも、最初にどの数量を求めるべきか判断できます。

<span id="worked-material-cutoff"></span>

### 例題　翌月に記入した伝票から、当月の出入りを拾い直す

月末の残高は、月末までに実際に出入りした材料から求めます。納入前の請求書を受け取ったり、材料を動かした翌日に伝票を入力したりすると、資料には日付が二つ並びます。月末時点の数量を求めるときは、請求日や入力日と、材料の受入れ・払出し・返却が実際に行われた日を区別します。

ある工場で、6月末の材料元帳には、月初40kg、6月受入46kg、製造への払出し51kg、月末35kgとあります。倉庫で6月末に数えた現物は24kgです。単価はすべて800円/kg。6月初めに製造現場の未使用分はなく、下の3件以外に記録漏れや誤りはありません。製造現場への払出しのうち、倉庫へ返却した分を除いた量はすべて6月中に使用しました。

| 確認した資料（練習用） | 月末時点の事実と確認する欄 | 元帳の35kgを直す向き |
| --- | --- | ---: |
| 6月29日付の請求書。受入票では7月1日に8kgを受領。元帳の6月受入に記入済み | 6月末には受け取っていないため、6月の受入46kgから除く | −8kg |
| 6月30日に、受領済みの材料6kgを仕入先へ返却。元帳には7月1日に入力 | 6月末に倉庫から出ているため、6月の受入側から返品分を差し引く | −6kg |
| 製造現場で余った3kgを6月30日中に倉庫へ戻した。元帳には7月1日に入力 | 6月末の倉庫に戻っているため、6月の製造への払出しから返却分を差し引く | ＋3kg |

まず、元帳の残高35kgと現物24kgの差11kgを、表の「直す向き」で説明します。受領前の8kgと仕入先へ返した6kgは倉庫にないため差し引き、使用せずに倉庫へ戻った3kgは加えます。35−8−6＋3＝24kgとなり、現物に一致します。この照合で分かるのは、見かけの不足が3件の時期のずれで生じたことです。

次に、6月の消費額を求めるため、受入れ側と消費側を別々に書き直します。受入46kgから、翌月に受け取る8kgと仕入先への返品6kgを引くと、正味受入は32kgです。月初40kgと合わせ、6月に利用できたのは72kg。一方、製造で使ったのは、払出し51kgから倉庫へ戻した3kgを引いた48kgです。72kgは、消費48kgと月末24kgに分かれます。800円/kgで換算すると、利用可能額57,600円＝消費額38,400円＋期末残存額19,200円です。

元帳の35kgが現物より11kg多いことを見て、すべて消費に加えると、払出し51kgを62kgと誤って計算します。差の中には、そもそも当月に受け取っていない材料と、製造では使わず仕入先へ返した材料が含まれていたからです。差を説明した後は、受入れと消費の両側を書き直します。正味受入と実際の消費がそれぞれ確定すれば、残高の差に含まれる動きを混同せずに済みます。

## 練習　月末に残る材料と製品別消費額を求める

単価が一律800円/kgの材料について、月初24kg、当月受入36kg、仕入先への返品5kgと記録されています。Aへ28kgを払い出し、うち4kgは未使用のまま戻りました。Bへは16kgを払い出し、すべて消費しています。ほかの増減はなく、代金は翌月払いです。月末残高、A・Bの消費額、当月の材料消費総額を求めてください。

<details id="try-material-use-transfer">
  <summary>解答と照合の手順を確認する</summary>
  <p>利用可能量は24＋36−5＝55kg。製造消費はAが28−4＝24kg、Bが16kgで、計40kgです。したがって月末残高は15kg。Aは19,200円、Bは12,800円を消費し、当月の材料消費総額は32,000円です。月末材料は15×800＝12,000円で、利用可能額44,000円が消費分と残存分に分かれます。代金の支払いは、これらの当月の数量と消費額を変えません。</p>
</details>

購入、払出し、消費を区別できると、材料費を集計する対象が明確になります。次の[材料費・労務費・経費のレッスン](../cb2-elements/)では、消費した資源の種類から製造原価を分類します。
