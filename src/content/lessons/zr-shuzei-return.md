## 同じ酒類へ課税が重ならないよう、移動の理由を記録します

酒類を製造場から出すときも、原料として他の製造場へ送る場合、輸出する場合、課税済みの酒を返品で戻す場合では取扱いが違います。酒税には、法定条件を満たす未納税移出、輸出免税、戻入れ等の税額控除があります。数量だけでなく、移動の目的と証明、どの時点の税額かを確認することが必要です。

このレッスンでは国内製造者の基本形を扱い、各制度の要件や証明等は問題で満たすと明示した例を使います。実際の申告には必要書類、承認、明細、期限等の個別規定があります。制度名だけを理由に税額を0円へするのではなく、要件と手続をつなげて説明します。

## 未納税移出は、移出先と目的が法定の範囲かを読みます

未納税移出は、所定の要件と手続を満たす移出について、その移出に係る酒税を免除する制度です。例えば他の製造場で酒類の原料として使う等の一定の目的のため、法定の手続に従って移出する場合には、未納税移出の制度を検討します。移出先の製造場への移入等を確認する証明や明細が必要となる仕組みです。自社の別の場所へ運ぶという理由だけで、どんな移動も未納税になるわけではありません。

独自の数量例で、当月に清酒合計1,000Lを製造場から出し、そのうち200Lが未納税移出の全要件を満たし、800Lは通常の国内課税移出とします。税額計算の対象を区分し、通常分は0.8kLです。税率100,000円/kL、他の調整なしなら、通常分の税額は80,000円となります。

未納税移出200Lが、帳簿上も移動しなかったことになるわけではありません。物量としては在庫から出ており、免除等の明細でその理由を説明します。後の段階の移出等で課税される関係を含め、徴収の段階を整理する制度として理解します。

## 輸出免税は、輸出の事実と所定の手続を対応させます

国外へ輸出する酒類等については、法定の対象と輸出証明等の条件に従い免税を検討します。相手が外国企業というだけで、国内に引き渡した酒類を自動的に免税へするものではありません。実際の輸出と、その取引を示す資料を確認します。

上の1,000Lの内訳を、通常課税700L、要件を満たす未納税移出200L、要件を満たす輸出免税100Lへ変えたとします。税率100,000円/kLなら通常分は70,000円です。通常分の数量、未納税分、輸出分の合計が1,000Lへ戻るかを照合します。課税数量を小さく書くだけでなく、除く理由別の数量を残します。

| 移動区分               |   数量 | この例の税額計算   |
| ---------------------- | -----: | ------------------ |
| 通常の課税移出         |   700L | 0.7kL×100,000円    |
| 要件を満たす未納税移出 |   200L | 所定の免除等を確認 |
| 要件を満たす輸出免税   |   100L | 所定の免税を確認   |
| 物量の移出合計         | 1,000L | 全区分を照合       |

## 戻入れは、過去に課税した額との関係を確認します

通常の課税移出をした酒類が製造場へ戻る場合等には、二重課税の排除等のための税額控除又は還付の規定があります。返品の販売代金を返金した額そのものを、酒税から引く制度ではありません。対象酒類の数量と、当初の課税移出に係る税額等を資料から確かめます。

独自の例で、税率100,000円/kLで課税移出した清酒100Lが、所定の戻入れ控除の全要件を満たして戻ったとします。控除の基礎となる額は0.1kL×100,000＝10,000円です。当月の通常の税額70,000円から、この控除10,000円を差し引く条件なら、差引額は60,000円です。

酒類の税率改正をまたぐ場合は、現在の移出税率と、当初の課税移出の税額を混ぜないようにします。例えば、戻った物と同じ品目だから今の税率で一律に計算し直すとは限りません。いつ、どこから、どの区分で課税された酒類かという履歴が必要になります。

## 数量の在庫表と、税額の控除表は役割が違います

戻入れ100Lは現物の在庫を増やしますが、それと控除税額10,000円は単位も意味も異なります。当月製成、移出、戻入れ、場内使用等の数量表と、税額、控除、差引額の金額表を分けて作ります。二つを取引番号等で対応させれば、同じ返品を二回控除したり、数量だけ戻して控除を見落としたりする誤りを確認できます。

戻入れ酒類を再び通常移出する場合には、その時点での課税を検討します。最初の戻入れ控除を受けたから、再販売時にも永久に非課税になるという制度ではありません。酒類を原料として使用する等の別の場面にも、法定の条件があります。

## 通常の月例申告と納付の期限を分けます

酒類製造者は、原則として製造場ごとに、移出のあった月の課税標準や税額等を申告します。通常の月例申告の期限は移出月の翌月末日、納付期限は翌々月末日です。申告と納付が同じ日だと決め付けないでください。休日の扱い、期限延長、都度申告等の特則は別に確認します。

独自の2026年6月の通常移出の例なら、原則の申告期限は7月末日、納付期限は8月末日という関係です。日付の具体化では休日等を確認します。移出がなかった月の通常の月例申告の扱いと、還付を求める申告等も同じではありません。税額が0円という一つの結果だけで、必要な手続を省略しないようにします。

## 解答では、要件・証明・効果を順につなげます

理論の記述では、誰のどの移出か、適用する制度の要件は何か、必要な手続や証明は何か、その結果として免除・控除等をどう扱うかを説明します。「未納税だから0円」とだけ書くと、何を根拠にその制度を使えるかが伝わりません。

## 移出数量と控除対象数量を、別の帳簿で照合します

その月に移出した酒類の数量と、過去の課税済み酒類が戻った数量を、単純に相殺した在庫移動だけで申告へ写さないようにします。戻入れ等の控除には、対象となる課税済み酒類との対応や帳簿等の要件があります。返品という販売上の名前があっても、法定の控除額が直ちに確定するわけではありません。

独自の計算例で、当月の移出に係る税額90万円、所定の控除要件を満たす戻入れに係る税額12万円、他の調整なしなら、差引額は78万円です。戻った商品の売価12万円を控除するという意味ではありません。税率が改正された前後の酒類が混在する場合も、控除対象となる元の税額との対応を確認します。

申告と納付の期限は一つの締切へ省略しません。通常の移出課税の基本形で、六月の移出なら申告は原則七月末、納付は原則八月末という時間差があります。休日等の取扱いや個別の例外は別に確認します。移出月、申告月、納付月を三列にした予定表を作り、輸出免税・未納税移出の証明等も同じ月次資料へ関連付けます。

科目の復習では、分類から免許、移出時点、課税数量、税率、免除・控除、申告へ順にたどります。全17品目の定義や軽減制度、承認手続の詳細は、対応表の追加学習も確認してください。独自基礎模試では数量計算と、条件を示した短い記述を組み合わせて確かめます。
