一年間の費用・収益を計算し、財務諸表を作った後も、帳簿には各勘定の残高があります。次の年度では収益と費用を新しくゼロから集計し、資産・負債・純資産は期末残高を引き継ぐ必要があります。帳簿の締切は、そのために当期の記録を区切る作業です。

この課では損益勘定へ収益と費用を集め、その差額を繰越利益剰余金へ移し、資産・負債・純資産の次期繰越と翌期開始記入を行います。決算整理、精算表、財務諸表、締切を一つの動作と考えず、何がどの時点で残っているかを確かめながら進めます。

<span id="objective-1"></span>
## 収益と費用の残高を、損益勘定へ移してゼロにする

売上は通常貸方残高なので、借方に同額を書けば残高がゼロになります。相手は損益の貸方です。売上400,000円なら、借方「売上400,000」、貸方「損益400,000」。売上を減らすことは、販売取引を取り消しているわけではありません。当期の収益として計算した内容を、決算の集計勘定へ移しています。

費用は通常借方残高なので、貸方へ同額を書き、相手を損益の借方にします。給料80,000円なら、借方「損益80,000」、貸方「給料80,000」です。これで給料勘定はゼロとなり、損益勘定の借方に当期費用80,000円が集まります。

収益・費用をゼロにするという操作だけに注目して、反対側の相手を現金にしないでください。既に計算した成果を集める振替なので、お金は動きません。現金の減少をもう一度記録すると、当期の支払いを二重に数えることになります。

<span id="worked-1"></span>
### 例題1：収益二科目と費用五科目を損益へ集める

独自設例の決算整理後残高は、収益が売上400,000円と受取利息2,000円、費用が売上原価算定済みの仕入240,000円、給料80,000円、支払家賃36,000円、減価償却費12,000円、法人税等8,000円です。すべて当期分の整理が済み、他の収益費用はありません。

収益の締切は借方「売上400,000／受取利息2,000」、貸方「損益402,000」。費用の締切は借方「損益376,000」、貸方「仕入240,000／給料80,000／支払家賃36,000／減価償却費12,000／法人税等8,000」です。費用の合計240,000＋80,000＋36,000＋12,000＋8,000＝376,000円を先に確かめます。

答案の行数が足りないときに複数の振替仕訳へ分ける指定なら、例えば仕入・給料・家賃の計356,000円と、償却費・法人税等の計20,000円に分けられます。合計376,000円が損益の借方へ移り、各費用勘定がゼロになる結果は同じです。設問が一つの科目の締切を求める場合には、その科目だけを振り替えます。

| 損益勘定の借方 | 金額 | 損益勘定の貸方 | 金額 |
| --- | ---: | --- | ---: |
| 仕入 | 240,000円 | 売上 | 400,000円 |
| 給料 | 80,000円 | 受取利息 | 2,000円 |
| 支払家賃 | 36,000円 |  |  |
| 減価償却費 | 12,000円 |  |  |
| 法人税等 | 8,000円 |  |  |
| 利益振替前合計 | 376,000円 | 利益振替前合計 | 402,000円 |

損益勘定の左右は、損益計算書で費用を借方、収益を貸方に並べる関係と対応しています。各収益・費用勘定では反対側へ記入し、損益勘定では本来の収益・費用の側へ集めます。この対応が見えると、振替仕訳の向きを一つずつ暗記せずに作れます。

<span id="objective-2"></span>
## 損益の差額を、繰越利益剰余金へ振り替える

例題1では収益402,000円が費用376,000円を上回り、損益は貸方残高26,000円です。この残高をゼロにするため損益の借方へ26,000円を書き、相手は繰越利益剰余金の貸方とします。借方「損益26,000」、貸方「繰越利益剰余金26,000」です。

当期利益によって純資産が増えるので、利益剰余金は貸方へ増加します。資本金へ移すと、株主の払込みと事業の利益が混ざります。損益勘定の残高を翌期の損益として持ち越すこともしません。当期の成果を純資産へ反映して、来期の収益・費用は別に始めるためです。

<span id="worked-2"></span>
### 例題2：締切前後の試算表を、同じ会社で照合する

例題1の会社には、現金預金330,000円、売掛金100,000円、繰越商品80,000円、備品200,000円、減価償却累計額60,000円、買掛金64,000円、資本金500,000円、締切前繰越利益剰余金60,000円があります。上の収益費用を含めた整理後試算表は、借方・貸方とも1,086,000円です。

収益費用を損益へ移し、利益26,000円を振り替えると、損益残高はゼロ。繰越利益剰余金は86,000円になります。締切後に残る勘定は次のとおりです。現金預金等の資産は締切で新たに増減せず、残高を引き継ぎます。

| 勘定科目 | 締切後借方残高 | 締切後貸方残高 |
| --- | ---: | ---: |
| 現金預金 | 330,000円 | — |
| 売掛金 | 100,000円 | — |
| 繰越商品 | 80,000円 | — |
| 備品 | 200,000円 | — |
| 減価償却累計額 | — | 60,000円 |
| 買掛金 | — | 64,000円 |
| 資本金 | — | 500,000円 |
| 繰越利益剰余金 | — | 86,000円 |
| 合計 | 710,000円 | 710,000円 |

貸借対照表で備品から累計額60,000円を控除すると、資産純額は650,000円です。負債64,000円と純資産586,000円の合計も650,000円。締切後試算表の合計710,000円との違いは、控除勘定を別側へ置くか資産から引くかの表示の違いです。

整理後試算表にあった費用・収益の科目が締切後試算表へ残っていないことも確認します。費用376,000円を締切後にも借方へ残し、利益26,000円も純資産へ足すと、当期の損益を二重に残してしまいます。

## 当期損失の場合は、振替の向きが逆になる

収益300,000円、費用340,000円なら、損益は借方残高40,000円です。これを消すには貸方へ40,000円を書き、相手は繰越利益剰余金の借方になります。借方「繰越利益剰余金40,000」、貸方「損益40,000」です。

期首相当の利益剰余金70,000円なら、締切後残高は30,000円です。損失を記録したからといって、繰越利益剰余金が必ず借方残高になるわけではありません。もともとの貸方残高を減らし、なお残る場合があるためです。仕訳の方向と、処理後の残高の方向を分けます。

<span id="objective-3"></span>
## 次期繰越と前期繰越は、残高を反対側と本来側へ置く

資産勘定に借方残高がある場合、当期の締切では貸方へ次期繰越を記入して両側をそろえます。翌期首には借方へ前期繰越を記入し、同じ資産残高から開始します。負債や純資産の貸方残高は逆で、締切時は借方に次期繰越、開始時は貸方に前期繰越です。

次期繰越が反対側へ書かれるからといって、資産や負債が実際に消えたわけではありません。帳簿の年度を区切るための記入です。会社が持つ現金や売掛金、返すべき買掛金は次期へ続いています。収益費用を損益へ振り替える仕訳と、残高を繰り越す記入は役割が違います。

<span id="worked-3"></span>
### 例題3：売掛金と買掛金を締め、翌期の始まりを書く

売掛金勘定の当期借方合計は540,000円、貸方合計は440,000円です。残高は借方100,000円なので、貸方へ次期繰越100,000円を記入し、両側540,000円で締めます。翌期首は借方へ前期繰越100,000円と書きます。

買掛金勘定の当期借方合計は286,000円、貸方合計は350,000円です。残高は貸方64,000円なので、借方へ次期繰越64,000円を記入し、両側350,000円で締めます。翌期首は貸方へ前期繰越64,000円です。

「次期繰越」は当期の表で反対側、「前期繰越」は翌期の表で元の残高側へ置く、と対応させます。売掛金の次期繰越100,000円を借方へ加えると、両側差がさらに広がります。残高を計算し、少ない側へ置いて締め、翌期は本来の側から再開する順番で確かめます。

### 未払費用の繰越と、再振替を混ぜない

期末未払利息6,000円があれば、未払利息の負債を翌期へ繰り越します。翌期首に再振替を行う指定なら、その開始残高から借方「未払利息6,000」、貸方「支払利息6,000」を記録します。残高の繰越を省いて再振替だけを考えると、何を消しているかが分からなくなります。

開始記入は前期末の残高を引き継ぐ作業、再振替は特定の決算整理仕訳を戻して日常記帳とつなぐ作業です。開始記入後の未払利息6,000円が再振替でゼロになっても、前期の当期費用が取り消されたわけではありません。各年度の損益を分けたうえで、次の支払いを処理する準備です。

### 自力演習：利益と勘定の締切を一緒に作る

収益は売上250,000円、費用は仕入150,000円、給料55,000円、家賃25,000円です。締切前繰越利益剰余金40,000円、他の損益・配当等なし。当期利益と、利益振替後の繰越利益剰余金残高を求め、利益振替仕訳を書いてください。

費用合計230,000円、利益20,000円、利益剰余金残高60,000円です。利益振替は借方「損益20,000」、貸方「繰越利益剰余金20,000」。繰越利益剰余金を当期の帳簿で締めるときは借方へ次期繰越60,000円、翌期首は貸方へ前期繰越60,000円です。仕訳額20,000円と繰越残高60,000円を区別します。

## 帳簿を区切っても、取引の関係は次期へ続く

収益・費用・損益の残高は当期の締切でゼロ、資産・負債・純資産は残高を次期へ持ち越す、という二種類の扱いを確認します。累計額や引当金は貸方残高でも資産を控除する勘定として持ち越し、当期費用のように全部を損益へ移しません。

最後に、各収益費用のゼロ、損益勘定のゼロ、利益剰余金の期末残高、締切後試算表の貸借一致、翌期開始記入の側を確かめます。元の当期利益が財務諸表と締切仕訳の両方で同じ額なら、取引の記録から次期の帳簿まで一つの流れで追えています。

### 締切後に、仕入代金の未払義務はなくならない

仕入勘定を損益へ振り替えてゼロにしても、買掛金の未払残高は残ります。仕入は当期の費用を集計する勘定、買掛金は仕入先へまだ払っていない義務を記録する勘定で、締切の役割が違うからです。翌期にその買掛金を支払うときは、借方「買掛金」、貸方「普通預金」とし、前期に費用計算済みの仕入をもう一度増やしません。

同様に、売上を損益へ振り替えた後も売掛金は回収まで残ります。翌期の入金で売掛金を消すときに売上を再計上すると、同じ販売が二つの年度の収益になります。当期の成果を締めることと、債権債務が決済されることを区別して、翌期最初の仕訳まで確認してみてください。

## 仕訳帳・元帳・補助簿を、同じ年度で区切る

総勘定元帳を締めたら、仕訳帳と補助簿も当期の記録を区切ります。仕訳帳には、日常取引に加え、必要な決算整理と損益の振替まで記入し、指定された期間の借方・貸方金額をそれぞれ合計します。この合計は、当期に記録した仕訳の金額を集めたもので、現金の残高や利益ではありません。

<span id="worked-4"></span>
### 例題4：一社の年末記録を、仕訳帳から翌期の帳簿まで締める

当期に設立した会社について、次の四取引だけがあるとします。①株主から現金120,000円の出資を受けた。②商品30,000円を仕入れ、現金12,000円を払い、残り18,000円を掛けにした。③この商品をすべて45,000円で売り、現金20,000円と掛け25,000円で受け取った。④当期の給料10,000円を現金で払った。三分法で、期首・期末商品はゼロ。税金や他の損益・整理事項は、この仕訳と締切の設例では考えません。

| 順序 | 借方 | 貸方 | 片側の金額合計 |
| --- | --- | --- | ---: |
| ①出資 | 現金120,000 | 資本金120,000 | 120,000円 |
| ②仕入 | 仕入30,000 | 現金12,000・買掛金18,000 | 30,000円 |
| ③販売 | 現金20,000・売掛金25,000 | 売上45,000 | 45,000円 |
| ④給料 | 給料10,000 | 現金10,000 | 10,000円 |
| ⑤収益の締切 | 売上45,000 | 損益45,000 | 45,000円 |
| ⑥費用の締切 | 損益40,000 | 仕入30,000・給料10,000 | 40,000円 |
| ⑦利益の振替 | 損益5,000 | 繰越利益剰余金5,000 | 5,000円 |
| 全期間の仕訳合計 | 借方合計295,000 | 貸方合計295,000 | 295,000円 |

日常取引①〜④の片側合計は120,000＋30,000＋45,000＋10,000＝205,000円です。売上45,000円から費用40,000円を引いた利益は5,000円。⑤〜⑦の振替合計90,000円を加えると、仕訳帳の当期借方・貸方合計は各295,000円になります。複合仕訳②の借方30,000円と貸方の二科目計30,000円を、片側の合計へ60,000円として二重加算しないでください。

現金は借方120,000＋20,000＝140,000円、貸方12,000＋10,000＝22,000円で、残高118,000円です。⑤〜⑦では現金が動きません。仕訳帳合計295,000円、現金残高118,000円、利益5,000円は、同じ会社の異なる情報です。元帳では売上・仕入・給料・損益がゼロとなり、資産は現金118,000円と売掛金25,000円の計143,000円。買掛金18,000円・資本金120,000円・繰越利益剰余金5,000円の合計も143,000円になります。

現金勘定は貸方に次期繰越118,000円を書き、両側140,000円で締めます。売掛金元帳の得意先残高25,000円、買掛金元帳の仕入先残高18,000円も、総勘定元帳の各残高と照合して繰り越します。現金出納帳は日常の入出金を集計して118,000円を持ち越し、商品有高帳の期末数量・原価はゼロです。残高のある補助簿と、残高ゼロの商品記録を同じ金額で締めようとはしません。

各帳簿は指定様式に従って当期の合計を記入し、二重線で期間を区切ります。翌期の帳簿には、現金118,000円と売掛金25,000円を借方、買掛金18,000円と純資産各残高を貸方の前期繰越として引き継ぎます。得意先・仕入先別の内訳も引き継ぎますが、当期の販売や仕入れを新しい年度の取引として写し直しません。

仕訳帳は新年度の取引記録を始めます。元帳の開始記入のために、前年の①〜⑦をもう一度仕訳するわけではありません。開始記入と開始仕訳等の扱いに様式指定がある問題では、その指示に従い、同じ残高を二重に転記しないよう確認します。翌期に売掛金25,000円を現金回収したら、現金25,000／売掛金25,000です。前年の売上を再び増やさず、残っていた権利を消す取引だと説明できます。
