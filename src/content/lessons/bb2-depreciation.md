備品を買うと購入日に現金などが減りますが、備品はその後の月にも使えます。購入代金を支払った時点と、使用による費用を記録する時点を分けて考えるのが減価償却です。この課では、初級の出題範囲に合わせ、問題で示された見積額を毎月計上します。年末の決算整理を前提にした計算や、備品の売却仕訳は扱いません。

<span id="objective-1"></span>

## 購入した月の支出と、使用する月の費用を分ける

事務用パソコンを240,000円で買えば、取得日の仕訳で備品240,000円が増え、現金または預金が減ります。翌月以降に使用したことを費用にする際には、支払い済みの代金を使用期間へ配分します。その月の減価償却費を記録して、取得原価のうち使用した期間に対応する部分を費用へ配分します。

毎月の費用を8,000円とする条件なら、購入時に240,000円を記録したうえで、使用月の費用を8,000円ずつ計上します。現金支出240,000円と当月の費用8,000円は、異なる金額として記録します。反対に、その月に支払いがないから費用も0円になる、という関係でもありません。

減価償却費を見積もるためには使用期間などの考え方がありますが、この適用範囲では「毎月の見積額を計上する」という条件を中心に読みます。問題が毎月8,000円と与えていれば、その8,000円を使います。問題が示していない耐用年数や税務上の割合を推測して、別の額へ変更してはいけません。

| 問われているもの | 使う金額 |
| --- | --- |
| 備品を取得した金額 | 購入代金と取得に必要な付随費用 |
| 当月の減価償却費 | 当月について与えられた見積額 |
| 現金支出額 | 実際に支払った取引の金額 |
| 月末の帳簿価額 | 取得原価から月末の減価償却累計額を引いた額 |

土地も有形固定資産ですが、通常の使用によって価値が減る備品や建物とは扱いが異なり、この課の土地には減価償却を行いません。土地の購入額に毎月の割合を掛ける問題へ、勝手に置き換えないようにしてください。土地の売却は、前課で学んだ帳簿価額と代金の比較で処理します。

<span id="objective-2"></span>

## 減価償却費は借方、累計額の増加は貸方へ記録する

この課では間接法を使います。借方に費用である減価償却費、貸方に減価償却累計額を記録します。減価償却累計額は、取得原価から差し引くための勘定です。名前に「額」とあるだけでは方向を判断できないので、「資産を控除する累計額が増えた」と読み替えるとよいでしょう。

貸方に記録するからといって、減価償却累計額が借入金のような負債になるわけではありません。また、収益が発生する取引でもありません。備品勘定に購入時の金額を残しながら、別の勘定で減価償却した額を示すため、両方を照合して資産の残りを求めます。

<span id="worked-1"></span>

### 例題1：当月の見積額を一回だけ記録する

備品の当月の減価償却費は、見積額6,000円と指示されました。当月分はまだ記録していません。仕訳は借方「減価償却費6,000」、貸方「減価償却累計額6,000」です。支払いの指示はないので、現金や普通預金を使いません。

計上前の備品が300,000円、対応する減価償却累計額が24,000円なら、計上後の累計額は24,000＋6,000＝30,000円です。備品勘定は300,000円のままで、帳簿価額は300,000−30,000＝270,000円となります。備品勘定からも6,000円を減らすと、同じ減価償却を二重に控除してしまいます。

当月分をすでに記録済みなら、月末にもう一回同じ仕訳をする必要はありません。「未計上」「すでに計上済み」の記述を、金額の前に確認してください。取引の追加記録を求めているのか、記録後の残高を読むだけなのかによって、必要な作業が異なります。

<span id="worked-2"></span>

### 例題2：複数の資産に関する月額を合計する

建物の当月見積額は18,000円、備品は7,000円、車両運搬具は12,000円です。三つとも当月分は未計上で、問題では減価償却累計額を一つの勘定で記録するものとします。

当月の費用は18,000＋7,000＋12,000＝37,000円です。借方「減価償却費37,000」、貸方「減価償却累計額37,000」とします。ここで集めたのは、各資産について見積もられた当月の費用です。取得原価の合計とは区別します。

内訳表には、どの資産にどれだけ対応するかを残します。建物の帳簿価額だけを問われたときに、累計額全体37,000円を建物から控除すると、備品と車両の分まで差し引くことになります。勘定が合計表示でも、資料にある資産との対応関係を維持して読みます。

<span id="objective-3"></span>

## 累計額の増加と当月費用を、対象期間で読み分ける

減価償却累計額は、過去からの計上額が蓄積された金額です。当月の減価償却費は、当月だけの費用です。累計額が90,000円であっても、その90,000円すべてを当月の費用とするとは限りません。月初の累計額、当月の計上額、月末の累計額を順に並べると区別できます。

資産の取得や売却などがなく、減価償却累計額の動きが当月の減価償却だけであれば、「月末累計額−月初累計額」で当月の計上額を求められます。この条件が外れる場合にまで、同じ引き算を機械的に使わないでください。初級では、まず問題の範囲と変動の原因を確認します。

<span id="worked-3"></span>

### 例題3：三か月の費用と帳簿価額を分けて求める

備品の取得原価は480,000円、4月初めの減価償却累計額は48,000円です。4月から6月まで、毎月8,000円を計上します。ほかに備品と累計額の変動はありません。

三か月分の減価償却費は8,000×3＝24,000円です。6月末の累計額は48,000＋24,000＝72,000円、帳簿価額は480,000−72,000＝408,000円です。6月だけの費用を問われたら8,000円、4〜6月の費用なら24,000円、6月末の累計額なら72,000円と、答えが変わります。

| 時点・期間 | 減価償却累計額 | その月の減価償却費 | 帳簿価額 |
| --- | ---: | ---: | ---: |
| 4月初め | 48,000円 | 対象外 | 432,000円 |
| 4月末 | 56,000円 | 8,000円 | 424,000円 |
| 5月末 | 64,000円 | 8,000円 | 416,000円 |
| 6月末 | 72,000円 | 8,000円 | 408,000円 |

6月末の帳簿価額に72,000円を足すと、取得原価480,000円に戻ります。また、4月初めの帳簿価額432,000円と6月末の408,000円の差は24,000円で、三か月分の費用と一致します。期間をまたぐ問題では、この二通りの検算が役立ちます。

<span id="worked-4"></span>

### 例題4：未計上の減価償却費を反映して損益を読む

当月の収益合計は260,000円、減価償却費を除く費用合計は212,000円です。当月の見積減価償却費9,000円は未計上で、ほかに未処理の費用はありません。

反映前の差額は260,000−212,000＝48,000円です。ここへ費用9,000円を追加するので、反映後の費用合計は221,000円、利益は260,000−221,000＝39,000円になります。累計額も9,000円増えます。一つの仕訳を損益と資産の両方から見ているため、費用として引くのは一回の9,000円です。

減価償却の仕訳だけでは、当月の現金残高は変わりません。したがって「利益が9,000円減ったので現金も9,000円減る」とは言えません。現金残高は入金・出金の取引から、利益は収益・費用から、それぞれ計算します。減価償却は、この違いを確かめるよい例です。

## 間違えたときは、金額・勘定・期間を分けて調べる

当月の見積額が正しいか、減価償却費と累計額の左右が正しいか、対象期間が正しいかを別々に確認します。合計が合っていても、借方「備品」、貸方「現金」としてしまえば購入仕訳です。月次の減価償却をしたことにはなりません。

また、累計額が付いている資産の取得原価から、累計額を引いた残りに毎月の率を掛け直すとは限りません。この課の計算は、指示された見積額をそのまま用います。問題にない計算方法を加えると、正しい資料を使っているのに異なる答えになります。

費用の金額を問う問題では、「当月」「三か月合計」「現在までの累計」の語句に印を付けてください。帳簿価額を問う問題では、どの資産の原価と累計額を対応させるかを確認します。これは、複数資産を一つの累計額勘定で集計している場合にも必要です。

## 月初の残りから、月末の残りへたどる

ある備品の月初帳簿価額が150,000円、当月の見積額が5,000円で、取得・売却などの変動がなければ、月末帳簿価額は145,000円です。取得原価と累計額の両方が資料にない場合でも、月初の残りから当月費用を差し引くことで求められます。ただし、月初帳簿価額150,000円を取得原価と読み替えてはいけません。過去の減価償却がすでに反映された金額だからです。

月初累計額がいくらか分からなくても、当月の累計額増加は5,000円と判断できます。反対に、取得原価が示されなければ、月末累計額そのものは確定できません。問われている額と、分かっている額を区別すると、必要以上の推測をせずに解けます。

減価償却による帳簿価額は、帳簿上の費用配分に基づく残額です。実際に売却する場合の価格とは区別します。この課では売却相場を推定せず、取得原価と指示された見積額・累計額の関係だけを使います。帳簿の残りと市場での売値を混ぜないようにしましょう。

費用資料の集計期間も確認してください。例えば、ある集計期間の月初までに減価償却費20,000円が記録済みで、当月分5,000円を追加するなら、集計期間全体の費用残高は25,000円です。しかし、当月分だけを問われた答えは5,000円になります。費用勘定の残高が、そのまま一か月分の費用とは限らないという点を、問題の表示期間に合わせて読みます。

同様に、月末累計額が25,000円でも、月初累計額が示されなければ当月費用を一意に求められない場合があります。分かる額を整理し、足りない情報を根拠なく補わないことも、残高問題の確認手順です。

## 自分で解く：仕訳から月次集計まで

1. 当月分の減価償却費4,500円が未計上です。間接法で仕訳してください。
2. 備品取得原価360,000円、月初累計額54,000円、当月見積額6,000円です。当月分計上後の累計額と帳簿価額を求めてください。
3. 月初累計額80,000円、月末累計額95,000円です。変動原因は当月の減価償却だけです。当月の費用を求めてください。
4. 減価償却費計上前の利益が28,000円で、当月の見積額が7,000円です。反映後の利益と、この仕訳による現金増減額を求めてください。

1は借方「減価償却費4,500」、貸方「減価償却累計額4,500」です。2は累計額60,000円、帳簿価額300,000円です。3は95,000−80,000＝15,000円です。4は利益21,000円、現金増減0円です。3で月末累計額95,000円をそのまま費用とした場合は、月初までの費用を当月にもう一度含めています。

自分の解答には、計算式だけでなく「当月分を一回追加」「取得原価は変わらない」など、誤りを避ける理由も書いてください。理由を残すと、似た金額の問題で条件が変わっても、暗記した答えに引っ張られにくくなります。
