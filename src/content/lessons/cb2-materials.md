材料を買った金額を、そのまま当月の製品原価へ入れると、使わずに残った材料まで製品へ負担させてしまいます。材料の計算では、まず何kgが使える状態にあり、そのうち何kgを使い、何kgが残ったかを追います。数量のつながりを作ってから単価を掛けると、購入と消費を落ち着いて区別できます。

<span id="objective-1"></span>

## 月初と受入れを合わせ、払出しと月末へ分ける

材料の種類ごとに、月初数量に当月受入数量を足したものが当月利用できる数量です。これが当月の払出数量と月末数量に分かれます。紛失や他の増減がない条件なら、「月初数量＋受入数量＝払出数量＋月末数量」という関係になります。

製造への払出しがそのまま消費を表す問題では、消費量は月初数量＋受入数量−月末数量で求められます。逆に払出数量が分かれば、月末数量を差額で求められます。式の形を暗記するだけでなく、入ってきた分と残った分を数量の表へ置いて考えましょう。

材料元帳は、材料の種類ごとに受入れ、払出し、残高を記録する帳簿です。材料Aと材料Bでは数量の単位や単価が違うことがあるため、それぞれの残高を追います。木材の板10枚と鋼材20kgの数量を足して「30」とは集計できません。金額に換算すれば合計できますが、その前の数量計算は種類ごとに行います。

材料を製造現場へ渡す際の記録があれば、何の製品のために使ったかを確認できます。問題文では払出しと実際の消費が一致するのか、未使用で戻した材料があるのかも見てください。月末に工場内へ運んだだけで未使用の材料があるときは、その扱いの条件を読む必要があります。このレッスンの各例では、特に断りのない払出しは消費として扱います。

<span id="worked-1"></span>

### 例題1：材料元帳の空欄を数量で埋める

同じ材料について、月初40kg、当月受入180kg、製品Aへの払出90kg、製品Bへの払出70kgという記録があります。他の増減はありません。月末数量と当月消費量を求めます。

使える数量は40＋180＝220kgです。払出合計は90＋70＝160kgなので、月末数量は220−160＝60kgとなります。220kgが消費160kgと残高60kgへ分かれたと説明できます。受入180kgを消費量と取り違えると、20kg多く計算してしまいます。

| 区分 | 数量 |
| --- | ---: |
| 月初 | 40kg |
| 当月受入 | 180kg |
| 利用可能合計 | 220kg |
| Aへ払出し | 90kg |
| Bへ払出し | 70kg |
| 月末 | 60kg |

倉庫で実際に数えた月末数量も60kgなら、記録上の数量と一致します。仮に現物が55kgなら、差の5kgの原因を追加確認する必要があります。問題が減耗や紛失の条件を示していないのに、差額を勝手に製品Aだけの消費へは足せません。数量記録がつながるかという確認が、金額計算より先です。

## 指定された消費単価で金額へ換算する

消費単価が1kg当たり500円なら、160kgの消費額は160×500＝80,000円です。単価の分母は1kgなので、kgを掛けることで円が求められます。材料が「1袋10kg、1袋5,000円」と示される場合には、1kg当たりは5,000÷10＝500円です。袋の数とkg数を混ぜないように、単位を式へ書きます。

材料単価がすべて同じなら、数量のつながりをそのまま金額にも使えます。月初額＋当月受入額−月末額＝当月消費額です。ただし、材料の購入価格が途中で変わると、使った分へ付ける単価の指定が必要です。このコースでは問題が示す条件を用い、価格の違う材料へ理由なく最後の購入単価を当てはめません。

平均単価を使うように指示された場合は、利用できる材料の総額を総数量で割ります。各購入単価を単純に足して件数で割るのは、購入量が違う場合には正しくありません。数量の多い購入分が、総額と総数量の中でその量に応じて反映される仕組みを式で確かめます。これは条件付きの基礎計算であり、上位の原価計算方式を別に持ち込む必要はありません。

<span id="worked-2"></span>

### 例題2：価格が違う材料を指定の平均単価で評価する

同じ材料が月初に20kg、単価400円で残っています。当月は80kgを単価500円で受け入れました。当月の消費量は70kgです。この問題では、利用できる全数量の金額を平均した単価を、消費分と月末分の両方に用いるものとします。

利用可能数量は20＋80＝100kg、総額は20×400＋80×500＝48,000円です。平均単価は48,000÷100＝480円/kgとなります。400円と500円を単純平均した450円では、20kgと80kgという量の違いが無視されます。

消費額は70×480＝33,600円です。月末数量は100−70＝30kg、月末額は30×480＝14,400円です。33,600＋14,400＝48,000円となり、利用可能な総額と一致します。計算を終えたら、数量70＋30＝100kgと金額33,600＋14,400＝48,000円の両方を確かめてください。

### 材料を返したときは、その向きを読む

購入した材料の一部を仕入先へ返すと、倉庫へ受け入れた材料が外へ出るため、正味の受入数量が減ります。製造へ払い出した材料の未使用分を倉庫へ戻すと、製造での正味の消費量が減ります。同じ「返品・返却」でも、相手が仕入先か製造現場かで数量表の置き方が違います。

月初10kg、購入50kg、仕入先へ返品5kg、月末15kgなら、利用可能量は10＋50−5＝55kg、消費量は55−15＝40kgです。別の例で、製造へ45kg払い出して5kg戻したなら、正味消費量は45−5＝40kgです。どちらも40kgになりますが、途中の事実は異なります。記録の向きを言葉で説明してから足し引きを決めます。

## 製品別の消費記録を直課し、共通分を分けておく

材料費の総額が求まった後は、どの製品へ集計するかを確認します。製品別に使用量が記録されている主材料は、その消費額を各製品へ直課できます。全製品に共通して使い、製品別には直接把握しない補助材料は、間接材料費として別に集計し、後で指定基準により配賦します。

材料の受入れから月末までの表と、製品別の消費額の表はつながります。消費総額のうち一部をAへ、別の一部をBへ、残りを共通分へ集計するので、それらの合計は材料消費総額へ戻るはずです。材料費総額を製品ごとへそのまま記入して二重に計上しないよう、集計先を一つずつ決めます。

<span id="worked-3"></span>

### 例題3：二種類の材料から直接・間接を集計する

主材料の月初は30kg、当月受入は170kg、月末は40kg、単価はすべて600円/kgです。消費160kgの内訳はA用90kg、B用70kgと記録されています。別の共通補助材料は月初5,000円、当月受入12,000円、月末3,000円です。補助材料は全額を間接材料費とし、他の増減はありません。

主材料の消費額は160×600＝96,000円です。Aへ90×600＝54,000円、Bへ70×600＝42,000円を直課します。補助材料の消費額は5,000＋12,000−3,000＝14,000円で、製造間接費の材料分として集めます。

材料消費総額は54,000＋42,000＋14,000＝110,000円です。主材料の月末24,000円と補助材料の月末3,000円は未消費なので、この110,000円へ加えません。材料全体の利用可能額137,000円が、消費110,000円と月末27,000円に分かれることも確認できます。


### 不明なのが購入量のときも、同じ関係式を使う

月初、受入れ、消費、月末の四つの関係を理解すると、どこが空欄でも逆に求められます。式を新しく覚えるより、「入ってきた総量と行き先の総量が等しい」と考えてください。特に購入量を問う問題では、消費量と月末残高の合計から、月初にすでにあった分を引きます。

<span id="worked-4"></span>

### 例題4：必要な受入量と返品の影響を逆算する

材料が月初に35kgあり、当月はAへ90kg、Bへ65kgを消費し、月末には25kgを残しました。紛失や返品はありません。当月の受入数量は、消費155kg＋月末25kg−月初35kg＝145kgです。月初35kg＋受入145kg＝消費155kg＋月末25kg＝180kgで一致します。

今度は、当月購入分のうち仕入先への返品が10kgあったとします。他の条件が同じなら、正味受入145kgを確保するため、返品前に購入した数量は145＋10＝155kgです。受入と返品を合わせた145kgを「返品前の購入量」と答えないようにします。155kg買い、10kg戻し、正味145kgが加わったという順で読みます。

単価がすべて500円/kgなら、月初17,500円、返品前購入77,500円、返品5,000円、消費77,500円、月末12,500円です。17,500＋77,500−5,000＝90,000円が、77,500＋12,500＝90,000円に分かれます。購入額と消費額がこの例では偶然どちらも77,500円ですが、計算の意味は別です。同額になったことを理由に、購入額を常に消費額とみなさないようにします。

### 数字を表へ写す前に条件を短くメモする

材料の問題では「月末残高は帳簿額」「単価はすべて同じ」「払出しはそのまま製造で消費」「返品以外の増減なし」などが計算を決めます。条件が付いた単価や数量を省略すると、後からどの数字を使ったか追えなくなります。最初は計算用紙に「kg」「円/kg」「A用」「共通」と書き添えてください。途中式を丁寧に残すことは、理解のためだけでなく、答えの単位や集計先を確認する手段にもなります。


### 受入れの時点と、支払いの時点を読み分ける

月末までに倉庫へ届いて受け入れた材料が、代金の支払いだけ翌月という条件なら、その数量は当月の受入記録へ含めます。逆に、来月届く材料の予約代を当月払っただけでは、当月の倉庫にその材料が増えたとは限りません。数量表の受入れを現金の動きだけから作らないようにしてください。

たとえば、当月受入済みの材料が100kg、来月受入予定が20kgで、予定分の代金も当月払いという資料なら、当月の受入数量は100kgです。120kgへ足すと、まだない材料を当月使えることにしてしまいます。資料が「当月購入」とだけ書くときは、各設問の受入条件に従います。このコースの例では数量の関係を明確にするため、受入れと他の増減の有無を示しています。

## 数量の式から、自分で金額へ進む

案内付きで練習します。1袋8kgの材料を月初2袋、当月に10袋を受け入れ、月末3袋残っています。1袋2,400円で価格差はありません。使ったのは2＋10−3＝9袋、重さは9×8＝72kg、消費額は9×2,400＝21,600円です。1kg当たり300円に直して72×300と計算しても同じです。袋数9へkg単価300円を直接掛けると、単位が一致しません。

次は自力で解きましょう。月初材料25kg、当月受入125kg、月末30kg、すべて単価400円/kgです。製品Aへ80kg、Bへ40kgを消費しました。他に共通の補助材料を6,000円分消費しています。主材料消費量、A・Bの直接材料費、間接材料費、材料消費総額、主材料月末額を求めてください。

主材料消費量は25＋125−30＝120kg、A32,000円、B16,000円です。間接材料費6,000円を加えた消費総額は54,000円、主材料月末額は30×400＝12,000円です。主材料だけなら、月初10,000円＋受入50,000円＝消費48,000円＋月末12,000円と一致します。補助材料の消費6,000円は、この主材料数量表へ混ぜず、金額段階で合計します。
