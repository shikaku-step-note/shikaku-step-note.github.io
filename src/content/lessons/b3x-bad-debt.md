売掛金は将来お金を受け取る権利ですが、すべてを予定どおり回収できるとは限りません。簿記では、実際に回収不能になった債権を消す処理と、まだ残っている債権の将来の貸倒れを見積もる処理を分けます。どちらも「貸倒」という言葉が出てくるため、今起きた事実か、期末の見積りかを先に区別しましょう。

<span id="objective-1"></span>

## 貸倒引当金は、現金を別口座へ積み立てた額ではない

貸倒引当金は、売掛金などの回収見込みを示すための控除額です。期末に引当金を追加しても、それだけで現金や預金が増減するわけではありません。貸借対照表では対象債権から差し引いて表示し、損益ではその期に必要な繰入れ等を扱います。

実際に貸倒れたとき、前期以前に発生した債権に対応する引当金があれば、それを使って債権を減らします。不足分は貸倒損失です。当期の取引によって発生した売掛金が当期中に貸倒れた場合は、通常、その額を当期の貸倒損失とします。問題で発生年度や引当対象が示されていれば、その条件を確認してください。

<span id="worked-1"></span>

### 例題1：引当金で足りる場合と、不足する場合

前期以前の売掛金12,000円が回収不能となりました。使える貸倒引当金残高が15,000円あれば、貸倒引当金12,000／売掛金12,000とします。債権は消え、引当金は3,000円残ります。この時点で貸倒損失12,000円を追加する必要はありません。

同じ債権12,000円に対して引当金が7,000円しかなければ、借方に貸倒引当金7,000円と貸倒損失5,000円、貸方に売掛金12,000円を記録します。消す債権は12,000円、過去の見積りで賄える部分7,000円、新たな損失5,000円という内訳です。

| 利用できる引当金 | 借方：引当金の使用 | 借方：当期損失 | 貸方：債権消去 |
| --- | ---: | ---: | ---: |
| 15,000円 | 12,000 | 0 | 12,000 |
| 7,000円 | 7,000 | 5,000 | 12,000 |

もしその売掛金が当期の販売から生じ、当期中に貸倒れた条件なら、貸倒損失12,000／売掛金12,000です。貸倒引当金という科目が試算表にあるから必ず使う、と決めつけません。どの債権のために設定されたものかを読みます。

<span id="objective-2"></span>

## 期末は、必要な残高と追加する額を分ける

期末に残った債権へ指定の率を掛けて、必要な貸倒引当金残高を求めます。すでに引当金が残っているなら、その差だけを追加するのが差額補充法です。問題で実績率や対象債権が与えられる場合、率を独自に変えたり、対象にない資産へ広げたりしません。

<span id="worked-2"></span>

### 例題2：対象残高を修正してから率を掛ける

整理前の売掛金は300,000円、受取手形は100,000円、貸倒引当金は貸方9,000円です。売掛金20,000円の回収が未記帳で、前期以前に発生した売掛金4,000円が貸倒れ、これも未処理でした。期末には売掛金と受取手形の合計に3%の引当金を設定します。

まず回収は普通預金20,000／売掛金20,000、貸倒れは貸倒引当金4,000／売掛金4,000です。修正後売掛金は300,000−20,000−4,000＝276,000円、受取手形は100,000円です。対象債権は376,000円なので必要引当金は376,000×3%＝11,280円です。

一方、引当金の整理前残高も貸倒れへ使用した分を引き、9,000−4,000＝5,000円に変わっています。追加額は11,280−5,000＝6,280円です。借方「貸倒引当金繰入6,280」、貸方「貸倒引当金6,280」と記録すれば、最終残高が11,280円になります。

| 確認する数字 | 計算 | 結果 |
| --- | --- | ---: |
| 修正後売掛金 | 300,000−20,000−4,000 | 276,000円 |
| 見積り対象 | 276,000＋100,000 | 376,000円 |
| 必要引当金 | 376,000×0.03 | 11,280円 |
| 追加前の引当金 | 9,000−4,000 | 5,000円 |
| 当期の繰入額 | 11,280−5,000 | 6,280円 |

最初の300,000円へ率を掛けたり、引当金を元の9,000円のまま差し引いたりすると、両方の修正を無視します。仕訳で動いた科目を一覧へ反映してから、最後の見積りへ進みましょう。

### 案内に沿って解く：既存残高のほうが大きい

修正後の対象債権は240,000円、必要率は2%、引当金は貸方6,100円残っています。必要残高は4,800円で、現在は1,300円多い状態です。借方貸倒引当金1,300／貸方貸倒引当金戻入1,300として減らします。繰入額をマイナスで書くのではなく、科目と方向を選びます。

問題が戻入れの科目や表示方法を指定した場合は、その指定を使います。減らす額1,300円と残す額4,800円を区別し、6,100−1,300＝4,800円へ戻ることを確認してください。

<span id="objective-3"></span>

## 後日回収は、すでに消した債権を再度減らさない

貸倒処理が済むと、その売掛金は帳簿から消えています。前期以前に貸倒処理した債権を後日回収した場合は、現預金の増加に対応して償却債権取立益を計上します。まだ残っている普通の売掛金回収とは異なります。

<span id="worked-3"></span>

### 例題3：前期に貸倒処理した額の一部を回収する

前期に貸倒処理した売掛金18,000円について、当期に6,000円が普通預金へ入りました。当期に債権を復活させる別の処理はしていません。仕訳は普通預金6,000／償却債権取立益6,000です。元の販売を再び行ったわけではないので、貸方を売上にしません。

未回収の12,000円を、回収時にもう一度貸倒損失へ計上する必要もありません。前期に18,000円全額をすでに処理しています。今回の事実は、そのうち6,000円を取り戻したことです。処理の時点を分けると、同じ損失を二回計上しないで済みます。

同じ当期中に発生・貸倒処理した債権の回収を問う条件なら、当期の貸倒損失を取り消す場合があります。どの期に貸倒処理したのかを必ず読み、過年度の償却債権回収と一律に扱わないようにします。

<span id="worked-4"></span>

### 例題4：損益と貸借対照表を同時に点検する

決算後の売掛金が180,000円、受取手形が70,000円、貸倒引当金が5,000円とします。対象債権総額は250,000円、引当金を引いた正味額は245,000円です。貸倒引当金5,000円を債務として負債に足すのではなく、関連する資産から控除する関係を示します。

当期繰入額が2,000円なら、損益へ反映する繰入費用は2,000円です。期末残高5,000円をそのまま当期費用としてもう一度計上しません。必要残高、当期繰入額、実際に使った引当金という数字の役割を分けます。前期の見積り残高が残っているため、引当金残高と当期費用は通常同額とは限りません。


## 債権の減少と、引当金の減少を別々に追う

売掛金が減った事実がすべて引当金の使用になるわけではありません。回収・売上返品・電子記録への変更・実際の貸倒れは、同じ売掛金の貸方でも相手科目が違います。引当金の期末残高を計算する前に、どの取引が引当金へ影響したかを印で区別します。

<span id="worked-5"></span>

### 例題5：複数の債権変動を一つの見積りへつなげる

整理前の売掛金は500,000円、電子記録債権は120,000円、引当金は貸方14,000円です。追加資料は、売掛金の回収40,000円、売上返品10,000円、前期以前の売掛金8,000円の貸倒れ、当期発生売掛金5,000円の貸倒れで、すべて未処理です。期末には修正後の売掛金と電子記録債権へ2%を設定します。

売掛金は500,000−40,000−10,000−8,000−5,000＝437,000円です。電子記録債権120,000円を加えた対象は557,000円、必要引当金は11,140円です。一方、引当金を使うのは前期以前の貸倒れ8,000円だけなので、既存残高は14,000−8,000＝6,000円です。追加繰入は11,140−6,000＝5,140円となります。

| 売掛金が減る理由 | 売掛金の減少 | 引当金の使用 |
| --- | ---: | ---: |
| 代金の回収 | 40,000円 | 0円 |
| 売上返品 | 10,000円 | 0円 |
| 前期以前の貸倒れ | 8,000円 | 8,000円 |
| 当期発生分の貸倒れ | 5,000円 | 0円 |

当期の貸倒損失5,000円と期末繰入費用5,140円は別の費用です。前期以前の貸倒れ8,000円は、設定済み引当金を使ったので、この条件ではさらに当期損失にはしません。債権の減少合計63,000円を、そのまま当期損失63,000円としないようにしてください。

見積りの対象に電子記録債権を含めるかどうかも、設問の条件によります。単に債権という名前があるから貸付金や未収利息をすべて加えるのではなく、指定された対象を列挙します。今回の2%という率は独自例の条件であり、実際の会社の適正な貸倒率や税務上の率を示すものではありません。

独立演習では、最初の整理前数字、債権の修正、引当金の修正、必要残高、差額仕訳という五段階を書いてみましょう。最終額が違う場合も、どの段階で条件を読み落としたかを特定できます。


## 自力で貸倒れと見積りを連続処理する

整理前の売掛金220,000円、電子記録債権80,000円、貸倒引当金貸方7,000円です。売掛金のうち当期発生分5,000円が貸倒れ、別の売掛金15,000円は預金へ回収済みで、どちらも未記帳でした。期末には修正後の売掛金と電子記録債権の合計に2%の引当金を設定します。

貸倒れは貸倒損失5,000／売掛金5,000、回収は普通預金15,000／売掛金15,000です。売掛金は200,000円、対象合計280,000円、必要引当金5,600円です。今回は当期発生分を損失で処理したので引当金7,000円は減っておらず、1,400円戻し入れます。貸倒引当金1,400／貸倒引当金戻入1,400とすれば、残高5,600円になります。

債権の種類や発生年度を見ずに、貸倒れを引当金から一律控除しないことがこの問題の要点です。解答後は、期末債権280,000円と控除額5,600円、当期貸倒損失5,000円と戻入1,400円を、それぞれの表示先へ分けて説明してください。

仕訳の名前から判断しにくいときは、貸倒引当金勘定だけを取り出して、貸方の期首残高と追加額、借方の使用額・戻入額を記入してください。最終貸方残高が対象債権に指定率を掛けた額になれば、引当金の増減を照合できます。債権勘定の減少とは別々に検算します。
