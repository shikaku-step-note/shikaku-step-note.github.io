店に現金が増えても、売上が増えたとは限りません。反対に、まだ入金されていなくても売上を記録する場合があります。この章では、開業した修理店の一か月を例に、出来事が起きた日から月末の数字まで追います。消費税は考えません。修理に使った費用は資料にある金額だけとします。

## 資料から記録する日を選ぶ

| 日付 | 出来事 |
| --- | --- |
| 1日 | 店主が開業資金として現金80,000円を出した |
| 2日 | 銀行から30,000円を借り、普通預金口座に入った |
| 4日 | 修理を25,000円で行う約束をした。まだ作業も入金もない |
| 9日 | 修理を終え、5,000円を現金で受け取り、残りは掛けとした |
| 15日 | 当月の店の家賃12,000円を普通預金から払った |
| 22日 | 借入元金6,000円と当月の利息300円を普通預金から払った |
| 28日 | 修理代の一部8,000円を普通預金で受け取った |

4日にはまだ、修理をしたことで代金を受け取る権利が生じていません。この例では、修理が終わった9日に売上を記録します。金額が書かれた資料でも、見積り、作業完了、入金では意味が異なります。「約束した日」「仕事が終わった日」「入金日」をまず分けてください。

## 科目を選び、左右を決める

ここでは修理代を「売上」で記録します。各行で最初に、資産・負債・純資産・収益・費用の何が変わるかを考えます。

| 日付 | 借方 | 貸方 | 判断の根拠 |
| --- | --- | --- | --- |
| 1日 | 現金80,000 | 資本金80,000 | 資産の増加と、店主が出した元手 |
| 2日 | 普通預金30,000 | 借入金30,000 | 資産は増えるが返済義務も増える |
| 9日 | 現金5,000、売掛金20,000 | 売上25,000 | 仕事は全額分完了し、受け取り方だけが二つに分かれる |
| 15日 | 支払家賃12,000 | 普通預金12,000 | 当月の費用が生じ、預金が減る |
| 22日 | 借入金6,000、支払利息300 | 普通預金6,300 | 元金の返済は負債の減少。利息は費用 |
| 28日 | 普通預金8,000 | 売掛金8,000 | 受け取る権利を預金へ振り替える |

9日は左側が5,000＋20,000＝25,000円。22日は6,000＋300＝6,300円です。左右を合わせた後で、使った科目とその金額を出来事に戻って確認します。例えば28日に「普通預金8,000／売上8,000」と書いても左右は合いますが、売上を二度記録し、売掛金を減らし忘れます。

## 二つの表を組み立てて検算する

貸借対照表は、月末という一時点の財産とその調達の内訳を表します。現金は85,000円、普通預金は30,000−12,000−6,300＋8,000＝19,700円、売掛金は20,000−8,000＝12,000円です。資産は計116,700円。負債は借入金24,000円なので、純資産は116,700−24,000＝92,700円です。

損益計算書は、ひと月の収益・費用と利益を表します。売上25,000円から支払家賃12,000円と支払利息300円を引くと、利益は12,700円です。純資産92,700円から店主が出した元手80,000円を引いても12,700円になります。今回は開業月で月初純資産が0円、追加の出資はなく、引出しもありません。別の月にこの方法を使うなら、月初純資産と期間中の出資・引出しを確認します。

### 貸借対照表と損益計算書に並べる

| 月末の貸借対照表（円） | 金額 |
| --- | ---: |
| 資産：現金・普通預金・売掛金 | 116,700 |
| 負債：借入金 | 24,000 |
| 純資産：資本金80,000円と当月利益12,700円 | 92,700 |
| 負債と純資産の合計 | 116,700 |

| 当月の損益計算書（円） | 金額 |
| --- | ---: |
| 収益：売上 | 25,000 |
| 費用：支払家賃と支払利息 | 12,300 |
| 当月利益 | 12,700 |

貸借対照表では、資産の合計が負債と純資産の合計に一致するかを見ます。損益計算書では、収益から費用を引きます。表の対象は同じ店ですが、一方は月末時点、もう一方は月初から月末までの集計です。

手元の現金と預金の合計104,700円は利益ではありません。出資や借入れでお金が増え、元金の返済でお金が減ります。一方、月末時点でまだ受け取っていない12,000円は売掛金として残っています。

## 条件を変えて解く

28日の回収が翌月1日になったとします。月末の普通預金、売掛金、資産合計、当月利益はそれぞれどうなりますか。変わる項目と変わらない項目を予想してから答えを開きます。

<details><summary>仕訳と集計を確かめる</summary><p>28日の振替を当月には記録しないので、普通預金は19,700−8,000＝11,700円、売掛金は12,000＋8,000＝20,000円です。現金85,000円は変わりません。資産は85,000＋11,700＋20,000＝116,700円で同じです。9日の売上は変わらないため、当月利益も12,700円のままです。</p></details>

## 別の店の資料で自分で解く

店主が現金60,000円を出しました。別の日に、作業を終えて代金18,000円のうち3,000円を現金で受け取り、残額は掛けとしました。その月の電気代4,000円を現金で支払い、ほかの取引はありません。月末の現金、売掛金、資産合計と利益を求め、元手と利益から資産の合計を検算してください。

<details><summary>途中計算と答えを見る</summary><p>現金は60,000＋3,000−4,000＝59,000円、売掛金は18,000−3,000＝15,000円です。資産は計74,000円。利益は売上18,000−水道光熱費4,000＝14,000円です。負債がないので、資本金60,000円と利益14,000円の合計74,000円が資産合計と一致します。</p></details>

## 取引を漏らしても左右が合うことがある

22日の支払い全体を記録し忘れると、帳簿上の普通預金は6,300円多く、借入金は6,000円多く、支払利息は300円少なくなります。それでも左右の合計には差が出ません。貸借の一致は金額を確かめる一つの手段です。漏れや重複を探すには、取引の日付と証ひょうを仕訳に突き合わせます。

## 開業後の店では、月初残高と元手の動きも見る

前の設例は開業月だったので、月初の純資産は0円でした。すでに営業している店には前月から繰り越した財産と借金があります。また、月の途中で店主が元手を足したり、個人のために店から資金を引き出したりすることもあります。利益を求めるときは、商売による変化と店主との資金のやり取りを分けます。

小さな修理店の月初は、現金40,000円、普通預金60,000円、売掛金20,000円、借入金35,000円です。資産の合計は120,000円。返す義務35,000円を引くと、月初の純資産は85,000円です。以下はすべて円で、この設例では消費税を考えません。

| 日 | 資料 | 当月に何が変わったか |
| --- | --- | --- |
| 2日 | 店主が個人の資金15,000を店の普通預金へ入れた | 店の預金と元手が増えた |
| 4日 | 来月に機器を借りる契約を結んだ。引渡しも支払いもない | この条件では当日の記録を起こさない |
| 8日 | 修理を終えた。代金42,000のうち現金7,000を受け、残りは掛け | 現金と受取る権利が増え、売上が発生した |
| 13日 | 前月の売掛金11,000が普通預金に入った | 売掛金が預金に移った |
| 17日 | 当月の電気代9,000を現金払い | 現金が減り、当月の費用が発生した |
| 22日 | 普通預金から借入元金8,000と利息1,000を払った | 借入金が減り、利息だけが費用になった |
| 25日 | 店主が生活費として店の現金4,000を持ち出した | 店の現金と元手側の持分が減った |

この設例では店主による持出しを資本金勘定の減少で処理します。試験問題で処理方法や使用科目が指定されているときは、その指定に従います。

### 一件ずつ仕訳し、現金と利益を別に追う

| 日 | 借方 | 貸方 |
| --- | --- | --- |
| 2日 | 普通預金 15,000 | 資本金 15,000 |
| 4日 | 仕訳なし | 仕訳なし |
| 8日 | 現金 7,000、売掛金 35,000 | 売上 42,000 |
| 13日 | 普通預金 11,000 | 売掛金 11,000 |
| 17日 | 水道光熱費 9,000 | 現金 9,000 |
| 22日 | 借入金 8,000、支払利息 1,000 | 普通預金 9,000 |
| 25日 | 資本金 4,000 | 現金 4,000 |

8日の修理で受け取った7,000円だけを売上とすると、後日受け取る35,000円分が消えてしまいます。修理全体を終えたので、当月の売上は42,000円です。13日に受け取ったのは前月の売上の代金です。受け取った日に同じ売上を足しません。

22日に預金から出た9,000円も、全額が費用とは限りません。借入元金8,000円を返すと返済義務が減ります。資金を借りた対価である利息1,000円だけを費用にします。25日の持出しは店主個人の生活費なので、店が修理業務のために負担した費用とは区別します。

### 月末残高から、利益を別の方法で確かめる

- 現金は40,000＋7,000−9,000−4,000＝34,000円。
- 普通預金は60,000＋15,000＋11,000−9,000＝77,000円。
- 売掛金は20,000＋35,000−11,000＝44,000円。
- 資産合計は34,000＋77,000＋44,000＝155,000円。負債は35,000−8,000＝27,000円。月末純資産は128,000円です。

収益と費用からは、42,000−9,000−1,000＝32,000円の利益です。月末純資産からも、128,000−85,000−15,000＋4,000＝32,000円と求められます。出資は純資産を増やすので差し引き、店主の持出しは純資産を減らすので足し戻します。手元資金は月初100,000円から月末111,000円になりました。手元資金の増加11,000円と当月利益32,000円は、異なる変化を測っています。

## 貸借が合う誤りを、元の資料から直す

13日の預金の入金を「普通預金11,000／売上11,000」とした場合、借方と貸方は同額です。どの金額が誤り、二つの表はどう変わるでしょうか。先に「銀行明細が示すこと」と「売掛金の記録が示すこと」を別々に考えてください。

<details>
<summary>誤りを見付ける手順と訂正後の数値</summary>
<p>普通預金は実際に増えたので借方は正しいです。前月の請求と照合すると、今回減ったのは既存の売掛金です。貸方を売上にすると、売掛金が11,000円多く残り、当月の収益と利益も11,000円多くなります。誤った帳簿では資産166,000円、純資産139,000円、利益43,000円となります。貸方を売掛金へ直すと、資産155,000円、純資産128,000円、利益32,000円に戻ります。</p>
<p>資産と負債・純資産の左右は、誤った帳簿でも合っています。二つの利益計算が同じ誤記を共有すれば、両方で43,000円になります。帳簿の数値同士を比べるだけでなく、入金の理由を請求記録に戻って確かめます。</p>
</details>

## 自分で解く：開業月と違う条件で損益を確かめる

別の店の月初は現金24,000円、普通預金35,000円、売掛金13,000円、借入金18,000円です。当月、店主が現金9,000円を追加出資し、修理代29,000円は全額掛けとしました。前月の売掛金のうち8,000円を普通預金で回収しました。当月の家賃11,000円を預金から支払い、借入元金6,000円と利息400円も預金から支払いました。店主の引出しはありません。仕訳し、月末純資産と当月利益を求めてください。入金8,000円を売上とした場合にも貸借が合うか考えます。

<details>
<summary>仕訳、月末残高、二通りの利益計算を見る</summary>
<p>借方／貸方の順に、現金9,000／資本金9,000、売掛金29,000／売上29,000、普通預金8,000／売掛金8,000、支払家賃11,000／普通預金11,000、借入金6,000と支払利息400／普通預金6,400です。</p>
<p>月末の現金33,000円、預金25,600円、売掛金34,000円で資産92,600円。借入金12,000円を引くと純資産80,600円です。月初純資産は24,000＋35,000＋13,000−18,000＝54,000円。利益は80,600−54,000−9,000＝17,600円で、29,000−11,000−400と一致します。入金を売上とすると貸借は合いますが、売掛金と利益がそれぞれ8,000円過大になります。</p>
</details>

## 次に進む前の確認

約束、仕事の完了、決済を区別します。収益・費用から利益を出した後、財産の増減から同じ利益になるかを調べます。次の章では、仕訳を勘定ごとの帳簿に移す手順を学びます。
