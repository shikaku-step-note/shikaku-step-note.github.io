店に現金が増えても、売上が増えたとは限りません。反対に、まだ入金されていなくても売上を記録する場合があります。この章では、開業した修理店の一か月を例に、出来事が起きた日から月末の数字まで追います。消費税は考えません。修理に使った費用は資料にある金額だけとします。

## 資料から記録する日を選ぶ

| 日付 | 出来事 |
| --- | --- |
| 1日 | 店主が開業資金として現金80,000円を出した |
| 2日 | 銀行から30,000円を借り、普通預金口座に入った |
| 4日 | 修理を25,000円で行う約束をした。まだ作業も入金もない |
| 9日 | 修理を終え、5,000円を現金で受け取り、残りは掛けとした |
| 15日 | 当月の店の家賃12,000円を普通預金から払った |
| 22日 | 借入元金6,000円と当月の利息300円を普通預金から払った |
| 28日 | 修理代の一部8,000円を普通預金で受け取った |

4日にはまだ、修理をしたことで代金を受け取る権利が生じていません。この例では、修理が終わった9日に売上を記録します。金額が書かれた資料でも、見積り、作業完了、入金では意味が異なります。「約束した日」「仕事が終わった日」「入金日」をまず分けてください。

## 科目を選び、左右を決める

ここでは修理代を「売上」で記録します。各行で最初に、資産・負債・純資産・収益・費用の何が変わるかを考えます。

| 日付 | 借方 | 貸方 | 判断の根拠 |
| --- | --- | --- | --- |
| 1日 | 現金80,000 | 資本金80,000 | 資産の増加と、店主が出した元手 |
| 2日 | 普通預金30,000 | 借入金30,000 | 資産は増えるが返済義務も増える |
| 9日 | 現金5,000、売掛金20,000 | 売上25,000 | 仕事は全額分完了し、受け取り方だけが二つに分かれる |
| 15日 | 支払家賃12,000 | 普通預金12,000 | 当月の費用が生じ、預金が減る |
| 22日 | 借入金6,000、支払利息300 | 普通預金6,300 | 元金の返済は負債の減少。利息は費用 |
| 28日 | 普通預金8,000 | 売掛金8,000 | 受け取る権利を預金へ振り替える |

9日は左側が5,000＋20,000＝25,000円。22日は6,000＋300＝6,300円です。左右を合わせた後で、使った科目とその金額を出来事に戻って確認します。例えば28日に「普通預金8,000／売上8,000」と書いても左右は合いますが、売上を二度記録し、売掛金を減らし忘れます。

## 二つの表を組み立てて検算する

貸借対照表は、月末という一時点の財産とその調達の内訳を表します。現金は85,000円、普通預金は30,000−12,000−6,300＋8,000＝19,700円、売掛金は20,000−8,000＝12,000円です。資産は計116,700円。負債は借入金24,000円なので、純資産は116,700−24,000＝92,700円です。

損益計算書は、ひと月の収益・費用と利益を表します。売上25,000円から支払家賃12,000円と支払利息300円を引くと、利益は12,700円です。純資産92,700円から店主が出した元手80,000円を引いても12,700円になります。今回は開業月で月初純資産が0円、追加の出資はなく、引出しもありません。別の月にこの方法を使うなら、月初純資産と期間中の出資・引出しを確認します。

### 貸借対照表と損益計算書に並べる

| 月末の貸借対照表（円） | 金額 |
| --- | ---: |
| 資産：現金・普通預金・売掛金 | 116,700 |
| 負債：借入金 | 24,000 |
| 純資産：資本金80,000円と当月利益12,700円 | 92,700 |
| 負債と純資産の合計 | 116,700 |

| 当月の損益計算書（円） | 金額 |
| --- | ---: |
| 収益：売上 | 25,000 |
| 費用：支払家賃と支払利息 | 12,300 |
| 当月利益 | 12,700 |

貸借対照表では、資産の合計が負債と純資産の合計に一致するかを見ます。損益計算書では、収益から費用を引きます。表の対象は同じ店ですが、一方は月末時点、もう一方は月初から月末までの集計です。

手元の現金と預金の合計104,700円は利益ではありません。出資や借入れでお金が増え、元金の返済でお金が減ります。一方、月末時点でまだ受け取っていない12,000円は売掛金として残っています。

## 条件を変えて解く

28日の回収が翌月1日になったとします。月末の普通預金、売掛金、資産合計、当月利益はそれぞれどうなりますか。変わる項目と変わらない項目を予想してから答えを開きます。

<details><summary>仕訳と集計を確かめる</summary><p>28日の振替を当月には記録しないので、普通預金は19,700−8,000＝11,700円、売掛金は12,000＋8,000＝20,000円です。現金85,000円は変わりません。資産は85,000＋11,700＋20,000＝116,700円で同じです。9日の売上は変わらないため、当月利益も12,700円のままです。</p></details>

## 別の店の資料で自分で解く

店主が現金60,000円を出しました。別の日に、作業を終えて代金18,000円のうち3,000円を現金で受け取り、残額は掛けとしました。その月の電気代4,000円を現金で支払い、ほかの取引はありません。月末の現金、売掛金、資産合計と利益を求め、元手と利益から資産の合計を検算してください。

<details><summary>途中計算と答えを見る</summary><p>現金は60,000＋3,000−4,000＝59,000円、売掛金は18,000−3,000＝15,000円です。資産は計74,000円。利益は売上18,000−水道光熱費4,000＝14,000円です。負債がないので、資本金60,000円と利益14,000円の合計74,000円が資産合計と一致します。</p></details>

## 取引を漏らしても左右が合うことがある

22日の支払い全体を記録し忘れると、帳簿上の普通預金は6,300円多く、借入金は6,000円多く、支払利息は300円少なくなります。それでも左右の合計には差が出ません。貸借の一致は金額を確かめる一つの手段です。漏れや重複を探すには、取引の日付と証ひょうを仕訳に突き合わせます。
