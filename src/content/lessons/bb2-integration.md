この演習では、一つの店の当月取引を最後まで追います。初めに自分で仕訳と残高を計算し、その後で解説と照合してください。答えの数値だけを写すより、どの取引でその残高が増減したかを説明することが大切です。途中で誤っても、原因の取引へ戻って直せるよう、計算の内訳を残します。

金額はすべて円です。消費税は考慮しません。月初・月末の商品残高はいずれも0円で、当月の正味仕入商品はすべて当月に販売されています。したがって、この演習では正味仕入高を当月の商品原価として使えます。ほかの在庫条件の問題に、この関係を無条件で当てはめないでください。年末の締切仕訳や決算整理は行いません。

## 月初残高と当月取引を分けて記録する

月初の残高は次のとおりです。減価償却累計額は備品に対応し、資産から控除する金額です。ほかの月初残高はありません。

| 月初の科目 | 借方残高 | 貸方残高 |
| --- | ---: | ---: |
| 現金 | 100,000 | 0 |
| 普通預金 | 200,000 | 0 |
| 売掛金 | 50,000 | 0 |
| 備品 | 120,000 | 0 |
| 減価償却累計額 | 0 | 24,000 |
| 買掛金 | 0 | 40,000 |
| 借入金 | 0 | 100,000 |
| 資本金 | 0 | 306,000 |
| 合計 | 470,000 | 470,000 |

当月の取引は次の15件です。返品は元の掛け取引の未決済部分について行われ、対応する売掛金・買掛金を減らします。減価償却費の当月見積額は6,000円で、取引13まで未計上です。

| 番号 | 当月の取引 |
| --- | --- |
| 1 | 商品30,000円を現金で仕入れた |
| 2 | 商品90,000円を掛けで仕入れた |
| 3 | 商品60,000円を現金で販売した |
| 4 | 商品140,000円を掛けで販売した |
| 5 | 取引4の商品10,000円分が返品された |
| 6 | 取引2の商品5,000円分を返品した |
| 7 | 売掛金100,000円を普通預金で回収した |
| 8 | 買掛金70,000円を普通預金から支払った |
| 9 | 従業員の当月給料30,000円を普通預金から支払った。控除はない |
| 10 | 当月家賃20,000円を現金で支払った |
| 11 | 事業主が40,000円を普通預金へ追加元入した |
| 12 | 事業主が現金10,000円を生活費として引き出した |
| 13 | 備品の当月分減価償却費6,000円を間接法で計上した |

### 例題1：返品・元入・返済の仕訳を確認する

商品関係の取引1〜4は、仕入・売上と現金または掛けの科目で記録します。取引5は借方「売上10,000」、貸方「売掛金10,000」です。取引6は借方「買掛金5,000」、貸方「仕入5,000」です。返品によって新しい売上や仕入を増やすのではなく、元の取引を減らします。

取引7は借方「普通預金100,000」、貸方「売掛金100,000」です。取引8は借方「買掛金70,000」、貸方「普通預金70,000」です。回収時の売上、支払い時の仕入を再度計上しないでください。取引9は借方「給料30,000」、貸方「普通預金30,000」、取引10は借方「支払家賃20,000」、貸方「現金20,000」です。

取引11は借方「普通預金40,000」、貸方「資本金40,000」、取引12は借方「資本金10,000」、貸方「現金10,000」です。取引13は借方「減価償却費6,000」、貸方「減価償却累計額6,000」です。取引14は借方「借入金20,000／支払利息1,000」、貸方「普通預金21,000」です。取引15は借方「水道光熱費4,000」、貸方「現金4,000」です。

取引14を支払利息21,000円とすると、元本まで費用に含み、借入金も減りません。複数の意味を持つ支払いは、合計額だけでなく内訳ごとに科目を選びます。元本と利息を分けた借方合計21,000円が、実際の預金支出と一致することを確かめます。

### 例題2：資産・負債の月末残高から試算表を作る

現金残高は100,000−30,000＋60,000−20,000−10,000−4,000＝96,000円です。普通預金は200,000＋100,000−70,000−30,000＋40,000−21,000＝219,000円です。現金と普通預金を混ぜず、どの支払い手段を使ったかで区別します。

売掛金は50,000＋140,000−10,000−100,000＝80,000円、買掛金は40,000＋90,000−5,000−70,000＝55,000円です。借入金は100,000−20,000＝80,000円、資本金は306,000＋40,000−10,000＝336,000円です。

備品は120,000円のまま、減価償却累計額は24,000＋6,000＝30,000円です。正味仕入は30,000＋90,000−5,000＝115,000円、正味売上は60,000＋140,000−10,000＝190,000円となります。

## 損益は収益と費用を集め、元入・引出を除く

当月の収益は、返品控除後の売上190,000円です。費用を集める前に、この演習は月初・月末商品が0円で、正味仕入商品がすべて販売済みという条件を再確認します。この条件により、商品原価115,000円を費用に含めます。

### 例題3：利益と資産・負債の関係を照合する

費用合計は商品原価115,000＋給料30,000＋家賃20,000＋減価償却費6,000＋支払利息1,000＋水道光熱費4,000＝176,000円です。利益は190,000−176,000＝14,000円です。追加元入40,000円は収益に、生活費10,000円と借入元本返済20,000円は費用に含めません。

月末の資産総額は、現金96,000＋預金219,000＋売掛金80,000＋備品120,000−累計額30,000＝485,000円です。負債総額は買掛金55,000＋借入金80,000＝135,000円です。その差350,000円は、資本金336,000円と当月利益14,000円の合計に一致します。ここでは利益を資本金へ振り替える仕訳を行わず、関係だけを確かめます。

月初の純資産は306,000円でした。追加元入40,000円、引出10,000円、利益14,000円を反映すると350,000円となります。また、現金の純増減は96,000−100,000＝マイナス4,000円です。利益が14,000円でも現金は4,000円減っており、二つは同じ数字になりません。

## 差額が出た箇所を直し、差額が出ない誤りも確認する

左右が合わない場合は、まず表の足し算、次に勘定ごとの差引き、最後に仕訳と転記の対応を追います。差額に合う取引を推測して加えると、別の誤りを作ることがあります。資料に戻り、何が漏れたか、どちら側に誤記したかを特定してください。

左右が一致している場合も、現金・預金の明細、相手先別の債権債務、購入や支払いの証ひょうと照合します。集計上の一致は、事実と科目の正確さをすべて保証しません。

### 例題4：家賃の記録漏れと、買掛金支払いの科目誤りを診断する

取引10の家賃支払い20,000円を両側とも記録し忘れた場合、現金は116,000円と20,000円多くなり、支払家賃は0円と20,000円少なくなります。借方の増減が相殺されるため、残高試算表の合計は左右691,000円のままです。しかし、利益は34,000円と20,000円過大になります。支払い証ひょうと現金残高の照合が必要です。

別の独立した誤りとして、取引8を借方「仕入70,000」、貸方「普通預金70,000」と記録した場合を考えます。正しい買掛金55,000円が125,000円と70,000円多く残り、仕入は185,000円と70,000円多くなります。この場合も左右は一致しますが、当月利益は14,000−70,000＝マイナス56,000円になってしまいます。

誤った記録を、正しい借方「買掛金70,000」へ直すには、借方「買掛金70,000」、貸方「仕入70,000」という修正で差を解消できます。この修正では預金を再び減らしません。すでに預金の支出は正しく記録されているためです。まず正しい仕訳と誤った仕訳を並べ、どの部分だけが違うかを確認します。

## 総合問題を自力で解くための確認順序

取引資料を読んだら、当月の範囲、消費税の有無、商品残高の条件、未計上の見積額を先に確認します。次に仕訳し、現金・預金・債権・債務などを勘定別に集計します。残高試算表を作って貸借を確認してから、設問で求められる利益や資産総額を計算します。

計算が遅いときは、金額を一つずつ頭で覚えず、取引番号を各勘定の明細へ添えます。売掛金には4・5・7、買掛金には2・6・8というように番号を残せば、漏れや重複を探しやすくなります。途中の数字を消し続けるより、訂正の理由が追える書き方を練習してください。

## 自分で解く：条件が変わったら、影響する項目だけを変える

上の正しい15取引の資料を基準に、次の変更をそれぞれ独立して考えます。

1. 取引7の回収額が100,000円ではなく90,000円だった場合、普通預金と売掛金の月末残高を求める。
2. 取引13の当月見積額が6,000円ではなく8,000円だった場合、累計額、帳簿価額、利益を求める。
3. 取引11の追加元入額だけが10,000円増えた場合、普通預金、資本金、利益の変化を答える。
4. 取引5の返品を両側とも記録し忘れた場合、売掛金、売上、利益へ生じる誤差を答える。

1は預金209,000円、売掛金90,000円です。回収が少ない分が債権として残るため、資産総額は変わりません。2は累計額32,000円、備品帳簿価額88,000円、利益12,000円です。3は預金と資本金が各10,000円増え、利益は14,000円のままです。4は売掛金・売上・利益がいずれも10,000円過大になります。この変更問題では、返品に伴う追加の原価変動はないという基準資料の条件を維持します。
