月末に現金を数えたら、月初より減っていました。この月は赤字だったといえるでしょうか。仕事を済ませていれば、代金の回収が翌月でも当月の収益になる場合があります。借入金の元金を返して現金が減っても、元金は当月の費用になりません。損益を求めるときと、現金を数えるときで、集計する項目を切り替えます。

### 基礎の例：同じ週の二つの答えを出す

小さな修理店は今週、修理を終え、料金12,000円は来週受け取ります。今週分の作業場所の家賃3,000円を現金で払い、銀行から10,000円を現金で借りました。仕事が完了した日に全額を売上に記録し、この三件以外の取引と費用はありません。

| 資料 | 損益の計算に入れる額 | 現金の増減に入れる額 |
| --- | --- | ---: |
| 完了した修理の請求書 | 売上 ＋12,000円 | 0円 |
| 家賃の領収書 | 支払家賃 −3,000円 | −3,000円 |
| 借入れの入金記録 | 収益・費用に入れない | ＋10,000円 |

今週の利益は12,000−3,000＝9,000円です。現金は10,000−3,000＝7,000円増えました。修理代は受け取る権利として残り、借りた10,000円には返す義務が残ります。

## 収益と費用を同じ期間で集める

通常の商品を販売して得る売上は収益です。店が仲介などのサービスを行って受け取る受取手数料、貸したお金に対して得る受取利息も収益に含まれます。店が借入れで資金を受け取ったときは、同時に返済義務が生じるため、売上や受取手数料に含めません。

費用には、給料、支払家賃、通信費、水道光熱費、広告宣伝費などがあります。ただし、支払額を何でも費用とするわけではありません。借入元金の返済では負債が減り、資産として扱う備品の購入では現金が備品へ入れ替わります。借入れの利息は、元金とは別に支払利息という費用にします。

ある月の収益が費用を上回れば、その差額が利益です。費用が収益を上回れば、その差額が損失になります。費用180,000円、収益150,000円の場合は30,000円の損失です。「利益はマイナス30,000円」と計算できても、表や選択肢で「損失の額」を尋ねられたら30,000円を選びます。数字に加え、利益・損失の別まで確かめてください。

損益計算書は、一定期間の収益と費用をまとめる表です。貸借対照表の「ある時点」と異なり、「何月1日から何月末まで」のように期間を持ちます。翌月の売上を今月の収益に混ぜれば、今月の経営成績を正しく表せません。問題文の対象期間と、発生した取引の日付を合わせて読む習慣を付けましょう。

### 例題1：売上以外の収益も含めて損益を計算する

1か月の売上は260,000円、受取手数料は8,000円、受取利息は2,000円でした。この月の費用は、問題の条件によって与えられた売上原価150,000円、給料50,000円、支払家賃30,000円、通信費6,000円、支払利息4,000円です。他の収益・費用はありません。

収益合計は260,000＋8,000＋2,000＝270,000円です。費用合計は150,000＋50,000＋30,000＋6,000＋4,000＝240,000円となります。したがって利益は270,000−240,000＝30,000円です。

| 収益の内訳 | 金額 | 費用の内訳 | 金額 |
| --- | ---: | --- | ---: |
| 売上 | 260,000 | 売上原価・問題指定額 | 150,000 |
| 受取手数料 | 8,000 | 給料 | 50,000 |
| 受取利息 | 2,000 | 支払家賃 | 30,000 |
|  |  | 通信費 | 6,000 |
|  |  | 支払利息 | 4,000 |
| 収益合計 | 270,000 | 費用合計 | 240,000 |

売上から費用を引く前に、受取手数料と受取利息を含めたかを点検します。また、ここでは売上原価が問題で与えられています。商品が残る場面で、当月仕入額を無条件にすべて当月の費用とみなす計算にはしていません。商品の記録と月次集計を学ぶときも、原価の指定条件を省略しないようにします。

条件を変え、給料が90,000円だった場合は、費用合計が280,000円へ増えます。収益270,000円に対し、10,000円の損失です。売上が出ていることと、利益が出ていることは別なので、必ず費用全体と比較してください。

## 代金の受払いと、取引の内容を分けて考える

商品を掛けで販売すると、売上と売掛金が同時に発生します。代金を受け取る日まで売上を待つのではありません。後日売掛金を回収すると、現金や預金が増え、売掛金が減ります。この回収を再び売上にすると、同じ販売を二回数えてしまいます。

同様に、借入金を受け入れたときは資産と負債が増えます。受け取った資金そのものを利益に含めると、返す必要のある金額まで営業成果にしてしまいます。借入元金を返したときは資産と負債が減り、利息を払ったときは費用が発生します。一回の振込で元金と利息をまとめて払った場合でも、簿記では内容を分けます。

| 取引 | 現金・預金への影響 | その取引による損益への影響 |
| --- | --- | --- |
| 現金でサービスを提供し、対価を受け取る | 増える | 収益が発生する |
| 商品を掛けで販売する | その時点では増えない | 売上が発生する |
| 以前の売掛金を回収する | 増える | 回収だけで収益は発生しない |
| 銀行から借り入れる | 増える | 収益は発生しない |
| 借入元金を返す | 減る | 元金部分に費用は発生しない |
| 借入利息を支払う | 減る | 支払利息が発生する |

### 例題2：現金の増加額と利益を別々に求める

月初の現金は100,000円です。今月、サービスを現金70,000円で提供し、別のサービス40,000円を提供して代金は翌月受け取ることにしました。どちらも受取手数料を使う条件です。今月の家賃30,000円を現金で払い、銀行から現金60,000円を借り入れ、借入元金20,000円と利息2,000円を現金で返しました。他の取引はありません。

現金の月末額は100,000＋70,000−30,000＋60,000−20,000−2,000＝178,000円です。現金は78,000円増えました。未回収のサービス代40,000円は現金の計算には加えませんが、サービスが完了したので収益には含めます。

収益は70,000＋40,000＝110,000円、費用は30,000＋2,000＝32,000円です。利益は78,000円となり、この条件では現金の増加とたまたま一致しました。一致したという結果だけで、両者が同じ意味だと判断しないでください。

違いを確かめるため、借入額だけを90,000円へ変えます。現金の増加は108,000円になりますが、収益と費用は変わらず、利益は78,000円のままです。変えた条件が借入額なので、現金と負債が増えるだけです。一条件ずつ変えて検算すると、計算手順を丸暗記していないか確認できます。

もう一つ、前月の売掛金25,000円を今月現金で回収した場合は、現金がさらに25,000円増えます。前月に売上として記録済みという条件なので、今月の収益へ追加しません。どの月に取引の成果を記録したか、という時間の区別も必要です。

## 純資産の増加から利益を調べるときは元入れを除く

利益が生じれば、その結果として企業の純資産が増えます。ただし、純資産は追加元入れでも増え、事業主の引出しでも減ります。期間の前後の純資産だけを比べて、増加額のすべてを利益とすることはできません。

このコースの単純な個人企業の例では、利益以外の変動が追加元入れと引出しだけとします。このとき「月末純資産＝月初純資産＋追加元入れ−引出し＋利益」です。利益を求めるなら「月末純資産−月初純資産−追加元入れ＋引出し」と計算できます。損失の場合は利益を負の数として同じ関係で確認できます。

引出しを足し戻す理由を考えてみましょう。利益が出ても、その一部を事業主が生活費として店から持ち出せば、店に残る純資産は少なくなります。その持ち出し分を戻して比較しないと、稼いだ利益まで少なく見積もることになります。式だけでなく、店に残った財産が何によって動いたかを説明してください。

### 例題3：二つの財務諸表をつないで検算する

月初の資産は500,000円、負債は180,000円でした。月末の資産は610,000円、負債は210,000円です。月中に追加元入れ50,000円、事業主の家計への引出し20,000円がありました。これらと損益以外に純資産の変動はありません。

月初純資産は500,000−180,000＝320,000円、月末純資産は610,000−210,000＝400,000円です。純資産は80,000円増えていますが、そのうち元入れと引出しの差50,000−20,000＝30,000円は営業成果ではありません。利益は400,000−320,000−50,000＋20,000＝50,000円です。

同じ月の収益が240,000円、費用が190,000円だったなら、収益−費用も50,000円です。財産から見た損益と、収益・費用から見た損益が一致します。貸借対照表は月初・月末という時点、損益計算書はその間という期間を表しています。

確認として320,000＋50,000−20,000＋50,000＝400,000円を計算します。最初の50,000円は追加元入れ、最後の50,000円は利益です。同額でも意味が違うので、式の各数字へ名称を書き添えると読み違えを減らせます。

## 独立練習：条件を分類してから計算する

1. 収益は売上180,000円と受取手数料5,000円、費用は問題で指定された原価90,000円、給料50,000円、家賃30,000円、通信費8,000円です。利益または損失を求めます。
2. 現金50,000円を借り入れ、利息1,500円と借入元金10,000円を現金で払いました。この3取引による現金の増減額と、費用の額を求めます。
3. 月初純資産280,000円、月末純資産340,000円、追加元入れ80,000円、引出し10,000円です。ほかの純資産変動はないとして、利益または損失を求めます。

## 練習の解答

1は収益185,000円、費用178,000円、利益7,000円です。受取手数料を落とすと2,000円という誤答になります。2は現金が50,000−1,500−10,000＝38,500円増え、費用は利息1,500円です。借入元金の受入れや返済を損益へ混ぜません。3は340,000−280,000−80,000＋10,000＝−10,000円なので、10,000円の損失です。元入れによって純資産が増えていても、損失が生じることはあります。

解くときは、まず対象期間を確認し、各取引を「収益・費用」「資産・負債の移動」「元入れ・引出し」に分類します。そのあとで集計する順序にすると、金額が大きい借入れを誤って売上へ含めるミスを防げます。次の取引のレッスンでは、これらの変化を借方・貸方の要素へ分けます。

## 入出金表と損益計算書を一つの事例で作る

利益を求めるときは、現金の列から計算を始めるより、何をした取引かを先に見ます。商品を渡せば掛けでも売上が生じ、以前の売掛金を回収しただけなら、今月は売上を繰り返し計上しません。借入元金や事業主との資金移動も、店の営業で生じた収益・費用と分けます。

### 例題：同じ資料から三つの数字を説明する

6月初めの純資産は400,000円です。6月に掛けで商品を販売し、代金120,000円は翌月入金されます。この例の販売に対応する原価は55,000円と指定されており、原価に当たる商品は店にすでにあったものです。前月の売掛金70,000円を現金で回収し、今月分の家賃25,000円を現金で払い、借入元金20,000円と利息2,000円を現金で支払いました。さらに店主は30,000円を元入れし、生活費5,000円を引き出しました。

| 6月の出来事 | 現金の増減 | 今月の収益・費用 | 直接の純資産増減 |
| --- | ---: | --- | ---: |
| 今月の掛売りと原価 | 0 | 収益120,000円、費用55,000円 | 0 |
| 前月の売掛金を回収 | ＋70,000円 | なし | 0 |
| 今月の家賃を支払い | −25,000円 | 費用25,000円 | 0 |
| 借入元金と利息を支払い | −22,000円 | 費用2,000円 | 0 |
| 元入れと生活費の引出し | ＋25,000円 | なし | ＋25,000円 |

### 例題：資料が一つ足りなくても逆算する

月末純資産463,000円と月初純資産400,000円だけを見て、利益を63,000円と答えると、事業主の出し入れ25,000円まで利益に含めることになります。資本の増加から元入れ30,000円を引き、引出し5,000円を足すと、利益38,000円に戻ります。

## 損益計算書の利益を貸借対照表で確かめる

損益計算書では、一定期間に得た収益と、その期間の費用を集めます。貸借対照表では、ある一日時点の資産・負債・純資産を示します。「6月の利益」と「6月末の現金」では、表の対象も答え方も違います。二つの表をつなぐには、利益と、店主による資金の出し入れを分けます。

### 例題：現金が減った月でも利益は出るか

小さな事務代行店の4月1日の残高は、現金80,000円、前月の仕事の代金を後日受け取る権利（売掛金）30,000円、借入金40,000円です。資産110,000円から負債40,000円を引くと、月初純資産は70,000円です。以下は4月に起きた取引です。事務代行を通常の営業とし、完了した仕事の代金は売上へ記録します。

| 4月の資料 | 現金の増減 | 4月の収益・費用 | ほかに動くもの |
| --- | ---: | --- | --- |
| 仕事が完了。代金52,000円は5月に回収 | 0円 | 売上52,000円 | 売掛金が52,000円増える |
| 3月の売掛金30,000円を現金で回収 | ＋30,000円 | なし | 売掛金が30,000円減る |
| 4月分の家賃20,000円を現金払い | −20,000円 | 支払家賃20,000円 | なし |
| 借入元金18,000円と利息1,000円を現金払い | −19,000円 | 支払利息1,000円 | 借入金が18,000円減る |
| 店主が現金10,000円を元入れし、生活費15,000円を引き出した | −5,000円 | なし | 資本金が差引5,000円減る |

まず4月の損益計算書を考えます。収益は売上52,000円、費用は家賃20,000円と利息1,000円です。したがって利益は52,000−21,000＝31,000円です。前月の売掛金の回収を売上へ入れると、3月に記録した売上を4月にも数えてしまいます。元金の返済は、支払う義務がなくなる取引です。18,000円の元金と1,000円の利息を一つの費用にすると、利益を18,000円少なく見積もります。

次に4月末の貸借対照表を作ります。現金は80,000＋30,000−20,000−19,000−5,000＝66,000円、売掛金は30,000＋52,000−30,000＝52,000円。資産の合計は118,000円です。借入金は40,000−18,000＝22,000円なので、純資産は118,000−22,000＝96,000円です。純資産は、月初70,000円＋利益31,000円＋元入れ10,000円−引出し15,000円でも96,000円になります。

### 条件が変わったら：仕事の完了日が翌月になった

52,000円の仕事が4月末にまだ完了しておらず、この問題では完了時に全額を売上にする条件だとします。前受けもありません。4月中の入出金は変わらないため、現金は66,000円のままです。4月の売上52,000円と売掛金52,000円は生じないため、4月は費用21,000円だけで損失21,000円です。月末純資産は70,000−21,000＋10,000−15,000＝44,000円。資産66,000円−負債22,000円でも44,000円です。代金が入る日を動かす問題と、売上が発生する日を動かす問題では、影響する数字が違います。

### よくある誤り：月末の現金を利益と考える

最初の条件では現金が14,000円減った一方、利益は31,000円でした。取引を「お金が入ったか」だけで分類すると、掛けで売り上げた52,000円を見落とします。まず収益・費用だけで損益を出し、次に現金だけの増減を計算します。両方の答えに同じ項目を入れる必要はありません。

## 応用：二か月の資料を分け、誤差が生じた日を探す

完了した仕事の料金を完了日に記録する店を考えます。5月25日に終えた仕事の料金は34,000円で、現金を受け取ったのは6月3日です。6月28日に終えた別の仕事の料金51,000円は、6月末まで未回収です。6月分の家賃19,000円を6月中に現金で払い、6月の資料には6月分以外の費用がありません。月初の現金は40,000円、売掛金は5月の仕事の代金34,000円だけです。

もし6月の売上として「6月の入金34,000円」と「6月に完了した仕事51,000円」を両方数えると、売上は85,000円、利益は66,000円になります。これを元の資料へ戻して修正します。

1. 完了日を確認します。34,000円の仕事は5月25日に完了したため、5月の売上です。6月3日は、すでにある売掛金を現金へ移した日です。
2. 6月の収益と費用を集めます。6月の売上は51,000円、費用は19,000円です。当月利益は32,000円です。
3. 6月末の資産を確認します。現金は40,000＋34,000−19,000＝55,000円。売掛金は34,000−34,000＋51,000＝51,000円です。
4. 二つの資産を合わせて検算します。この三件でほかの資産・負債・資本金は動きません。現金と売掛金の合計は月初74,000円から月末106,000円へ増え、増加額32,000円は当月利益と一致します。

<p><strong>予測してから開く：</strong>6月3日だった回収が7月3日に延び、6月28日だった仕事の完了は7月2日に延びました。代金の前受けはなく、家賃は同じです。二つの日付の変更が、それぞれ「6月の利益」「6月末の現金」「6月末の売掛金」のどれを動かすか考えてから、六つの答えを照合します。</p>

<details><summary>二つの日付の変更がもたらす違いを確認する</summary>

| 変わった日 | 6月の損益への影響 | 6月末の現金への影響 | 6月末の売掛金への影響 |
| --- | --- | ---: | ---: |
| 5月分の仕事の回収が7月に延びた | 変化なし | −34,000円 | ＋34,000円 |
| 6月の仕事の完了が7月に延びた | 利益が51,000円減る | 変化なし | −51,000円 |

両方が変わると、6月は売上がなく家賃19,000円だけで、19,000円の損失です。現金は40,000−19,000＝21,000円、売掛金は古い仕事の34,000円だけが残ります。資産55,000円は月初74,000円から19,000円減り、損失と一致します。

</details>

試験で「この月の利益」を聞かれたら、最初にどの月に収益と費用が発生したかを確認します。「月末残高」なら月初からの変化を追います。二つを検算で結ぶときは、当月利益以外に純資産を変える元入れや引出しの有無も確かめます。
