利益は、ある期間の収益から費用を差し引いて求めます。現金が増えた額と同じとは限りません。銀行からの借入れや事業主の出資でも現金は増えますし、商品を掛けで売った場合は代金をまだ受け取っていなくても売上が発生します。この違いを、具体的な金額で確かめます。

<span id="objective-1"></span>

## 収益と費用を同じ期間で集める

通常の商品を販売して得る売上は収益です。店が仲介などのサービスを行って受け取る受取手数料、貸したお金に対して得る受取利息も収益に含まれます。店が借入れで資金を受け取ったときは、同時に返済義務が生じるため、売上や受取手数料に含めません。

費用には、給料、支払家賃、通信費、水道光熱費、広告宣伝費などがあります。ただし、支払額を何でも費用とするわけではありません。借入元金の返済では負債が減り、資産として扱う備品の購入では現金が備品へ入れ替わります。借入れの利息は、元金とは別に支払利息という費用にします。

ある月の収益が費用を上回れば、その差額が利益です。費用が収益を上回れば、その差額が損失になります。費用180,000円、収益150,000円の場合は30,000円の損失です。「利益はマイナス30,000円」と計算できても、表や選択肢で「損失の額」を尋ねられたら30,000円を選びます。数字に加え、利益・損失の別まで確かめてください。

損益計算書は、一定期間の収益と費用をまとめる表です。貸借対照表の「ある時点」と異なり、「何月1日から何月末まで」のように期間を持ちます。翌月の売上を今月の収益に混ぜれば、今月の経営成績を正しく表せません。問題文の対象期間と、発生した取引の日付を合わせて読む習慣を付けましょう。

### 例題1：売上以外の収益も含めて損益を計算する

1か月の売上は260,000円、受取手数料は8,000円、受取利息は2,000円でした。この月の費用は、問題の条件によって与えられた売上原価150,000円、給料50,000円、支払家賃30,000円、通信費6,000円、支払利息4,000円です。他の収益・費用はありません。

収益合計は260,000＋8,000＋2,000＝270,000円です。費用合計は150,000＋50,000＋30,000＋6,000＋4,000＝240,000円となります。したがって利益は270,000−240,000＝30,000円です。

| 収益の内訳 | 金額 | 費用の内訳 | 金額 |
| --- | ---: | --- | ---: |
| 売上 | 260,000 | 売上原価・問題指定額 | 150,000 |
| 受取手数料 | 8,000 | 給料 | 50,000 |
| 受取利息 | 2,000 | 支払家賃 | 30,000 |
|  |  | 通信費 | 6,000 |
|  |  | 支払利息 | 4,000 |
| 収益合計 | 270,000 | 費用合計 | 240,000 |

売上から費用を引く前に、受取手数料と受取利息を含めたかを点検します。また、ここでは売上原価が問題で与えられています。商品が残る場面で、当月仕入額を無条件にすべて当月の費用とみなす計算にはしていません。商品の記録と月次集計を学ぶときも、原価の指定条件を省略しないようにします。

条件を変え、給料が90,000円だった場合は、費用合計が280,000円へ増えます。収益270,000円に対し、10,000円の損失です。売上が出ていることと、利益が出ていることは別なので、必ず費用全体と比較してください。

## 代金の受払いと、取引の内容を分けて考える

商品を掛けで販売すると、売上と売掛金が同時に発生します。代金を受け取る日まで売上を待つのではありません。後日売掛金を回収すると、現金や預金が増え、売掛金が減ります。この回収を再び売上にすると、同じ販売を二回数えてしまいます。

同様に、借入金を受け入れたときは資産と負債が増えます。受け取った資金そのものを利益に含めると、返す必要のある金額まで営業成果にしてしまいます。借入元金を返したときは資産と負債が減り、利息を払ったときは費用が発生します。一回の振込で元金と利息をまとめて払った場合でも、簿記では内容を分けます。

| 取引 | 現金・預金への影響 | その取引による損益への影響 |
| --- | --- | --- |
| 現金でサービスを提供し、対価を受け取る | 増える | 収益が発生する |
| 商品を掛けで販売する | その時点では増えない | 売上が発生する |
| 以前の売掛金を回収する | 増える | 回収だけで収益は発生しない |
| 銀行から借り入れる | 増える | 収益は発生しない |
| 借入元金を返す | 減る | 元金部分に費用は発生しない |
| 借入利息を支払う | 減る | 支払利息が発生する |

<span id="worked-2"></span>

### 例題2：現金の増加額と利益を別々に求める

月初の現金は100,000円です。今月、サービスを現金70,000円で提供し、別のサービス40,000円を提供して代金は翌月受け取ることにしました。どちらも受取手数料を使う条件です。今月の家賃30,000円を現金で払い、銀行から現金60,000円を借り入れ、借入元金20,000円と利息2,000円を現金で返しました。他の取引はありません。

現金の月末額は100,000＋70,000−30,000＋60,000−20,000−2,000＝178,000円です。現金は78,000円増えました。未回収のサービス代40,000円は現金の計算には加えませんが、サービスが完了したので収益には含めます。

収益は70,000＋40,000＝110,000円、費用は30,000＋2,000＝32,000円です。利益は78,000円となり、この条件では現金の増加とたまたま一致しました。一致したという結果だけで、両者が同じ意味だと判断しないでください。

違いを確かめるため、借入額だけを90,000円へ変えます。現金の増加は108,000円になりますが、収益と費用は変わらず、利益は78,000円のままです。変えた条件が借入額なので、現金と負債が増えるだけです。一条件ずつ変えて検算すると、計算手順を丸暗記していないか確認できます。

もう一つ、前月の売掛金25,000円を今月現金で回収した場合は、現金がさらに25,000円増えます。前月に売上として記録済みという条件なので、今月の収益へ追加しません。どの月に取引の成果を記録したか、という時間の区別も必要です。

## 純資産の増加から利益を調べるときは元入れを除く

利益が生じれば、その結果として企業の純資産が増えます。ただし、純資産は追加元入れでも増え、事業主の引出しでも減ります。期間の前後の純資産だけを比べて、増加額のすべてを利益とすることはできません。

このコースの単純な個人企業の例では、利益以外の変動が追加元入れと引出しだけとします。このとき「月末純資産＝月初純資産＋追加元入れ−引出し＋利益」です。利益を求めるなら「月末純資産−月初純資産−追加元入れ＋引出し」と計算できます。損失の場合は利益を負の数として同じ関係で確認できます。

引出しを足し戻す理由を考えてみましょう。利益が出ても、その一部を事業主が生活費として店から持ち出せば、店に残る純資産は少なくなります。その持ち出し分を戻して比較しないと、稼いだ利益まで少なく見積もることになります。式だけでなく、店に残った財産が何によって動いたかを説明してください。

### 例題3：二つの財務諸表をつないで検算する

月初の資産は500,000円、負債は180,000円でした。月末の資産は610,000円、負債は210,000円です。月中に追加元入れ50,000円、事業主の家計への引出し20,000円がありました。これらと損益以外に純資産の変動はありません。

月初純資産は500,000−180,000＝320,000円、月末純資産は610,000−210,000＝400,000円です。純資産は80,000円増えていますが、そのうち元入れと引出しの差50,000−20,000＝30,000円は営業成果ではありません。利益は400,000−320,000−50,000＋20,000＝50,000円です。

同じ月の収益が240,000円、費用が190,000円だったなら、収益−費用も50,000円です。財産から見た損益と、収益・費用から見た損益が一致します。貸借対照表は月初・月末という時点、損益計算書はその間という期間を表しています。

確認として320,000＋50,000−20,000＋50,000＝400,000円を計算します。最初の50,000円は追加元入れ、最後の50,000円は利益です。同額でも意味が違うので、式の各数字へ名称を書き添えると読み違えを減らせます。

## 独立練習：条件を分類してから計算する

1. 収益は売上180,000円と受取手数料5,000円、費用は問題で指定された原価90,000円、給料50,000円、家賃30,000円、通信費8,000円です。利益または損失を求めます。
2. 現金50,000円を借り入れ、利息1,500円と借入元金10,000円を現金で払いました。この3取引による現金の増減額と、費用の額を求めます。
3. 月初純資産280,000円、月末純資産340,000円、追加元入れ80,000円、引出し10,000円です。ほかの純資産変動はないとして、利益または損失を求めます。

## 練習の解答

1は収益185,000円、費用178,000円、利益7,000円です。受取手数料を落とすと2,000円という誤答になります。2は現金が50,000−1,500−10,000＝38,500円増え、費用は利息1,500円です。借入元金の受入れや返済を損益へ混ぜません。3は340,000−280,000−80,000＋10,000＝−10,000円なので、10,000円の損失です。元入れによって純資産が増えていても、損失が生じることはあります。

解くときは、まず対象期間を確認し、各取引を「収益・費用」「資産・負債の移動」「元入れ・引出し」に分類します。そのあとで集計する順序にすると、金額が大きい借入れを誤って売上へ含めるミスを防げます。次の取引のレッスンでは、これらの変化を借方・貸方の要素へ分けます。
