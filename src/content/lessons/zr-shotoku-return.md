## 税率を掛ける相手は、控除後の課税所得です

収入、所得、課税所得を分けて計算した後に、税額を求めます。総合課税の所得税には超過累進税率が用いられます。所得がある区分へ増えたときに、過去の低い区分の部分まで一律に高い税率へ変える仕組みではありません。税率表の速算控除額は、この段階的な計算を短く表す役割があります。

このレッスンでは、居住者の通常の総合課税だけを扱い、分離課税、平均課税、外国税額控除等はないとします。課税所得の端数処理を済ませた金額が与えられる条件から始め、税額控除、復興特別所得税、源泉徴収税額の精算へ順に進みます。

## 超過累進税率を、区分ごとの計算で確かめます

独自の2025年分の例として、課税される所得金額を300万円とします。最初の195万円に5％、195万円を超える105万円に10％を適用する範囲なので、195万円×5％＋105万円×10％＝97,500＋105,000＝202,500円です。300万円全体へ10％を掛けた300,000円との差を説明してください。

速算表では、300万円が属する区分の税率10％を掛け、控除額97,500円を引きます。3,000,000×10％－97,500＝202,500円となり、区分別の計算と一致します。この97,500円は基礎控除や給与所得控除とは別の、累進税率の速算のための額です。所得の計算段階で引かないようにします。

| 課税所得の範囲                   | 税率 |  速算控除額 |
| -------------------------------- | ---: | ----------: |
| 195万円未満の範囲                |  5％ |         0円 |
| 195万円以上330万円未満の範囲     | 10％ |    97,500円 |
| 330万円以上695万円未満の範囲     | 20％ |   427,500円 |
| 695万円以上900万円未満の範囲     | 23％ |   636,000円 |
| 900万円以上1,800万円未満の範囲   | 33％ | 1,536,000円 |
| 1,800万円以上4,000万円未満の範囲 | 40％ | 2,796,000円 |
| 4,000万円以上の範囲              | 45％ | 4,796,000円 |

表は千円未満の端数を切り捨てた課税所得について、境界を読みやすく示したものです。実際の申告の速算表や端数処理は公式資料で確認します。例えば課税所得400万円なら、4,000,000×20％－427,500＝372,500円です。前の区分の控除額97,500円を使い続けない点を確かめます。

## 税額控除と、復興特別所得税を順に計算します

税額控除がある場合は、各制度の限度や順序に従って適用します。ここでは課税所得300万円の例に、全額を差し引ける税額控除20,000円だけがあると与えます。所得税額202,500円から引いて182,500円となります。この例では、それが復興特別所得税の基準所得税額にもなる条件とします。

復興特別所得税は、この条件で182,500×2.1％＝3,832.5円です。1円未満を切り捨てて3,832円とし、所得税と合わせて186,332円です。2.1％を所得300万円へ直接掛けたり、所得税の税率10％へ単純に足して12.1％としたりしないでください。基礎となる税額を先に求めます。

別例で、課税所得400万円、税額控除なしなら、本税372,500円、復興特別所得税は7,822円で、合計380,322円です。372,500×0.021＝7,822.5円から端数を処理します。公式の解説例を読むときも、数値を自分で再計算し、式の元の税額と一致するかを確認する習慣を付けましょう。

## 先に徴収された税額を、年間の税額と精算します

源泉徴収は、給与や一定の報酬等を支払う人が、支払時に所得税等を徴収して納付する仕組みです。納税者の年間の所得計算が、その時点ですべて終わるわけではありません。給与では一定の範囲で年末調整が行われ、必要に応じて確定申告で全体を精算します。年末調整と確定申告は、同じ名称の手続ではありません。

上の300万円の例で、源泉徴収済みの所得税等が200,000円、予定納税等なしとします。年間の合計税額186,332円より13,668円多いので、この例の還付額は13,668円です。源泉徴収額が150,000円なら差額36,332円が計算上の不足額となり、申告納税額の100円未満を切り捨てる条件では36,300円を納めます。還付額と納付額で端数処理の位置が異なる点も確認します。

## 申告する人と、申告の目的を区別します

確定申告では、一年間の各所得と税額、源泉徴収税額等を申告して精算します。通常の申告期間は原則として翌年2月16日から3月15日です。還付申告は原則として翌年1月1日から5年間行えます。休日等による期限の扱いも公式案内で確認します。更正の請求、修正申告、死亡時の準確定申告等には、それぞれ対象や期限の規定があります。一般的な確定申告の期限を、すべての手続へ当てはめないようにします。

給与所得者には一定の申告不要の制度がありますが、収入、他の所得、勤務先、控除の申告等の条件を確認します。所得税の申告が不要となる場合でも、住民税の申告等の扱いが同じとは限りません。また、還付を受けるため確定申告をする際には、申告に含めるべき所得の範囲を改めて確認します。

期限内申告と帳簿保存等の条件は、青色申告の特典にも関係します。税額だけ計算できても、承認・届出・申告の条件を満たしていなければ、想定した制度を使えないことがあります。解答では、金額とともに対象年や適用条件を示す練習を行います。

## 税率表の速算控除は、超過部分だけに高い率を掛けるための調整です

課税所得400万円について、税率20％、速算控除427,500円という表の区分を使う条件なら、算出所得税額は800,000－427,500＝372,500円です。400万円の全額へ単純に20％を掛けた800,000円を税額とするのは、下の所得段階に対応する低い税率を無視した計算です。速算表は超過累進の仕組みを短い式で表したものと理解します。

基準所得税額の計算上控除する種類の税額控除20,000円だけがある例では、基準所得税額は352,500円となります。復興特別所得税をその2.1％、一円未満切捨てで求める指定なら7,402円で、合計359,902円です。源泉徴収400,000円を差し引くと、差額40,098円は還付側となります。この例では納付額の百円未満処理を還付額へ機械的に当てはめていません。

源泉徴収は前払的な精算の仕組みですが、すべての所得が必ず同じ確定申告で合算されるわけではありません。源泉分離課税や申告不要制度などを区別します。通常の確定申告と還付申告の期間も同一ではないため、「申告は常に三月だけ」と覚えるのは不適切です。対象年、申告義務の有無、選択する制度を確認してから期限を判断します。

復習では、課税所得、所得税額、税額控除後の基準額、復興特別所得税、源泉徴収済み額という順に欄を作ってください。所得税法の科目総復習では区分と控除の位置を確かめ、用語確認の後に120分の独自基礎模試へ進みます。模試の点数は公式の採点や合否を予測するものではありません。
