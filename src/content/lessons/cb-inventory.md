## 製造した原価と、売れた原価を分ける

工場で材料を使っても、月末にすべてが完成し、すべて売れるとは限りません。製造途中のものが仕掛品、完成したものが製品です。完成した製品のうち売れた分の原価が売上原価になります。この流れを分けることで、在庫に残る原価と当月の売上に対応する原価を区別できます。

今月に材料・労務費・経費を200,000円投入したからといって、その全額を当月の売上原価とは決められません。月初に残っていた仕掛品や製品、月末に残る仕掛品や製品を考慮します。問題文の「製造」「完成」「販売」が、それぞれどの段階の数字なのかを確かめましょう。

## 例題：完成品原価を求める

月初仕掛品原価30,000円、当月製造費用200,000円、月末仕掛品原価50,000円とします。製造の工程へ入っていた原価は合計230,000円です。そのうち、月末にまだ製造途中の50,000円を除くと、当月に完成した製品の原価は180,000円です。

式は、月初仕掛品30,000＋当月製造費用200,000−月末仕掛品50,000＝当月製品製造原価180,000円です。月末仕掛品を加えると、未完成のものを完成した原価へ含めてしまいます。投入された原価のうち、どこへ移ったかを考えてください。

| 製造工程の原価 | 金額 |
| --- | ---: |
| 月初の仕掛品 | 30,000円 |
| 当月に追加した原価 | 200,000円 |
| 合計 | 230,000円 |
| 月末の未完成分 | 50,000円 |
| 当月の完成分 | 180,000円 |

ここでは月末仕掛品の評価額が問題で与えられています。完成度などから評価する詳しい計算は2級の総合原価計算で学びます。初級の段階では、与えられた評価額を原価の流れに正しく置くことを目標にします。

## 完成した製品から売上原価へ進む

月初製品原価20,000円、当月製品製造原価180,000円、月末製品原価40,000円とします。販売に使える製品の原価総額は200,000円です。売れずに残る40,000円を引くと、売上原価は160,000円です。

当月製品製造原価180,000円と売上原価160,000円を、同じ数字として扱わないようにします。前者は今月完成した分、後者は今月売れた分です。以前の月に完成した製品が今月売れたり、今月完成した製品が翌月まで残ったりするため、金額がずれます。

## 製品別の売上総利益と営業利益

売上高300,000円、売上原価160,000円なら、売上総利益は140,000円です。販売費及び一般管理費60,000円があれば、営業利益は80,000円です。製造原価に含めない販売や管理の費用を、営業利益の計算で差し引きます。

二つの製品の利益を比べる場面を考えます。Aの売上200,000円、売上原価120,000円、Bの売上150,000円、売上原価90,000円なら、売上総利益はA80,000円、B60,000円です。どちらも売上総利益率は40%ですが、利益の額は異なります。

共通の販売管理費70,000円を売上高比で分ける条件なら、Aは70,000×200,000÷350,000＝40,000円、Bは30,000円です。営業利益はA40,000円、B30,000円になります。利益を出す製品を比べるときは、配賦前の利益なのか、共通費配賦後の利益なのかも確認します。

## 在庫が増えたときの読み方

製造して在庫として残った原価は、通常その月の売上原価から除かれます。製品がたくさん残ると、投入した原価の全額がその月の費用にはならないということです。ただし、在庫を増やせば会社の現金や販売力も同じように増える、とはいえません。原価の計算と、販売や資金の管理は関連する別の問題です。

検算では、仕掛品と製品について、それぞれ「月初＋当月増加＝当月減少＋月末」が成り立つかを確認しましょう。二つの在庫段階を混ぜず、金額の移動を矢印や表で書くと、どの原価が売上へ対応したかを説明しやすくなります。

## 復習の進め方

完成品原価を求める式、売上原価を求める式、営業利益を求める式を順に並べ、同じ数字が次の段階へ渡るところに印を付けてください。式だけでなく、差し引く月末在庫が何を表すかまで説明できれば、損益分岐点の学習へ進めます。
