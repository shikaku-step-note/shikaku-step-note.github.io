## プロジェクトとは

プロジェクトは、特定の成果を得るために、期間を区切って行う取り組みです。毎日の受付業務のように繰り返す仕事とは、計画や管理の仕方が異なります。

## 予約システムを導入する例

お店が3か月後の運用開始を目指すとします。予約を登録する機能だけでなく、担当者が使えるようになることや、必要なデータを移すことも計画に入れます。

1. 誰が何に困っているかを確認する。
2. 必要な機能と今回扱わない範囲を決める。
3. 作業を分け、担当者と期限を決める。
4. 動作確認と操作の練習をしてから運用を始める。

## 品質・費用・納期のバランス

「機能を増やす」「費用を抑える」「早く完成させる」を同時に最大限満たすのは難しい場合があります。追加機能が必要になったら、その影響を関係者と確認します。

| 観点 | 確認すること               |
| ---- | -------------------------- |
| 品質 | 必要な動作を満たしているか |
| 費用 | 予算内で進められるか       |
| 納期 | 必要な時期に利用できるか   |

## 振り返り

作業の遅れを隠すよりも、早く共有して対策を決めることが重要です。計画は一度作って終わりではなく、進捗や変更に合わせて見直します。
