試験形式のまとまった資料では、材料費、作業時間、仕掛品、製品在庫、売上高が一つの表に並びます。必要なのは、目に入った数字をすべて同じ式へ入れることではありません。まず何を求める問題かを決め、原価を製品へ集める作業、期間の費用へ移す作業、将来の数量を計画する作業を区別します。

この課の前半では、二製品A・Bの当月実績から製品別の損益を作ります。その後のCVPは「翌月は在庫を変えない」という別の計画条件です。実績の在庫が変わった月と、在庫一定で単位変動費を使う月を同じものとして照合しないよう、対象期間と条件を明示します。

<span id="objective-1"></span>

## 原価を集計し、在庫を経由して販売分だけを費用にする

製造活動に使った原価は、直接費なら該当製品へ直課し、共通の間接費なら与えられた基準で配賦します。こうして集計した当月製造費用が、すべて当月の売上原価になるとは限りません。月末に未完成品や未販売の完成品が残れば、その原価は在庫に残るからです。

流れは「月初仕掛品＋当月製造費用−月末仕掛品＝当月完成品原価」、次に「月初製品＋当月完成品原価−月末製品＝売上原価」です。仕掛品の式と製品の式を別々に作れば、同じ在庫を二重に引く誤りを防げます。月初は加え、月末は残すために引くという方向も確認します。

### 実績資料：製品A・Bを製造する工房

すべて当月分、金額は円です。間接製造費120,000円を直接作業時間により配賦します。Aの時間は300時間、Bは200時間です。直接費には材料費・労務費・直接経費を含み、以下の表に示した額以外の当月製造費用はありません。仕掛品と製品在庫の評価額は与えられており、評価方法の追加計算は不要です。

| 原価の資料 | A | B |
| --- | ---: | ---: |
| 直接材料費 | 180,000 | 120,000 |
| 直接労務費 | 90,000 | 70,000 |
| 直接経費 | 10,000 | 10,000 |
| 月初仕掛品 | 20,000 | 10,000 |
| 月末仕掛品 | 30,000 | 14,000 |
| 月初製品 | 40,000 | 30,000 |
| 月末製品 | 32,000 | 20,000 |

<span id="worked-1"></span>

### 例題1：配賦から売上原価までをつなぐ

総作業時間は300＋200＝500時間です。配賦率は120,000÷500＝240円／時間。Aには240×300＝72,000円、Bには240×200＝48,000円を配賦します。合計120,000円に戻ることを確認してから、直接費へ足します。

Aの当月製造費用は180,000＋90,000＋10,000＋72,000＝352,000円。完成品原価は20,000＋352,000−30,000＝342,000円です。売上原価は40,000＋342,000−32,000＝350,000円となります。

Bは120,000＋70,000＋10,000＋48,000＝248,000円の当月製造費用、完成品原価10,000＋248,000−14,000＝244,000円、売上原価30,000＋244,000−20,000＝254,000円です。

合計当月製造費用は600,000円、仕掛品は月初30,000円から月末44,000円へ14,000円増加しています。したがって完成品原価は586,000円です。製品在庫は70,000円から52,000円へ18,000円減少したため、売上原価は586,000＋18,000＝604,000円となります。350,000＋254,000とも一致します。

当月製造費用600,000円に比べて売上原価が4,000円大きいのは、仕掛品の増加14,000円と製品在庫の減少18,000円の差です。製造費用と売上原価を同じ金額にしてしまうと、この在庫の動きが消えてしまいます。

## 製品別の利益を計算し、全体の損益と照合する

当月売上はAが400個×1,200円＝480,000円、Bが250個×1,600円＝400,000円です。製品別の販売費および一般管理費はA30,000円、B20,000円です。さらに共通分50,000円を、問題で指定したA：B＝4：1の基準で配賦します。この課では売上高の比率による配賦ではありません。

共通分の配賦額はA50,000×4÷5＝40,000円、B50,000×1÷5＝10,000円です。合計50,000円へ戻ります。製造間接費の作業時間基準と、共通販売費等の4：1基準は別の指示です。それぞれの費用に対応した基準を使います。

<span id="worked-2"></span>

### 例題2：売上総利益と営業利益を一段ずつ求める

Aの売上総利益は480,000−350,000＝130,000円。販売費等は直接分30,000円と共通配賦分40,000円の計70,000円なので、営業利益は60,000円です。Bの売上総利益は400,000−254,000＝146,000円。販売費等30,000円を引いて営業利益116,000円となります。

全体では売上高880,000円、売上原価604,000円、売上総利益276,000円です。販売費等は直接分50,000円と共通分50,000円の合計100,000円。営業利益176,000円となり、A60,000＋B116,000と一致します。

ここでは共通費を含む営業利益がBのほうが大きいことは分かりますが、共通費の配賦を受けた後の金額だけで、Aをやめるべきだとは判断できません。Aを中止した場合に消える費用、Bへの影響などの条件は与えられていないからです。まず製品別と全体が正しくつながる計算に集中します。

<span id="objective-2"></span>

## 翌月のCVPは、在庫一定という新しい前提で作る

翌月は単一の商品セットだけを販売し、製造数量と販売数量は一致、仕掛品・製品在庫の増減はないとします。一セットの売価2,000円、変動製造費900円、変動販売費100円、月の固定製造費120,000円、固定販売費等80,000円です。この条件は、前半のA・B実績とは別の計画資料です。

単位変動費は900＋100＝1,000円、単位貢献利益も1,000円です。固定費総額200,000円を回収する損益分岐点数量は200セットです。目標利益100,000円なら300セットが必要になります。製造固定費を一個当たり原価からも引き、さらに固定費総額として引くと二重計上になります。

<span id="worked-3"></span>

### 例題3：同じ計画利益を二つの表示で確認する

300セットを販売すれば売上高600,000円、変動製造費270,000円、固定製造費120,000円で、売上原価390,000円です。在庫が変わらないため、この月の製造費用はすべて販売分に対応します。売上総利益は210,000円です。

販売費等は変動分30,000円と固定分80,000円で110,000円。営業利益は100,000円です。CVP表示では売上高600,000円から変動費300,000円を引いて貢献利益300,000円、固定費200,000円を引いて同じ100,000円となります。

売上総利益210,000円と貢献利益300,000円は違います。前者は固定製造費をすでに引き、変動販売費をまだ引いていないからです。両方の中間利益を足す必要はありません。費用を別の切り口で並べ直した表示であると分かれば、最終利益だけが一致する理由を説明できます。

もし前半のように製品在庫が動く月なら、製造費用の一部が在庫へ残ったり、以前の在庫原価が売上原価に加わったりします。その月の利益を、在庫条件のない単純なCVP式と無条件に一致させてはいけません。何を一定とした比較なのかを確かめることが先です。

<span id="objective-3"></span>

## 売上の予算実績差異は、損益の売上高へ照合する

当月のA・Bに戻ります。Aの予算は380個×1,250円＝475,000円、実績は400個×1,200円＝480,000円でした。Bの予算は260個×1,500円＝390,000円、実績は250個×1,600円＝400,000円です。前半の損益計算で使った実際売上高880,000円と、差異分析の実績合計をそろえます。

<span id="worked-4"></span>

### 例題4：二製品の数量差異と価格差異をまとめる

Aの数量差異は（400−380）×1,250＝＋25,000円、価格差異は（1,200−1,250）×400＝−20,000円で、全体＋5,000円です。Bは数量差異（250−260）×1,500＝−15,000円、価格差異（1,600−1,500）×250＝＋25,000円で、全体＋10,000円となります。

合計の数量差異は＋10,000円、価格差異は＋5,000円、売上高差異は＋15,000円です。予算合計865,000円と実績880,000円の差にも一致します。この＋15,000円を、そのまま営業利益の予算差とすることはできません。費用の予算情報がまだないからです。

この問題で求めた営業利益176,000円は当月実績の原価・在庫・販売費を使った結果です。売上高差異15,000円は予算売上と実際売上を比べた額です。期間が同じでも比較している対象が違うので、「実績利益から売上差異を引けば予算利益が分かる」とは限りません。

## 途中の誤りを見つける三つの照合

第一に配賦総額です。製造間接費なら72,000＋48,000＝120,000円、共通販売費等なら40,000＋10,000＝50,000円に戻します。配賦率を掛ける対象や単位が違えば、ここで不一致が出ます。

第二に原価の流れです。A・Bを合計してから仕掛品・製品の式を計算した604,000円と、製品別売上原価350,000円・254,000円の合計を照合します。月初・月末を逆にした誤りは、在庫の増減方向を言葉で確かめると発見しやすくなります。

第三に損益と差異の照合です。製品別営業利益の合計は全体営業利益へ、数量差異と価格差異の合計は実際売上高−予算売上高へ戻します。同じ結果を別の経路から計算するので、元の計算をそのまま見直すだけより誤りを探しやすくなります。

## 独力で解くための短い総合課題

次は一製品の別条件です。月初仕掛品12,000円、当月製造費用240,000円、月末仕掛品20,000円、月初製品30,000円、月末製品18,000円、実際売上高360,000円、販売費等40,000円です。売上原価と営業利益を、自分で二段階の原価計算から求めてください。

完成品原価は232,000円、売上原価244,000円、売上総利益116,000円、営業利益76,000円です。当月製造費用との差4,000円は、仕掛品が8,000円増え、製品が12,000円減った差から説明できます。

別の在庫一定の翌月計画では、売価1,500円、単位変動費900円、固定費120,000円、目標利益60,000円とします。必要数量300個、目標売上高450,000円です。ここに前月在庫18,000円を勝手に加えないでください。二つの問題が扱う期間と前提が異なります。条件を分けたうえで、それぞれの計算が元の式へ戻るかを確認して総復習に進みましょう。

## 総合資料のどの欄から始めるか

設問が営業利益を求めるなら、売上高から逆にたどり、売上原価と販売費等の不足欄を探します。売上原価が空欄なら月初・月末製品と完成品原価を確認し、完成品原価も空欄なら仕掛品と当月製造費用へ戻ります。この順で不足情報を探せば、資料中のすべての数字を無関係に組み合わせずに済みます。

設問が配賦額を求めるなら、間接費総額、配賦基準総量、各製品の基準量を最初にそろえます。配賦基準が作業時間か販売数量かを決めるのは問題の条件です。売上高が大きい製品へ必ず多く配賦する、という独自の判断に置き換えないでください。

CVPの設問では、直接費か間接費かより、変動費か固定費かが必要です。前半の製品別損益の原価集計と同じ数字が使えそうに見えても、活動量への反応が示されているかを確認します。配賦されているから固定費、一個当たりだから変動費という判断はできません。

## 原価の流れを、数量ではなく金額から確かめる

月初仕掛品、当月投入、月末仕掛品は、いずれも原価の金額です。仕掛品の個数が分かっても、その個数に完成品一個原価を無条件に掛けるわけではありません。この範囲の例では仕掛品の評価額を与えているため、それを使って完成した分の原価を求めます。

たとえば月末仕掛品が10個で30,000円と示されていれば、控除する額は30,000円です。完成品の売価1,200円を掛けた12,000円は原価評価になりません。完成品の数量や売価は売上高の計算へ、在庫の評価額は原価の流れへ対応させます。売価と原価を混ぜないことが、総合問題の基本です。

## 短い総合課題を、別の検算でも確かめる

最後の課題では、月初仕掛品12,000円と月初製品30,000円で、期首の途中・完成在庫を合計42,000円引き継いでいます。当月投入240,000円を加えた282,000円から、月末仕掛品20,000円と月末製品18,000円の合計38,000円を残すと、販売分244,000円になります。

二段階で計算した売上原価244,000円と一致します。製品別の完成・販売の流れを理解した後なら、合計在庫の増減でも全体原価を確かめられます。ただし、当月製造費用に含まれていない費用を途中へ勝手に入れたり、販売費を仕掛品へ含めたりしないよう、同じ集計範囲の金額で照合します。

営業利益76,000円に販売費等40,000円、売上原価244,000円を足すと売上高360,000円へ戻ります。利益から逆に費用を足して収益へ戻す検算は、原価の合計が合っていても販売費を引き忘れた誤りを見つけられます。

## 下の演習で、自分の判断を再現できるようにする

理解度チェックでは、配賦、当月製造費用、完成品原価、売上原価、営業利益を段階ごとに尋ねる問題と、CVPや売上差異の条件を読み分ける問題を用意しています。同じ条件の段階問題は、どの計算から次へつながるかを確認するためのものです。答えの数字だけを覚えず、式の意味も書き残してください。

復習では、誤った設問を「集計範囲」「月初・月末」「変動・固定」「数量・単価」「符号」のどこで間違えたかに分けます。材料費の足し忘れと、月末在庫を足す誤りでは、戻って学ぶ課が異なります。解説から関連課へ戻り、新しい数値で同じ判断ができるかを試してから模擬試験へ進みましょう。

## 同じ総額でも、利益の表示段階を区別する

売上高880,000円から売上原価604,000円を引いた276,000円は売上総利益です。ここから販売費等100,000円を引いて176,000円が営業利益です。「利益」という設問だけを目で追うと、途中の276,000円を最終解答にしやすくなります。求める名称まで読んで、費用をどこまで引いた値かを確認します。

CVPで貢献利益を答えるときも同じです。固定費を引く前の額を問うのか、引いた後の営業利益を問うのかで答えは違います。関係する金額を足し合わせて利益を大きくするのではなく、異なる段階の残額だと考えてください。

一つの問題を復習するときは、答案の各値の横へ「当月に投入した原価」「完成品に移した原価」「売った分の原価」「販売費等控除前」「固定費控除前」などの説明を書きます。式を再計算しなくても、この説明が矛盾していれば、集計範囲や表示段階を取り違えた可能性があります。正しい数値に加えて、その数値が何を表すかを言えることを仕上げの目標にしてください。
