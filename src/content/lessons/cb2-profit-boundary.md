製品を作るために使った原価は、製造原価に集めます。製品が売れたときは、その売れた分に対応する製造原価を売上原価に移します。宣伝や会社全体の管理などにかかった費用は、販売費及び一般管理費として、その期間の利益から差し引きます。この区分により、売上と製品そのものの原価との差、その後に販売・管理の費用まで引いた差を順に求められます。

<span id="objective-1"></span>

## 何のための費用かを読んで、製造・販売・管理を区別する

製造原価には、製品を完成させるための材料、作業、設備の利用などを集めます。製品を買い手に知ってもらう広告や、完成品を顧客に届けるための費用は販売費です。会社全体の人事、経理などにかかる費用は一般管理費に当たります。販売費と一般管理費の合計を**販売費及び一般管理費**といい、資料では**販管費**と略されることもあります。

資料に「梱包資材費」とだけある場合は、梱包の目的を確認します。製品の仕様として包装まで行うのであれば、その包装に使った材料は製造に関係します。すでに完成した商品を買い手に発送するための梱包であれば、販売活動です。費目が同じでも、どの活動で使ったかによって損益計算書へ届く経路が変わります。

### 費用の名前を、活動の証拠に結び付ける

一枚の領収書に複数の活動の費用が含まれる場合は、請求書を発行した会社名や代金を払った部署だけでは集計先が決まりません。内訳に書かれた用途や、使用記録を手掛かりに金額を分けます。たとえば工場が本社の文書保管用の段ボールまでまとめて買った場合でも、その段ボールの使用目的は会社全体の管理です。反対に、本社が製品の包装材をまとめて発注しても、製品が完成するまでに使う分は製造活動へ集めます。

初めに各金額の集計先を決め、その後で製造・販売・管理の小計を照合します。こうすると、集計する費用の合計が合っていても、用途を取り違えて二つの利益がずれた場合に原因を見つけやすくなります。

### 例題1　同じ費目の内訳を、活動ごとに振り分ける

文具工場では、製品の仕様として定規を紙箱に入れ、箱詰めまでを製造工程に含めています。一方、出荷の担当者は、完成済みの定規を顧客へ送るために配送用の段ボールを使います。全社の総務部でも、文書の保管に段ボールを使いました。

| 使用記録 | 金額 | 集計先と理由 |
| --- | ---: | --- |
| 定規の製造に使った製品用の紙箱 | 9,500円 | 製品が完成するまでに消費したため、製造原価 |
| 出荷用の段ボール | 5,000円 | 完成済みの製品を顧客に届けるため、販売費 |
| 総務部が使った文書保管用段ボール | 2,500円 | 全社の文書管理に使うため、一般管理費 |

製造原価に入る金額は9,500円です。販売費と一般管理費は5,000＋2,500＝7,500円で、元の17,000円を9,500円と7,500円に分けられます。「梱包資材」は品物の呼び名です。集計では、資材をどの活動に使ったかを根拠にします。

## 完成した分と売れた分を分け、利益を二段階で求める

製品が完成しても、売れていないものは会社に残っています。完成品の原価をすべて当月の費用にすると、売れていない製品の原価まで今月の売上高から差し引くことになります。この章の計算では、前月から繰り越した製品も未完成品もなく、完成品の1個当たり原価は同一とします。その条件なら、完成品の原価総額を完成数で割り、販売数に対応する金額を求められます。

**売上総利益**は、製品の販売額と売った製品の原価との差です。そこには宣伝や全社の管理にかかった費用が含まれていないため、それらを差し引いて求める**営業利益**とは異なります。資料に販売費と一般管理費が別々に記されているときは、両方を足してから売上総利益より差し引きます。

### 例題2　80個を作り、64個を販売した

同じ製品を80個完成させ、その製造原価は120,000円でした。期首製品と期首・期末仕掛品はありません。当月に64個を1個2,700円で販売しました。販売費は16,000円、一般管理費は8,500円です。売上原価と二つの利益を求めます。

| 計算欄 | 計算 | 金額 |
| --- | --- | ---: |
| 完成品の単位原価 | 120,000円÷80個 | 1,500円/個 |
| 売上高 | 64個×2,700円/個 | 172,800円 |
| 売上原価 | 64個×1,500円/個 | 96,000円 |
| 売上総利益 | 172,800円−96,000円 | 76,800円 |
| 販管費 | 16,000円＋8,500円 | 24,500円 |
| 営業利益 | 76,800円−24,500円 | 52,300円 |
| 期末製品の原価 | 16個×1,500円/個 | 24,000円 |

完成数80個で単位原価を求め、販売数64個で売上原価を求めたところがこの計算の要点です。売上原価96,000円と期末製品24,000円を足すと、完成した80個の原価120,000円に戻ります。売上総利益と営業利益の差24,500円も、資料にある販管費と一致します。

## 用途を訂正したとき、在庫と利益のどこに影響するか

費用を製造原価から販管費へ移すと、製造原価が減り、販管費が増えます。製品に売れ残りがある場合は、もとの製造原価の一部が期末製品に入っていたため、製造原価の減少額が売上原価へすべて反映されることはありません。販管費へ移した額は、当月に全額を差し引きます。

両方の差額が異なるときは、利益と在庫のどちらに金額が移ったかを追います。すべて販売した場合なら、完成品の原価が全部売上原価になるため、売上原価の減少額と販管費の増加額が等しくなります。

### 例題3　共用電力の用途が判明し、原価の集計先を訂正した

ある工場では製品60個を完成させ、48個を1個2,200円で販売しました。すべて同じ単位原価で、期首製品と期首・期末仕掛品はありません。訂正前の製造原価90,000円には共用建物の電力料がすべて入っていて、販管費は16,000円です。その後、電力使用記録から、うち3,000円は全社の管理業務に使ったと分かりました。

まず、電力3,000円を製造原価から一般管理費へ移します。製造原価は87,000円となり、販管費は19,000円に増えました。製造原価と販管費を足した106,000円そのものは変わりません。

| 項目 | 訂正前 | 訂正後 |
| --- | ---: | ---: |
| 単位原価 | 1,500円/個 | 1,450円/個 |
| 売上高 | 105,600円 | 105,600円 |
| 売上原価（48個分） | 72,000円 | 69,600円 |
| 売上総利益 | 33,600円 | 36,000円 |
| 販管費 | 16,000円 | 19,000円 |
| 営業利益 | 17,600円 | 17,000円 |
| 期末製品（12個分） | 18,000円 | 17,400円 |

訂正により、売上原価は1個50円×48個＝2,400円減り、売上総利益が2,400円増えました。そこから差し引く販管費は3,000円増えたため、営業利益は600円減ります。残り600円は、訂正前には12個の在庫に含まれていた金額です。訂正後は当月の一般管理費に含まれるため、期末製品も600円減っています。

### 例題　売上総利益の増加から、用途を訂正した金額を逆算する

製造原価から販売費へある金額を移したとき、売上総利益が増えるのは、そのうち販売済みの製品の原価から外れた分です。売上高と数量が変わらず、同じ単位原価の製品だけを扱うなら、売上総利益の増加額と販売割合から、移した金額を逆向きに求められます。

同じ製品100個を完成させ、75個を1個2,400円で売りました。期首の製品と期首・期末仕掛品はありません。訂正前の製造原価は120,000円、販管費は36,000円です。その後、販売活動の費用が製造原価に入っていたため、製造原価から販売費へ移しました。この変更だけで、売上総利益が3,600円増加しました。

売上高は一定なので、売上総利益の増加3,600円は、売上原価の減少でもあります。当月の販売割合は75個÷100個＝4分の3。移した費用の4分の3が3,600円に当たることから、振り替えた額は3,600円÷（75個÷100個）＝4,800円です。差の1,200円は、訂正前には売れ残り25個が負担していました。

### 例題　売れ残りが翌月に売れたとき、各月の利益を確かめる

製造原価に入れた費用は、製品が売れた月に売上原価になります。目的から見て販売費に当たる費用は、その販売活動を行った月の費用です。売れ残りが翌月に売れると、分類の訂正による営業利益の変化が、二つの月にまたがって現れます。この例では、同じ月に作った一種類の製品だけを追い、翌月に新たな製造はないものとします。

6月に同じ製品を100個完成させ、60個を1個2,400円で販売しました。6月初めに製品はなく、仕掛品はありません。6月の製造原価に集計した150,000円のうち、5,400円は6月に行った販売広告の費用でした。この広告費とは別に、6月に販管費18,000円が発生しています。残り40個は7月に同じ単価ですべて売り、7月の販管費は12,000円です。両月の営業利益を、広告費の集計先を直す前と後で比べます。

費用の訂正は6月に行います。製品を作るために使った額は150,000−5,400＝144,600円、1個当たりの製造原価は1,446円です。訂正前は1個1,500円なので、広告費54円を各製品が負担していました。6月末に残る40個からは54円×40個＝2,160円が外れます。ここを押さえると、翌月に売上原価へ移る額がどれだけ変わるかを先に見通せます。

| 原価や費用が移る場所 | 訂正前 | 訂正後 | 訂正が及ぶ理由 |
| --- | ---: | ---: | --- |
| 6月に販売した60個の売上原価 | 90,000円 | 86,760円 | 60個分の広告費3,240円が売上原価から外れる |
| 6月末に残った40個の在庫 | 60,000円 | 57,840円 | 40個分の広告費2,160円が在庫から外れる |
| 6月の販管費 | 18,000円 | 23,400円 | 6月に行った広告の5,400円を全額集める |
| 7月に販売した40個の売上原価 | 60,000円 | 57,840円 | 前月から繰り越した原価を、40個の販売に対応させる |
| 7月の販管費 | 12,000円 | 12,000円 | 今回の広告は6月に行ったため、7月には計上しない |

6月の売上高は60×2,400＝144,000円です。訂正前の営業利益は144,000−90,000−18,000＝36,000円、訂正後は144,000−86,760−23,400＝33,840円となります。売上原価は3,240円減りましたが、広告費全額5,400円を販管費へ加えたため、営業利益は2,160円減ります。

7月の売上高は40×2,400＝96,000円。訂正前の営業利益は96,000−60,000−12,000＝24,000円、訂正後は96,000−57,840−12,000＝26,160円です。7月には新たな広告費を加えず、6月末から繰り越した製品の原価だけが2,160円減ります。そのため、7月の営業利益は同額だけ増えます。

2か月分を合わせた営業利益は、訂正前が36,000＋24,000＝60,000円、訂正後も33,840＋26,160＝60,000円です。7月にすべて売れた時点では、広告費5,400円の全額が、訂正前・訂正後のどちらでも2か月分の費用に含まれます。2か月の合計が同じでも、月ごとの営業利益には2,160円ずつ差が出ます。7月の売上高はどちらも96,000円です。訂正による利益の増加は、6月の広告費が7月の売上原価から外れたことで説明できます。利益の変化を読むときは、販売数や売価の変化と、前月から引き継いだ原価の変化を分けて確認します。

## 練習　完成数、販売数、集計先を自分で見分ける

製品50個の製造原価として90,000円を計上しました。そのうち6,000円は、完成した製品を宣伝するために支出した広告費です。当月の販売数は40個、販売単価は2,500円。広告費以外の販管費は11,000円です。期首製品も仕掛品もなく、完成品の単位原価は同じとします。正しい売上原価、売上総利益、営業利益、期末製品を求めてください。

<details id="try-profit-boundary-transfer">
  <summary>解答と計算欄の照合を確認する</summary>
  <p>広告費を販売費へ移すと、製造原価は90,000−6,000＝84,000円、販管費は11,000＋6,000＝17,000円です。単位原価は84,000÷50＝1,680円。販売40個に対応する売上原価は67,200円なので、売上総利益は100,000−67,200＝32,800円、営業利益は32,800−17,000＝15,800円です。期末製品は10×1,680＝16,800円。売上原価67,200円と合わせると、訂正後の製造原価84,000円になります。</p>
</details>

この章では未完成品や前月の製品を置かずに、販売分の原価と在庫を分けました。[売上原価と損益計算のレッスン](../cb2-pnl/)では、月初と月末の製品がある問題へ進みます。
