工場の原価を集めた資料に、木材代、組立担当者の賃金、電気代、営業担当者の給料が並んでいたとします。すべて会社に必要な支出ですが、「製品を作るためにいくら使ったか」を知るには、同じ箱へまとめるだけでは不十分です。使った資源の種類と、それを使った活動の二つを確かめましょう。

<span id="objective-1"></span>

## 物、人の作業、それ以外の製造資源に分ける

木材を切って家具を作ると、木材という物を消費します。その消費から生じる原価が材料費です。主要な原材料だけでなく、製造で消費する補助的な物品も含めて考えます。製品に大きく目立って残る物だけが材料とは限りません。どの活動で何を使ったかを読み、製造のための物品消費を判断します。

家具を組み立てる担当者の作業は、労働力という資源の消費です。製造に関する賃金などを労務費に分類します。材料費と労務費の違いは、支払先が会社か個人かではなく、何を消費したかです。また、作業者へ実際に現金で払った日だけを見るのではなく、対象期間の製造活動に対応する労務費を考えます。

製造に使う資源のうち、材料費と労務費に当たらないものを経費に分類します。工場の電力料、工場の賃借料、製造設備の減価償却費などが例です。日常語では「経費」を会社の支出全般の意味で使いますが、この形態別分類では範囲が狭くなります。「材料費も会社の経費だから経費へ入れる」とすると、三つの分類が重なってしまいます。

減価償却費は、長く使う設備の取得額を使用期間へ配分した費用です。設備を買った月に、その購入額をすべて当月の製造原価へ入れるとは限りません。このコースの問題では当月分の減価償却費などを条件として示します。設備の購入額と、当月の設備使用に対応する金額を区別してください。

| 消費した資源の例 | 製造に使った場合の分類 | 分類の根拠 |
| --- | --- | --- |
| 製品に使う木材・鋼材 | 材料費 | 物品の消費 |
| 組立作業の労働力 | 労務費 | 人の労働力の消費 |
| 工場で使った電力 | 経費 | 材料費・労務費以外の製造資源 |
| 工場建物を借りたことによる使用 | 経費 | 当月の建物利用に対応 |
| 製造設備の当月の減価償却 | 経費 | 設備の期間的な使用に対応 |

### 例題1：製造原価を三つの形態へ集計する

当月の製造で、木材を84,000円分、製造用の接着剤を6,000円分使いました。製造作業の賃金は75,000円、工場の電力料は12,000円、工場賃借料は30,000円、製造設備の減価償却費は8,000円です。すべて当月の消費額で、他の製造原価はありません。

材料費は木材84,000円と接着剤6,000円を合わせた90,000円です。接着剤が補助的だからという理由で外すと、使った物品の原価が集計から抜けます。労務費は賃金75,000円です。経費は電力料12,000円、賃借料30,000円、減価償却費8,000円を足して50,000円となります。

製造原価の合計は90,000＋75,000＋50,000＝215,000円です。元の六つの金額をそのまま足しても215,000円となるか確かめます。分類後の合計が大きくなったら二重計上、小さくなったら分類漏れの可能性があります。三つに分類するのは総額を変えるためでなく、何を消費したかが見える形へ整理するためです。

## 同じ「給料」でも、製造と販売では集計先が違う

次に活動の目的を確かめます。製品を作るための原価は製造原価、製品を売るための費用は販売費、会社全体を管理するための費用は一般管理費です。販売費と一般管理費を合わせて、販売費及び一般管理費といいます。問題や表では「販管費」と短く示すこともあります。

工場の組立担当者の賃金は製造原価の労務費ですが、営業担当者の給料は販売活動の費用です。同じ人への支払いでも、何を行うための作業かで集計先が変わります。本社の管理担当者の給料は、問題の条件がそのように与えられていれば一般管理費になります。勘定科目の名前だけを見て、給料はすべて製造原価へ入れるという決め方はできません。

また、工場の電気代は製造原価、本社管理部の電気代は一般管理費、販売店舗の電気代はその販売活動の費用と考えます。一つの請求書にまとめて記載されていても、使用場所や活動が分かれていれば内訳を分けて読む必要があります。このとき、建物の名前よりも問題で指定された使用目的を優先します。

完成品を買い手に届けるための発送費や、販売の広告費も販売活動に関係します。材料を工場へ受け入れるための運送費とは役割が違います。ただし、原価へ含める金額は問題の指定に従います。「運賃」という単語が出たら一律に同じ分類を選ぶのでなく、何をどこへ運ぶ費用なのかを読みましょう。

<span id="worked-2"></span>

### 例題2：一枚の支払一覧から製造と販売・管理を分ける

当月の費用一覧は次のとおりです。金額はすべて当月分で、それぞれ示した活動だけに使われています。

| 費用項目 | 金額 |
| --- | ---: |
| 製造担当賃金 | 96,000円 |
| 営業担当給料 | 54,000円 |
| 本社管理担当給料 | 40,000円 |
| 工場電力料 | 18,000円 |
| 販売広告費 | 12,000円 |
| 本社通信費 | 5,000円 |

製造原価に入れるのは製造担当賃金96,000円と工場電力料18,000円で、合計114,000円です。販売費は営業担当給料54,000円と広告費12,000円で66,000円、一般管理費は本社給料40,000円と通信費5,000円で45,000円となります。したがって販売費及び一般管理費は66,000＋45,000＝111,000円です。

六つの金額の総額225,000円は、114,000＋111,000＝225,000円と一致します。「人に関する費用」だけを先に集めると190,000円ですが、これをそのまま製造の労務費と扱うと、営業と管理の給料94,000円が混ざります。資源の種類を読む前後に、製造か販売・管理かの範囲を確かめる必要があります。

### なぜ製造と販売・管理を分けるのか

製造原価を集計すると、製品を作る活動にいくらかかったか分かります。製品が完成してもまだ売れていなければ、その原価の一部は製品在庫として残ります。売れた製品に対応する製造原価が売上原価となり、売上高と比較されます。販売費及び一般管理費は、その期間の販売・管理活動の費用として別に示します。

この違いを無視して、工場で発生した原価と販管費をすべて「当月作った製品の原価」へ入れると、製品の原価と販売活動の費用を区別できません。ここでは損益計算書の細かい作成まで覚えず、「作るため」と「売る・管理するため」の区分が、後で在庫と利益を計算する土台になると理解してください。

## 分類は二段階で行い、合計で確かめる

資料を読む順番は、まず製造と販売・管理を分け、次に製造の金額を材料費・労務費・経費へ分けると整理しやすくなります。最初からすべてを一度に判断する必要はありません。一つの金額に分類先を一つずつ付け、判断できない項目は使用目的の条件を探します。

分類は名前を付けるだけの作業に見えますが、計算の前提を作る重要な判断です。製造原価の総額を尋ねられたら、材料費だけを計算して終わらず、製造の労務費と経費を加えます。経費の額を尋ねられたら、製造原価総額から材料費と労務費を引いて求めることもできます。正方向と逆方向で同じ関係を使えるようにしましょう。

<span id="worked-3"></span>

### 例題3：混ざった内訳と、一部不明の経費

工場と本社を合わせた当月の原価・費用が310,000円です。このうち販売費及び一般管理費が70,000円、製造の材料費が110,000円、製造の労務費が85,000円と分かっています。他の区分は製造の経費だけです。

はじめに、全体310,000円から販管費70,000円を引き、製造原価240,000円を求めます。その製造原価から材料費と労務費を除くので、経費は240,000−110,000−85,000＝45,000円です。310,000−110,000−85,000＝115,000円で止めると、販管費70,000円が経費に混ざったままになります。

検算は110,000＋85,000＋45,000＋70,000＝310,000円です。求めた45,000円は「当月の製造経費」であり、「企業全体の現金支払額」や「材料購入額」を求めたのではありません。答えの名称を数字の横に書くと、計算の途中で集計対象が変わっていないか確認できます。


### 工場で払ったことと、製造に使ったことを区別する

支払いを担当した部署だけでは、費用の目的は決まりません。工場の事務担当者が販売広告の代金をまとめて払ったとしても、その広告は販売活動の費用です。逆に本社が工場の電力料を払っていても、使った場所と目的が製造なら製造原価です。支払伝票の部署名と、資源を消費した活動が一致しているかを確認します。

また、すべての製造原価が直ちに当月の費用になるとは限りません。製造に投入した材料費や労務費が未完成品に含まれて残る場合、その部分は仕掛品の原価です。形態別に集計する段階では「作るために何を使ったか」を整理しており、「当月に売れた分の原価」をすでに求めたわけではありません。各計算がどの段階まで進んでいるかを、表の見出しで読みます。

<span id="worked-4"></span>

### 例題4：総額が同じでも、内訳の変化を読み取る

前月の製造原価は材料費90,000円、労務費70,000円、経費40,000円で、合計200,000円です。当月は材料費80,000円、労務費85,000円、経費35,000円で、合計200,000円でした。総額だけ見ると変化がありませんが、材料費は10,000円減り、労務費は15,000円増え、経費は5,000円減っています。

この表から言えるのは、それぞれの消費額と総額の変化です。なぜ変わったかを判断するには、製造数量、材料単価、作業時間などの資料が必要です。「材料費が減ったから材料の使い方が改善した」と原因まで断定しないでください。分類する目的の一つは、何を追加で調べればよいかが見えるようにすることです。単なる名称の暗記にせず、内訳を読む道具として使います。

## 使用場所が分かれるときの練習

まず、工場と本社が共同で使う建物の当月賃借料80,000円のうち、工場分60,000円、本社管理分20,000円と指定されている場合を考えます。製造経費へ入るのは60,000円、一般管理費へ入るのは20,000円です。支払先が一つであることや、請求書が一枚であることは、全額を同じ活動に入れる根拠になりません。

自力で次を分類してください。製造用材料の消費額42,000円、製造担当賃金36,000円、工場の電力料7,000円、工場設備の減価償却費5,000円、営業担当給料18,000円、本社管理費用12,000円です。製造原価の三つの小計、製造原価総額、販管費を求めます。

材料費42,000円、労務費36,000円、経費7,000＋5,000＝12,000円、製造原価は90,000円です。販管費は18,000＋12,000＝30,000円となります。全体120,000円が90,000円と30,000円に分かれています。設備の減価償却費に当月の現金支払いがなくても、当月の製造に対応する資源の消費として含める点を説明できるか確かめましょう。

分類に迷った項目があれば、「何に使ったか」「何を消費したか」を一文で書いてみてください。工場の監督者の給料なら製造のための労働力、営業所の家賃なら販売活動のための建物利用です。次のレッスンでは、これに「特定の製品へ直接結び付けられるか」という別の見方を加えます。
