## 同じ入金でも、所得の種類で計算が変わります

会社から受け取る給料、店の売上、自宅を貸した家賃、銀行の利子は、いずれも個人のお金を増やします。しかし、所得税の計算では一つの収入欄へまとめません。まず納税する人の範囲を確認し、次に収入の性質を判定します。区分によって差し引ける費用、損失の扱い、他の所得と合算するかどうかが変わるためです。

所得税法は所得を十種類に区分します。名前を覚えた後は、誰が何をして得た対価なのかを一文で説明してください。「毎月もらうから給与」「一度きりだから一時所得」という頻度だけの判定では、契約や所得の性質を取り違えることがあります。

## 人の区分を先に確かめます

国内に住所がある人、又は現在まで引き続き一年以上国内に居所がある人は、所得税法上の居住者です。住所は生活の本拠という実質から判断します。日本国籍を持つかどうかだけで決まる区分ではありません。例えば、国内に生活の本拠がある外国籍の人も、条件を満たせば居住者になります。

居住者のうち非永住者に当たる人には国外源泉所得等の特則があり、それ以外の居住者と課税対象が同じとは限りません。また、非居住者では国内源泉所得の規定を確認します。ここでは「非永住者以外の居住者で、国内の所得だけがある」という条件から始めます。外国の勤務や送金が登場したら、この条件を外して納税義務の範囲から検討し直す必要があります。

## 十区分を、収入が生まれる場面と結び付けます

| 区分       | 最初に思い浮かべる場面     | 主な確認点             |
| ---------- | -------------------------- | ---------------------- |
| 利子所得   | 預貯金の利子等             | 商品の種類、源泉分離等 |
| 配当所得   | 法人の利益の配当等         | 株式の種類、課税方式   |
| 不動産所得 | 土地や建物の貸付け等       | 貸付対象、必要経費     |
| 事業所得   | 独立して営む事業           | 活動の実態、帳簿       |
| 給与所得   | 雇用に基づく給与等         | 給与収入、給与所得控除 |
| 退職所得   | 退職に基因する一時金等     | 勤続年数、支給の区分   |
| 山林所得   | 一定の山林の伐採・譲渡     | 保有期間、対象資産     |
| 譲渡所得   | 資産の譲渡                 | 資産の種類、保有期間   |
| 一時所得   | 法定条件を満たす一時の所得 | 対価性、支出、特別控除 |
| 雑所得     | 他の九区分に当たらない所得 | 年金、業務、必要経費等 |

この表は判定の出発点です。商品として仕入れた品を売る店の売上は、資産を売ったという言葉だけで譲渡所得にしません。事業で商品を販売する収入として検討します。同様に、不動産の売却と貸付けを区別します。貸付けの規模が大きいという事情だけで、家賃収入が当然に事業所得へ変わるわけでもありません。

事業所得と業務に係る雑所得の区別では、営利性、継続性、独立性等の実態を踏まえます。「副業」という呼び方や開業届を出したという一つの事実だけでは結論が出ません。公的年金等も雑所得に含まれますが、業務の収支と同じ計算欄へ無条件に合算して経費を引くのではなく、法定の計算を確認します。

## 収入と所得を二段階で整理します

独自の例として、2025年に小売業の売上500万円、必要経費として認められる売上原価・家賃等320万円があり、青色申告特別控除をまだ考えないとします。この段階の事業所得は500－320＝180万円です。500万円が総収入金額、180万円が費用等を差し引いた所得です。収入の大きさと税を計算する所得の大きさを分けます。

同じ人に給与収入800万円があり、適用する給与所得控除を190万円と与えると、給与所得は610万円です。給与には小売業と同じように日々の生活費を実額で引く計算をしません。この例の事業所得180万円と給与所得610万円は、他の調整がない条件なら合計790万円となります。まだ所得控除や税額の計算前の段階です。

条件を変え、事業の必要経費が350万円なら、事業所得は150万円へ下がり、合計は760万円です。売上500万円と給与収入800万円をそのまま足した1,300万円を「所得」とする誤りや、給与所得610万円から小売業の経費を再度引く二重控除を避けてください。

## 借入れ・非課税・控除には、それぞれ別の理由があります

銀行から借りた100万円は、返済義務を伴う資金調達です。事業の売上100万円とは性質が違います。また、預けたお金を自分の口座間で移動しても、それだけで新しい所得が生じるわけではありません。入金一覧から所得を求めるときは、まず収入の原因を調べます。

所得に当たり得る経済的利益でも、法令が非課税とするものがあります。例えば、通常必要と認められる範囲の一定の通勤手当や、身体の傷害に基因する一定の保険金等には非課税の規定があります。名称だけで全額を非課税と決めず、対象と限度等を確かめます。相続・贈与で取得した財産にも所得税と相続税・贈与税の区分が関わります。

一方、基礎控除や扶養控除は、課税対象となる所得の計算後に個人の事情等を反映する所得控除です。非課税収入をいったん事業売上へ入れて基礎控除で相殺する、という仕組みではありません。どの段階で除く金額かを分けることで、控除額が変わった年も計算の順序を保てます。

## 総合課税と分離課税を、区分の次に確認します

総合課税では一定の所得を合算し、所得控除後の課税所得へ税率を適用します。これに対し、土地建物や株式等の譲渡には、他の所得と区分して申告する分離課税等があります。十種類の所得区分と課税方式は、違う切り口です。譲渡所得と判定した後にも、何を譲渡したのかに応じて計算を進めます。

## 同じ入金でも、受け取る理由を確かめます

個人が銀行口座へ受け取った30万円を、通帳だけで所得区分へ振り分けることはできません。商品の代金、賃貸料、借入金、預けていた保証金の返還では意味が異なります。借入金には返済義務があり、元本を借りたことだけで所得が30万円増えるわけではありません。最初に契約書や請求書から、誰が何の対価として支払ったかを確認します。

例えば、会社員が休日に所有アパートを貸して賃料を受け取る場合、本業が会社員であることを理由に給与所得へまとめません。貸付けの対価は不動産所得として検討します。一方、勤務先から労務の対価として受ける給与は給与所得です。「人の職業」と「個々の収入の性質」を分けて読むと、複数の所得を持つ人の計算へ進めます。

非課税所得は、課税所得を計算した後に税額から差し引く制度ではありません。所得控除や税額控除と同じ欄へ並べると、どの段階から除くのかが不明確になります。解答では、課税対象に入るか、入るならどの所得か、控除はどの段階かを順に記述してください。生活上の名称だけで判定が難しい場合は、契約や法令上の要件へ戻る姿勢が必要です。

復習では、給与、店の売上、店舗家賃、借入金の四つを並べ、それぞれの原因と計算の入口を説明します。続く事業所得の学習では、入金した年と収入を認識する年、支出した額と必要経費になる額を、帳簿の例で確かめます。
