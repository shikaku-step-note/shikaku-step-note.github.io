損益計算書は、ある一期間の収益と費用から、その期間の利益又は損失を説明する表です。期末に現金がいくら残るかを示す表ではありません。売掛金の回収は入金でも新しい売上ではなく、減価償却費は出金がなくても費用です。取引の現金収支と、当期の成果を分けて読みます。

この課では、決算整理を終えた勘定残高から損益計算書を作ります。三分法の売上原価、費用・収益の期間対応、固定資産売却損益、法人税等を復習しながら、各段階の利益をつなげます。設問の表示様式を優先し、勘定科目名を財務諸表の表示名へ読み替える練習も行います。

<span id="objective-1"></span>
## 売上高と売上原価を対応させる

売上高は、当期の商品販売による収益を、返品等を反映した後の金額で示します。商品の売価と仕入原価を同じ金額と思わないでください。売上原価は、当期に売れた商品の原価です。売上高から売上原価を差し引くと、商品売買から生じた売上総利益になります。

三分法で期末整理前の資料を使う場合、売上原価は期首商品＋当期純仕入高−期末商品で求めます。当期純仕入高には設問で原価へ含める仕入付随費用を加え、仕入返品を差し引きます。仕入勘定で売上原価を算定済みの整理後残高が与えられる場合は、その残高へ期首・期末商品をもう一度加減しません。

例えば整理後の仕入残高が500,000円なら、その設例で売上原価へ読み替えます。期首商品60,000円と期末商品82,000円の情報が表に残っていても、既に整理へ使ったものなら二重に加減しないようにします。資料が整理前か整理後かを、最初に確認する理由です。

<span id="worked-1"></span>
### 例題1：売上総利益までを、元の明細から作る

当期の売上記録総額900,000円、売上返品20,000円、期首商品60,000円、仕入記録総額520,000円、仕入返品10,000円、仕入へ含める引取運賃12,000円、期末商品82,000円です。これらは整理前の明細で、税金は考えません。

純売上高は900,000−20,000＝880,000円。当期純仕入高は520,000−10,000＋12,000＝522,000円。売上原価は60,000＋522,000−82,000＝500,000円です。したがって売上総利益は880,000−500,000＝380,000円となります。

期末商品82,000円は来期へ持ち越す資産なので、当期の売上原価から除きます。売上総利益の計算で期末商品を費用へ加えると、まだ売っていない商品の原価も当期の売上へ対応させることになります。数量の流れと同じく、売れた分と残った分を分けて考えてください。

## 支払いの有無と分けて、当期の費用を集める

給料、家賃、水道光熱費、保険料、減価償却費などは、当期に対応する整理後残高を使います。未払給料を追加した場合、その費用はまだ支払っていなくても損益計算書へ入ります。翌期分保険料を前払へ振り替えた場合、その金額は既に支払っていても当期費用へ含めません。

売掛金に対する貸倒引当金繰入も、当期の費用として示します。貸倒引当金の期末残高そのものを費用へ入れないことを確認します。繰入額は当期の費用、引当金残高は売掛金から控除する項目で、別の役割です。減価償却費と累計額も同じように区別します。

<span id="objective-2"></span>
## 勘定式では費用を借方、収益を貸方へ並べる

2026年度3級で学ぶ損益計算書は、勘定式の作成を中心に扱います。費用を左側、収益を右側へ配置し、収益と費用の差を当期純利益又は当期純損失として示します。金額を並べる前に、各科目が費用か収益かを判断してください。ここでは2級の報告式や細かな区分表示を必須技能として求めません。

当期の費用は通常借方残高、収益は貸方残高なので、整理後試算表の該当行をそれぞれの側へ移します。ただし資産や負債の行は、名前が似ていても損益計算書へ直接入れません。前払保険料と支払保険料、未収利息と受取利息などを一組ずつ比べると、何が期末残高で何が当期損益かを確認できます。

<span id="worked-2"></span>
### 例題2：整理後残高から勘定式損益計算書を完成する

例題1の売上高880,000円、売上原価500,000円へ、次の整理後費用・収益を加えます。給料140,000、支払家賃60,000、水道光熱費24,000、支払保険料18,000、減価償却費40,000、貸倒引当金繰入5,000。受取利息3,000、支払利息8,000、固定資産売却益12,000、法人税等30,000です。他の項目はありません。

費用は500,000＋140,000＋60,000＋24,000＋18,000＋40,000＋5,000＋8,000＋30,000＝825,000円。収益は880,000＋3,000＋12,000＝895,000円。その差70,000円が当期純利益です。売上高だけから費用を引くと、ほかの収益15,000円が抜けます。収益の全科目を集めてから差を取ります。

| 費用側（借方） | 金額 | 収益側（貸方） | 金額 |
| --- | ---: | --- | ---: |
| 売上原価 | 500,000円 | 売上高 | 880,000円 |
| 給料 | 140,000円 | 受取利息 | 3,000円 |
| 支払家賃 | 60,000円 | 固定資産売却益 | 12,000円 |
| 水道光熱費 | 24,000円 |  |  |
| 支払保険料 | 18,000円 |  |  |
| 減価償却費 | 40,000円 |  |  |
| 貸倒引当金繰入 | 5,000円 |  |  |
| 支払利息 | 8,000円 |  |  |
| 法人税等 | 30,000円 |  |  |
| 費用合計 | 825,000円 | 収益合計 | 895,000円 |
| 当期純利益 | 70,000円 |  |  |
| 最終合計 | 895,000円 | 最終合計 | 895,000円 |

費用側へ利益70,000円を置くのは、少ない側へ差額を記入して両側をそろえるためです。利益が費用の一種になるわけではありません。収益895,000円から費用825,000円を差し引いた結果を、勘定式の中で表示しています。利益の欄と、元の費用科目を区別してください。

売上原価の表示名が「仕入」と指定され、整理後の仕入勘定で売上原価を算定済みの答案なら、その名称に従います。前の例の500,000円と同じ内容です。仕入の整理前購入額522,000円をそのまま写さず、指定様式と資料の処理段階を確認します。

### 同じ科目の複数の残高を先にまとめる

店舗Aの給料80,000円、本部の給料60,000円を同じ給料科目へまとめる設問なら、損益計算書の給料は140,000円です。逆に「給与手当」「支払手数料」等が別科目として示されるときは、指示なく雑費へまとめません。金額の縦合計を短くするために科目を省略しないことが必要です。

元帳の当期記入合計と差引残高も区別します。給料勘定の借方記入150,000円、誤記訂正による貸方10,000円なら、当期費用は差引140,000円です。借方の取引金額をすべて足した150,000円だけで損益計算書を作ると、正しく取り消した10,000円が費用へ戻ってしまいます。

### 損失の場合は、収益側へ差額を置く

別の会社で収益合計420,000円、費用合計448,000円なら、当期純損失は28,000円です。少ない収益側へ損失28,000円を置き、両側448,000円でそろえます。左右をそろえる位置を暗記する前に、収益と費用のどちらが多いかを確かめます。

損失を費用側へ足すと476,000円対420,000円となり、差が広がります。逆に利益の例で収益側へ差額を足しても合いません。差額を求める計算、利益か損失かの判断、表示する側の選択を三段階に分けて練習してください。

<span id="objective-3"></span>
## 決算整理の漏れが、利益のどこを変えるか追う

未払給料8,000円の追加を忘れれば、費用合計が8,000円少なく、法人税等を控除する前の利益が8,000円多くなります。未収利息2,000円を落とした場合は、受取利息という収益が2,000円少なくなります。費用の増減なのか収益の増減なのかを分けて、利益へどう影響するかを追ってください。

税額が指定の確定額なら、その額を設問どおりに使います。税引前利益に率を掛ける設例なら、調整後の税引前利益で税額も計算し直す必要があります。この二つの条件を区別せず、どの問題でも利益差額に税率を掛けると、指定を変えてしまいます。

<span id="worked-3"></span>
### 例題3：期末商品を取り違えた利益を直す

商品期末残高を本来82,000円のところ72,000円と誤って使ったとします。例題1の売上原価は510,000円となり、正しい500,000円より10,000円多くなります。売上総利益と、法人税等控除前の利益は10,000円少なくなります。

税額が30,000円で固定指定なら、誤った当期純利益は60,000円、正しくは70,000円です。もし別の設例で税額を税引前利益の30％と指定するなら、誤った税引前利益90,000円に対する税額27,000円、純利益63,000円になります。正しい純利益70,000円との差は7,000円です。条件が変われば最終影響額も変わります。

資産の期末商品も10,000円少なくなっているので、貸借対照表では商品と純資産が関連して誤ります。棚卸の資料が損益計算書にも貸借対照表にも影響する理由を、当期費用から除いた商品が期末資産へ残る関係から説明してください。

### 自力演習：収入と収益を分けて、当期利益を求める

当期の商品販売による売上は500,000円、売掛金の回収は420,000円、売上原価は300,000円、当期費用として整理済みの給料等150,000円、法人税等10,000円です。ほかの収益費用はありません。当期純利益を求めてください。

500,000−300,000−150,000−10,000＝40,000円です。回収420,000円は当期売上と二重に加算しません。売掛金の期首残高や期末残高がある可能性もあり、回収額が売上額と違っていても矛盾しません。損益計算書へ入れるのは収益と費用であって、すべての入金と出金ではありません。

### 期末の残高を、費用の累計と取り違えない

減価償却累計額120,000円、当期減価償却費30,000円と示された場合、損益計算書の減価償却費へ入るのは30,000円です。貸倒引当金の期末残高6,000円、当期繰入額2,000円なら、費用は2,000円。残高と当期増減額を分ける考え方は、二つの控除勘定に共通します。

前払保険料12,000円は来期以降のサービスを受ける権利で、当期の保険料ではありません。未払給料7,000円は負債ですが、それに対応する当期費用は給料に含めます。資産や負債の名前が資料にあるから費用・収益から外して終わりにせず、その整理がどの当期項目を調整したかまで追ってください。

## 最終利益を貸借対照表と結ぶ

当期純利益は、他の条件が同じなら純資産を増やします。締切処理前の繰越利益剰余金へ当期純利益を加え、決算後の利益剰余金へつなぐのは後の課で扱います。損益計算書に利益70,000円が出たから現金が70,000円増えたとは言えませんが、その期間の純資産変化を説明する一部になります。

解き終えたら、期間と単位、純売上高、売上原価、整理後の当期費用、費用収益の配置、小計と最終利益を見直します。利益がたまたま一致しても、売上と費用を同額ずつ過大にしている可能性は残ります。各行を元の勘定と資料へ戻して確かめることが、答案を作る練習になります。
