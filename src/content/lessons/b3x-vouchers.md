店に届く領収書や請求書は、形も取引の内容もさまざまです。その内容を社内の決まった書式へ写して記録する方法の一つが伝票制です。ここでは入金・出金・振替の三種類を使います。一つの仕訳をどの伝票で表すかを考えながら、書式の使い方を学んでいきます。

<span id="objective-1"></span>

## 三種類の伝票は、会社の現金が動くかで選ぶ

入金伝票には現金が増える取引、出金伝票には現金が減る取引を記録します。振替伝票には、現金の増減を伴わない取引を借方・貸方の形で記入します。「振替」という名前でも、口座間の振込だけを記録する書類ではありません。

現金売上50,000円なら入金伝票で、通常は相手科目の売上と50,000円を記します。現金で通信費4,000円を払ったなら、出金伝票に通信費と4,000円です。預金から家賃30,000円を払った場合は、出金伝票ではなく振替伝票で支払家賃30,000／普通預金30,000を記録します。

銀行の預金から払う取引も日常語では「出金」と呼びますが、この三伝票制の出金伝票は現金の支払いを対象とします。問題の条件に別の定義がなければ、会社の現金か預金かを分けて読みます。書式にすでに現金側が印刷されている場合もあるので、空欄へ重ねて現金を記入しないようにします。

<span id="worked-1"></span>

### 例題1：四つの取引を伝票へ振り分ける

①商品を現金で24,000円販売した。②現金で旅費交通費3,000円を払った。③商品18,000円を掛けで仕入れた。④普通預金から現金10,000円を引き出した。税は考慮しません。先に全体の仕訳を書いて判断します。

| 取引 | 仕訳 | 使う伝票と記入内容 |
| --- | --- | --- |
| ① | 現金24,000／売上24,000 | 入金：売上24,000 |
| ② | 旅費交通費3,000／現金3,000 | 出金：旅費交通費3,000 |
| ③ | 仕入18,000／買掛金18,000 | 振替：仕入18,000／買掛金18,000 |
| ④ | 現金10,000／普通預金10,000 | 入金：普通預金10,000 |

④では預金口座から現金へ形が変わっただけで、収益は生じていません。入金伝票だから相手科目を常に売上にする、という選び方はできません。また③の掛仕入れは支払義務が増えるものの、その時点で現金は動いていないので振替伝票です。

<span id="objective-2"></span>

## 一部現金取引は、指定された方式で分ける

商品を販売し、一部を現金、残額を掛けにした取引は、現金が動く部分と動かない部分が混在します。伝票への分け方には、取引をそのまま二つへ分割する方法と、いったん全額を掛取引にしてから現金部分を回収した形にする方法があります。どちらを使うかは設問の指示に従います。

方式が異なれば伝票に現れる科目や金額も違いますが、全部を合わせた仕訳は同じになります。途中に出る売掛金や買掛金の増減が、最終的に残る権利・義務と対応しているか確かめてください。

<span id="worked-2"></span>

### 例題2：一部現金売上の二つの方式を比べる

商品80,000円を販売し、現金30,000円を受け取り、50,000円を掛けとしました。税は考慮しません。取引全体は現金30,000・売掛金50,000／売上80,000です。

分割する方式では、入金伝票に売上30,000円、振替伝票に売掛金50,000／売上50,000を記録します。合わせると現金30,000・売掛金50,000／売上80,000へ戻り、売上の合計は80,000円です。

いったん全額を掛けとする方式では、振替伝票に売掛金80,000／売上80,000、入金伝票に売掛金30,000円を記します。後者を仕訳に直すと現金30,000／売掛金30,000です。売掛金の増加80,000円と減少30,000円を差し引き、最終的に50,000円が残ります。

| 方式 | 入金伝票 | 振替伝票 | 最終の売掛金増加 |
| --- | --- | --- | ---: |
| 分割 | 売上30,000 | 売掛金50,000／売上50,000 | 50,000 |
| 全額掛け | 売掛金30,000 | 売掛金80,000／売上80,000 | 50,000 |

入金伝票を全額掛け方式の売掛金30,000とし、振替伝票を分割方式の売掛金50,000／売上50,000にすると、売上は50,000円しか記録されず、売掛金増加も20,000円になってしまいます。二つの方式の伝票を混ぜることが誤りの原因です。

### 案内に沿って解く：一部現金仕入れを全額掛け方式で記録する

商品65,000円を仕入れ、現金15,000円、残り50,000円を掛けとしました。振替伝票に仕入65,000／買掛金65,000、出金伝票に買掛金15,000円とします。出金伝票を仕訳へ戻すと買掛金15,000／現金15,000です。買掛金は65,000−15,000＝50,000円残ります。

分割方式なら出金伝票の相手科目は仕入15,000円、振替は仕入50,000／買掛金50,000です。どの方式でも仕入合計65,000円、現金支出15,000円、買掛金増加50,000円になることを三つ並べて照合できます。

## 伝票を科目別に足して、仕訳日計表を作る

一日分の伝票をまとめて元帳へ転記するときは、借方・貸方それぞれについて科目別の金額を集計します。仕訳日計表はその一覧です。現金が省略されている入金・出金伝票についても、現金側の記録を忘れずに補います。入金伝票の合計は現金の借方、出金伝票の合計は現金の貸方です。

<span id="worked-3"></span>

### 例題3：一日分の伝票から、すべての科目を集計する

同じ日の伝票は次のとおりです。一部現金取引は含めず、各伝票は別の取引を表しています。入金伝票は売上40,000円と売掛金25,000円。出金伝票は仕入18,000円と通信費4,000円。振替伝票は仕入32,000／買掛金32,000、支払家賃20,000／普通預金20,000の二枚です。

入金合計65,000円を現金の借方、出金合計22,000円を現金の貸方へ置きます。仕入の借方は出金伝票18,000円と振替伝票32,000円を合わせ50,000円です。同じ科目が複数種類の伝票に現れる点が、単に伝票ごとの総額を足すだけの計算との違いです。

| 仕訳日計表の科目 | 借方合計 | 貸方合計 |
| --- | ---: | ---: |
| 現金 | 65,000 | 22,000 |
| 売掛金 | 0 | 25,000 |
| 普通預金 | 0 | 20,000 |
| 買掛金 | 0 | 32,000 |
| 売上 | 0 | 40,000 |
| 仕入 | 50,000 | 0 |
| 通信費 | 4,000 | 0 |
| 支払家賃 | 20,000 | 0 |
| 合計 | 139,000 | 139,000 |

借方は65,000＋50,000＋4,000＋20,000＝139,000円、貸方は22,000＋25,000＋20,000＋32,000＋40,000＝139,000円で一致します。入金と出金を差し引いた43,000円だけを現金欄へ入れるのではなく、集計表の合計欄では両側を別々に示します。

月初からこの日の前までの現金残高が70,000円なら、この日の増加は65,000−22,000＝43,000円なので、日末残高は113,000円です。仕入勘定には借方50,000円をまとめて転記しますが、元の伝票を直接転記済みなら重ねて記録してはいけません。集計転記か個別転記かをそろえる必要があります。

## 日計表の一致と、伝票の正しさを別々に確かめる

伝票一枚を丸ごと集計から落とすと、借貸とも同額抜けるため、日計表は一致したままになることがあります。例題3で家賃の振替20,000円が丸ごと抜ければ、借方・貸方は両方119,000円です。一致だけでなく、伝票番号や枚数と突き合わせて全件を集計したかを確認します。

入金伝票に普通預金とあるのに売上へ集計するような相手科目の取り違えも、貸借差額では発見できません。元の証ひょうから取引全体の仕訳を復元し、どの伝票で表したかを調べます。伝票の種類、相手科目、金額という三つをセットで点検しましょう。


<span id="worked-4"></span>

### 例題4：全額掛け方式を含む日計表を照合する

同じ日の取引を次の二件だけとします。①商品70,000円を販売し、現金20,000円、残額を掛けにした。②商品50,000円を仕入れ、現金15,000円、残額を掛けにした。両方とも全額掛け方式です。①の振替伝票は売掛金70,000／売上70,000、入金伝票は売掛金20,000円。②の振替伝票は仕入50,000／買掛金50,000、出金伝票は買掛金15,000円です。

| 科目 | 日計表の借方合計 | 日計表の貸方合計 |
| --- | ---: | ---: |
| 現金 | 20,000 | 15,000 |
| 売掛金 | 70,000 | 20,000 |
| 買掛金 | 15,000 | 50,000 |
| 売上 | 0 | 70,000 |
| 仕入 | 50,000 | 0 |
| 合計 | 155,000 | 155,000 |

伝票にある全記録を集めるので、売掛金の借方70,000円と貸方20,000円を両方示します。最終の売掛金増加は50,000円、買掛金増加は35,000円、現金増加は5,000円です。日計表で示す借貸合計と、取引の結果の差引増減を区別してください。

同じ二件を分割方式へ変えると、現金部分の売上20,000円と仕入15,000円を直接記録するため、日計表の借貸合計は120,000円になります。どちらの方式でも最終の現金、売掛金、買掛金、売上、仕入の増減は同じです。途中の総額が異なるだけで、正しく集計した二方式の最終結果は一致します。

この検算を使えば、空欄の伝票がどちらの方式かを判断する練習ができます。先に指示された方式を確定し、そのあとに伝票の金額を求めてください。片方の伝票だけを違う方式へ置き換えると、結果が元の仕訳と一致しなくなります。

## 自力で日計表を作る

入金伝票は売掛金36,000円、売上14,000円。出金伝票は買掛金20,000円、旅費交通費3,000円。振替伝票は備品45,000／未払金45,000、給料12,000／普通預金12,000です。現金の借方・貸方と、全科目を集めた日計表の借貸合計を求めてください。

現金の借方は50,000円、貸方は23,000円です。その他の借方は買掛金20,000・旅費交通費3,000・備品45,000・給料12,000で、借方合計130,000円。貸方は現金23,000・売掛金36,000・売上14,000・未払金45,000・普通預金12,000で、合計130,000円です。現金増加27,000円と日計表総額130,000円は、別の情報なので混同しないようにします。

伝票ごとに取引番号を付け、一つの取引を二枚へ分けた場合も同じ元取引に戻れるようにしておくと、集計漏れと二重集計を区別できます。
