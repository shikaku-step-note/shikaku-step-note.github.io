## 成立・確定・納付を一つの日にまとめない

所得税の納税義務が年末に成立しても、その日に申告書を提出し、その日に納付するとは限りません。国税徴収法の事例では、納税義務が生じる時、納付すべき税額が定まる時、実際に納めるべき期限、担保権との優先を比較する日を分けます。同じ税目の同じ年度でも、期限内申告分と後の修正による増差分では、比較する日が異なる場合があります。

本講は2026年4月3日現在施行の国税通則法・国税徴収法等によります。個別税目の申告特例、災害延長、延納、振替納税等が指定されていない例は、通常の申告と金銭納付を前提にします。休日や特例について設問が別の条件を置くときは、その条件も年表へ記録します。

## 納税義務の成立は課税の原因となる時点を表す

通則法15条は、納税義務の成立と納付すべき税額の確定を区分しています。成立は、その国税の納税義務が法律上生じる段階です。確定手続を要する国税では、その後に申告や処分等により、具体的に納付すべき税額を確定させます。

| 国税の通常の類型 | 納税義務の成立時点 |
| --- | --- |
| 申告所得税 | 暦年の終了時 |
| 通常の法人税・地方法人税 | 事業年度の終了時 |
| 源泉徴収による所得税 | 源泉徴収すべき所得の支払時 |
| 相続税 | 相続・遺贈等による財産取得時 |
| 贈与税 | 贈与等による財産取得時 |
| 課税資産の譲渡等に係る消費税 | 課税資産の譲渡等をした時等 |
| 酒税等の製造場移出に係るもの | 課税物件の製造場からの移出時等 |
| 印紙税・登録免許税 | 課税文書作成時・登記等の時 |

表は15条2項の基礎的な対応です。各号には附帯税を除く区分や政令への委任、国際最低課税額に対する法人税等の別区分があります。特殊な税額を通常の法人税の欄へそのまま入れず、設問が扱う税額の類型を特定します。

消費税では、課税資産の譲渡等の時と、課税期間末、申告時を区別します。「消費税も所得税と同じように年末にだけ納税義務が成立する」と一般化しません。また、源泉所得税の成立は給与等の支払時であり、源泉徴収義務者が後日申告して初めて義務が生じる制度ではありません。

## 確定する方法は三つに分けて読む

申告納税方式は、納税者の申告による確定を原則とする方式です。申告がない、計算が法令に従っていない、調査した税額と異なる等の場合には、税務署長等の更正・決定で確定します。申告納税方式だから税務署の処分は一切ない、という意味ではありません。

賦課課税方式は、専ら税務署長又は税関長の処分により税額を確定する方式です。これに対して、成立と同時に特別の手続を要しないで税額が確定する国税は、通則法15条3項で別に列挙されています。源泉徴収等による国税、予定納税に係る所得税、所定の印紙税・登録免許税、延滞税・利子税等です。

源泉所得税は、納税義務の成立時に自動的に確定するものの一つです。期限未納で税務署長が後に納税の告知をしても、その告知が最初の確定手続になるわけではありません。告知には徴収上の役割があり、確定の方式とは別に読む必要があります。

同じく、加算税と延滞税を「税務署から通知される追加の税」として一括りにしません。15条の成立・自動確定の規定、賦課決定等の手続、納期限をそれぞれ確認します。附帯税の詳細な成立時点と計算は、附帯税の講で学びます。

## 期限内申告・期限後申告・修正申告・更正を区別する

期限内申告書に記載した納付税額は、通則法35条1項により、原則として法定納期限までに納めます。通常の居住者の確定所得申告では所得税法120・128条、通常の内国法人の確定申告では法人税法74・77条等の個別規定も確認します。早めに期限内申告をしたから、その日が常に納期限になるわけではありません。

期限後申告により納付すべき税額と、修正申告による増差税額は、別段の納期限等がない限り、その申告書を提出した日が納付すべき日です。例えば法定納期限を過ぎた6月24日に修正申告をしたなら、その増差分を「翌月末までに払えばよい」とはしません。

更正又は決定により増加した税額等は、通則法35条2項2号により、原則として通知書が発せられた日の翌日から起算して1月を経過する日までに納めます。通知書の発出日と送達日がずれているとき、ここで起算に用いるのは条文が指定する発出日です。他方、28条は更正・決定を通知書の送達により行うと定めています。処分の手続と納期限計算が着目する日を取り違えません。

| 税額を定めた行為 | 通常の納付すべき日 |
| --- | --- |
| 期限内申告 | 法定納期限まで |
| 期限後申告 | 申告書提出日 |
| 修正申告の増差分 | 修正申告書提出日 |
| 更正・決定による増差等 | 通知書発出日の翌日から1月を経過する日 |

納税の告知を要する国税は通則法36条で別に定めています。未納の源泉徴収等による国税等がその対象です。納税告知書に記載した納期限と、もとの法定納期限を別の欄へ記録します。

法定申告期限は申告書の提出期限、法定納期限は納付の期限を表す用語です。通常の確定申告では一致することが多くても、概念は別です。資料に「申告期限を延長した」とあれば、その根拠制度で納付期限もどう扱うかを確認します。税額がすでに確定している場合の納税の猶予も、申告書の提出を遅らせる制度へ読み替えません。年表の欄を分けておけば、一方の期限を動かしたとき他方まで根拠なく動かす誤りを避けられます。

## 法定納期限・納期限・法定納期限等を使い分ける

法定納期限は、徴収法2条10号及び通則法2条8号の定義に従います。期限後申告・修正申告・更正等の増差分については、期限内申告に記載されていたとみなした場合の期限を用いる特則があります。したがって、修正申告の増差分を提出日までに納める義務があっても、その提出日を常に法定納期限と呼ぶわけではありません。

繰上請求により繰り上げた期限、延納・納税の猶予等の期限も、法定納期限の定義にそのまま置き換えません。何の目的の期限を求めているか、問題の文言を確かめます。督促や延滞税、担保との優先では、同じ日付欄を使い回せない場面があります。

法定納期限等は、担保権と国税の優先等を調整するために徴収法15条1項が定める比較日です。原則は法定納期限ですが、法定納期限後に申告で確定した税額は申告日、更正等で確定した税額は通知書発出日等となります。源泉所得税等の自動確定国税の未納分にも、告知書発出日等を用いる特則があります。

15条にはこのほか、繰上請求、予定納税、特定の相続税・贈与税、相続・合併・分割財産、第二次義務者等の特則が列挙されています。本講の通常例をすべての税額へ一般化せず、優先関係の講で財産の区分と併せて適用号を確認します。

## 期間は暦と起算方法から数える

通則法10条1項は、日・月・年による期間の初日不算入を原則とし、午前零時から始まる場合等の例外を定めます。月による期間は30日固定ではなく暦に従います。6月11日午前零時から1月の期間なら、7月11日の前日である7月10日に満了します。応当日がないときは、その月末日で満了します。

10条2項の期限特例では、所定の申告・納付等の期限が日曜、祝日等に当たるとき、その翌日を期限とする取扱いがあります。除外される期限もあり、単なる期間の経過日と提出・納付期限を同じように延長しないようにします。災害等の期限延長は11条等に基づく別の制度で、対象者・対象行為と延長後の期限を確認します。

## 例題1：年末成立と期限内申告の関係

個人甲の2025年分の通常の申告所得税について、納税義務は2025年12月31日に成立します。甲は2026年3月10日に期限内申告書を提出し、納付すべき税額は80万円です。本例の通常の法定申告・納期限は、3月15日が日曜日のため2026年3月16日とし、延納・振替等はないものとします。

税額は3月10日の申告により確定し、80万円は3月16日までに納付します。成立日12月31日、確定日3月10日、納期限3月16日の三つを年表へ置きます。3月10日に申告した時点で未納でも、3月16日より前から当然に期限徒過とは扱いません。

その後5月12日に増差20万円の修正申告をした場合、その20万円の納付日は5月12日です。法定納期限は通常3月16日のままで、優先比較の法定納期限等は増差分について5月12日となります。最初の80万円と増差20万円は、同じ2025年分でも比較日を分けます。

## 例題2：更正通知書の発出日と送達日

法人乙について、当初の税額は期限内申告で確定しており、その法定納期限は2026年6月1日です。後に増差30万円の更正通知書が6月10日に発せられ、6月12日に適法に送達されました。別段の期限・延長はなく、7月10日は休日等に当たらないものとします。

増差30万円の納付期限は、発出日の翌日6月11日午前零時から1月を経過する7月10日です。送達日6月12日から計算して7月12日とするのは、35条の起算方法と違います。更正処分は送達により行われるという28条の規定と、納期限計算の起算は両立します。

増差分の法定納期限は6月1日、法定納期限等は6月10日です。7月10日は現実に納付すべき期限であり、この事例の担保比較日ではありません。元の税額と増差分を一括して7月10日とする答案も避けます。

## 例題3：源泉所得税は告知で初めて確定するのか

会社丙は2026年2月25日に給与を支払い、源泉所得税18万円が成立・確定しました。通常の法定納期限を3月10日とし、納期特例は適用しません。期限未納のため4月20日発出の納税告知書が適法に送達され、告知による納期限は5月15日と指定されました。

源泉所得税は2月25日の支払時に成立し、自動的に税額が確定します。4月20日の告知は、申告納税方式の更正と同じ確定処分ではありません。告知で指定した5月15日の納期限、もとの3月10日の法定納期限、徴収法15条1項5号の2による4月20日の法定納期限等を区別します。

この区別は、告知より前に設定された担保を比べるときにも関わります。告知時点が重要な特則であって、源泉徴収すべき所得の支払時に納税義務が生じた事実が消えるわけではありません。

## 例題4：源泉所得税を告知前に期限後納付した場合

会社丁の源泉所得税12万円は2026年8月5日の給与支払時に成立・確定し、法定納期限は9月10日でした。丁は納税の告知を受ける前に、9月18日に12万円を納付しました。納付日までに告知はなく、他の特則はないものとします。

徴収法15条1項5号の2は、このように告知を受けず法定納期限後に納付した国税について、納付日を法定納期限等としています。したがって本例の比較日は9月18日です。源泉税の法定納期限等は必ず告知書発出日、とだけ覚えると、この条件を処理できません。法定納期限以前の納付を除外する同号の条件も読みます。

この例は12万円が納付された後も未納であるという意味ではありません。同号がどの日を定めているかを理解するための例です。実際の配当問題では、納付済み税額を未納残高に再び加えず、関係する他の税額・担保・納付の経過と併せて判断します。

## 日付を使った答案を検算する

税額を行に、成立、確定行為、発出、送達、法定納期限、現実の納期限、法定納期限等を列にします。修正・更正で増加した額は別行です。納付があれば、どの税額がいつ減ったかも記入します。この表ができてから、督促、差押え、優先順位、延滞税の対象期間へ進みます。

「納期限は何月何日」とだけ答えて済ませず、「修正増差分の納付日は提出日」「担保比較日は15条の法定納期限等」という用途を併記すると、異なる日を取り違えた箇所が見つかります。日付と税額を対応させることが、後続の複合問題を解く前提になります。
