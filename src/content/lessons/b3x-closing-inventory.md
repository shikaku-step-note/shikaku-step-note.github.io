一年間に仕入れた商品が、すべてその年に売れたとは限りません。前の年から残った商品も今年販売でき、今年買った商品も一部は来年へ持ち越されます。決算では、当期の仕入額をそのまま費用とせず、販売した商品に対応する原価へ直します。これが商品棚卸の整理の役割です。

<span id="objective-1"></span>

## 販売できた商品の原価を、売れた分と残った分へ分ける

当期に販売できる商品は、期首にあった分と当期に仕入れた分の合計です。ここから期末に残った分を除けば、売れた分の原価になります。基本式は「売上原価＝期首商品棚卸高＋当期純仕入高−期末商品棚卸高」です。棚卸数量と金額に差異がなく、ほかの特殊な処理がない問題では、この関係から計算を始めます。

期末商品は販売価格ではなく原価で測ります。商品を300円で売る予定でも、取得原価が180円なら、残った一個に原則として180円を使う条件です。先入先出法や移動平均法が指定されるときは、その方法で期末原価を算定します。売価と原価の区別は、商品有高帳で学んだものと同じです。

<span id="worked-1"></span>

### 例題1：数量と原価から売上原価を二方向で確認する

期首に一個400円の商品が50個あり、当期は同じ単価で200個仕入れ、期末に65個残りました。紛失や返品、単価の変更はなく、販売価格は一個700円とします。まず販売可能数量は50＋200＝250個、販売数量は250−65＝185個です。

原価の式で計算すると、期首20,000円＋仕入80,000円−期末26,000円＝売上原価74,000円です。数量から求めても185個×400円＝74,000円で一致します。売上高は185個×700円＝129,500円、売上総利益は129,500−74,000＝55,500円です。

| 原価の行方 | 数量 | 単価 | 金額 |
| --- | ---: | ---: | ---: |
| 期首＋当期仕入 | 250個 | 400円 | 100,000円 |
| 当期販売 | 185個 | 400円 | 74,000円 |
| 期末在庫 | 65個 | 400円 | 26,000円 |

74,000＋26,000＝100,000円という検算は、集めた原価が販売分と在庫に分かれたことを示します。期末商品を売価700円で評価すると45,500円になり、売れなかった商品の原価を過大に残して利益も誤ります。

## 仕入勘定の残高を、当期に売れた分へ直す

三分法で仕入勘定を使って売上原価を計算する場合、期首の繰越商品を仕入へ加え、期末の商品を仕入から除きます。仕訳は、期首商品について借方仕入・貸方繰越商品、期末商品について借方繰越商品・貸方仕入です。覚え方だけでなく、それぞれが仕入勘定をいくら増減させるかを追いましょう。

<span id="worked-2"></span>

### 例題2：決算整理前後の仕入勘定を作る

整理前の繰越商品は借方35,000円、仕入は借方280,000円で、期末棚卸原価は48,000円です。仕入残高は返品等の処理をすでに反映した純額とします。期首商品を当期の原価計算へ含めるため、仕入35,000／繰越商品35,000を記録します。次に残った商品を資産へ戻すため、繰越商品48,000／仕入48,000とします。

| 仕入勘定の整理 | 借方 | 貸方 |
| --- | ---: | ---: |
| 整理前残高 | 280,000 | — |
| 期首商品を加える | 35,000 | — |
| 期末商品を除く | — | 48,000 |
| 整理後借方残高 | 267,000 | — |

仕入の整理後残高は280,000＋35,000−48,000＝267,000円です。この残高が売上原価として損益へ移ります。繰越商品勘定は、もとの35,000円が貸方で消え、新たな48,000円が借方に残ります。貸借対照表に載せる商品は35,000円と48,000円の合計ではありません。

売上が420,000円なら売上総利益は153,000円です。もし期末48,000円を除く仕訳を忘れると売上原価が315,000円となり、利益が48,000円少なくなります。期末在庫を費用へ入れたままにした影響を、利益の方向でも点検できます。

### 案内に沿って解く：売上原価勘定を用いる指定

同じ資料で、売上原価勘定を用いるよう指定された場合は、仕入だけで完成させる方法と区別します。売上原価35,000／繰越商品35,000、売上原価280,000／仕入280,000、繰越商品48,000／売上原価48,000と記録すれば、売上原価勘定に267,000円が残ります。

ここでの三つの仕訳は、決算時に原価を集約する指定への対応です。2027年度から加わる「販売のつど売上原価へ振り替える方法」と混同しないでください。2026年度のこのレッスンでは、期中は三分法で記録し、決算で原価を確定する仕組みを学びます。

## 純仕入は、追加資料を反映してから使う

試算表の仕入残高が返品をすでに差し引いているなら、同じ返品をもう一度引きません。一方、期末の仕入れが未記帳なら、その分を追加する必要があります。棚卸高の資料にその未記帳の商品が含まれているかも読みます。仕入額と期末商品を同じ範囲へそろえないと、原価がずれます。

<span id="worked-3"></span>

### 例題3：返品と未記帳仕入を含めて計算する

期首商品60,000円、整理前仕入残高510,000円です。この残高には返品12,000円が未反映で、期末に掛けで仕入れた24,000円も未記帳でした。期末商品は82,000円で、未記帳仕入24,000円のうち期末に残っている分も含め、適切に集計済みです。税は考慮しません。

返品は買掛金12,000／仕入12,000、未記帳仕入は仕入24,000／買掛金24,000です。よって純仕入は510,000−12,000＋24,000＝522,000円です。ここへ期首60,000円を加え、期末82,000円を除き、売上原価500,000円を求めます。

| 計算段階 | 金額 |
| --- | ---: |
| 整理前仕入 | 510,000円 |
| 未反映返品 | −12,000円 |
| 未記帳仕入 | ＋24,000円 |
| 修正後純仕入 | 522,000円 |
| 期首商品 | ＋60,000円 |
| 期末商品 | −82,000円 |
| 売上原価 | 500,000円 |

販売に使える原価は582,000円、残る原価は82,000円です。差額500,000円が売れた分です。期末棚卸高に未記帳商品がすでに入っているので、82,000円へ24,000円を機械的に加算しません。追加資料の「含む」「含まない」を、自分が二重に数えていないかという視点で読みます。

<span id="worked-4"></span>

### 例題4：期末在庫の増減から利益への影響を判断する

期首商品と純仕入が同じ条件で、期末商品だけが前の見積りより10,000円多いと分かった場合、売上原価は10,000円減ります。売上や他の費用が変わらなければ、利益は10,000円増えます。式の期末商品が引き算になっているので、期末在庫を多く残すほど当期へ配分する原価は小さくなります。

これは在庫を自由に増やしてよいという意味ではありません。実際に残った数量と指定評価方法に基づく正しい原価を確認する必要があります。問題で利益への影響を問われたときは、売上原価の増減と利益の増減が逆向きになることを、一つずつ式で確かめてください。


## 元帳の空欄を、決算整理と損益振替から逆算する

仕入勘定や繰越商品勘定の空欄を問う問題では、最終の原価額だけでなく、その額が生まれる各記入の相手科目を判断します。仕入勘定に期首商品を加えるときの相手は繰越商品、原価を損益へ移すときの相手は損益です。同じ仕入勘定の貸方でも、期末在庫を除く記入と、残高全部を締め切る記入は役割が違います。

<span id="worked-5"></span>

### 例題5：仕入と繰越商品の二つの勘定を完成する

繰越商品の期首借方残高が25,000円、仕入の期中借方合計が240,000円、期中返品の貸方が15,000円です。期末商品は40,000円。仕入勘定で売上原価を求め、最後に損益へ振り替えます。まず仕入純額は225,000円です。期首25,000円を加え、期末40,000円を除けば、原価は210,000円になります。

| 仕入勘定の記入 | 借方 | 貸方 | 相手科目 |
| --- | ---: | ---: | --- |
| 期中仕入 | 240,000 | — | 買掛金等 |
| 期中返品 | — | 15,000 | 買掛金等 |
| 期首商品振替 | 25,000 | — | 繰越商品 |
| 期末商品振替 | — | 40,000 | 繰越商品 |
| 損益への振替 | — | 210,000 | 損益 |
| 締切合計 | 265,000 | 265,000 | — |

繰越商品勘定では、期首25,000円を仕入へ移したことで元の資産が消え、期末40,000円を仕入から戻したことで新しい資産が残ります。翌期へ繰り越す額は40,000円です。仕入勘定の貸方にある40,000円は未販売分、210,000円は販売分という違いを説明できます。

ここで期中返品15,000円を純仕入で差し引いたあと、損益振替の210,000円からもう一度差し引くと195,000円となり誤ります。帳簿の合計から計算すると265,000−15,000−40,000＝210,000円、純額から計算すると225,000＋25,000−40,000＝210,000円です。どちらを使うかを決め、返品を一度だけ反映します。

このような勘定記入では、期首・期末の位置や摘要を暗記だけで埋めず、仕訳へ戻して確認してください。繰越商品40,000／仕入40,000だから、仕入勘定の貸方摘要は繰越商品です。仕入210,000円を損益へ移す仕訳は損益210,000／仕入210,000なので、同じ貸方でも摘要は損益になります。


## 自力で整理仕訳と利益を求める

整理前の繰越商品45,000円、仕入390,000円、売上620,000円です。仕入に含まれる未反映返品は15,000円、未記帳仕入20,000円があり、期末棚卸高は70,000円です。棚卸高には未記帳商品も含まれています。消費税とその他の損益は考慮せず、仕入勘定で売上原価を計算します。

先に純仕入を390,000−15,000＋20,000＝395,000円へ直します。次に仕入45,000／繰越商品45,000、繰越商品70,000／仕入70,000を記録します。売上原価は370,000円、売上総利益は620,000−370,000＝250,000円です。繰越商品70,000円が資産へ残り、原価370,000円だけが損益へ移ることを説明してください。

本レッスンは3級の棚卸整理を対象とします。商品評価損や棚卸減耗の独立した会計処理を、この原価式へ根拠なく加えないようにします。資料の値が数量なのか、原価なのか、販売価格なのかを確かめ、与えられた条件の範囲で完成させましょう。
