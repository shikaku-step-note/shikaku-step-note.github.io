元帳が科目ごとの記録なら、試算表は元帳全体の一覧です。「現金の残高はいくらか」という質問から一歩進み、各勘定の計算を一つの表へ集めます。ここで扱う三種類の試算表は、同じ資料から作れます。示す数字が合計なのか差額なのかを、先に見分けましょう。

<span id="objective-1"></span>

## 一つの勘定について、合計と残高を別々に求める

現金の借方合計が150,000円、貸方合計が45,000円なら、残高は借方105,000円です。150,000円は期首から集まった収入側の金額、45,000円は支出側の金額で、いま保有している現金は差額です。同じ勘定でも、どの欄を問われたかで答える値が変わります。

残高が借方にある勘定では、貸方残高の欄を空欄または指定されたゼロ表示にします。借方に150,000円、貸方に45,000円を記入するのは合計の表示です。残高欄へ両側の合計をそのまま写すと、差引計算をしていないことになります。

負債も、計算の操作自体は同じです。買掛金の借方合計25,000円、貸方合計70,000円なら、70,000−25,000＝45,000円が貸方に残ります。資産か負債かを見て先に残高の金額を決めるのではなく、実際の借貸差額を計算し、結果が自然かを分類で点検します。

### 例題1：七つの勘定をもつ小さな元帳

次の資料は、ある月の取引を転記したあとの勘定合計です。金額は円です。月初の繰越は元帳合計に含まれ、月末締切のための次月繰越はまだ記入していません。消費税、決算整理、ここにない科目は考慮しません。

| 勘定科目 | 元帳の借方合計 | 元帳の貸方合計 |
| --- | ---: | ---: |
| 現金 | 150,000 | 45,000 |
| 売掛金 | 80,000 | 30,000 |
| 備品 | 60,000 | 0 |
| 買掛金 | 25,000 | 70,000 |
| 資本金 | 0 | 120,000 |
| 売上 | 0 | 90,000 |
| 給料 | 40,000 | 0 |
| 合計 | 355,000 | 355,000 |

まず縦計算です。借方は150,000＋80,000＋60,000＋25,000＋40,000＝355,000円、貸方は45,000＋30,000＋70,000＋120,000＋90,000＝355,000円。合計試算表では、この元帳の両合計を各科目の欄へそのまま写せば完成します。

現金の行を105,000円だけにしてしまうと、合計試算表ではなく残高の情報になります。表の名前を読んでから転記する、という簡単な確認が必要です。合計が大きい側にだけ数字を書くか、両側を書くかを科目ごとに変えることもできません。表全体で一つの形式を使います。

## 残高試算表へ変えると、金額は小さくなっても関係は保たれる

各行の借方合計と貸方合計を差し引きます。現金は105,000円、売掛金は50,000円、備品は60,000円で、いずれも借方残高です。買掛金45,000円、資本金120,000円、売上90,000円は貸方残高、給料40,000円は借方残高です。

| 残高試算表の科目 | 借方残高 | 貸方残高 |
| --- | ---: | ---: |
| 現金 | 105,000 | — |
| 売掛金 | 50,000 | — |
| 備品 | 60,000 | — |
| 買掛金 | — | 45,000 |
| 資本金 | — | 120,000 |
| 売上 | — | 90,000 |
| 給料 | 40,000 | — |
| 合計 | 255,000 | 255,000 |

残高の合計は255,000円です。合計試算表の355,000円から100,000円減っています。現金45,000円、売掛金30,000円、買掛金25,000円という合計100,000円を、それぞれの行の両側から差し引いたので、表の左右の合計が両方とも100,000円ずつ減りました。数字が変わっても、一方だけを減らしたわけではないため一致が続きます。

### 例題2：合計残高試算表を四つの金額欄で作る

上の同じ元帳について、合計残高試算表を作ります。科目の左右に、合計の欄と残高の欄を分けて置きます。書式によって欄の並び方は違うため、ここでは説明用に借方合計・貸方合計・借方残高・貸方残高の順に示します。

| 科目 | 借方合計 | 貸方合計 | 借方残高 | 貸方残高 |
| --- | ---: | ---: | ---: | ---: |
| 現金 | 150,000 | 45,000 | 105,000 | — |
| 売掛金 | 80,000 | 30,000 | 50,000 | — |
| 備品 | 60,000 | 0 | 60,000 | — |
| 買掛金 | 25,000 | 70,000 | — | 45,000 |
| 資本金 | 0 | 120,000 | — | 120,000 |
| 売上 | 0 | 90,000 | — | 90,000 |
| 給料 | 40,000 | 0 | 40,000 | — |
| 合計 | 355,000 | 355,000 | 255,000 | 255,000 |

合計欄同士を比較し、残高欄同士を比較します。合計欄355,000円と残高欄255,000円を同額にしようとしてはいけません。見ている情報が異なります。個々の行では「借方合計−貸方合計」が、借方残高なら正、貸方残高なら負となることを確認できます。

### 案内に沿って解く：借方残高から借方合計を求める

売掛金の借方合計が不明、貸方合計が62,000円、借方残高が18,000円です。借方合計−62,000＝18,000なので、借方合計は80,000円です。残高を求める式を逆に使っています。単に62,000−18,000と引く前に、勘定のどちらの合計が大きいかを図で確かめてください。

## 不一致を調べるとき、差額を手掛かりにする

試算表が一致しなければ、まず表の縦計算をし直します。次に各勘定の合計と残高を確認し、最後に仕訳と元帳の対応へ戻ります。差額だけに合う架空の雑損などを作って合わせてはいけません。原因となる記入を見つけ、どこまで正しく記録されているかを判断します。

### 例題3：反対側への転記は、差額が二倍になる

借方に入れるべき通信費7,000円を、誤って貸方へ転記しました。本来は借方合計へ7,000円加えるところ、借方へは入らず貸方へ7,000円加わったので、貸方が借方より14,000円多くなります。差額14,000円だけの取引を探すと、元の7,000円を見逃します。

正しく直すには、貸方へ入れた7,000円を取り消し、借方へ7,000円を入れます。試算表上の修正では、貸方が7,000円減り借方が7,000円増えるため、両側の差が14,000円縮まります。差額の半分に当たる転記を探すのは、この関係があるからです。ただし、差額が偶数なら必ず左右の誤りというわけではありません。

数字の桁を逆に写す誤りもあります。43,000円を34,000円とした差額は9,000円です。差が9で割り切れることは手掛かりになりますが、ほかの誤りでも同じ差が出るので、元資料との照合が必要です。手掛かりは原因を決めつける法則ではありません。

## 貸借が一致しても、正しい帳簿とは限らない

取引を丸ごと一件書き忘れると、その取引の借方も貸方も同額だけ抜けるため、合計は一致します。備品の購入を誤って仕入へ記録しても、借方同士の科目違いなので試算表の一致は保たれます。同じ取引を借貸とも二度記録した場合も同様です。

例題1で現金20,000円の仕入取引が丸ごと抜けたと仮定すると、仕入と現金の両記録がなくなります。表全体の一致だけでは発見できません。請求書・領収書、仕入帳、現金出納帳などと対応させ、記録した取引の漏れや内容を確認する必要があります。

当座預金に貸方残高が出る場合は、借越契約に基づく借越の可能性があります。一方、現金の貸方残高は通常の保有現金の状態として不自然です。どの資産でも必ず借方残高であると機械的に決めず、取引条件を読み、期末に必要な振替を検討します。借越の詳しい整理は決算のレッスンで扱います。

### 例題4：取引を追加してから、新しい残高試算表を作る

例題1の月末残高に、未記帳の次の取引を追加するとします。①売掛金12,000円を現金で回収した。②買掛金18,000円を現金で支払った。③今月分の給料5,000円を現金で支払った。ここでは、期末の期間配分等へ進む前に、記帳漏れだった期中取引を反映します。

①で現金は12,000円増え、売掛金は12,000円減ります。②で現金と買掛金が18,000円ずつ減り、③で現金が5,000円減って給料が5,000円増えます。整理後の残高は次のとおりです。

| 科目 | 修正前の残高 | 今回の増減 | 修正後の残高 |
| --- | ---: | ---: | ---: |
| 現金（借方） | 105,000 | 12,000−18,000−5,000 | 94,000 |
| 売掛金（借方） | 50,000 | −12,000 | 38,000 |
| 備品（借方） | 60,000 | 0 | 60,000 |
| 買掛金（貸方） | 45,000 | −18,000 | 27,000 |
| 資本金（貸方） | 120,000 | 0 | 120,000 |
| 売上（貸方） | 90,000 | 0 | 90,000 |
| 給料（借方） | 40,000 | ＋5,000 | 45,000 |

修正後の借方合計は94,000＋38,000＋60,000＋45,000＝237,000円、貸方合計は27,000＋120,000＋90,000＝237,000円です。回収では同じ借方残高同士の入替え、支払では資産と負債が同額減少、給料では資産が減って費用が増加するので、合計の変化も取引ごとに説明できます。

残高試算表では、各仕訳によって科目の残高が増えるか減るかを判断しました。特に買掛金の支払18,000円を貸方残高へ加えると、支払ったのに義務が増える不自然な結果になります。元帳へ戻って借方を増やす記録だと確認すれば、27,000円を正しく求められます。

## 自力で残高表を完成する

次の元帳合計から残高試算表を作ってください。現金は借方100,000・貸方40,000、売掛金は借方50,000・貸方20,000、備品は借方80,000・貸方0、買掛金は借方15,000・貸方45,000、資本金は借方0・貸方100,000、売上は借方0・貸方60,000、給料は借方20,000・貸方0です。

解答は、借方残高が現金60,000・売掛金30,000・備品80,000・給料20,000、貸方残高が買掛金30,000・資本金100,000・売上60,000です。両側合計は190,000円。元帳合計は両側265,000円で、行ごとに差し引いた合計75,000円を控除すると190,000円になります。三種類の表が同じ元帳から生まれたことを、縦と横の両方で確かめましょう。

残高ゼロの勘定でも、合計試算表には期間中の借方・貸方が同額で載ることがあります。借方30,000円、貸方30,000円の勘定なら、合計欄には両方30,000円、残高欄には残す金額がありません。残高ゼロを、取引がなかったことと取り違えないでください。

問題の単位が千円なら、円の資料をそのまま入れず、指定単位へそろえてから表を完成してください。
