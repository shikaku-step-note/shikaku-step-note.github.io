## 問いを決めてからデータを集める

業務分析は「何を改善したいか」を明確にすることから始まります。インタビューは理由を深く聞く方法、アンケートは同じ問いを広く集める方法です。標本の偏りや質問の誘導があれば、数が多くても結論は不確かです。業務フローは作業と分岐、DFDはデータの流れに着目します。

## 図は目的に合わせて選ぶ

| 調べたいこと               | 向いている表現       | 注意点                               |
| -------------------------- | -------------------- | ------------------------------------ |
| 苦情の多い原因から改善する | パレート図・ABC分析  | 件数と影響の大きさは同じとは限らない |
| 原因の候補を整理する       | 特性要因図           | 図に書いただけでは因果は証明されない |
| 二つの数量の関係を見る     | 散布図               | 第三の要因も調べる                   |
| 時間に沿った変化を見る     | 折れ線グラフ・管理図 | 管理限界と仕様の許容値を混同しない   |
| 作業の依存関係を整理する   | PERT図               | 合計期間は全作業の単純合計ではない   |

## 例：苦情100件を分類する

配送遅れ50件、破損30件、案内不足20件なら、件数の累積は50%、80%、100%です。件数を減らす目的なら配送遅れから調べる根拠になります。ただし破損の損失が特に大きい場合、金額での優先度は変わります。ABC分析の区切りは運用上決めるもので、常に特定の割合に固定されません。

## 相関をそのまま原因にしない

気温が高い日に飲料売上と熱中症搬送がともに増えても、飲料の販売が搬送の原因とはいえません。相関係数は直線的な関係の強さを表し、因果を保証しません。回帰分析は関係を式で近似しますが、観測範囲外への予測や、収集方法が変わったデータには注意が必要です。ORは数理的な意思決定、IEは作業や工程の改善に役立つ考え方です。

## まとめ

図を描く前に問いと単位を決め、結果を見た後に別の説明がないか確認します。
