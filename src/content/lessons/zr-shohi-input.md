## 仕入れの支払額全体を、売上税額から引くものではありません

事業者は、売上に係る税額から、所定の課税仕入れ等に係る税額を控除する仕組みを使います。商品の仕入代金そのものを税額から引くのではなく、そこに対応する税額を計算します。さらに、課税仕入れへの該当、使途、帳簿や請求書等の保存、課税売上割合等を確認します。

このレッスンは本則課税の国内事業者を対象にし、2025年又は2026年6月の取引を明示して扱います。簡易課税や二割特例を使う場合は、次のレッスンの別の計算となります。仕入控除の条件を検討せず、預かったように見える税額と支払税額だけを機械的に相殺しないことが大切です。

## 帳簿と、適格請求書等の保存を確認します

原則として、所定の帳簿と適格請求書等を保存することが控除の条件になります。請求書の名称や用紙の形式ではなく、登録番号、取引内容、税率別の金額や税額等の必要事項を確認します。領収書という名前でも要件を満たす場合があり、逆に「インボイス」と書かれただけでは足りません。

帳簿には取引先、年月日、内容、対価等の必要事項を記録します。一定の公共交通機関の利用等には請求書等の保存を要しない例外があり、一定の小規模事業者の少額特例にも条件があります。例外を使う場合も、その対象、金額、期間、帳簿記載等を確認します。すべての少額支出が無条件に控除できるわけではありません。

## 課税売上割合は、輸出と非課税売上を分けて計算します

課税売上割合の基礎形は、国内の総売上高等に占める課税売上高等の割合です。輸出免税売上を分子へ含め、非課税売上は原則として分母へ含めます。有価証券の譲渡等には分母へ入れる金額の調整もあるため、全入金を分母にするものではありません。

独自の例で、2025年の税抜課税売上800万円、輸出免税売上100万円、非課税売上100万円、他の調整なしとします。割合は（800＋100）÷（800＋100＋100）＝90％です。非課税があるから仕入税額を全部控除できない、又は輸出売上は税が0円なので分子から外す、という両極端の判断を避けます。

その課税期間の課税売上高が5億円以下で、課税売上割合が95％以上という条件では、原則として課税仕入れ等の税額の全額控除を検討します。売上高が5億円超又は割合が95％未満なら、個別対応方式又は一括比例配分方式等を確認します。売上高と割合は、二つとも判定する条件です。短期課税期間の年換算等も別に必要となります。

## 個別対応方式では、仕入れを三つの用途へ分けます

個別対応方式は、課税売上にのみ要する仕入れ、非課税売上にのみ要する仕入れ、両方に共通する仕入れへ区分します。基本の控除額は「課税売上専用の税額＋共通税額×課税売上割合」です。非課税売上専用の税額は、この式へ足しません。購入した物の名称だけでなく、実際に何へ使うかを確認します。

独自の例で、条件を満たす国税の仕入税額が、課税専用50万円、非課税専用10万円、共通20万円とします。割合90％なら、控除額は50＋20×90％＝68万円です。合計80万円を全額控除する計算や、全額へ90％を掛ける計算とは違います。共通部分だけを割合で配分するためです。

同じ資料で一括比例配分方式を適用できる条件なら、合計80万円×90％＝72万円という関係です。二つの方式の結果が常に一致するわけではありません。方式の継続適用等の条件もあり、その年の数字を見て自由に部分的に組み合わせる制度ではない点に注意します。

| 用途                 |   税額 | 個別対応方式での控除 |
| -------------------- | -----: | -------------------: |
| 課税売上にのみ対応   | 50万円 |               50万円 |
| 非課税売上にのみ対応 | 10万円 |                  0円 |
| 共通                 | 20万円 |               18万円 |
| 合計                 | 80万円 |               68万円 |

## 登録のない相手からの仕入れには、経過措置を確認します

適格請求書発行事業者以外からの一定の課税仕入れについて、2023年10月1日から2026年9月30日までの取引には、仕入税額相当額の80％を控除する経過措置があります。帳簿や区分記載請求書等に関する保存条件、取引先ごとの金額制限等も確認します。相手が免税だから控除は常に0円、と決め付けないようにします。

独自の例で、2026年6月30日に標準税率の商品を税込110,000円で仕入れ、80％経過措置の全要件を満たすとします。国税の仕入税額相当額は110,000×7.8/110＝7,800円、その80％は6,240円です。この例では課税売上専用の仕入れで、用途による追加配分はないとします。地方を含む相当額10,000円の80％は8,000円ですが、国税の計算欄へ8,000円を入れるのではありません。

同じ取引が登録事業者からの適格請求書等を備えた通常の仕入れで、全額控除の条件を満たすなら、国税の控除は7,800円です。この差1,560円は、適用する控除割合の違いに対応します。取引額自体を80％へ値引きした計算とは区別します。

## 改正の施行日と、仕入日の関係を確認します

2026年10月以後の実際の制度には、70％等へ変わる改正があります。その関係部分は2026年10月1日施行で、第76回試験の4月3日時点の施行法令とは分けて確認します。本例は6月の取引なので80％を使います。古い資料の10月以後50％という表と、新たな70％という表を、対象日を確認せず混ぜないでください。

固定資産の用途変更や課税売上割合の著しい変動、居住用賃貸建物等には別の控除制限・調整があります。保存条件を満たしたから、あらゆる資産取得をそのまま全額控除できるわけではありません。科目の次の演習では、資産の種類と取得後の利用も時系列で確認します。

## 保存要件と用途区分は、どちらも確認が必要です

適格請求書を保存していれば、すべての支払の税額を必ず全額控除できるわけではありません。事業用の課税仕入れ等であるか、帳簿等の保存、請求書等の要件、非課税売上に対応する用途等の制限を順に確かめます。給与の支払を、請求書という名前の書類があるだけで課税仕入れへ変えることはできません。

個別対応方式では、課税売上にのみ要するもの、非課税売上にのみ要するもの、共通して要するものを分けます。課税専用の国税額10万円、非課税専用3万円、共通5万円、課税売上割合80％という基本条件なら、控除は10＋5×80％＝14万円です。すべての18万円へ80％を掛ける計算ではありません。一括比例配分方式を使う条件では、別の方法となります。

免税事業者等からの仕入れの経過措置では、取引日を確認します。第76回の基準日で参照する規定と、基準日後に施行された変更を混ぜず、帳簿・書類の保存条件も記録します。現在の制度を調べ直すときは、古い教材の割合だけを置換するのではなく、施行日と対象期間を公式資料で確認してください。

復習では、課税仕入れ該当性、保存条件、取引日、国税相当額、控除割合、使途による配分を順に計算します。各段階の率が何を意味するかを説明してから、簡易課税等との比較へ進みます。
