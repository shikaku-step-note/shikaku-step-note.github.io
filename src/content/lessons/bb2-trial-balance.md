試算表は、総勘定元帳の各勘定を一覧にしたものです。一つの勘定の動きから残高を計算し、すべての勘定の借方と貸方を集計します。表が合うかどうかに加えて、各科目が何を意味するかを読む必要があります。この課では、同じ一か月の資料から三種類の試算表を作ります。

<span id="objective-1"></span>

## 勘定ごとの左右の合計を求めてから差し引く

現金は増加が借方、減少が貸方です。借方合計が200,000円、貸方合計が100,000円なら、残高は借方100,000円です。ここでいう借方合計200,000円は、月末に残る現金そのものではありません。期間中の増加や、この資料に含めた月初残高などを合計した額です。

買掛金は負債なので、通常は増加が貸方、減少が借方です。借方合計20,000円、貸方合計30,000円なら、貸方に10,000円残ります。差額の10,000円は同じでも、どちら側に残るかまで答える必要があります。

減価償却累計額のように、資産の控除を表し貸方に残高がある勘定もあります。すべての勘定を「資産なら借方、負債なら貸方」とだけ覚えて、資料と照合しないのは危険です。まず左右の合計を比較し、その科目でその残高が自然かを確認します。

<span id="worked-1"></span>

### 例題1：三つの勘定から残高を出す

現金の借方合計200,000円・貸方合計100,000円、売掛金の借方合計70,000円・貸方合計50,000円、買掛金の借方合計20,000円・貸方合計30,000円という資料があります。

現金は200,000−100,000＝100,000円の借方残高です。売掛金は70,000−50,000＝20,000円の借方残高です。買掛金は30,000−20,000＝10,000円の貸方残高です。いずれも大きい側から小さい側を引き、残高は大きい側へ記入します。

「借方から貸方を引いてマイナスなら反対側」という方法でも計算はできますが、解答欄へ負の金額をそのまま入れないでください。試算表では通常、借方残高欄か貸方残高欄へ正の額を記入します。左右が同額なら残高は0円で、合計欄には動きが残っていても残高欄には金額が残りません。

## 一か月の取引資料

月初の現金100,000円は、資本金100,000円で拠出されたものとします。以下の合計欄には、この月初残高も含めます。ほかに月初残高はありません。当月の取引は次のとおりです。金額はすべて円で、消費税は考慮しません。

| 番号 | 取引 |
| --- | --- |
| 1 | 商品40,000円を現金で仕入れた |
| 2 | 商品30,000円を掛けで仕入れた |
| 3 | 商品70,000円を掛けで販売した |
| 4 | 商品50,000円を現金で販売した |
| 5 | 買掛金20,000円を現金で支払った |
| 6 | 売掛金50,000円を現金で回収した |
| 7 | 当月の家賃10,000円を現金で支払った |
| 8 | 現金30,000円を普通預金へ預け入れた |

この資料では、月初残高を含む勘定合計を示すことを明記しています。当月の入出金だけを問う別問題では、月初現金100,000円を入金に含めません。合計欄の対象範囲は、どの問題でも同じとは限らないため、表示条件を必ず読みます。

<span id="objective-2"></span>

## 同じ元帳から、三種類の表示へ変換する

合計試算表は左右の動き、残高試算表は差し引いた残り、合計残高試算表はその両方を示します。異なる三つの帳簿から作るのではなく、同じ勘定資料を異なる形式でまとめます。合計額を残高欄へそのまま移さないことが、最初の注意点です。

<span id="worked-2"></span>

### 例題2：取引を転記し、合計試算表を作る

現金の借方には月初100,000円、取引4の50,000円、取引6の50,000円が入り、合計200,000円です。貸方には40,000円、20,000円、10,000円、30,000円が入り、合計100,000円です。普通預金の借方は30,000円、売掛金の借方は70,000円・貸方は50,000円となります。

買掛金は掛け仕入れによって貸方30,000円、支払いによって借方20,000円です。仕入は借方40,000＋30,000＝70,000円、売上は貸方70,000＋50,000＝120,000円です。支払家賃は借方10,000円、資本金は貸方100,000円です。

| 勘定科目 | 借方合計 | 貸方合計 |
| --- | ---: | ---: |
| 現金 | 200,000 | 100,000 |
| 普通預金 | 30,000 | 0 |
| 売掛金 | 70,000 | 50,000 |
| 買掛金 | 20,000 | 30,000 |
| 資本金 | 0 | 100,000 |
| 仕入 | 70,000 | 0 |
| 売上 | 0 | 120,000 |
| 支払家賃 | 10,000 | 0 |
| 合計 | 400,000 | 400,000 |

借方合計は200,000＋30,000＋70,000＋20,000＋70,000＋10,000＝400,000円です。貸方合計も400,000円で一致します。資産の勘定だけを合計していないことに注意してください。負債や資本金、収益・費用も、記入された側で合計します。

<span id="worked-3"></span>

### 例題3：残高試算表と合計残高試算表へまとめる

各行の左右の差額を計算すると、現金100,000円、普通預金30,000円、売掛金20,000円、仕入70,000円、支払家賃10,000円が借方残高です。買掛金10,000円、資本金100,000円、売上120,000円が貸方残高です。

| 勘定科目 | 借方残高 | 貸方残高 |
| --- | ---: | ---: |
| 現金 | 100,000 | 0 |
| 普通預金 | 30,000 | 0 |
| 売掛金 | 20,000 | 0 |
| 買掛金 | 0 | 10,000 |
| 資本金 | 0 | 100,000 |
| 仕入 | 70,000 | 0 |
| 売上 | 0 | 120,000 |
| 支払家賃 | 10,000 | 0 |
| 合計 | 230,000 | 230,000 |

合計残高試算表は、例題2の左右合計と、この残高の二列を同じ科目行で並べます。例えば現金の行は、借方合計200,000円、貸方合計100,000円、借方残高100,000円、貸方残高0円です。買掛金の行は、借方合計20,000円、貸方合計30,000円、借方残高0円、貸方残高10,000円となります。

合計欄400,000円と残高欄230,000円が違っていても誤りではありません。残高欄では、同じ勘定の借方・貸方のうち重なる部分を差し引いているためです。合計欄の左右どうし、残高欄の左右どうしを比較します。合計と残高が同額になるように帳尻を合わせないでください。

<span id="objective-3"></span>

## 左右が合うことは、正確さの一つの確認にすぎない

試算表の左右が合わなければ、集計・転記などに誤りがあると分かります。一方、左右が合っても、すべての取引が正しいとは限りません。取引の両側を丸ごと記録し忘れた場合や、両側を同じ誤った金額で記録した場合は、左右は一致したままです。

同額の別科目へ転記しても、合計は一致することがあります。家賃10,000円を通信費10,000円と誤記すれば、費用の内訳が違いますが貸借差額は生じません。試算表の照合と、証ひょう・仕訳・科目の照合を組み合わせる必要があります。

<span id="worked-4"></span>

### 例題4：片側の転記漏れと、両側の記録漏れを比べる

取引7の家賃10,000円について、現金の貸方は記録したものの、支払家賃の借方を転記し忘れたとします。借方合計は390,000円、貸方合計は400,000円となり、借方が10,000円少なくなります。残高試算表でも、借方220,000円、貸方230,000円で差額10,000円が生じます。

家賃の仕訳そのものを両側とも記録し忘れた場合は、合計試算表の借方・貸方がともに390,000円となり、一致します。現金残高は正しい100,000円より10,000円多い110,000円、支払家賃は0円となります。借方残高全体では現金の過大と費用の過小が相殺され、残高合計は左右230,000円のままです。

この比較から、差額が0円なら誤りがない、と結論づけられないことが分かります。現金実査や家賃支払いの証ひょうを確認すれば、両側の記録漏れを見つける手がかりになります。差額だけを消す架空の雑費を入れる方法は、原因を隠してしまいます。

## 表の空欄を埋めるときも、取引へ戻る

現金の貸方合計が空欄で、借方合計200,000円、借方残高100,000円が分かれば、貸方合計は100,000円です。買掛金の借方合計が空欄で、貸方合計30,000円、貸方残高10,000円なら、借方合計は20,000円です。残高がどちら側かを確かめて、逆算します。

ただし、表の全体合計から一つの空欄を埋めるだけでは、科目の誤りを防げません。計算後は、現金の出金合計や買掛金の支払額など、取引の内容へ戻って確認します。数字のつじつまと事実のつじつまを、両方満たす必要があります。

## 金額の左右を取り違えたときの差額を確かめる

借方へ記入すべき現金入金9,000円を、誤って現金の貸方へ記入した場合を考えます。正しい状態に比べ、借方合計が9,000円少なく、貸方合計が9,000円多くなります。したがって試算表の左右差額は18,000円です。誤った取引額9,000円と、左右の差額18,000円が同じになるとは限りません。

差額が取引額の二倍であれば、左右を逆にした転記を疑う手がかりにはなります。ただし、ほかの誤りでも同じ差額が生じる可能性があるため、二倍という特徴だけで断定しません。該当する仕訳と現金元帳の記入を見比べ、事実として逆記入があることを確かめます。

残高0円の勘定も、期間中の動きが0円とは限りません。未払金の借方合計・貸方合計が各50,000円なら、残高は0円でも、合計試算表には両側50,000円が表示されます。残高試算表だけから、その月の購入や支払がなかったと推測しないでください。残高と取引量の違いを読む場面でも、三種類の試算表の役割が分かります。

残高を両側へ同額記入する方法も避けてください。借方合計45,000円、貸方合計20,000円の勘定なら、残高は借方25,000円だけです。両残高欄に25,000円ずつ書くと、差額が何も残っていない表示になり、勘定の実態と合いません。集計する前に、各行で合計の差と残高の側が一致するかを確かめます。

一方、借方・貸方の合計がともに45,000円なら残高0円です。合計欄の取引は消さず、残高欄を0円として区別します。

## 自分で解く：形式を変えて同じ残高を読む

1. 普通預金の借方合計260,000円、貸方合計185,000円の残高を、金額と側で答える。
2. 未払金の借方合計35,000円、貸方合計62,000円の残高を答える。
3. 売掛金の借方残高28,000円、貸方合計92,000円から、借方合計を求める。
4. 8,000円の現金販売を両側とも記録し忘れた場合、試算表の貸借差額だけで発見できるか答える。

1は借方75,000円、2は貸方27,000円、3は92,000＋28,000＝120,000円です。4は差額だけでは発見できません。現金と売上がともに8,000円少なくても、左右の合計は一致します。4を「一致するので正しい」とした場合は、試算表の確認範囲を復習してください。
