取引を帳簿に記録すると、現金や売掛金など、科目ごとに記入が集まります。そのままでは、別々のページにある記録をまとめて確かめるのに手間がかかります。そこで、元帳の各科目について、左側の借方と右側の貸方の金額を一か所に並べます。この一覧が**試算表**です。一件の仕訳を借方・貸方に同じ金額で記録したなら、科目別に集め直しても、全科目の借方と貸方の合計は同じになるはずです。

科目の左右に書いた金額のすべてを集めたものが**合計**で、一方から他方を差し引いた後に残る額が**残高**です。元帳に借方120,000円と貸方30,000円があれば、合計はそれぞれの額を示し、残高は借方90,000円と示します。<a class="lesson-term" data-lesson-term href="#lesson-term-glossary-d847544c52">合計試算表</a>は左右の合計、<a class="lesson-term" data-lesson-term href="#lesson-term-glossary-b6de5349eb">残高試算表</a>は差を取った残高、<a class="lesson-term" data-lesson-term href="#lesson-term-glossary-c977a964aa">合計残高試算表</a>はその両方を並べます。月初残高を左右の合計に含めるかは、資料や設問で示された表の作り方に従います。

## 元帳の合計は両側に、差だけを残高欄に写す

同じ月の元帳から、現金、買掛金、仮払金を一行ずつ取り出した例です。他にも勘定があるため、この三行だけで試算表全体の合計は作りません。中央の二列は元帳に記入された額をそのまま集計し、外側の二列は差額を大きい側に書きます。

| 借方残高 | 借方合計 | 勘定科目 | 貸方合計 | 貸方残高 |
| ---: | ---: | --- | ---: | ---: |
| 5,000円 | 12,000円 | 現金 | 7,000円 | — |
| — | 3,000円 | 買掛金 | 8,000円 | 5,000円 |
| — | 2,000円 | 仮払金 | 2,000円 | — |

現金と買掛金は差額が同じ5,000円でも、残高の側が異なります。現金は借方12,000円の方が大きく、買掛金は貸方8,000円の方が大きいためです。残高の欄にはマイナスの数を置かず、差が残る側に正の金額を置きます。仮払金の残高は0円ですが、左右に2,000円の記入があったという情報は合計欄に残ります。残高だけを示す表からは分からない取引の動きです。

この表を残高試算表へ写すなら、現金と買掛金は外側にある額を使います。合計試算表にするなら、三つとも中央の二列から写します。0円欄の記号は資料の指示に合わせ、合計欄で2,000円を落とさないようにしましょう。

## 勘定ごとの左右の合計を求めてから差し引く

現金は増加が借方、減少が貸方です。借方合計が200,000円、貸方合計が100,000円なら、残高は借方100,000円です。ここでいう借方合計200,000円は、月末に残る現金そのものではありません。期間中の増加や、この資料に含めた月初残高などを合計した額です。

買掛金は負債なので、通常は増加が貸方、減少が借方です。借方合計20,000円、貸方合計30,000円なら、貸方に10,000円残ります。差額の10,000円は同じでも、どちら側に残るかまで答える必要があります。

減価償却累計額のように、資産の控除を表し貸方に残高がある勘定もあります。すべての勘定を「資産なら借方、負債なら貸方」とだけ覚えて、資料と照合しないのは危険です。まず左右の合計を比較し、その科目でその残高が自然かを確認します。

<span id="worked-1"></span>

### 例題1：三つの勘定から残高を出す

現金の借方合計200,000円・貸方合計100,000円、売掛金の借方合計70,000円・貸方合計50,000円、買掛金の借方合計20,000円・貸方合計30,000円という資料があります。

現金は200,000−100,000＝100,000円の<a class="lesson-term" data-lesson-term href="#lesson-term-glossary-6e92b18d3c">借方残高</a>です。売掛金は70,000−50,000＝20,000円の借方残高です。買掛金は30,000−20,000＝10,000円の<a class="lesson-term" data-lesson-term href="#lesson-term-glossary-bfed7bdad2">貸方残高</a>です。いずれも大きい側から小さい側を引き、残高は大きい側へ記入します。

「借方から貸方を引いてマイナスなら反対側」という方法でも計算はできますが、解答欄へ負の金額をそのまま入れないでください。試算表では通常、借方残高欄か貸方残高欄へ正の額を記入します。左右が同額なら残高は0円で、合計欄には動きが残っていても残高欄には金額が残りません。

## 一か月の取引資料

月初の現金100,000円は、資本金100,000円で拠出されたものとします。以下の合計欄には、この月初残高も含めます。ほかに月初残高はありません。当月の取引は次のとおりです。金額はすべて円で、消費税は考慮しません。

| 番号 | 取引 |
| --- | --- |
| 1 | 商品40,000円を現金で仕入れた |
| 2 | 商品30,000円を掛けで仕入れた |
| 3 | 商品70,000円を掛けで販売した |
| 4 | 商品50,000円を現金で販売した |
| 5 | 買掛金20,000円を現金で支払った |
| 6 | 売掛金50,000円を現金で回収した |
| 7 | 当月の家賃10,000円を現金で支払った |
| 8 | 現金30,000円を普通預金へ預け入れた |

この資料では、月初残高を含む勘定合計を示すことを明記しています。当月の入出金だけを問う別問題では、月初現金100,000円を入金に含めません。合計欄の対象範囲は、どの問題でも同じとは限らないため、表示条件を必ず読みます。

## 同じ元帳から、三種類の表示へ変換する

合計試算表は左右の動き、残高試算表は差し引いた残り、合計残高試算表はその両方を示します。異なる三つの帳簿から作るのではなく、同じ勘定資料を異なる形式でまとめます。合計額を残高欄へそのまま移さないことが、最初の注意点です。

<span id="worked-2"></span>

### 例題2：取引を転記し、合計試算表を作る

現金の借方には月初100,000円、取引4の50,000円、取引6の50,000円が入り、合計200,000円です。貸方には40,000円、20,000円、10,000円、30,000円が入り、合計100,000円です。普通預金の借方は30,000円、売掛金の借方は70,000円・貸方は50,000円となります。

買掛金は掛け仕入れによって貸方30,000円、支払いによって借方20,000円です。仕入は借方40,000＋30,000＝70,000円、売上は貸方70,000＋50,000＝120,000円です。支払家賃は借方10,000円、資本金は貸方100,000円です。

| 勘定科目 | 借方合計 | 貸方合計 |
| --- | ---: | ---: |
| 現金 | 200,000 | 100,000 |
| 普通預金 | 30,000 | 0 |
| 売掛金 | 70,000 | 50,000 |
| 買掛金 | 20,000 | 30,000 |
| 資本金 | 0 | 100,000 |
| 仕入 | 70,000 | 0 |
| 売上 | 0 | 120,000 |
| 支払家賃 | 10,000 | 0 |
| 合計 | 400,000 | 400,000 |

借方合計は200,000＋30,000＋70,000＋20,000＋70,000＋10,000＝400,000円です。貸方合計も400,000円で一致します。資産の勘定だけを合計していないことに注意してください。負債や資本金、収益・費用も、記入された側で合計します。

<span id="worked-3"></span>

### 例題3：残高試算表と合計残高試算表へまとめる

各行の左右の差額を計算すると、現金100,000円、普通預金30,000円、売掛金20,000円、仕入70,000円、支払家賃10,000円が借方残高です。買掛金10,000円、資本金100,000円、売上120,000円が貸方残高です。

| 勘定科目 | 借方残高 | 貸方残高 |
| --- | ---: | ---: |
| 現金 | 100,000 | 0 |
| 普通預金 | 30,000 | 0 |
| 売掛金 | 20,000 | 0 |
| 買掛金 | 0 | 10,000 |
| 資本金 | 0 | 100,000 |
| 仕入 | 70,000 | 0 |
| 売上 | 0 | 120,000 |
| 支払家賃 | 10,000 | 0 |
| 合計 | 230,000 | 230,000 |

合計残高試算表は、例題2の左右合計と、この残高の二列を同じ科目行で並べます。例えば現金の行は、借方合計200,000円、貸方合計100,000円、借方残高100,000円、貸方残高0円です。買掛金の行は、借方合計20,000円、貸方合計30,000円、借方残高0円、貸方残高10,000円となります。

合計欄400,000円と残高欄230,000円が違っていても誤りではありません。残高欄では、同じ勘定の借方・貸方のうち重なる部分を差し引いているためです。合計欄の左右どうし、残高欄の左右どうしを比較します。合計と残高が同額になるように帳尻を合わせないでください。

<span id="objective-3"></span>

## 左右が合うことは、正確さの一つの確認にすぎない

試算表の左右が合わなければ、集計・転記などに誤りがあると分かります。一方、左右が合っても、すべての取引が正しいとは限りません。取引の両側を丸ごと記録し忘れた場合や、両側を同じ誤った金額で記録した場合は、左右は一致したままです。

同額の別科目へ転記しても、合計は一致することがあります。家賃10,000円を通信費10,000円と誤記すれば、費用の内訳が違いますが貸借差額は生じません。試算表の照合と、証ひょう・仕訳・科目の照合を組み合わせる必要があります。

<span id="worked-4"></span>

### 例題4：片側の転記漏れと、両側の記録漏れを比べる

取引7の家賃10,000円について、現金の貸方は記録したものの、支払家賃の借方を転記し忘れたとします。借方合計は390,000円、貸方合計は400,000円となり、借方が10,000円少なくなります。残高試算表でも、借方220,000円、貸方230,000円で差額10,000円が生じます。

家賃の仕訳そのものを両側とも記録し忘れた場合は、合計試算表の借方・貸方がともに390,000円となり、一致します。現金残高は正しい100,000円より10,000円多い110,000円、支払家賃は0円となります。借方残高全体では現金の過大と費用の過小が相殺され、残高合計は左右230,000円のままです。

この比較から、差額が0円なら誤りがない、と結論づけられないことが分かります。現金実査や家賃支払いの証ひょうを確認すれば、両側の記録漏れを見つける手がかりになります。差額だけを消す架空の雑費を入れる方法は、原因を隠してしまいます。

## 表の空欄を埋めるときも、取引へ戻る

現金の貸方合計が空欄で、借方合計200,000円、借方残高100,000円が分かれば、貸方合計は100,000円です。買掛金の借方合計が空欄で、貸方合計30,000円、貸方残高10,000円なら、借方合計は20,000円です。残高がどちら側かを確かめて、逆算します。

ただし、表の全体合計から一つの空欄を埋めるだけでは、科目の誤りを防げません。計算後は、現金の出金合計や買掛金の支払額など、取引の内容へ戻って確認します。数字のつじつまと事実のつじつまを、両方満たす必要があります。

## 金額の左右を取り違えたときの差額を確かめる

借方へ記入すべき現金入金9,000円を、誤って現金の貸方へ記入した場合を考えます。正しい状態に比べ、借方合計が9,000円少なく、貸方合計が9,000円多くなります。したがって試算表の左右差額は18,000円です。誤った取引額9,000円と、左右の差額18,000円が同じになるとは限りません。

差額が取引額の二倍であれば、左右を逆にした転記を疑う手がかりにはなります。ただし、ほかの誤りでも同じ差額が生じる可能性があるため、二倍という特徴だけで断定しません。該当する仕訳と現金元帳の記入を見比べ、事実として逆記入があることを確かめます。

残高0円の勘定も、期間中の動きが0円とは限りません。未払金の借方合計・貸方合計が各50,000円なら、残高は0円でも、合計試算表には両側50,000円が表示されます。残高試算表だけから、その月の購入や支払がなかったと推測しないでください。残高と取引量の違いを読む場面でも、三種類の試算表の役割が分かります。

残高を両側へ同額記入する方法も避けてください。借方合計45,000円、貸方合計20,000円の勘定なら、残高は借方25,000円だけです。両残高欄に25,000円ずつ書くと、差額が何も残っていない表示になり、勘定の実態と合いません。集計する前に、各行で合計の差と残高の側が一致するかを確かめます。

一方、借方・貸方の合計がともに45,000円なら残高0円です。合計欄の取引は消さず、残高欄を0円として区別します。

片側に入れるはずの金額を反対側に入れた場合を、合計の左右に分けて追いましょう。

## 同じ元帳を三種類の試算表に組み替える

<figure id="bb2-trial-balance-aid-1"><svg viewBox="0 0 350 140" width="350" height="140" role="img" aria-label="元帳の左右を合計、勘定ごとに差を計算、残高を左右へ配置" style="max-width:100%;height:auto"><g fill="none" stroke="currentColor"><rect x="12" y="8" width="326" height="32" rx="5"/><rect x="12" y="54" width="326" height="32" rx="5"/><rect x="12" y="100" width="326" height="32" rx="5"/><path d="M175 40v14m-4-5 4 5 4-5m-4 37v14m-4-5 4 5 4-5"/></g><g fill="currentColor" text-anchor="middle" font-size="16"><text x="175" y="29">元帳の左右を合計</text><text x="175" y="75">勘定ごとに差を計算</text><text x="175" y="121">残高を左右へ配置</text></g></svg><figcaption>元帳の左右を合計 → 勘定ごとに差を計算 → 残高を左右へ配置</figcaption></figure>

月初は現金20,000円、普通預金30,000円、資本金50,000円です。当月は現金仕入8,000円、掛売上14,000円、売掛金の普通預金への回収5,000円、通信費の現金払い2,000円がありました。月初を含む合計を求める条件です。

| 勘定 | 借方合計 | 貸方合計 | 借方残高 | 貸方残高 |
| --- | ---: | ---: | ---: | ---: |
| 現金 | 20,000 | 10,000 | 10,000 | — |
| 普通預金 | 35,000 | — | 35,000 | — |
| 売掛金 | 14,000 | 5,000 | 9,000 | — |
| 仕入 | 8,000 | — | 8,000 | — |
| 通信費 | 2,000 | — | 2,000 | — |
| 資本金 | — | 50,000 | — | 50,000 |
| 売上 | — | 14,000 | — | 14,000 |
| 合計 | 79,000 | 79,000 | 64,000 | 64,000 |

現金は、月初20,000円を借方、仕入8,000円と通信費2,000円を貸方に転記します。左右を合計したあと、20,000−10,000＝10,000円を借方残高へ書きます。売掛金も、借方の掛売上14,000円と貸方の回収5,000円を差し引き、借方残高9,000円を出します。合計試算表は表の前半二列、残高試算表は後半二列を使い、合計残高試算表では四列を並べます。79,000円と64,000円が違っていても、両形式ともそれぞれの左右が一致しています。

### 差額から原因の候補を絞る

通信費2,000円を借方に書くところ貸方へ移したなら、借方合計が2,000円減り、貸方合計が2,000円増えます。差額は4,000円です。通信費だけの転記漏れなら差額は2,000円です。差額だけで原因を決めず、まず該当額の仕訳・転記・元帳を突き合わせます。

<details><summary>確認：売掛金回収の両側を転記し忘れたら</summary><p>普通預金と売掛金の転記がともに欠けるので、貸借は合います。普通預金が5,000円少なく、売掛金は5,000円多くなります。入金明細と相手先別の売掛金を照合すると見つかります。</p></details>

<span id="unit6-trial-balance-reconcile"></span>

### 合計欄と残高欄の違いを、同じ勘定で見比べる

たとえば売掛金勘定の借方合計が70,000円で貸方合計が25,000円なら、借方残高は45,000円です。合計試算表では70,000円と25,000円の両方を載せます。一方、残高試算表は、差額45,000円を借方に一つだけ載せます。両方の列を載せる合計残高試算表でも、合計欄と残高欄を足し合わせる必要はありません。

### 差額が同じ二つの誤りを見分ける

借方合計100,000円、貸方合計94,000円の試算表に差が出ています。6,000円の差から、次に何を確かめますか。仕訳帳は正しく、誤ったのは元帳への転記だけだとします。

<details><summary>貸方への転記漏れの場合を調べる</summary><p>貸方の6,000円が抜けると、貸方合計だけが6,000円少なくなります。仕訳帳の貸方6,000円の記録と、その勘定の元帳を照合します。この仮説なら正しい合計は左右とも100,000円です。</p></details>
<details><summary>貸方を借方へ転記した場合を調べる</summary><p>貸方の3,000円を借方に入れると、貸方が3,000円少なく、借方が3,000円多いので差は6,000円です。仕訳帳の貸方3,000円と元帳の借方3,000円を照合します。この仮説なら左右とも97,000円が正しい合計です。</p></details>

### 資料を使って差額の原因を一つに絞る

合計試算表は借方78,500円、貸方72,500円でした。仕訳帳には「通信費3,000円／現金3,000円」があり、通信費への転記は正しく、現金勘定にはこの仕訳番号で借方3,000円の記入があります。このほかに誤りはありません。修正後の左右の合計と、現金残高への影響を求めましょう。

<details><summary>現金の行と、修正後の左右を確認する</summary><p>現金の3,000円を借方から除き、貸方へ移します。借方78,500−3,000＝75,500円、貸方72,500＋3,000＝75,500円です。現金には入金3,000円の誤記を取り消し、さらに支払い3,000円を反映するので、修正前より残高が6,000円減ります。</p></details>

## 月次まで追う例　一つの口座から三つの表を作る

みずき修理店の普通預金を元帳に集めます。問題に「月初残高を含めて借方・貸方を合計する」とあるため、6月初めにあった120,000円を借方に置きます。6月の入金は店主からの元入れ6,000円と以前の売掛金の回収20,000円です。出金は工具代40,000円、以前の買掛金の支払い10,000円、電気代5,000円でした。

| 元帳で調べる量 | 計算 | 普通預金の欄に書く額 |
| --- | --- | ---: |
| 借方合計 | 120,000＋6,000＋20,000 | 146,000円 |
| 貸方合計 | 40,000＋10,000＋5,000 | 55,000円 |
| 借方残高 | 146,000−55,000 | 91,000円 |

合計の表には146,000円と55,000円を、残高の表には借方91,000円を使います。146,000円を月内の入金と考えると、もともとあった120,000円まで新たな入金に数えてしまいます。月内の動きだけを求めるなら、入金26,000円と出金55,000円を比べ、預金が29,000円減ったと読みます。月初120,000円から29,000円減った結果も、月末の91,000円と一致します。

**自分で確かめる。** 誤って6月14日の貸方「普通預金」10,000円を借方へ写したとします。ほかの科目の転記は正しい場合、この科目の誤った借方残高はいくらですか。また、試算表全体の借方は貸方をいくら上回りますか。

**解答。** 誤記で借方が10,000円増えて156,000円になり、貸方が10,000円減って45,000円になります。誤った借方残高は111,000円です。両側を10,000円ずつ反対方向へ変えているため、試算表全体では借方が20,000円多くなります。貸借に差が出たら、差額と同額だけでなく、その半額に当たる取引も確認候補になります。ただし、差額だけで原因を断定せず、元の仕訳と突き合わせます。
