# ITパスポートの教材改訂（2026-11-20）

## 対象と確認した一次資料

対象は現行シラバスVer.6.5、3分野・23中分類・番号付き63項目。ITパスポートに公式な級や選択科目はない。[IPAシラバス一覧](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)、[詳細PDF](https://www.ipa.go.jp/shiken/syllabus/omgdg50000005kn1-att/syllabus_ip_ver6_5.pdf)、[試験要綱Ver.5.6](https://www.ipa.go.jp/shiken/syllabus/rcu1hd00000141gq-att/youkou_ver5_6.pdf)、[対象者像](https://www.ipa.go.jp/shiken/kubun/ip.html)を再確認した。120分・四肢択一100問で、92問をIRT評価に使う。全100問を各1点とする独自模試は、IPAの総合600点・各分野300点という合格基準へ換算できない。

2027年度の見直しは[シラバス案Ver.0.1](https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260630.html)が公表されている段階。現行の試験範囲とは区別する。[2027年1月のCBT再開予定](https://www.ipa.go.jp/shiken/2026/cbt-202701-yotei.html)は別の運用案内として扱う。新しい正式な適用版が出たときに、学習範囲と問題を再照合する。

## 教材を見直した判断

現行の47章は、前提となる基礎、方法、資料を読む演習を学習順に分けている。以前の教材で追加した標本の偏り、在庫の発注、人員配置、回帰の残差、関数呼出し、表計算の照合も含めて点検した。今回の改訂は、各章の専門語を最初に説明し、資料の条件から判断へ進む文章を増やすことを優先した。既存の章の目的と公開URLを保ち、その章で必要な説明と初見の練習を補っている。章数はストラテジ16、マネジメント7、テクノロジ24。

[いぬぼきの流れ図とトレースの教材](https://inuboki.com/ipass/technology14-2/)では、実行する手順を図にし、そのときの変数を表に残して結果を説明する方法を参照した。文章・図表・例題・設問は独自に作成した。

| 分野 | 説明と練習で確かめること |
| --- | --- |
| ストラテジ | 企業・業務・会計・法務の用語を初出で説明する。取引と測定の資料を読み、収益と入金や利益と費用、調査の母集団と回答者を分ける。 |
| マネジメント | 要件と設計・テストを同じ条件で対応させる。作業の依存と人員の空き、SLAの測定区間、監査の証拠の対象と時点を区別する。 |
| テクノロジ | 論理式・プログラム・数式の値を一段ずつ追う。構成、データ、通信、セキュリティの資料で、主張できることと必要な追加確認を判断する。 |

マネジメントの新しい例では、クリティカルパスを短縮すると経路が入れ替わり、8日から7日になることを図と工程表で確認する。SLAの例は、重なった停止を35分と集計し、445/480で約92.71％。計画停止10分を分母と停止時間の両方から除く場合は445/470で約94.68％になる。申請・承認・操作時刻を使う監査例では、規程の存在と実行を裏付ける記録を分ける。実行状況を明らかにする証拠の範囲を超えて結論を一般化しない。

## 章別の根拠

[章別の説明・図表・途中演習の位置](teaching-evidence-20261120.json)に、改訂前の目標とアンカー、追加した説明箇所、全63項目の対応を記録した。本文・例題の見積りは合計3,495分から3,917分。復習、章末のテスト、模試と解き直しの時間は別に確保する。

## 問題と記録

第1回模試の8問を改訂。CTR、期待値、再現率、キュー操作、SQLの行絞込みと集計、取引法規、認証、暗号鍵の使い分けを具体的な条件から考える。答えの選択位置、設問ID、3分野35/20/45問という配分は維持する。第1回はv4、第2回もその独立したv4のまま。第1回の旧版で未提出の記録は保管し、新版では新しい受験を始める。過去の採点済み結果は消さず、同じ版の第2回は途中から再開できる。[設問別の検算と出典](mock-review-20261120.md)。

## 更新方法と限界

章の本文は src/content/lessons/ip-*.md、学習順は各章のorderとunit、問題は分野ごとのip-*.json。設問や採点、解答の意味を変えるときは、その評価の版を更新する。本文の同じ意味を詳しく説明しただけの変更では、受験記録を書き換えない。配布TXTは pnpm build で共有データから再生成する。

63項目の対応だけで、すべての例示用語の独立演習や本試験と同じ難度が検証済みとは判断しない。公式の個々の例示語を全て同じ深さで評価する確認と、受験者による成績・合否との相関は未検証。実際の案件の法的判断と、範囲外の高度な統計モデル等は扱わない。今回の教え方と検算、設問の構造、ソフトウェアの確認、外部専門家の監修を区別する。

## 公開前の動作確認

型チェックはエラー・警告・ヒント各0件。学習記録・評価・コンテンツの105テストとIndexNowの3テスト、計108件が成功した。静的ビルドは1,142ページを生成し、383件のサイトマップURLと32,390件の内部参照、構造化データ、タイトル、公開・noindex区分、共有広告設定の検査を通過した。

隔離したブラウザーで47章すべてを360px幅で確認し、ページ全体の横方向のはみ出しがないことを確かめた。途中演習の誤答と全角数値による正答、用語説明、星と学習中の再読込、検索、共有URL、バックアップの書き出し・不正ファイル拒否・統合・確認付き置換を確認した。両模試の回答保存と、仮想時刻を121分進めて再び開いたときの期限切れ確定も成功した。JavaScriptを無効にした状態の静的解説、キーボード操作できる表の横スクロール、印刷用PDF、明暗の図表表示も点検した。

ブラウザー検査では広告を含む外部通信を遮断した。広告配信そのものの確認はこの検査に含まない。検索順位やAI引用の変化は測定していない。
