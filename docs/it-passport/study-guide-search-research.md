# ITパスポート 勉強ガイドの検索意図調査（2026-11-13）

対象は日本語・日本の学習者。日本向け Google / Bing の結果ページおよび Google Trends の比較画面は、この実行環境から取得できなかった。Google Search Console / Bing Webmaster Tools の権限済みエクスポートや検索数データは利用できていない。以下は公開ウェブ検索で確認した検索意図の手掛かり。検索量、順位、トレンドの実測値はない。

| 調査した語句 | 確認したページと意図 | 対応 |
| --- | --- | --- |
| ITパスポート 模試 復習／ITパスポート 過去問 復習 | [資格ナビ](https://shikakunavi.jp/it-passport/past-questions-guide) は過去問の年数・復習を扱い、[かころーぷ](https://itpassport.kakoloop.com/benkyo/mogi-shiken/) は模試全般を扱う。 | 完成した答案を起点に、誤答・迷った正解・未解答から次の教材を選ぶ新規ガイド。 |
| ITパスポート 何から 勉強／ITパスポート 勉強 順番 | [勉強の進め方の例](https://dokugaku.wheelhouse.jp/itpass/guide/) は週単位の順序を扱う。 | 既存コースの学習プランが担当。新規ガイドは作らない。 |
| ITパスポート 過去問 何周／ITパスポート 点数 伸びない | 公開ウェブ検索で過去問の使い方と点数に関する記事が見つかる。需要の大小は確認できない。 | 解答を覚えた場合は別条件で解くという助言を収録。得点から合否を予測しない。 |
