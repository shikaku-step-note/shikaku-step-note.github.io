# ITパスポート 模試第1回の設問確認（2026-11-20）

## 公式範囲・形式

[IPAの現行シラバス一覧](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)で、2026年1月掲載の[Ver.6.5](https://www.ipa.go.jp/shiken/syllabus/omgdg50000005kn1-att/syllabus_ip_ver6_5.pdf)と、2026年7月掲載の[試験要綱Ver.5.6](https://www.ipa.go.jp/shiken/syllabus/rcu1hd00000141gq-att/youkou_ver5_6.pdf)を確認した。

現行は120分・四肢択一100問。分野別の出題目安はストラテジ35問、マネジメント20問、テクノロジ45問。総合評価は92問で行い、残り8問は今後の出題のための評価に使われる。分野別評価の問題数は32・18・42問。公式の合格基準は総合600点以上、かつ各分野300点以上で、いずれも1,000点満点のIRT評価点で判定される。当サイトは100問を各1点で採点する独自練習で、公式の評価点や合否の予測へ換算しない。

[2027年度からの新制度のシラバス案](https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260630.html)は案Ver.0.1として掲載され、変更の可能性が明記されている。今回の100問の分野・採点前提は現行版に合わせる。新制度の予定と現行の適用範囲を区別する。公式の公開問題一覧へのリンクは確認したが、iパス側の一覧はネットワーク制限表示となり、最新年度100問の原本を全問確認したとは扱わない。

## 記録と検証

第1回の改訂版は2026-11-mock-01-v4、第2回は2026-11-mock-02-v4。第2回の問題本文は変更していない。旧第1回の得点と履歴は旧版として保存し、旧版の途中解答は新しい問題へ当てはめない。各回100問、120分、四つの選択肢、35／20／45の分野数を確認。200問のIDの一意性と問題文の重複を検査する。
