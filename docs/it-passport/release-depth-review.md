# ITパスポート Ver.6.5 深度レビュー

## 公式情報

- IPAの現行シラバス一覧と詳細版 Ver.6.5、試験区分の案内、試験要綱 Ver.5.6、2027年度向けのシラバス案を2026-11-12に確認。適用版、公式出典、確認日の表示はコースの対応表およびTXTへ出力する。
- 現行試験は120分・四肢択一100問。公開問題は教材に転載しない。形式の比較には確認できた2024・2025年度のIPA公開問題の該当箇所を使った。2026年度公開問題の本文は検証時に取得できなかった。
- 模試の配分は35／20／45問。実試験の評価対象は92問で、IRTを用いる。本サイトは全100問を練習用に各1点で採点する。

## 教学・評価の証拠

- [coverage-depth.json](coverage-depth.json) は63番号と実装済み本文・設問を結ぶ項目索引。番号が一致するだけで細目の学習達成とは判定しない。
- ストラテジの法務、管理図、標本と検定、財務の条件変更、調達資料の読み合わせについては [strategy-coverage.json](strategy-coverage.json) と [strategy-depth.md](strategy-depth.md) を参照。
- マネジメントの要求・受入、開発手法、工程、サービス移行、監査・統制については [management-depth.json](management-depth.json) と [management-depth.md](management-depth.md) を参照。
- テクノロジの数理、擬似言語、機器、DB、通信、AI、セキュリティの根拠と細目は [technology-depth.md](technology-depth.md) を参照。
- 37レッスンのURLと固定IDを保持。理解度チェックは186問から347問へ拡充（ストラテジ57、マネジメント38、テクノロジ66問を追加）。全37レッスンで新しい視覚教材を確認。既存問題は残し、新しい理解度チェックは新しい版で実施。ケース演習は図書館、配送通知、在庫補充を題材に、5資料・12問を収録。計算例を別式で検算。
- 模試2回の200問を独立したAIレビューで確認。200問の問題文、正答と解説を通読し、誤答選択肢は問題点のある箇所と代表例を詳しく確認。第1回は短い解説67問を拡充し、前問への依存と容量の前提を明確にした。問題ID、採点、版は維持。第2回は重複しやすい技能を、境界の判定、切戻し、可用性、疑似手順の追跡などの新作13問に変更し、版を更新。旧採点履歴を保持し、新版で再解釈しない。
- 教材の図は独自制作。ハードウェアの写真風イラストは生成画像を確認してWebPに変換し、学習用の例として公開した。内容はUSBでつながるキーボードと外付けSSD、LAN端子からスイッチへつながるケーブル。公開画像の場所は `public/images/it-passport/workstation-connections.webp`。

## 残る確認範囲

番号ごとの対応は確認した。公式資料に列挙された細かい用語のすべて、法令の個別案件・詳細な例外、複数手法にわたる統計検定の計算、長い実務資料のあらゆる組合せを個別の試験水準まで確認したわけではない。AIによる独立点検を実施したが、専門家による外部監修や受験者での難易度校正は行っていない。
