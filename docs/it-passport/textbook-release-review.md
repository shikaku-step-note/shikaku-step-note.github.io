# ITパスポート Ver.6.5 教材改訂の確認記録

## 対象

IPAの現行シラバス一覧、詳細シラバスVer.6.5、試験区分の案内を2026-11-12に確認。現行試験は四肢択一100問、120分。2027年度向けシラバス案は現行教材の適用範囲から区別した。令和7年度公開問題のIPA検索結果から擬似言語と表計算の資料を伴う形式を確認した。公開問題PDFの直接取得はこのセッションではエラーだったため、特定問題の頻度や難易度は推定していない。追加した問題と図は独自作成。

## 教学と評価

- 既存37章のURLと固定IDを保持し、3章を前提レッスンの直後へ追加。全40章。理解度チェックは347問から485問へ拡充（ストラテジ36、マネジメント33、テクノロジ57、読解12問を追加）。経営データでは比較の分母、構成の変化、利益と費用を順に扱う。工程計画では前進・後退計算、工期を決める経路の切替え、期限と費用を扱う。表計算では複合参照、条件付き合計、コピー先での検算を扱う。
- 読解3章は横棒図、作業の依存関係図、セルを選ぶと参照先と結果が変わる表計算の教材を使用。静的な図、本文、解説も用意した。数値解答8件を別の式で再計算した。
- 公式63項目、23中分類と章の対応は `textbook-register.json`。分野別の記録は各節の位置、例題、独立練習とその判断根拠を示す。番号付き項目の対応と、全例示語の確認は別に扱う。
- 独立したAIレビューで、ストラテジとマネジメントの新問、テクノロジの数値・事実の重点箇所、読解3章の全新問を確認した。前後比較の因果、広告費指標、SLAの予定時間、発電切替え、期限と費用、数式の参照、例題と独立練習の重複を修正した。
- 既存の二つの100問模試はそれぞれ120分。今回の変更は章末の理解度チェックで、模試の設問・版・採点には変更を加えていない。過去版の結果とレッスンの記録は保持。章末チェックを新しい版で開始した場合、旧版の途中解答を新版へ流用しない。

## 残る確認範囲

個別の法的判断、シラバスに挙げられた全例示語を個別に問う演習、特定の統計検定手法の詳しい計算、公式試験と同じ難易度の実証は対象外または未確認。一次資料で確認できる事項と教材内の架空例を区別する。専門家の外部監修および受験者による実測は実施していない。
