# ITパスポート全範囲の教材レビュー（2026-11-16）

## 対象と出典

現行シラバス Ver.6.5 の3分野、23中分類、番号付き63項目を対象とした。ITパスポートの公式の級・選択科目はない。サイトの23ユニット、41ステップは学ぶ順番を示す区切り。以下を2026-11-16に再確認した。

- [IPA ITパスポート試験の概要と評価基準](https://www.ipa.go.jp/shiken/kubun/ip.html)
- [IPA シラバス一覧](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)・[現行詳細 Ver.6.5](https://www.ipa.go.jp/shiken/syllabus/omgdg50000005kn1-att/syllabus_ip_ver6_5.pdf)
- [IPA 試験要綱 Ver.5.6](https://www.ipa.go.jp/shiken/syllabus/rcu1hd00000141gq-att/youkou_ver5_6.pdf)
- [IPA 公開問題・解答例一覧](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html)
- [IPA 2027年度以降の試験制度見直しに関する案内](https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260630.html)

公開資料の試験形式と用語・表計算の規則を参照し、問題・数値・図表は独自に作成した。公開問題一覧を参照できたが、該当する全公開問題の原本を通覧した記録ではない。120分・四肢択一100問（評価対象92問）が本試験。IPAのIRT評価点・基準点に練習得点を換算できない。将来版の改定案は現行の範囲に加えていない。

## 教材と評価

- [番号付き項目・各レッスン・図表の対応](course-aid-evidence-20261116.json)。41章・23ユニット・103点の図表・解答を本文でも読める途中演習41件を記録した。
- [ストラテジ](strategy-objective-audit.md)・[マネジメント](management-release-audit.md)・[テクノロジ](technology-chapter-audit.md)の各監査で、目標、例題、追加演習への対応をたどれる。既出の説明や例題を残し、条件変更、途中計算と検算、判定の根拠を補った。
- 独立した最終章では受入条件、集計表、復旧記録を読む。指標の対象範囲を合わせる作業を練習し、6問は本文と異なる資料で確かめる。23ユニットに転用問題を1問ずつ追加。テクノロジの既存の技能表で独立設問との対応が空だった26件に練習問題を追加した。
- 最終工程の資料読解の後は、既存の入力式総復習と資料別ケース、120分100問の異なる模試2回へ進む。複数経路の工期、共通障害、条件付き集計、通信の所要時間など、一部の模試問題を差し替えた。本文・例題の目安は3,030分。復習・模試は別に確保する。
- 過去のレッスンIDと評価IDを保ち、設問構成を変えた評価の版を更新した。旧版結果は保存する。旧版の途中解答を新版の問題へ流用しない。
- 番号付き63項目はすべて対応先を確認した。シラバス中の例示用語ごとの演習、出題頻度、受験者による模試成績と本試験の相関は独立に検証していない。

## 検索向けの編集判断

11月15日のGoogle Search Consoleの24時間エクスポートには、一部の授業ページと「業務分析とは」「itパスポート 何問」などのクエリが出ている。エクスポートはページとクエリの組合せを示さず、少数の表示回数から原因や需要は推定していない。Bingエクスポートはサイト全体の集計。タイトルでは教材と学ぶ順番、120分模試があることを明示し、既存の試験時間記事、出題範囲、表計算、受入試験の教材をそれぞれの検索意図に合わせて案内した。

## 次の版を作る場合

IPAが新しい適用開始日と正式版を出したら、まず63項目との対応と練習問題の前提を照合する。変更した章はIDを維持し、採点・設問を変更した評価は版を進める。公開用TXTは `pnpm build` で講義と評価データから再生成される。
