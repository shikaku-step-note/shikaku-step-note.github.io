# ITパスポート マネジメント系の教材確認

対象はIPAの現行シラバス Ver.6.5 の項目25〜32（印刷ページ27〜34）です。2026年11月12日にシラバス細目、令和7年度の監査・内部統制、令和6年度のアローダイアグラムを含む公開問題を参照しました。問題文、ケース、数値、図は新規作成です。

| 現行レッスンID | 作例・練習 | 新しい確認問題 |
| --- | --- | ---: |
| ip-development | 講習予約取消、負荷の達成判定、機能ポイント、発券データの不整合 | 8 |
| ip-agile | 貸出機の試作、スプリント結果の使い分け、点検端末の不確実性 | 8 |
| ip-project | 予約システムの切替え、短縮案と経路交代、リスク対応 | 6 |
| ip-services | 計画停止の除外、障害の振り分け、UPSと発電機の時間差 | 8 |
| ip-audit | 支払先変更の記録突合、調査範囲、異動時の権限削除 | 8 |

全ページに、例の手順や関係を示すインラインSVG図を追加しました。本文と代替テキストで図の意味を確認できます。元のレッスンID、URL、問題IDを使用します。学習目標別の証拠は `management-depth.json`、新しい問題は `src/data/ip-depth-management.json` を参照してください。新しい確認問題は計38問で、うち数値入力は4問です。品質特性、CMMIの成熟度、プロジェクト終結、サービスのライフサイクル、監査の保証・助言について、作例と練習を追加しました。

確認問題は各技能の代表例です。すべての例示語を単独で評価していません。受験者データによる難易度校正、外部専門家による査読、規格を実務に適用する専門資格水準の演習は含みません。統合済みのローカルビルドをChromiumで開き、360px、ライト・ダーク両配色、JavaScript無効の条件で全5ページの図の表示、代替名、キャプション、図と文字の収まりを確認しました。サービスの図は枠内の余裕を増やすためにラベルを短くしました。変更後の表示、公開先、採点の最終確認は公開工程で行います。
