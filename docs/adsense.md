# Google AdSenseの導入と運用

確認日：2026年10月28日。サイト：<https://shikaku-step-note.github.io/>。

## サイトに実装した内容

- パブリッシャーID：`ca-pub-4767048586306805`。公開用の識別子です。
- `src/layouts/Layout.astro`で、ホームと`/qualifications/`配下のindexableな公開ページのheadに、提供された非同期スクリプトを一度だけ出力します。今後追加する公開教材にも適用されます。
- `noindex`のテスト実行ページ、サンプル教材、マイ学習、検索、404、旧`/web/`の移転ページに広告タグを出力しません。規約・プライバシーポリシーなどの案内ページとHTMLサイトマップも対象外です。
- `public/ads.txt`をルートの<https://shikaku-step-note.github.io/ads.txt>へ公開します。行は`google.com, pub-4767048586306805, DIRECT, f08c47fec0942fa0`です。
- プライバシーポリシーに広告CookieとGoogleへの通信、設定の変更先を記載し、規約に広告と教材の関係を追記しました。
- 広告用に学習記録を読み出したり送信したりする処理や、独立したアクセス解析タグ、広告ユニットは追加していません。

## AdSense管理画面で必要な設定

このメモは管理画面の操作完了を示すものではありません。承認状態、自動広告、配信地域、同意メッセージの公開状態は、サイトのコードから確認できません。

1. 「サイト」で`shikaku-step-note.github.io`を選び、「AdSenseコードスニペット」の確認を進め、画面の案内に沿って審査をリクエストします。ads.txtも上記URLで確認できます。Google側への反映には時間がかかる場合があります。
2. 広告を有効にする前に「プライバシーとメッセージ」で、対象地域に必要な同意メッセージを設定・公開します。EEA・英国・スイス向けのパーソナライズ広告には、Google認定のCMPが必要です。Googleが提供するCMPも選択肢です。地域に応じた表示、拒否・設定変更・同意撤回の操作が実際に動くことを確認してください。独自の確認ダイアログで代替できるとは扱いません。
3. 審査後に「広告」で自動広告を使うか決めます。このリポジトリは自動広告の設定を変更しません。タグだけで広告表示が必ず始まるわけではありません。
4. 自動広告を使う場合は、モバイル・PCのプレビューで教材本文と理解度チェックを確認します。レッスン本文には理解度チェックが含まれるため、ページ内の問題・解答・学習ボタン付近は「除外エリア」で除外してください。HTMLの独自クラスだけでは広告の除外を保証できません。適切に除外できないページは「除外ページ」に登録します。
5. 推奨：最初は学習を中断しやすい全画面広告や、操作を覆う広告を無効にし、控えめな量から確認します。設問や解説と広告が混同されないこと、誤クリックを誘う配置にならないことを確認してください。

本番の広告をテストのためにクリックしないでください。広告ブロッカーやネットワーク制限によってタグが読み込まれなくても、教材や学習記録の機能はそれに依存しません。

## 保守と検証

`pnpm check`、`pnpm build`、`pnpm verify`で確認します。`verify`は全HTMLでの広告タグの対象・除外、ID、非同期設定、head内の位置、重複、ads.txtを検証します。教材のURL構造を変更した場合は、Layoutの条件と検証条件、管理画面の除外ページを見直します。

パブリッシャーを変更する場合は、Layoutの`ca-pub-`、ads.txtの`pub-`、検証スクリプトとこのメモを一緒に変更してください。広告ネットワークやデータの扱いを変更した場合は、公開中のプライバシーポリシーも見直します。
