- 4講から6講、講内の採点付き設問56問から70問、単元確認13問から22問。2講を追加し、既存の固定ID・URL・用語の順序を維持。設問が変わった理解度チェックと単元確認だけを新しい評価版にする。元のチェックは設問・版に紐づく履歴として保つ。
- 公式形式は選択式40分・100点満点で70点以上（S01・S04）。既存の全範囲40分模試2回は維持。各30問と30・40・30点は公式公開例を参考にした独自設計。講内と単元確認の入力練習は、科目選択・金額・根拠を練習するための補助。難易度・時間の実測や外部資格者の監修は行っていない。
- 当座預金は2027年度確定範囲にも残る。紙の小切手と手形は2027年4月1日からの出題で削除（S08・S10 PDF8頁）。値引、割引、決算整理、銀行勘定調整表を今回の必須としない。
- 資料・設問・図は独自作成。SVGを使い、金額と説明は本文・表からも確認できる。既存の公開ルールと保存スキーマを使う。更新時は lesson Markdown、Unit 2の質問JSON、対応表、問題と採点の版、TXTを同時に点検する。
