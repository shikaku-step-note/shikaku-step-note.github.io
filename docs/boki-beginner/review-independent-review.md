# 単元・総復習問題：独立した内容・目標対応レビュー

確認日：2026-10-28。別担当AIによるレビューです。人間の簿記資格保有者による監修、公式の採点認定、実際の受験者への効果検証ではありません。

## 対象と方法

`src/data/boki-beginner-reviews.json`の初稿にある単元問題72件と、新しい総復習問題12件の計84件を全問読みました。総復習に再利用される12件は同じIDの問題なので、別の独立問題として加算していません。

設問だけから解法と必要条件を読み、正答・誤答・解説の意味を確認しました。計算は著者の`review-arithmetic-witnesses.json`の値を転用せず、各設問から別に式を立てました。数値入力56件を`work/review-bb-review-arithmetic.py`で再計算し、56件すべての計算値が許容解答に一致しました。残る選択式28件は、科目、借貸、取引の時点、相手勘定、範囲の条件から正解内容を検討しました。

別途、対応する24記事の実際の目標を読み、問題が本当に評価する目標へ対応付け直しました。目標が3件あるから問題順に0・1・2を付ける方法や、総復習だから一律に全3目標を付ける方法は使っていません。

## 発見した内容上の問題

### 一枚の小切手を部分的に預け入れる設定

初稿の`bb2-u2-review-07`は、他人振出小切手18,000円を受け取り、そのうち10,000円だけを預け入れる設定でした。一枚の小切手の一部だけを預金に入れる説明としては成立しないため、10,000円と8,000円の二枚を受け取り、10,000円の一枚を預け入れる設定へ直すよう伝えました。数式18,000−10,000＝8,000円が合っていても、取引条件の妥当性は別に確認する必要があります。

### 試験範囲の運用方針を技能評価に数えていた問題

初稿の`bb2-u4-review-12`は、2027年度改定と現行範囲を区別する教材運用の理解を問う内容でした。説明の事実関係は現行・将来の区別に沿いますが、`bb2-bills`の「債権・債務の集計」目標を評価する問題とはいえません。実際の手形・電子記録の発生、切替え、決済、残高を問う問題へ置き換えるよう依頼しました。記事の公開方針を理解しただけで、簿記技能を習得した記録にしないためです。

### 参照先の記事が設問の主要技能とずれていた問題

- `bb2-cumulative-05`は土地の売却後の未収入金残高だけを問います。土地の帳簿価額は与えられていますが、売却損益の計算は求めていません。`bb2-assets`の売却損益目標へ無理に対応付けず、未収入金を扱う`bb2-other-claims`の残高目標を主にするよう依頼しました。
- `bb2-u5-review-09`は資産・負債と損益振替前資本金から利益を求めます。追加元入・引出しから資本金残高を求める設問ではないので、利益と純資産の関係を扱う`bb2-profit`の目標を主にするよう依頼しました。

この2問について、レビュー担当が許された変更範囲は目標情報だけでした。そのため一時的に主記事の目標を空配列とし、実際に対応する記事を`targetObjectives`へ明示しています。主記事IDと空配列を含む公開前の最終修正は統合担当が行います。空配列を「目標達成」と解釈してはいけません。

### 印紙の費用認識条件

`bb2-u5-review-12`の収入印紙代について、事業用の契約書に貼付して当月使用済みであることを明示するよう依頼しました。支払いという事実だけと、費用となる使用条件を区別するためです。初級で要求されていない貯蔵品の決算処理を追加する趣旨ではありません。

## 目標対応を直しただけでは埋まらない評価の不足

初稿の単元レビューだけでは、次の目標を直接評価する問題が不足しています。各レッスンの理解度問題や模試に同じ技能があっても、「単元レビューが全目標を評価する」とは表現できません。統合担当へ、必要なら対象を絞った追加問で埋めるよう伝えています。

- `bb2-transaction`目標2：複合取引の借貸合計の一致。
- `bb2-loans`目標0・2：貸付・借入発生時の仕訳、および元金の一部返済後の残高・利息。
- `bb2-temporary`目標0：不明な内容と確定した前渡し・立替えの分類。
- `bb2-depreciation`目標1：毎月の見積減価償却の仕訳そのもの。
- `bb2-vat`目標0：指定税率を使う税抜額・税込額・税額の計算。
- `bb2-trial-balance`目標1：同じ資料を三種の試算表へ整理する技能。
- `bb2-integration`目標0：整合した月初残高・当月取引から月末試算表を作る技能。

手形の範囲方針問題を実技能へ変更した後も、手形を振り出した側・受け取った側の発生仕訳を単元レビューで直接問うかは別に確認します。複数の残高問題へ同じ目標を付けただけでは、その発生仕訳を評価したことになりません。

## 結果と限界

初稿84件について、上記の取引条件・主要参照先・評価対応・明示条件の問題を伝達し、数値解答56件は独立再計算と一致しました。税額・利率・費用認識は設問で与えられた条件に基づき、一般的な申告納税額や取引相場を主張していません。

このレビューの後で統合担当が加える設問・変更する設問は、84件の点検結果へ自動的に含めません。新設問の再計算、目標対応、正解番号、再利用コピー、評価版の確認を追加で行う必要があります。ブラウザの採点・保存・バックアップ・表示・配信確認は別の統合検証です。
