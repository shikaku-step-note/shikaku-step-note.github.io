# 簿記初級 ユニット2 基礎から応用までの確認

2026年11月14日確認。対象は2026年度（2027年3月31日まで）。[現行出題範囲PDF](https://www.kentei.ne.jp/wp/wp-content/uploads/2018/01/h30bokishokyu.pdf)の1頁 §1(4)–(5)・§2(1)、2頁 §2(5)、3頁使用勘定を照合。帳簿・証ひょうと伝票、現金預金、三分法と返品を扱う。 [公式ネット試験案内](https://www.kentei.ne.jp/33013)・[公開サンプル](https://www.kentei.ne.jp/wp/wp-content/uploads/2018/04/s-sample0404.pdf)。[2027年度の改定説明書](https://www.kentei.ne.jp/wp/wp-content/uploads/2014/10/2027_kaitei_shushi_fixed.pdf#page=8)では紙の小切手・手形の出題を削除。普通・当座等の口座は紙の小切手と区別する。会計処理は資料で指定し、決算整理や銀行勘定調整表は扱わない。
