# 日商簿記初級 教材改訂の確認記録

## 公式範囲

2026年度の出題範囲（2027年3月31日まで）を対象にした。日本商工会議所の現行PDF、ネット試験案内、公開サンプル、2027年度確定版の適用境界を2026-11-12に確認。2027年4月1日からの手形、キャッシュレス決済、資本金の記載変更は現行教材・模試から分けた。出典の版と個別確認日は [source-register.json](source-register.json) に記載。

## 教材と確認

- 全24章・6ユニットのURL、固定IDと並び順を保ち、実例、条件を変えた練習、途中計算、検算を追加。公式範囲を分けた46技能から実際の本文と例題へリンクできる。[機械可読の対応表](textbook-register.json)
- 章末チェックは259問から349問へ拡充。基本原理32問、期中取引24問、固定資産と月次32問、月次ラボ2問を追加。金額を入力する問題、選択問題、借方・貸方を行単位で入力する仕訳を含む。
- [基本原理](textbook-principles.json)、[期中取引](textbook-transactions.json)、[月次集計](textbook-monthly.md) に教材の位置と新設問の証拠を記録。仕訳から元帳に追う図、差引入金と返済の図、税額・償却・純資産の図、共通資料、月次の残高を順に開く練習を追加。
- 独立したAIレビューで例題、追加の問題と数値、ラボの借貸および利益・純資産の検算を点検。家計と事業の区別、現金と掛けの混在、手形の判定時点、印紙の使用時点、月初の資産の前提を明確にした。
- 40分・100点の独自模試2回は選択式のまま既存の版と採点を維持。40分、100点中70点という公式案内と、公開サンプルの構成を参照している。公開サンプルには金額欄もある。教材の構成や部分点を本試験の固定仕様とはみなしていない。
- レッスン完了、ブックマークと評価履歴を保持。追加した章末チェックの版を更新し、旧版の途中解答を新設問へ流用しない。

## 限界

実受験者による難易度校正と外部専門家監修は未実施。公式の固定小問数、詳細な配点、部分点の基準は公開資料で確認していない。2027年度の本編への切替えはこの更新には含めない。
