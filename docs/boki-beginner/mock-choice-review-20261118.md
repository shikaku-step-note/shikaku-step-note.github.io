# 簿記初級模試の選択肢と解説の再点検

確認日：2026年11月18日

日本商工会議所の[ネット試験案内](https://www.kentei.ne.jp/33013)で、簿記初級の出題形式が選択式、試験時間が40分であることを確認しました。[趣旨・内容](https://www.kentei.ne.jp/bookkeeping/class-s/effect)には100点満点で70点以上と記載があります。二つの模試は、[公式の公開サンプル](https://www.kentei.ne.jp/wp/wp-content/uploads/2018/04/s-sample0404.pdf)の大問構成を参考にした、各30問・30点／40点／30点の独自問題です。小問数、配点、練習得点の算出方法は当サイトの設計です。

今回は第1群のうち12問を改訂しました。用語の語感や選択肢の長さで答えを見分けられる場面を減らし、資料の読み分け、科目の判断、途中計算を確かめる問題と解説にしました。

| 設問 | 正答を導く事実と確認した誤り |
| --- | --- |
| A-c01・c02 | 元金80,000円の返済では預金と借入金が同額減り、純資産は不変。今月の販売12,000円と前月の売掛金回収8,000円はどちらも現金を増やすものの、今月の売上は12,000円。 |
| A-c05・c06・c07 | 請求や振込の予定と実行、引渡し前の手付金と売上や仮受金、従業員の税金の預りと店の費用や立替金を、取引の条件から区別。 |
| A-c08・c09・c10 | 備品の帳簿価額は120,000−(24,000＋3,000)＝93,000円で預金は不変。税抜方式の全品返品では本体18,000円と税1,800円をともに取り消し、売掛金が19,800円減少。借方合計91,000円と借方残高91,000−65,000＝26,000円を区別。 |
| B-c07・c08・c09 | 振込の理由が確認できるまで仮受金を使用。記帳前の税額を支払う設問では、事業用建物の固定資産税20,000円だけを事業の費用に計上。簿記初級の購入時処理に従い、事務用封筒3,600円は購入時に消耗品費に計上。 |
| B-c10 | 売掛金の当月貸方記入56,000円から、返品8,000円と手形への振替13,000円を除くと、回収額は35,000円。 |

改訂前と比較し、各回30問で計100点になること、全60問の設問文がそれぞれ異なること、各問に異なる4選択肢があること、変更した12問の正答と計算を確認しました。残り48問と二つの月次資料は従来の内容です。月次資料の残高と損益の検証方法は[既存の独立レビュー](mock-independent-review.md)と[計算データ](mock-ledger-witnesses.json)を参照できます。

模試ID、設問ID、正答位置、配点、復習先は維持しました。選択肢の意味と解説が変わるため、模試の版を更新します。旧版の完了済み記録は旧版の得点として保持し、改訂後の選択肢を使って再採点しません。受験者による難易度や所要時間の試行は行っていません。
