# 簿記初級 ユニット1 基礎から応用までの確認

対象は2026年度（2027年3月31日まで）の簿記初級です。2026年11月14日に[現行の出題範囲 PDF 1ページ](https://www.kentei.ne.jp/wp/wp-content/uploads/2018/01/h30bokishokyu.pdf#page=1)、[公開サンプル](https://www.kentei.ne.jp/wp/wp-content/uploads/2018/04/s-sample0404.pdf)、[ネット試験案内](https://www.kentei.ne.jp/33013)、[2027年度確定版](https://www.kentei.ne.jp/wp/wp-content/uploads/2014/10/2027shokyu_fixed.pdf)を照合しました。対象は §1(1)～(3) の財産・損益・取引・勘定・仕訳・貸借平均。2027年度もこの基礎原理は同じです。将来版で追加される株式会社の設立・増資等は別の範囲です。公式資料の数値・設問は転載していません。

| 講 | 初歩から標準への説明 | 応用・誤り・教材 | 独立した理解度チェック |
| --- | --- | --- | --- |
| bb2-business | objective-1～3、worked-1～3。店と家計の区切り、資産・負債の分類、等式とB/S | unit1-business-checkpoints。貸借対照表の図と資料からの予測、貸借が一致する誤りと借換え | bb1-depth-business-equation。回収と返済後の純資産 |
| bb2-profit | objective-1～3、worked-1～3。収益と費用、資金と利益、二つの表 | unit1-profit-two-periods。利益と入金日の図、二期間の判断・解答 | bb1-depth-profit-equity。元入れと引出しから利益を逆算 |
| bb2-transaction | objective-1～3、worked-1～3。取引の判定・種類と8要素の結合 | unit1-transaction-predict と unit1-transaction-correct-classification。発注から手付金・納品までの時系列と訂正 | bb1-depth-transaction-contract。引渡し前の支払いの判定 |

| bb2-foundations-case | 開業月の順次仕訳、売上と回収の図、B/SとP/Lの照合 | unit1-case-existing-shop、unit1-case-error-clinic、unit1-case-transfer。元手の増減の図、貸借一致でも残る誤記を解く | bb1-depth-case-balanced-error。回収の誤記による利益の過大。単元確認の別資料6問でも応用 |

Unit 1は5講の固定ID・URL・語句を維持し、講内82→87問、単元確認13→19問。単元の共通資料では、発注・完了・回収・元入れ・引出し・元金と利息を区分し、別の数値と異なる誤りを独立に採点します。講内および単元確認を新しい評価版へ。旧試験記録とURLは既存の保存機構で維持し、問題が異なる進行中の解答は新版として採点しません。用語問題、Unit 2以降、既存の選択式40分模試2回を維持。公式は100点満点・70点以上。模試の内訳は公開サンプルを参考にした独自構成で、難易度の実測や外部専門家の監修はありません。

公開前に、現行範囲と根拠の独立照合、講内の新規作例の計算と仕訳、共通資料の残高と利益の二通りの計算、本文図と解答の表示を確認。支払いを全額費用にしても左右が合う例では、正しい結果との差まで説明しています。
