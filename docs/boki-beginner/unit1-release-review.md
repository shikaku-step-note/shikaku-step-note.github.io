# 簿記初級 ユニット1の教材確認

対象は2026年度の簿記初級です。日本商工会議所の[現行の出題範囲PDF](https://www.kentei.ne.jp/wp/wp-content/uploads/2018/01/h30bokishokyu.pdf)の1ページ目と[適用年度の案内](https://www.kentei.ne.jp/bookkeeping/exam-list)を参照。教材内のユニット番号は学習順です。帳簿・証ひょうを扱うレッスンへ続きます。2027年度確定版は別に記載しています。

| 技能 | 説明・例題 | 独立練習 |
| --- | --- | --- |
| 資産・負債・純資産と貸借対照表 | bb2-business#unit1-business-compare | 店の財産と返済義務を分類し、表を検算 |
| 収益・費用・利益と損益計算書 | bb2-profit#unit1-profit-statements | 収支の時点をずらし、二つの方法で利益を照合 |
| 取引の判定・八要素 | bb2-transaction#unit1-transaction-read-events / #unit1-eight-elements-equation | 発注・引渡し・決済を区別し、同じ増減の別の原因を見分ける |
| 勘定の記入・仕訳・貸借平均 | bb2-journal、[詳細対応](unit1-recording-evidence.json) | 金額の配分、複合仕訳、貸借一致では見つからない誤り |
| 技能を組み合わせる | bb2-foundations-case | 資料の読解、仕訳、月末の財産と利益の検算。追加6問 |

既存4章の固定ID、URL、用語を維持し、総合演習を1章追加。理解度チェックに計26問を追加し、ユニット1の評価版を更新。他ユニットの評価版、用語問題、模試の問題と採点は維持。月末の表は貸借対照表と損益計算書の関係を学ぶための簡略例です。外部専門家の監修、受験者による難易度の校正は行っていません。
