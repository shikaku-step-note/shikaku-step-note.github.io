# 日商簿記初級の試験日ガイド 検索調査

確認日 2026-11-15。対象は日本の日本語検索と、日商簿記初級の受験会場・日程をこれから選ぶ人。

## 採用した検索意図

「日商簿記初級をいつ受けられるか。会場をどう探し、どのページから申し込めばよいか」。第3金曜日と会場ごとの試験日を区別し、予約する試験名・担当窓口の見方、年度をまたぐ場合の教材の選び方を答える。

- [Googleの公開候補](https://suggestqueries.google.com/complete/search?client=firefox&hl=ja&gl=jp&q=%E7%B0%BF%E8%A8%98%E5%88%9D%E7%B4%9A%20%E8%A9%A6%E9%A8%93%E6%97%A5) は hl=ja、gl=jp で確認。「簿記初級 」の候補に「簿記初級 試験日」があり、「簿記初級 試験日」の入力で「試験日 2026」「試験日程」、「簿記初級 申し込み」の入力で「簿記初級 試験 申し込み」を確認。
- [Bingの公開候補](https://api.bing.com/osjson.aspx?market=ja-JP&query=%E6%97%A5%E5%95%86%E7%B0%BF%E8%A8%98%E5%88%9D%E7%B4%9A%20%E8%A9%A6%E9%A8%93%E6%97%A5) は market=ja-JP で確認。「日商簿記初級 試験日」「日商簿記初級 試験日程」、別の入力で「簿記初級ネット試験申し込み」を確認。「簿記初級 第3金曜日」の検索候補には強い信号が見られなかったため、試験日・申し込みの疑問を主にした。
- 「日商簿記初級 試験日 申し込み」「簿記初級 試験日 会場」の日本語公開結果では、[日本商工会議所の日程表](https://www.kentei.ne.jp/calendar_2026)、[初級・原価計算初級の民間Q&A](https://boki-navi.com/beginner-qa/)、[北九州商工会議所の案内](https://www.kitakyushucci.or.jp/kentei/n-netkentei/)を確認。会場独自の日程と申込みに触れる既存記事がある。新規記事では第3金曜日を使う場合の見方、直接申込とCBT-Solutions経由の違い、4月へ日程を変えた場合の適用範囲を一続きで説明する。
- Google Trends（日本、3か月・12か月）で「簿記初級 試験日」「簿記初級 申し込み」を比較しようとしたが、HTTP 429で取得できなかった。権限付きSearch Console・Bing Webmaster Toolsやキーワードツールによる推計は利用できず、検索量、季節性、掲載順位やクリックは未計測。候補は検索意図の定性的な手がかり。

## 公式資料と導線

- [初級Q&A](https://www.kentei.ne.jp/bookkeeping/class-s/qa)、[試験日程カレンダー](https://www.kentei.ne.jp/calendar_2026)（注2）、[統一試験日](https://www.kentei.ne.jp/netday)、[会場一覧](https://links.kentei.ne.jp/organization)で随時試験、2026年度の第3金曜日、参加会場の印を確認。2027年度の統一試験日の見込みは掲載しない。会場一覧は公開検索経由で本文を確認できたが、検証環境からの直接取得はHTTP 403だった。CBT-Solutionsの予約案内は直接取得できた。
- [2026年4月1日付のネット試験案内](https://www.kentei.ne.jp/33013)、[日本商工会議所の会場案内](https://links.kentei.ne.jp/organization/13/boki)、[CBT-Solutionsの日商簿記ページ](https://cbt-s.com/examinee/examination/jcci.html)で直接申込と初級のオンライン予約の案内を確認。CBT-Solutionsの申込日から3日後以降、変更は受験日の3日前までという条件は同社の経路に限って掲載。古い公式FAQには初級は会場問い合わせのみとの記述も残るため、現行の会場一覧と予約窓口を優先した。
- [2027年度確定版の告知](https://www.kentei.ne.jp/51147)と[改定資料の初級欄](https://www.kentei.ne.jp/wp/wp-content/uploads/2014/10/2027_kaitei_shushi_fixed.pdf#page=8)で施行日と小切手を確認。練習先は[2026年度範囲の独自模試A](https://shikaku-step-note.github.io/qualifications/boki-beginner/tests/bb2-mock-a/)。
