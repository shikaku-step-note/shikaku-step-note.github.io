# 国税徴収法・基礎6講の統合確認

確認日：2026年10月27日。対象は徴収の基礎6講、末尾77問、単元記述26問100点、事例用語12問24点、25例題。原稿は担当者の著者確認後、別担当者が本文・全設問・一次資料・計算を読み、発見した不一致の修正版を再確認した。独立記録は `collection-foundations-independent.md`。これはAIを用いた編集・確認であり、税理士等の専門家審査を装うものではない。

## 教授と評価の対応

各講4個、計24個の下位技能を、安定した`-d1`〜`-d4`識別子へ対応させた。元の著者索引と計画目標との対応は `collection-objective-correspondence.json` と `collection-assessment-provenance.json` に残す。本文の見出し・例題・末尾練習・非用語の累積問題が実在することを統合時に照合した。

複合事例は主要な復習先に加えて、実際に評価する他講の目標を保持する。これにより、当事者と財産帰属、期限と附帯税等を組み合わせた問題から、両方の該当講へ戻れる。設問の複製によって問題数や配点を増やしていない。

frameworkの優先配当の下位技能は、この講の明示された条件下の計算を確認するもの。後続の`zr2-kokuzei-priority-general`の修得完了へは加算しない。延滞税の独立した免除要件等は実在する`late-tax-complex`へ残し、基礎講の期間控除から全免除を履修済みとはしない。送達・特殊な時効・信託分割・充当の全要件・加算税の加重等の後続も未完了のままである。

## 入力と保存

途中計算や理由へ配点する問題は記述入力とし、全要素のルーブリックを表示する。単元26問の合計100点と用語12問の24点は別の評価・版・履歴。所要時間は試行による校正が済んでいないため、単元に時間制限を作っていない。本試験120分の模試とは表示しない。

用語問題は、元の場面・模範解答・2点基準をそのまま保持し、表示に必要な主要講・追加講・1始まりの目標番号を統合側で対応させた。定義26項目は問題数へ数えない。レッスンの学習済み印と各評価の結果を別に保存し、旧入門履歴から新講の完了を作らない。

## 資料と確認の限界

2026年4月3日の基準日に有効な法令revisionと、資料を実読した日を区別する。税務大学校の2026年1月1日基準の講本は補助資料として主法へ戻って照合し、裁決は過去事例であることを明示する。2027年以後の延滞税率を推定していない。

型・全体ビルド・リンク・ブラウザによる新単元の受入は、この統合の後に実行して別記録へ残す。ここでは全科目、全ての各論、本試験相当模試、全端末の操作が完成したとは扱わない。
