## 具体的な補足事項

1. **当期影響の注記の原則と分岐**。本文「原則的な遡及を行えない場合の当期影響の注記にも注意します。」では、何を求めるかが明確でない。基準24号50項は、過去の比較情報を遡及した場合は原則として当期影響額の注記を求めず、比較情報を遡及していない場合は変更前方針によった場合の当期影響額の注記も求める、という差を説明する。10項(5)/11項(3)と併せ、この分岐と主な表示科目・1株当たり情報の範囲まで教えるとよい。原則的遡及をしない全ケースの額を根拠なくゼロとする教材にはしない。

2. **見積変更の将来影響注記の条件**。本文「見積変更では内容と当期への影響、条件に応じた将来の影響等を示します。」の「条件」は、基準18項(2)に従って具体化できる。当期影響がある場合の当期額、当期影響がなくても将来へ影響する可能性があり合理的に見積れる場合の当該影響額、合理的な将来見積りが困難な場合のその旨を区分する。現在の18問ではこの注記分岐を独立評価していないため、単元評価で問う場合は先に教える必要がある。

3. **方針変更に当たらない事象とCFの分類**。本文の4分類と現在の例/問は正しいが、適用指針8項の、重要性増加による本来処理への移行、新事実による新たな処理の採用、連結/持分法適用範囲の変動は未教授。9項のCF資金範囲の変更（方針）と表示内訳の変更（表示）の区別も未教授。具体例を現講へ追加するか、実際の別講と累積評価へ各細目を対応付ける必要がある。指針18項の旧重要性判断が誤りでないという条件を落とさず、重要性増加による本来処理を誤謬と一括しない。

任意の明確化：q4/q5の「新旧差」は、本文例題2と同じく「新方針の在庫が旧方針より多い額（新−旧）」と明示すると符号の読み違いを防げる。現状も新旧の順から正の差として計算できるため、確定数値誤りとはしない。例題7の「X1各期の影響」は、単一のX1年度を指すため「X1年度の影響」の方が自然。
