# 所得税法・最初の拡充単元のブラウザ確認

実施日：2026年10月27日。ローカルの本番ビルドを、学習者の実データを含まない専用ブラウザで確認した。対象は `zr2-shotoku-unit-scope` と、そのレッスン・単元演習・共有部品である。全科目の受入完了を意味しない。

## 確認できたこと

- 旧入門教材を完了しても、新しい5講は未開始のまま。新しい講を1講完了すると1/5となり、次の講を案内する。
- ブックマーク、複数形式の回答、見直しフラグ、設問位置、提出結果、記述回答と自己採点が再読み込み後も保持される。
- 不正なバックアップを拒否する。合流・置換の選択ができ、エクスポートとインポートで旧・新の履歴と版番号を保持する。リセットを取り消すと残り、確認して実行すると専用環境のデータだけが消える。
- 100分の単元演習で、時計を30分進めて再読み込みしても開始時刻・締切・回答・フラグが変わらない。101分後には時間切れとして確定する。これは単元演習の共有タイマーの検証であり、未作成の本試験相当模試を検証したという意味ではない。
- 単元・レッスン・演習を320、390、768、1,440ピクセルで、明暗両テーマで確認し、ページ全体の横はみ出しがない。幅の広い共通資料表は表内で横移動できる。
- 所得区分の講にaxe-coreを実行し、明暗両テーマで対象WCAG A/AAルール違反は0件。キーボードの先頭スキップリンク、見えるフォーカス、200%の文字拡大、テーマの保持とシステム追従も確認した。全サイトのWCAG適合認証や実ブラウザズーム試験とは扱わない。
- 共通資料は該当する設問へ移動すると開く。利用者が閉じた資料を回答変更のたびに強制的に開かない。
- 検索、空の結果、科目から単元への導線、共有の公開canonical URL、コピーの完了通知、TXT中の実在ID、サイトマップへの教材掲載と演習ランナーの除外を確認した。

## 修正と限界

共通資料が設問移動時に自動で開かなかった点を修正した。バックアップ画面の旧20MB表示を実装の100MBと一致させた。スマートフォンの表には横移動を案内する説明を加えた。

記録確認は再読み込みと時刻変化を用いた専用環境で行った。ブラウザを完全終了した後の再起動、実端末のスリープ、全設問の全選択肢、全ページの支援技術による操作は、この記録の実施範囲に含まない。保存不能時の追加ブラウザ確認と、残りの各単元・模試の受入は未完了である。

実行スクリプトと詳細結果は制作時の `work/zeirishi-upgrade/` に保持する。共有部品の試験を各設問の内容審査や全教材の完成証拠へ読み替えない。
