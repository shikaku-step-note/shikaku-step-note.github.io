# 八つの財団抵当を、設定と実行の条件から判定する

鉄道、鉱業、漁業、交通事業などの財産をまとめる財団抵当では、事業を続けながら担保を設定するため、通常の土地抵当と違う条件があります。ただし、工場財団の要件をすべての財団へ写すこともできません。財団の設定に認可が必要な制度、所有権保存登記で設定する制度、後から取得した財産が当然に加入する制度を分けます。

本講は2026年4月3日現在の法令に基づき、①八制度の設定・組成・公示・追加加入と個別差押制限を資料へ適用し、②権利の取消し等による実行事由・期間と国税の優先を判断します。登録財産を差し押さえる一般の実務は「不動産・船舶等の差押え」、裁判所手続と国税の調整は「保全措置と他の執行手続との調整」へ接続します。

## 最初に、設定者・事業・組成財産を照合する

財団の構成物を集める前に、設定できる者と事業の条件を確認します。鉄道は原則として株式会社たる鉄道事業者、鉱業は採掘権者、港湾は法所定の許可を受けた一般港湾運送事業者等です。道路は国土交通大臣の認定した事業単位、観光は政令所定の施設が出発点です。営業用の財産というだけでは、任意に好きな財団へまとめられません。

| 制度 | 設定・組成の基本 | 公示等の確認 |
| --- | --- | --- |
| 鉄道 | 鉄道の全部又は一部。会社所有の線路・車両等 | 国土交通大臣の設定認可、鉄道抵当原簿の登録 |
| 軌道 | 軌道抵当法上の軌道に関する財団。線路・車両等 | 軌道抵当法による鉄道抵当法の準用と特則 |
| 運河 | 一般運送用運河。水路、船舶等の法定財産 | 運河法から軌道抵当法、鉄道抵当法への準用 |
| 鉱業 | 同一採掘権者に属する鉱業権・設備等の全部又は一部 | 工場財団規定の準用と鉱業の権利登録 |
| 漁業 | 個別漁業権、登記漁船又は養殖場を持つ者の財団 | 工場財団規定の準用、個別漁業権の知事認可等 |
| 道路交通 | 一又は二以上の認定事業単位に属する所定財産 | 道路交通事業財団登記簿の所有権保存登記 |
| 港湾運送 | 同一許可事業者に属する所定の事業財産等 | 工場財団規定の準用と財団登記・目録 |
| 観光施設 | 同一事業者の一又は二以上の所定施設 | 観光施設財団登記簿の所有権保存登記と目録 |

表の「準用」は、名前を読み替えれば条件がすべて同じになる、という意味ではありません。各法の別段の規定と準用条項を先に確認します。例えば道路交通事業抵当法19条は、工場抵当法の特定の条項を列挙して準用します。構成物の加入を定める独自の6条を、工場抵当法13条1項の一般的加入制限へ置き換えないようにします。

## 鉄道財団は、認可と登録を別々に確認する

鉄道抵当法の「会社」は株式会社たる鉄道事業者です。財団は鉄道の全部又は一部について設けられ、一個の物とされます。設定の効力を生じさせるのは国土交通大臣の認可です。工場財団と同じく所有権保存登記だけで設定できるという説明は誤りです。認可後6か月以内に抵当権設定登録の申請がなければ、認可は効力を失います。[鉄道抵当法1〜3・13条]

会社が所有する線路用地、工作物、工場や駅務等の建物、機械、車両、修繕材料等、3条の財産を確認します。他人の不動産上の地上権や登記賃借権なども同条の範囲に含まれます。認可されると、その鉄道に関する所定の会社財産は当然に加入し、設定後新たに会社へ属した所定財産も同様です。車両を取得するたび、工場財団と全く同じ任意加入だけを考える制度ではありません。[鉄道抵当法3・11条]

一方、設定時の第三者の権利・差押え等は4条の制限と、8条の公告・申出、11条の効力を確認します。公告による申出期間は1か月を下回れません。既存の担保を無視して登録するという自由な制度ではなく、申出と損害賠償等の別の問題も生じます。権利がないと確認できた事例と、未登記の他人の権利がある事例を同じに扱いません。

抵当権の得喪・変更と財団所有権の移転は、登録しなければ第三者へ対抗できません。同一財団上の複数抵当の順位は登録の先後により、鉄道抵当原簿を確認します。設定認可日、抵当の設定登録日、所有権移転日を一つの日付へまとめないことが大切です。[鉄道抵当法15・16・27条]

同じ債権を数個の鉄道財団で担保し、同時に代価を配当する場合は、23条により各財団の価額に比例して担保負担を分けます。一つの財団だけを先に配当する場合の全額弁済と後順位者の代位は別です。25条は財団から弁済を受けない部分についての他財産からの弁済と、他財産を先に配当する場合の供託請求等を定めます。一つの700万円債権を、二つの財団の各計算で700万円ずつ回収したことにしてはいけません。

財団全体は、通常の差押え等を制限されますが、4条には滞納処分による財団全体の差押えの例外があります。構成物は同条2項により個別の差押え等を制限され、この部分に財団全体と同じ例外を勝手に加えません。車両1両を動産として選ぶ前に、財団の構成物かを調べます。財団自体への滞納処分換価にも77条の2の特則があります。

### 例題1：認可、後から取得した車両、税との比較日

株式会社である鉄道会社が、2025年8月1日に財団設定認可を受け、同年9月1日に適法な抵当設定登録を終えたとします。会社が同じ鉄道のために同年11月に取得した車両は3条の範囲に入り、第三者の権利等の争いもありません。この車両は11条により財団に当然に属します。車両1両だけの国税差押えを計画するのではなく、財団全体と構成物を区分します。

2026年3月16日を法定納期限等とする国税500万円があり、対象の財団と担保財産の範囲はすべてそれ以前に確定しているとします。適法な滞納処分換価代金1,200万円、直接費用20万円、抵当優先額800万円、他の優先債権なしなら、原資1,180万円から抵当800万円、国税380万円です。国税120万円が残ります。財団を差し押さえた国税だから必ず抵当より先、という説明にはなりません。

本例は追加車両も国税の比較日より前です。国税の比較日をまたいで新たに加入した財産についての設定時点は、加入や公示の資料と法令解釈を別に照合する必要があります。本講の公開前の確認事項として残し、この例から当初の抵当登録日がすべての後加入財産へ無条件に及ぶとは一般化しません。

## 軌道と運河は、準用の連鎖と消滅の特則を読む

軌道の抵当は、軌道抵当法に別段の定めがある部分を除き、鉄道抵当法を準用します。組成財産は同法2条の線路、建物、車両、地上権・登記賃借権等です。特許条件によって財団所属財産を国又は公共団体へ無償で引き渡すべきときは、3条によりその財団を目的とする抵当権が消滅します。単に所有者が変わった場合の抵当の追及と同じにしません。

運河法は、一般運送に使う運河の開設に国土交通大臣の免許を求め、抵当について13条から軌道抵当法を準用します。14条は水路、用地・工作物、運河用通信信号設備、地上権・登記賃借権、船舶、維持修繕材料等の範囲を定めます。川辺の倉庫を所有することだけで、一般運送用運河という前提や免許を満たすわけではありません。

非株式会社の鉄道事業者・軌道営業者には、鉄道抵当法26条、軌道抵当法4条が別の定めを指示しています。株式会社の例をそのまま自治体等へ移せません。本講ではその区分と資料不足を判断できるようにし、別規定の実体を取得・検証するまでは非株式会社の設定・実行を完成した教材として扱いません。

## 鉱業と漁業は、権利の種類・認可・取消原因まで確認する

鉱業抵当法は、採掘権者が財団を設定する制度です。鉱業権、土地・工作物、地上権・土地使用権、賃貸人が承諾した物の賃借権、機械・車両等、工業所有権などが組成候補となります。鉱業に関係する同一採掘権者の財産の全部又は一部で組成し、工場財団の規定を準用します。試掘権者だから当然に同じ財団を設定できるとはしません。[鉱業抵当法1〜3条]

採掘権取消しの登録があれば、所管の経済産業大臣等による抵当権者への通知を確認します。抵当権者は所定の場合に直ちに実行でき、通知受領から6か月以内に手続を要します。その期間・実行終了までの採掘権存続みなしと、買受代金納付による取消しの扱いも4条に定められています。放棄による消滅登録には5条が準用されます。

ただし、鉱業法52〜54条による取消しには、鉱業抵当法4条の実行等の特則を適用しません。錯誤訂正、公共の福祉に著しく反する採掘、他の鉱業等への著しい妨害という取消原因を確認します。鉱業法53条の取消し等には補償・供託と抵当の規定があり、取消しなら例外なく同じ存続みなし、とはできません。

採掘権そのものだけを抵当の目的にした場合は、鉱業法57条の別制度です。通知到達から30日という申立期間を、鉱業財団の6か月へ置き換えません。この単体権利の公示・取消し・補償金・売却残余は「立木・鉱業権等の担保と公示」で独立して教授・評価します。財団と構成される権利の二つの制度を知ったことだけで、単体権利の全技能を修得済みとしません。

漁業財団の設定者は、個別漁業権を持つ者、漁業に使う登記した船舶を持つ者、又は養殖場を持つ者です。同一人に属する所定の漁業権、船舶・属具、土地・工作物、漁具、機械、賃借権等を確認します。移転に許認可が必要な権利には所定の許認可、賃借権には賃貸人の承諾が必要です。個別漁業権の加入には知事認可が必要で、経営に必要な資金融通のためやむを得ない場合という条件もあります。[漁業財団抵当法1・2条]

個別漁業権の取消しには抵当権者への通知、通知受領から6か月以内の実行、存続みなし等を確認します。ただし、漁業調整、船舶の航行・碇泊・繋留、水底電線の敷設その他公益上必要な場合の取消しは、その特則の対象から除外されます。取消しの名称だけで6か月を使わないようにします。[漁業財団抵当法4条]

### 例題2：同じ6か月でも、鉄道は取消日、鉱業・漁業は通知受領

鉄道事業許可の取消日は2026年1月8日、抵当権者がその情報を通知で受け取った日は1月21日とします。鉄道抵当法22条の期間は取消しの日から6か月で、日中の取消し・初日不算入による暦計算では7月8日が満了日です。通知が遅く届いたから7月21日になる、とはしません。

別の鉱業財団と漁業財団で、各法の適用除外でない適法な取消しがあり、所定通知を1月21日の日中に受領したとします。それぞれ受領から6か月で、満了日は7月21日です。いずれも休日延長の問題がない設定です。鉱業では52〜54条の取消しを、漁業では公益上の所定取消しを除いたという条件を、期限の前に確認します。

## 道路交通と港湾では、必須財産と加入の仕組みを読む

道路交通事業抵当法の事業単位は、法2条の対象事業の業務が独立して運営され、適当な規模を持つものとして国土交通大臣が認定した単位です。一般旅客、一般貨物、自動車道、所定の自動車ターミナル、第二種貨物利用運送等の区分を確認します。無償供用の一般自動車ターミナルは、同条の対象から除外されます。

自動車運送・第二種貨物利用運送では、法4条1号の不動産と事業用自動車が必要です。自動車道・ターミナルでは、一般自動車道又は一般自動車ターミナルの敷地がなければ財団を設定できません。車両と机があることだけで設定可能としないようにします。設定は専用財団登記簿への所有権保存登記で行います。[道路交通事業抵当法3〜6条]

設定時及び設定後に同じ事業単位に属する所定財産は、原則として当然に財団へ属します。ただし、他人の権利・差押え等の目的物を除く6条の条件があります。土地建物、所定自動車・小型船舶については、保存登記等の申請前に必要な所有権登記・登録を備えます。貸主の承諾がある賃借権の組入れと、他人の所有物そのものの加入を区別します。

港湾財団を設定できるのは、法4条の一般港湾運送事業等の許可を受けた者です。一般港湾、港湾荷役、はしけ、いかだの各事業がこの区分であり、検数・鑑定・検量だけの事業者を同じにしません。荷さばき施設とその敷地、船舶、事務所建物等、所定の地上権・登記賃借権、器具機械等を組成でき、荷さばき関係又は事務所等の所定不動産のいずれもない場合は設定できません。[港湾運送事業法3・4・23〜26条]

### 例題3：車両や船舶だけの一覧では足りない

運送会社Rは、対象事業の認定事業単位を持ち、登録済み事業用自動車と自社所有倉庫を含む適法な構成財産を持つとします。道路交通事業抵当法の必須財産・権利条件を満たし、保存登記を終えた後、同じ事業単位のための自由な所有機械を取得しました。この機械は6条による当然加入を判断します。他方、他人の抵当等の目的となっている追加財産を同じように加入させることはできません。

別の港湾会社Pは検量事業の許可しか持たず、船舶と測定器を持っています。一般港湾運送事業等の許可がなく、荷さばき施設・事務所等の所定不動産もありません。この資料では、23条の設定者条件と25条の必須財産条件の二つを満たしません。船舶の価額が高いことをもって不足を埋めることはできません。

道路財団の免許・許可取消しや所定の失効には、14条の通知、受領から6か月以内の実行、存続みなしを確認します。競売開始決定後に取消し等があれば15条により、買受代金納付まで競売目的の範囲で免許等が存続し、納付時には取消し等がなかったものとみなされます。18条では代金納付時に許可等の権利義務を承継しますが、所定の欠格等では大臣による取消しの可能性があります。港湾財団へ道路交通事業抵当法14条の6か月を、その根拠なく移すこともしません。

## 観光施設は、施設指定と土地の権原を確かめる

観光施設財団法の対象施設は政令で8類型が指定されています。遊園地、動物園、水族館、植物園等のほか、展望施設とスキー場は索道があるもの、アイススケート場は冷凍設備があるもの、水泳場は水質浄化設備があるものです。「観光客が来る」という事実だけでは足りません。これらが宿泊施設に附帯している場合は、法2条に従って宿泊施設との範囲を確認します。

同一事業者の土地・工作物、機械器具備品、動植物・展示物、地上権と承諾付き賃借権、船舶車両航空機、温泉利用権等が候補です。法5条所定の土地建物・船舶・自動車・航空機には、加入前の所有権登記・登録が必要です。土地又は法4条4号の土地に関する権利がなければ設定できません。動物や温泉利用権の価値だけでは、この土地の条件を満たせません。

設定は専用登記簿への所有権保存登記で行い、一個の不動産とします。財団目録を備え、工場抵当法13条等の準用から構成物の処分・個別差押制限を確認します。所有権・抵当権以外の権利の目的とすることは原則禁止ですが、抵当権者の同意による賃貸の例外があります。[観光施設財団抵当法3〜11条]

### 例題4：スキー場の設備と、特許条件による軌道の引渡し

会社Tは索道のないスキー場とホテルを経営しています。「スキー場」という名称とホテルだけで政令の施設条件を満たすことはできません。別の場合に索道を備え、法定条件を満たすスキー場がホテルに附帯していれば、対象施設と宿泊施設の範囲を確認し、土地権原・所有権登記登録・賃借権の承諾等へ進みます。

軌道会社Uでは、特許に付された条件により財団所属財産を国へ無償で引き渡すべきことが確定したとします。軌道抵当法3条により、財団を目的とする抵当権の消滅を判断します。別の運河会社Vについては、一般運送用運河の免許と法14条の組成財産を確認し、13条から軌道抵当法、さらに鉄道抵当法へ準用をたどります。Uの特許条件、Vの免許、Tの施設指定は、いずれも財団の名称だけでは判断できない条件です。

答案では、設定できる者、必要な事業認定等、加入する財産、設定と担保公示、処分制限、取消原因と実行期限、国税との優先を分けて書きます。財団の法的単位と構成物を取り違えず、適用除外や資料不足があれば、その事実と影響を具体的に示します。
