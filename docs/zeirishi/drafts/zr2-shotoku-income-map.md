## 所得区分と課税方式を二段階で決める

同じ人が賃料、原稿料、資産の売却代金、退職金を受け取っても、全てを一つの収入欄へ合計することはできません。所得の種類によって、経費や控除、赤字の処理、税額の計算方法が変わります。まず収入の原因から十所得へ区分し、次にその所得に適用される総合課税・分離課税等の方式を決めます。

このレッスンの目標は、①収入原因から十所得へ区分すること、②所得区分と課税方式の関係を説明することです。2026年4月3日現在施行版を基準に、例題は2025年分で作成しています。個々の特例の限度額を暗記する前に、資料をどの計算系列へ送るかを身につけます。所得区分が異なるときに、同じ控除や損失処理を使ってよいかも確かめます。

## 十所得は、収入が生じた原因で分ける

最初に、前のレッスンまでの納税義務者、課税範囲、帰属者、非課税の確認を行います。例えば、個人からの所定の贈与は所得税の非課税対象なので、現金を受け取ったというだけで一時所得へ入れません。課税範囲に入る収入について、原因となった行為・権利・契約へ戻り、各所得の定義を確認します。

預金の引出しや貸付元本の返済のような資金の移動も、利子等の所得と分けて読みます。元本と利子を合わせた振込なら、まず内訳を確認します。また、公的年金等の雑所得と、それに当たらない個人年金等の雑所得では計算規定が異なります。雑所得という区分を付けた後も、公的年金等控除を使える収入かを確かめてください。

| 所得 | 主に確認する収入原因 | 計算を始める際の注意 |
|---|---|---|
| 利子所得 | 預貯金・公社債の利子等 | 非営業用貸金の利子等とは区別します |
| 配当所得 | 株主・出資者等として受ける配当等 | 配当と株式自体の譲渡、資本払戻等の区分を調べます |
| 不動産所得 | 不動産・その権利、船舶・航空機の貸付け | 事業所得や譲渡所得に当たるものを除きます |
| 事業所得 | 物販、製造、サービス等の事業 | 山林所得や譲渡所得となるものを除きます |
| 給与所得 | 給料・賃金・賞与等 | 通常の経費計算へ直ちに置き換えず、給与の計算規定を使います |
| 退職所得 | 退職により一時に受ける給与等 | 一般・短期・特定役員等の条件を別に確認します |
| 山林所得 | 所定の保有期間を満たす山林の伐採・譲渡 | 取得後5年以内と土地部分を分けます |
| 譲渡所得 | 資産の譲渡 | 商品等、継続的売買、山林等の除外を確認します |
| 一時所得 | 継続的営利行為以外の一時の利益 | 役務や資産譲渡の対価等を除きます |
| 雑所得 | 他の九所得へ該当しない所得 | 公的年金等、業務、その他を区分して計算します |

表の名前へ直接当てはめるだけでなく、除外条件も読みます。資産を売ったという事実があっても、販売商品の売却は通常その事業の収入です。山林の譲渡には山林所得の規定があります。逆に、事業で使った資産だから売却も必ず事業所得、とも限りません。資産の種類と譲渡所得からの除外を確かめます。

所得の定義には、同じ日常語でも範囲が限定されたものがあります。貸した金に対する利息を全て利子所得とすると、非営業用貸金の利子等を誤ります。家賃に見える収入でも、宿泊サービス等の実態があれば事業所得の検討が必要です。題名や摘要欄に加えて、何を貸し、どのような役務を行ったかを確認します。

### 例題1：事業主の三つの売却を振り分ける

写真機材の販売事業を営む理人が、2025年に販売用の商品カメラを売り、代金90万円を得ました。別に、事業の撮影作業に長年使った固定資産のカメラを30万円で売り、自己の投資用土地も売っています。固定資産のカメラは少額減価償却資産等の譲渡所得から除かれる資産に当たらず、譲渡所得の対象となるものとします。土地の売買事業は営んでいません。

商品カメラ90万円は物販業の事業収入です。事業用固定資産のカメラと投資用土地は、この条件では譲渡所得の計算へ進みます。ただし、土地は土地建物等の申告分離課税の系列、固定資産カメラは総合譲渡の系列となります。売却を三件とも同じ譲渡欄へ入れたり、事業主の受取だから全て事業収入にしたりしません。

各系列へ移すときは、売却代金と所得を区別します。カメラ30万円がそのまま譲渡所得の金額になるわけではなく、取得費や譲渡費用等の計算が必要です。商品の90万円も、その収入に対応する原価・経費を含む事業所得全体の計算へ渡します。分類の後で必要となる取得資料や原価資料まで特定できれば、長い総合問題の準備が整います。

## 一回の入金でも、役務の対価なら一時所得を再検討する

一時所得は、一時的に受けたという条件だけでは決まりません。他の所定の所得に当たらず、継続的な営利行為から生じた所得以外で、労務その他の役務や資産譲渡の対価という性質を持たない等の条件があります。依頼されて文章を書いた対価は、一度限りの支払でも役務の対価です。事業所得に当たらない条件なら、雑所得の検討へ進みます。

事業所得と業務に係る雑所得の区別は、継続性や独立性、規模、実態等に基づく判断です。売上額のほか、活動を継続する状況や帳簿等の資料も合わせて検討します。ここでの例題は事業該当性等を条件として明示します。実際の判定では、帳簿保存や営利性等に関する通達の取扱いも含めて、後続の事業・雑所得の教材で調べます。

### 例題2：原稿料と懸賞賞金の控除を分ける

会社員の梓は、事業に当たらない単発の執筆依頼を受け、原稿料16万円を得ました。直接の必要経費は4万円で、他の該当所得はありません。別に、労務等の対価性がない一般の懸賞に趣味で応募し、賞金70万円を得ました。この賞金は一時所得に該当すると確定し、その収入のため直接要した支出は5万円で、他の一時所得はないものとします。

原稿料は役務の対価で、かつ事業所得ではない条件なので雑所得です。金額は16−4＝12万円となります。ここへ一時所得の50万円特別控除を使うことはできません。懸賞の一時所得は70−5−50＝15万円です。総所得金額へ算入する段階では、この15万円の2分の1である7万5千円を用います。雑所得12万円と一時所得の算入7万5千円を、この二項目について合計すると19万5千円です。

15万円が一時所得の金額、7万5千円が原則として総所得金額への算入額、と名称も分けて書きます。最初から賞金を半分にして費用や特別控除を引くと順序が変わります。また、本問が所得の合計額を問うことと、会社員に確定申告義務があるかという問題は別です。給与所得者の申告不要の要件等は、他の所得・給与・申告の目的まで調べて判断します。

## 総合課税・申告分離・源泉分離を区別する

総合課税は、対象となる各種所得を所定の計算で合計し、所得控除等を経て累進税率等で税額を計算する仕組みです。給与、事業、不動産等は通常この系列を確認します。赤字がある場合には、損益通算できる所得、除外、順序の規定を調べます。総合という言葉だけで、雑所得の赤字を給与へ充当する処理はしません。

申告分離課税は、他の所得と税額計算を分ける課税方式です。土地建物等や株式等の譲渡、山林、退職などには、それぞれの計算系列があります。方式を分けても、人的控除の所得要件等では分離所得を考慮することがあります。「分離だから他の計算へ一切影響しない」と決めず、各規定が用いる所得指標を確認します。

源泉分離課税は、原則として所定の源泉徴収によって課税関係を完結させる方式です。通常の国内預金の利子等が例です。これに対し、給与や申告分離となる配当等にも源泉徴収があります。源泉徴収の有無と、源泉分離という方式は別に判定します。退職所得も、所定の申告書を提出して適正に源泉徴収された場合の申告の取扱い等があり、単に源泉徴収があるから預金利子と同じ方式、と説明しません。

### 例題3：山林を土地付きで売った場合

恵は2014年に取得した山林を2025年に立木と土地を合わせて売りました。立木部分の収入600万円、土地部分の収入400万円と適正に区分されています。立木に係る適正な必要経費は300万円です。概算経費控除・森林計画特別控除その他の特例、他の山林所得はなく、山林の保有期間は5年を超えるものとします。土地部分の取得費等は別資料で計算する条件です。

立木部分は山林所得の系列で、600−300−50＝250万円です。土地部分は山林所得へ入れず、土地の譲渡所得の系列で計算します。土地と立木を合わせた1,000万円に山林所得の費用・控除を適用してはいけません。山林所得の税額は通常の総合所得と合算せず、五分五乗方式等の規定へ進みます。

取得後5年以内の山林を売った別のケースなら、山林所得から除かれ、事業所得または雑所得を検討します。取得後ちょうど5年は「5年以内」に含まれます。土地の長期・短期の判定には譲渡年の1月1日を用いる別のルールがあるため、二つの5年を同じ日数計算で済ませないことも重要です。資産、所得区分、判定日を組にして記録します。

## 金融所得は、商品と選択可能な方式を確かめる

利子所得という区分の中でも、課税方式は商品等の条件によって異なります。通常の国内預金利子等は源泉分離、所定の特定公社債等の利子等は申告分離の対象となり申告不要の選択がある等の違いがあります。配当所得にも、上場・非上場、大口株主等、支払法人等に応じた方式の違いがあります。商品と受取人の条件を読んで方式を判定します。

### 例題4：同じ「利息」と、上場配当の選択

国内の通常の銀行預金の利子1万2千円と、事業として行わない個人への貸付金の利子6万円を受けたとします。前者は利子所得として通常の源泉分離課税、後者は非営業用貸金の利子として雑所得の系列へ送ります。摘要に両方とも利息と記載されていても、所得区分と方式を同じにしません。

別に、一般の内国法人の上場株式配当45万円と、適用対象の上場株式等の譲渡損失60万円がある人を考えます。大口株主等には当たらず、配当控除や申告分離・不要の対象要件を満たし、負債利子もない条件です。配当を申告分離課税で申告すれば、所定の通算により60−45＝15万円の損失が残る計算です。配当を総合課税で申告するなら、その上場株式の譲渡損失を配当へ通算することはできません。申告不要とする選択も、申告しての通算とは区別します。

どの方式が有利かは、配当控除、他の所得、所得要件、繰越損失、住民税等も含めて比較する必要があります。有利不利は各人の条件に応じて判断します。残った損失15万円を翌年以後へ繰り越せるかも、連続申告等の要件を別に確認します。後続の金融所得では、商品ごとの方式と複数年の通算・繰越を実際の資料から選びます。

## 区分した後に、必要な資料を指定する

十所得への区分は、計算の入口です。区分ごとに、次の資料へ進みます。

| 区分した所得 | 次に確認する主な資料 |
|---|---|
| 給与 | 給与の収入額、給与所得控除の表、所得金額調整に必要な情報 |
| 退職 | 勤続年数、支給された手当の内容、過去と今回の支給の先後 |
| 事業 | 収入の計上時期、原価・必要経費を裏付ける帳簿と証憑 |
| 譲渡 | 取得費、譲渡費用、所有期間等を確かめる契約書や記録 |

所得を区分しただけで完了にせず、その区分で必要になる計算資料と、選択可能な方式を次に確かめます。

一覧表を作るときは、取引の内容、帰属者・年分、所得区分、非課税の有無、課税方式、必要資料の順に並べます。同じ収入を二つの所得へ重ねたり、方式を変えたら所得区分まで別物へ書き換えたりしないようにします。この順序を保てば、新しい特例を学んだ後も、その特例をどの段階に適用するかを判断できます。
