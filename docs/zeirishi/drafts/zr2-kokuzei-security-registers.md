# 個別担保法から目的財産と公示を選ぶ

抵当権の設定日を国税の法定納期限等と比べる前に、その財産について抵当権を設定できるかを確認します。車両、航空機、船舶、機械、工場の設備は、いずれも企業が使う財産ですが、適用する担保法と公示の方法が違います。契約書に「担保」と書かれていても、必要な登録・登記が備わっているとは限りません。

本講の目標は、①自動車・航空機・船舶・建設機械・工場抵当・企業担保の目的と公示を選ぶこと、②担保の効力が及ぶ財産を確定し、国税との優先と差押対象へ結び付けることです。法令は2026年4月3日を基準にします。鉄道、鉱業、漁業など八つの他財団の要件は、独立講「鉄道・鉱業・漁業・交通・観光等の財団抵当」で扱います。

## 財産の名前から、適用法と記録を探す

最初に所有者、財産の法的種類、個別の登録・登記番号を並べます。続いて担保の設定契約、登録・登記、被担保債権額を確認します。所有権の記録と抵当権の記録は別です。所有者として登録されているだけでは、特定の債権者の抵当権まで公示したことになりません。

| 財産・制度 | 対象を選ぶ手掛かり | 公示の主な確認先 |
| --- | --- | --- |
| 自動車抵当 | 法所定の登録自動車。建設機械法の対象になる大型特殊自動車を除外 | 自動車登録ファイル |
| 航空機抵当 | 航空法により登録された飛行機・回転翼航空機 | 航空機登録原簿 |
| 建設機械抵当 | 政令別表に該当し、所有権保存登記を受けた建設機械 | 建設機械登記簿 |
| 船舶抵当 | 商法847条の登記した船舶。本講は商行為目的の船舶を設定 | 船舶登記。船舶原簿の登録と混同しない |
| 工場抵当 | 工場の土地又は建物と法所定の備付物等 | 土地・建物の抵当登記と機械器具目録 |
| 工場財団 | 所定の財産・権利を組み合わせた一個の不動産 | 工場財団登記簿の所有権保存・抵当登記と財団目録 |
| 企業担保 | 株式会社の総財産による、その会社の社債の担保 | 本店所在地の株式会社登記簿 |

表は制度を探すための入口です。個々の法律には目的、効力範囲、処分制限等の条件があります。公示がある場合も、他人所有物を所有者の設定行為なしに担保へ取り込めません。借りている設備と自社所有の設備を同じ一覧へ載せた資料では、所有関係から確認し直します。

## 自動車・航空機と建設機械では、対象と質権禁止の範囲が違う

自動車抵当法は、同法2条に当たる登録自動車に、占有を移さずに担保を設定する制度です。抵当権の得喪・変更は登録しなければ第三者へ対抗できません。同法20条は対象自動車の質入れを禁じています。車を債権者へ預けたという事実だけで、法が禁止する質権を有効なものとして配当へ入れないようにします。[自動車法2〜5・20条]

建設機械は、工事で使う機械をすべて指す言葉ではありません。建設機械抵当法2条と施行令別表から種類・能力を選びます。別表には13の種類区分があり、名称だけでなく、自重・容量・出力などで対象を絞る行もあります。例えばトラクターの対象範囲は自重3トン以上、トラクターショベルはバケット容量0.4立方メートル以上です。他方、ショベル系掘削機は所定のアタッチメントを持つことから判定します。[建機法2条・令別表]

該当機械でも、建設機械法の抵当権の目的にするには、まず同法による登記を受けている必要があります。所有権保存登記には、登記できる所有者、第三者に対抗できる所有権、打刻・検認等の条件があります。すでに存在する質権や差押えを、その後の所有権保存登記だけで排除することもできません。[建機法3〜7条]

保存登記から30日以内に抵当権設定登記を受けないと、原則として登記記録が閉鎖されます。抵当登記を全部抹消した後も、30日以内に新たな抵当登記を受けなければ同様です。ただし、所有権保存・抵当権以外の登記がある場合の例外を同法8条で確認します。また、質権禁止は「登記した建設機械」に関する規定です。未登記の機械まで一律に同じ禁止を当てはめません。[建機法8・25条]

航空機抵当法も、登録された対象航空機について占有を移さず担保を設定する制度です。航空機登録原簿への登録が第三者対抗の条件となり、対象航空機は質権の目的にできません。航空会社の財産だからといって、格納庫、予備部品の在庫、売掛金まで航空機抵当の対象に広がるわけではありません。[航空機法2〜6・23条]

### 例題1：車両名だけで同じ担保を認めない

運送会社の財産一覧には、A＝法所定の登録トラック、B＝自重3.5トンのトラクター、C＝登録航空機があるとします。Bは建設機械法の所有権保存登記を受けていません。AとCには、それぞれ適用法に従った抵当権の登録があり、設定権限と第三者対抗に争いはありません。

Aは自動車抵当、Cは航空機抵当として確認します。Bは能力要件を満たしますが、未登記なので建設機械法5条の抵当権を認めることはできません。Aの自動車登録ファイルへBもまとめて登録したという説明では、Bの担保は完成しません。Bについて別の適法な担保が成立するかは、その制度の条件で判断します。

Aの抵当登録日は2026年1月20日、国税100万円の法定納期限等は同年3月16日です。換価代金150万円、直接の滞納処分費10万円、抵当権の優先対象額80万円、他の優先債権はないとします。原資140万円から抵当権80万円、国税60万円となり、国税残額は40万円です。150万円全部を国税の配当に用いる計算は、費用と抵当権を落としています。

## 効力範囲と利息の条文を、制度ごとに確かめる

自動車・航空機・建設機械の各法では、目的物に付加して一体となった物への効力、譲渡・貸付・滅失・損傷等によって受ける金銭等への物上代位を定めています。ただし、設定行為の別段の定めや詐害行為の場合の例外、代替金の払渡し・引渡し前の差押えという条件を落とせません。保険金をすでに受領した後に「元の車の抵当権がある」と述べるだけでは、未払保険金への物上代位をしたことになりません。[自動車法6・8条等]

普通抵当の利息・遅延損害金の範囲も確認します。自動車法12条と航空機法12条は、最後の2年分の制限と、利息等と損害賠償を合わせて2年分を超えないことを定めています。建設機械法16条には、それより前の定期金について満期後に特別の登記をした場合の規定があります。民法375条にある文言を、自動車・航空機の条文へそのまま補って読まないようにします。

根抵当については各法の準用条項と民法398条の3等を確認します。普通抵当の最後2年分と、確定元本・利息等の全部を極度額内で担保する根抵当は、計算の出発点が異なります。その上で徴収法18条の通知時限度やただし書を検討します。通知による多者間の配当調整は「競合する担保と税の配当」で扱った手順へ戻ります。

## 船舶登記、小型船舶登録、船舶原簿を区別する

本講の商法上の船舶は、商行為を目的として航海に用い、ろかいのみ等で運転する舟を除いたものです。商法686条は総トン数20トン未満について同条の登記等を適用しません。船舶登記令2条も、原則として20トン以上の所定船舶について船舶登記を定めています。商法847条の抵当権と849条の質権禁止は「登記した船舶」を対象とします。

20トン未満の船については、小型船舶登録法による登録があり得ます。同法の小型船舶には漁船等の除外があり、所有権の得喪に登録による第三者対抗が定められています。しかし、小型船舶の所有権登録があることを、商法847条の船舶抵当の登記と同じ意味には扱えません。また、20トン以上の船でも、登記と船舶原簿への登録・船舶国籍証書の制度は別の記録です。[船舶法5・20条、小型法2〜4条]

### 例題2：同じ所有会社の船でも、記録を読み分ける

会社が商行為目的で使う25トンの貨物船Dには船舶登記があり、8トンの遊覧船Eには適法な小型船舶の所有権登録があります。Dは商法847条の抵当の対象となり、登記したDの質入れは849条により禁止されます。Eについては、所有権登録があるという資料だけで、847条の抵当権の成立・対抗を認定できません。漁業財団等に組み入れたという別事情も本例にはありません。

Dの抵当登記が国税の法定納期限等以前で、担保される優先対象額170万円、直接費用5万円、換価代金300万円、国税150万円、他の先取特権等はないとします。原資295万円から抵当権170万円、国税125万円を配当し、国税残額25万円となります。現実の船舶には海事先取特権が問題となり得るので、本例の「他の先取特権なし」という条件を外して結論だけを使わないでください。海事の対象債権と優先は次講で判定します。

## 工場の土地・建物の抵当と、工場財団を分ける

工場抵当法2条は、工場の土地に設定した抵当権について、土地に付加して一体となった物や、工場の用に供するため備え付けた機械・器具等への効力を定めます。ただし、土地抵当の対象に建物をそのまま含める規定ではありません。建物に設定した抵当権にも準用があります。機械・器具等の目録と、設定行為の別段の定めの登記を読み、備付物と在庫商品を区分します。[工場法2〜4条]

土地・建物を差し押さえると、その抵当権の目的となる法2条の物にも効力が及びます。一方、その備付物等は土地又は建物とともにしなければ差押え等の目的にできません。取り外せそうな機械を選び、土地建物との関係を確認せず単独で差し押さえることはできません。抵当権者が所定の分離等へ同意した場合の抵当消滅は、同法6条で別に判定します。[工場法6・7条]

工場財団は、複数の財産・権利を一個の不動産としてまとめる制度です。設定は工場財団登記簿への所有権保存登記で行います。土地建物、機械等、地上権、賃貸人の承諾がある物の賃借権、工業所有権等の法11条の範囲を確認します。借りている物そのものを所有物として加入させることと、承諾を得た賃借権を加入させることは違います。

他人の権利や差押え等の目的となっている物は、原則として財団へ属させられません。加入後の構成物も、個別に譲渡し、所有権以外の権利や差押え等の目的にすることが禁じられます。財団全体と、その中の機械1台は差押対象として区別します。財団又は構成物の賃貸には、法13・14条の抵当権者の同意による例外があります。

所有権保存登記後6か月内に抵当権設定登記を受けなければ、その保存登記は効力を失います。また、抵当登記が全部抹消された後などに6か月内の新たな抵当登記がなければ、法8条の財団消滅を検討します。建設機械の30日と、工場財団の6か月を混ぜないようにします。[工場法8〜14条]

### 例題3：担保の原資と、別財産からの回収を分ける

工場財団を組成していない工場で、土地と法2条の対象機械を適法に一体として換価した代金が350万円、直接費用10万円とします。国税100万円の法定納期限等以前に効力を備えた工場抵当の優先対象額は250万円、他の優先債権はありません。原資340万円から抵当250万円、国税90万円となり、国税10万円が残ります。

別に、備付物ではなく抵当の及ばない在庫商品があり、その適法な換価から使える正味代金20万円を得たとします。この原資から残国税10万円を回収でき、残り10万円は他に配当対象債権がない条件で滞納者へ交付します。在庫20万円を工場抵当の原資へ加える処理も、最初の配当だけで国税全額を回収済みとする処理も誤りです。

この工場が適法な工場財団を設定していたなら、加入済みの機械を単独の動産として差し押さえる計画は見直します。また、財団目録へ賃借権を加える場合は賃貸人の承諾を確認します。「工場が使っている」という事実だけでは、他人の所有権・既存権利・財団の処分制限を解決できません。

## 企業担保を、個々の物の抵当権へ読み替えない

企業担保法1条は、株式会社の総財産を、その株式会社の発行する社債の担保として一体化する物権を定めます。一般の貸付債権について、契約で会社財産全部を担保にしただけでは、この制度の要件を満たしません。設定・変更契約には公正証書が必要で、本店所在地の株式会社登記簿への登記は、原則として権利の得喪・変更の効力要件です。単に第三者対抗の問題として扱わない点が重要です。[企業法1・3・4条]

企業担保権者の優先は法2条の規律によります。同条2項は、会社財産への強制執行・担保権実行競売では同条1項を適用しないと定めます。また、一般先取特権と、個別財産上の特別先取特権・質権・抵当権は、法7条に従って企業担保に優先します。個別財産の権利は、企業担保登記より後に対抗要件を備えたものも、法6条によって企業担保権者へ対抗できます。早い登記が常に個別の権利を排除するという図にはなりません。

### 例題4：企業担保の成立と私権相互の関係

株式会社Fは、自社社債を担保する企業担保契約を公正証書で締結しましたが、まだ登記していません。その後の登記前に、貸主Gが企業担保権の成立を主張してきました。公正証書だけでは法4条の登記による効力要件を満たしません。契約締結日をそのまま権利発生日として配当表へ入れることはできません。

適法に企業担保の登記を終えた別の場合に、個別の土地に抵当権を持つHと企業担保権者が競合すれば、Hの抵当の対象土地では法7条2項を確認します。企業担保の登記が先であるという理由だけでHを排除しません。さらに、企業担保の実行は同法の裁判所手続によります。滞納処分との調整や国税の手続上の位置は「保全措置と他の執行手続との調整」で各手続法とともに教えます。本例は企業担保と国税の最終配当額を確定する資料を与えていません。

## 取消しの通知があっても、すべて同じ期間ではない

登録等の基礎が失われる場合には、個別法が抵当権者の特別な実行を認めることがあります。自動車法17条は、法16条後段の所定の申請受理通知を受けた場合を対象とし、通知を受けた日から3か月以内の手続を要求します。法16条前段の実際の抹消登録通知まで、すべて同じ実行事由であるとまとめないようにします。

航空機法19・20条にも、所定の抹消登録申請受理又は催告後の不申請に関する通知と、受領から3か月以内の実行手続があります。他財団には6か月の規定や、通知受領ではなく取消しの日を起点にする規定もあるため、別講で比較します。徴収法22条の代位実行も、税が不足するという事情だけで個別法上の実行条件を省ける制度ではありません。

答案では、財産の種類、適用法、登録・登記とその法的効果、担保の及ぶ範囲、国税との比較日、原資と配当額を順に示します。成立・第三者対抗・優先・手続開始を一つの「有効」という言葉にまとめず、与えられた資料でどこまで判断できるかを書き分けます。
