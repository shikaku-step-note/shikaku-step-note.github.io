# 荷為替の用語を事例で使い分ける8問

これは未公開の著者草稿です。独立審査は未完了です。

## 対象と使い方

12定義カードとは別の、場面・条件を読んで用語を選び説明する8問。

既存cash coreの26問とは別のIDであり、本講の4詳細技能を対象とする。

## zr2-boki-documentary-glossary-assessment-q1（2点）

会社ひのきは自社を受取人として為替手形を振り出し、別会社もみじを支払人に指定した。この「自社を受取人にした」形を何と呼びますか。

1. 自己指図

2. 自己宛

3. 手形の不渡り

4. 銀行による買取り

### 正答と理由

正答：1

1が適切。自己指図は振出人と受取人が重なる。2は振出人と支払人が重なる形、3は支払拒絶等に関わる別の事実、4はその後に行われ得る別取引である。

## zr2-boki-documentary-glossary-assessment-q2（2点）

為替手形の支払人欄に名前がある会社を、担当者が署名等を確認せず「引受人」と呼んだ。「支払人」と「引受人」を、この確認不足に即して使い分けてください。

### 解答と理由

支払人は支払いを委託される者として手形に記載される立場である。引受人として満期の直接支払義務を負う段階については、有効な引受けを確認する。記名されている事実だけから、その段階まで終わったと扱わない。

### 採点の観点

1点：支払人という記載上の立場

1点：有効な引受けによる引受人の義務を別に確認

## zr2-boki-documentary-glossary-assessment-q3（2点）

輸入者の有効な引受けは終わったが代金は未払いである。必要書類は揃い、契約条件の変更もない。「支払い前の引受けとの交換で書類を渡す」という条件名はどれですか。

1. D/P

2. D/A

3. 円貨手取額

4. 保証債務の時価

### 正答と理由

正答：2

2のD/Aが該当する。D/Pは支払いとの交換条件である。3と4は受取額や負債の測定に関する用語で、書類引渡条件名ではない。

## zr2-boki-documentary-glossary-assessment-q4（2点）

銀行へ書類を預けて「取立委託」をした後、別の契約で銀行が手形を「買取り」した。二つの語の違いと、会計処理で確認すべき銀行の行為を説明してください。

### 解答と理由

取立委託は代金回収を依頼すること、買取りは銀行が手形を買い取る取引である。受領・受託だけの資料と買取実行の資料を分け、実務指針34項の同時認識には所与の銀行買取りが実行されたかを確認する。

### 採点の観点

1点：回収依頼と買取取引の区分

1点：受託証ではなく買取実行という対象事実を確認

## zr2-boki-documentary-glossary-assessment-q5（2点）

輸出手形の額面は430,000円、新たに認識する保証負債の時価は3,500円である。「保証債務3,500円」の説明として適切なものを選んでください。

1. 輸入者が銀行へ支払う額面全額である

2. 必ずその場で会社が追加現金支払する額である

3. 所与の保証義務を当初認識する負債の測定額で、額面や現金徴収と区分する

4. 会社が残す未取組売掛金の外貨額である

### 正答と理由

正答：3

3が適切。保証の負債認識額、主債務の額面、現金の控除額は別の資料で確かめる。1は額面との混同、2は与件にない現金支払の追加、4は残る資産との混同である。

## zr2-boki-documentary-glossary-assessment-q6（2点）

輸出代金の30％だけを銀行へ取り組み、担当者が残る70％も「割引済み手形」と呼んだ。残る部分に使うべき用語と、帳簿で残す対象を示してください。売掛金を手形へ別途振り替える事実はないものとします。

### 解答と理由

残る70％は未取組部分の売掛金である。銀行へ譲渡した部分と区分し、会社が保有する債権として通貨額と円帳簿価額を残す。取り組んでいない部分を割引済み手形や消滅済み債権と扱わない。

### 採点の観点

1点：未取組売掛金という対象を特定

1点：会社保有の通貨額・円帳簿を残すことを説明

## zr2-boki-documentary-glossary-assessment-q7（2点）

期末に米ドル建売掛金が残り、別に円建保証債務も計上されている。ヘッジ等はない。「残存外貨建金銭債権の決算換算」の対象と説明が適切なものを選んでください。

1. 売却して消滅したドル分を含む当初代金全額を換算する

2. 売掛金と円建保証債務をまとめてドル建資産へ換算する

3. 円建保証債務だけを為替差損益で再換算する

4. 会社が保有する米ドル建売掛金の残額を、決算時相場で円換算する

### 正答と理由

正答：4

4が適切。1は消滅済み部分を重ね、2は異なる通貨・資産負債を混ぜ、3は円建負債をドル建債権の換算対象へ置き換えている。保証の他の測定処理が必要かは別に確認する。

## zr2-boki-documentary-glossary-assessment-q8（2点）

前期末に正しく換算済みの売掛金を当期回収した。「当初記録の相場」と「前期末相場」を使う場面を分け、当期の決済差損益をどの円帳簿から求めるか説明してください。

### 解答と理由

当初記録の相場は取引発生時の円記録に用いる。前期末までに換算した損益は前期の処理である。当期の決済差損益は、前期末換算後の円帳簿価額と当期の円貨回収額から求め、当初からの差額を全て当期へ重ねない。

### 採点の観点

1点：当初記録と前期末までの換算を区分

1点：前期末換算後の帳簿と当期回収額を対応
