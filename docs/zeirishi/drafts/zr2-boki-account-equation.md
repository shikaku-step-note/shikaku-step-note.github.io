## 取引を、何が増え何が減ったかに分ける

会社が銀行から借り入れると、預金が増えます。同時に、銀行へ返す義務も増えます。売上代金が入金されたときも預金は増えますが、すでに売掛金を計上していたなら、今回はその売掛金が減ります。同じ入金でも、相手となる項目を調べなければ、会社の利益は分かりません。

この講では、取引を資産・負債・純資産・収益・費用の変化に分け、仕訳へ直す練習をします。帳簿への転記と試算表は次の講で扱います。まず本文の増減表を読み、例題では仕訳を書く前に、変化した項目を自分の言葉で説明してください。消費税、法人税、減価償却などは各例で考慮しないものとします。収益の細かな認識条件は収益認識の講で学ぶため、ここでは「役務提供を完了し、売上を計上すべき取引」と明示します。

会社の記録と株主個人の記録も分けます。株主の個人的な支出は、会社が支払ったか、会社が負担すべき費用かを確認してから扱います。株主の財布からお金が出ただけでは、会社の預金も費用も動きません。誰の取引を記録しているかをそろえることが、複式簿記の出発点です。

## 資産と負債の差が純資産になる

資産には、会社が保有する現金や設備、顧客から代金を受け取る売掛金などがあります。負債には、借入金、商品代金を後で支払う買掛金、発生済みの給与の未払額などがあります。純資産は資産から負債を差し引いた残額です。この関係を貸借対照表等式といいます。

資産＝負債＋純資産

例えば資産が2,000,000円、負債が700,000円なら、純資産は1,300,000円です。純資産は、金庫や預金口座に別に積んである現金を表す言葉ではありません。資産の中身が設備や売掛金でも、この差額の関係は変わりません。貸借対照表は、ある時点の資産・負債・純資産を示すので、残高を比較するときは同じ日でそろえます。

純資産には、株主から払い込まれた資本や、それまでに稼いで社内に留保した利益などが含まれます。純資産の増加をすべて当期利益にすると、増資による払込みまで売上にしてしまいます。反対に、配当による分配は利益の使途に関する取引で、その期の費用とは区別します。資本取引の詳細は後続講で扱いますが、この区別は最初の仕訳から必要です。

収益と費用は、期間の利益を計算する項目です。収益から費用を引いた額が利益となり、損失の場合は費用の方が大きくなります。営業利益や税引前利益などの段階は後で分けます。この講の数値例では、示された収益・費用だけで期間利益を計算し、税金その他の損益はないとします。

## 借方・貸方は記録する左右の名前

仕訳では左を借方、右を貸方と呼びます。「借りたから借方」「貸したから貸方」と言葉の日常的な意味で選ぶことはできません。借入金という負債が増える取引なら、その増加を貸方に記録します。先に項目の性質と増減を判断し、その後で記入する側を決めます。

| 項目 | 増加・発生を記録する側 | 減少・取消しを記録する側 |
| --- | --- | --- |
| 資産 | 借方 | 貸方 |
| 負債 | 貸方 | 借方 |
| 純資産のうち資本金等 | 貸方 | 借方 |
| 収益 | 貸方 | 借方 |
| 費用 | 借方 | 貸方 |

これはこの講で扱う通常の勘定の基本です。純資産の控除項目となる自己株式や、資産から控除する減価償却累計額などは、後続講で性質を確認します。表だけで例外のある勘定を分類し終えたことにはなりません。

借方と貸方の合計額は、一つの仕訳の中で一致します。変化した項目が三つあれば、借方一行・貸方二行となることもあります。複式簿記は「勘定を必ず二つだけ使う」記録方法ではありません。複数の変化を左右に記録し、合計で対応させます。

売上を貸方、費用を借方へ記録する方向も、利益と純資産の関係から確かめられます。売上が発生して売掛金が増えると、資産の増加に対応して、利益を通じ純資産を増やす原因が生じます。そこで売掛金の借方に対し、売上を貸方へ置きます。給与が発生して未払費用が増えると、負債増加の貸方に対して、利益を減らす給与費用を借方へ置きます。未払の給与も、この段階で費用を記録します。

また、同じ勘定が増える側と減る側の両方に現れます。借入金の受入れは貸方、返済は借方です。現金で入金と出金を相殺して一行にまとめる前に、何が原因で動いたかを取引ごとに記録してください。後から資金調達額や返済額を調べるには、純増額だけでは足りません。

## 支払の相手科目は、請求書の名称だけで決めない

支払総額63,000円のうち、借入元本の返済が60,000円、当期に発生した利息が3,000円だったとします。借方は借入金60,000円と支払利息3,000円、貸方は現金63,000円です。全額を支払利息にすると、借入金の残高が減らず、費用が60,000円過大になります。全額を借入金にすると、逆に費用3,000円が記録されません。通帳に出金が一本だけ載っていても、帳簿では性質に従って分けます。

消耗品の購入も、使った時点と記帳方法の指定を調べます。未使用の消耗品100,000円を資産として記録した後、そのうち30,000円を当期に使用したなら、借方・消耗品費30,000円／貸方・消耗品30,000円とします。現金は使用時には動かず、残る資産は70,000円です。購入時に現金が減ることと、使用して費用が生じることを分ける例です。重要性等によって購入時費用処理が指定される問題では、その指定に従います。

過去に計上した負債を消す支払か、新しく資産を得た支払か、当期の費用を伴う支払かを確認します。複数の性質が同時にあれば、元本と利息のように金額を分けます。増減の説明から仕訳へ進めると、見慣れない科目でも判断の理由を残せます。

## 例題1：出資・借入れと掛売上を区別する

設立時からの取引を、次の順に記録します。単位は円です。出資額は全額を資本金に計上するものとし、購入した消耗品は未使用なので資産の消耗品勘定で記録します。

| 取引 | 借方 | 貸方 |
| --- | --- | --- |
| 株主から現金1,200,000を受け入れた | 現金1,200,000 | 資本金1,200,000 |
| 銀行から現金800,000を借り入れた | 現金800,000 | 借入金800,000 |
| 備品600,000を現金で購入した | 備品600,000 | 現金600,000 |
| 未使用の消耗品200,000を後払いで購入した | 消耗品200,000 | 未払金200,000 |
| 役務提供を完了し売上300,000を掛けで計上した | 売掛金300,000 | 売上300,000 |
| 当期分の給与120,000を現金で支払った | 給料120,000 | 現金120,000 |
| 消耗品の未払金70,000を現金で支払った | 未払金70,000 | 現金70,000 |
| 売掛金100,000を現金で回収した | 現金100,000 | 売掛金100,000 |

借入金を受け取った時点では、現金と負債が同額増えます。返済義務があるため、800,000円を売上に含めません。備品購入は資産の入替えで、ここでは購入額をそのまま費用にしていません。消耗品購入も未使用資産として記録するという条件があるので、費用に含めない点を確認します。

売上計上時と回収時を分けると、二重計上を防げます。役務提供完了時に売上300,000円と売掛金300,000円を記録し、回収時は売掛金を100,000円減らします。回収で再び売上を記録すると、同じ役務の売上が400,000円になってしまいます。

最後の残高を別々に集計します。現金は1,200,000＋800,000−600,000−120,000−70,000＋100,000＝1,310,000円。売掛金は300,000−100,000＝200,000円、未払金は200,000−70,000＝130,000円です。

資産合計＝現金1,310,000＋売掛金200,000＋備品600,000＋消耗品200,000＝2,310,000円

負債合計＝借入金800,000＋未払金130,000＝930,000円

当期利益＝売上300,000−給料120,000＝180,000円

純資産は資本金1,200,000円と利益180,000円の合計1,380,000円です。負債930,000＋純資産1,380,000＝2,310,000円となり、資産合計と一致します。ここでは利益を計算へ含めていますが、帳簿で利益を純資産へ振り替える締切仕訳は別の講で行います。

## 例題2：一つの取得を複数の支払手段で記録する

備品の取得価額が500,000円で、現金200,000円を支払い、残り300,000円は銀行からの借入れによって直接決済されたとします。取得価額は確定しており、別の手数料や利息はありません。

借方：備品500,000円

貸方：現金200,000円、借入金300,000円

借方500,000円に対し、貸方も200,000＋300,000＝500,000円です。借入れは会社の現金を経由せずに決済されています。この指定なら現金300,000円の入金を別に重ねません。「借入れがあるから、必ず現金を増やす」と覚えると、契約上の流れと異なる記録になります。

購入前の残高が現金700,000円、売掛金300,000円、買掛金200,000円、資本金800,000円だったとします。上の取得に続けて、売掛金200,000円を回収し、買掛金100,000円を現金で支払いました。

現金は700,000−200,000＋200,000−100,000＝600,000円、売掛金は100,000円、備品は500,000円です。資産合計は1,200,000円。負債は買掛金100,000円と借入金300,000円で400,000円、純資産は800,000円です。この一連の取引から収益・費用は生じず、利益は0円です。現金が100,000円減っていても、損失100,000円とはなりません。

## 例題3：利益と現金の増減を両方計算する

期首に現金500,000円と資本金500,000円だけがあり、当期に次の取引を行いました。給与180,000円は全額が当期に発生した費用で、そのうち120,000円を支払い、60,000円は未払費用とします。

1. 役務提供を完了して現金売上200,000円、掛売上300,000円を計上した。
2. 給与のうち120,000円を現金で支払った。
3. 現金400,000円を借り入れ、その後、元本100,000円を返済した。
4. 当期の売掛金150,000円を現金で回収した。

利益を求めると、収益500,000−費用180,000＝320,000円です。給与の未払60,000円も当期費用に含めます。返済100,000円は元本なので費用に含めません。

現金は500,000＋200,000−120,000＋400,000−100,000＋150,000＝1,030,000円で、増加額は530,000円です。利益320,000円と現金増加530,000円は一致しません。売掛金150,000円が残り、未払費用60,000円と借入金300,000円が残っているからです。

利益から現金増加へ確かめるなら、320,000−売掛金増加150,000＋未払費用増加60,000＋借入元本純増300,000＝530,000円となります。この時点ではキャッシュ・フロー（CF）計算書の区分を作成する必要はありません。現金を伴わない損益と、損益を伴わない現金移動を、自分で説明できることを確認します。

## 例題4：純資産の変化から利益を逆算する

期首の資産2,000,000円、負債700,000円に対し、期末の資産は2,600,000円、負債850,000円でした。当期中に株主から300,000円の追加出資を受け、適法な手続を経た剰余金の配当100,000円を行ったとします。損益を経由せず純資産へ直接計上する評価差額、過年度の修正その他の純資産変動はありません。

期首純資産＝2,000,000−700,000＝1,300,000円

期末純資産＝2,600,000−850,000＝1,750,000円

純資産増加450,000円の中には、追加出資300,000円が入り、配当100,000円が差し引かれています。したがって利益は450,000−300,000＋100,000＝250,000円です。配当を足すのは、配当で減る前の利益を求めるためです。配当を収益に計上しているのではありません。

この計算式は、例の限定条件と一緒に使います。その他の包括利益や評価・換算差額、過年度修正があれば、それらによる純資産変動を分けなければ当期利益だけを取り出せません。式の暗記で未知項目を利益へ押し込まないようにします。

## 貸借一致を確認した後も、取引の中身を点検する

買掛金50,000円の支払を、給料50,000円の支払と誤って記録した場合を考えます。誤った仕訳でも、借方・給料50,000円と貸方・現金50,000円は一致します。しかし本来減るべき買掛金が残り、費用が50,000円多くなっています。左右の一致は確認の一つで、勘定科目や期間の正しさまで保証するものではありません。

仕訳を作るときは、取引主体、変化した権利・義務や費用収益、金額、記録する時点の順で確認します。そのうえで増減表に従って左右へ置きます。資産同士の入替え、資産と負債の同時増減、損益を伴う増減を分けられれば、見慣れない文章でも仕訳の候補を絞れます。

理解度問題では、利益を問うのか、現金残高を問うのか、純資産を問うのかを最初に確かめてください。問われていない額も別の式で検算し、食い違ったら取引の二重計上や返済元本の費用化を調べます。次の講では、ここで作った仕訳を元帳と補助簿へ転記し、取引別の記録が勘定別の残高へ変わる過程を追います。
