# 記録単元の用語を短い事例で使い分ける

用語集32定義は参照資料であり、以下の独立した24事例の設問数へ加えません。公開draft・審査pending。50分は学習者による検証前の目安です。

## 問題

### 問1

銀行からの借入金が入金された。担当者は「現金が増えた取引だから収益」とした。どの用語の区別が必要ですか。

1. 資産の増加と収益の発生を区別し、返済義務を負債に記録する
2. 現金収入はすべて収益なので区別不要
3. 資産が増えれば必ず純資産も同額増える
4. 借入金は翌期返済なので当期には記録しない

### 問2

備品に係る減価償却累計額は貸方残高である。残高の向きだけを見て負債へ入れた。最も適切な説明はどれですか。

1. 貸方残高は例外なく返済義務を意味する
2. 減価償却累計額は当期の現金支払額を示す
3. 減価償却累計額は当期の減価償却費と必ず同額である
4. 資産の控除項目なので、資産の帳簿価額を示す際に備品から控除する

### 問3

株式会社が過年度利益から配当を支払った。従業員給与の支払いと同じ「費用」とする説明を、費用と利益分配の用語を使って訂正してください。配当を費用にすると当期利益がどうなるかも述べてください。

### 問4

当期に販売済みの商品の代金を、翌期に売掛金から回収した。翌期の回収を表す組合せはどれですか。

1. 売掛金は現金収入なので負債である
2. 資産間の振替であり、販売時に計上済みの売上を重ねない
3. 翌期に現金が入ったので、翌期売上を必ず再計上する
4. 翌期の回収額はすべて前受収益である

### 問5

当座預金元帳の借方に、相手欄「諸口」、金額180,000円という一行がある。内訳の仕訳はまだ見ていない。担当者は同額の「諸口勘定」を独立に作ろうとした。なぜ適切でないか、内訳を調べる資料と、現段階で個別の相手科目を確定できるかを説明してください。

### 問6

同じ取引を発生日順に追いたい場合と、預金勘定だけの増減・残高を追いたい場合がある。主要簿の使い分けとして適切なのはどれですか。

1. 発生日順は総勘定元帳、預金集計は仕訳帳
2. どちらも得意先元帳だけで確認する
3. 総勘定元帳へ転記したら仕訳帳の記録は消す
4. 発生日順は仕訳帳、預金勘定ごとの集計は総勘定元帳

### 問7

売掛金の総勘定元帳残高は合っているが、どの得意先が未払いか分からない。直接確認する補助簿はどれですか。

1. 固定資産台帳
2. 現金出納帳の合計額だけ
3. 得意先別の売掛金元帳
4. 仕入先別の買掛金元帳

### 問8

預金元帳の当期借方記入合計300,000円、貸方記入合計120,000円。期首残高を含めた集計は今回は求めない。合計試算表で示す当期記入合計と、その差額180,000円の関係を説明し、二つを同じ数字として転記できるか述べてください。 また、この資料だけで180,000円を期末残高とできるか、必要な情報とともに説明してください。

### 問9

借入れの仕訳で、貸方を借入金ではなく売上と誤記した。貸借は同額で転記した。試算表が一致したことから言えるのはどれですか。

1. 左右の金額一致だけで、科目の正確性は保証されない
2. 借入金と売上はどちらも貸方なので同じ勘定でよい
3. 試算表が一致すれば元の証憑を確認する必要はない
4. 売上の過大計上は必ず貸借不一致を生む

### 問10

当期の売上・給料の残高をいったん集め、当期損益を計算する締切勘定はどれですか。

1. 残高勘定
2. 諸口勘定
3. 資本金勘定
4. 損益勘定

### 問11

締切後の残高勘定に、備品500,000円の借方と減価償却累計額80,000円の貸方がある。残高勘定の記載と貸借対照表の備品帳簿価額の違いを、金額と科目の性質から説明してください。

### 問12

締切後の繰越利益剰余金は、前期からの残高、当期利益、配当等を反映している。この残高を表す適切な説明はどれですか。

1. 翌期の売上予算の金額
2. 一定時点の純資産項目の残高で、当期利益そのものと必ずしも一致しない
3. 当期利益だけなので配当を考える必要はない
4. 会社が保有する現金残高の別名

### 問13

翌年一年間の保険保障を受けるために支払った保険料と、未完成の機械の購入代金として先払いした金額がある。最も適切な区別はどれですか。

1. 継続する役務の未経過分は前払費用、機械代金の前払いは前払金として取引内容を確認する
2. どちらも現金支出済みなので必ず当期費用
3. どちらも継続役務の前払費用として同じ期間で償却する
4. 機械代金の前払いは未払費用である

### 問14

従業員が当期末まで働いた給与の未払分と、納品・取得済み備品の未払代金がある。本講の勘定体系に従う区別はどれですか。

1. 両方とも未払費用なので資産の取得は記録しない
2. 給与は未収収益、備品代金は前払費用
3. どちらも支払いがないので帳簿に記録しない
4. 給与の期間対応は未払費用、備品代金は未払金

### 問15

保険契約を終了し、解約返金額の通知を受け、金額は確定したが未入金である。将来の保障を受ける権利は残らない。前払費用と未収入金のどちらの性質か、未収収益との違いも説明してください。

### 問16

翌期の半年間にわたり提供する倉庫賃貸の賃料を、当期末までに先に受け取った。まだその半年の役務は提供していない。対応する経過勘定はどれですか。

1. 売掛金
2. 前受収益
3. 未収収益
4. 未払費用

### 問17

前期末に未払費用を計上し、翌期首に再振替した。担当者は「再振替をすると、前期に生じた費用が翌期の費用へ移る」と説明した。再振替と費用の期間帰属の関係を訂正してください。

### 問18

年率をそのまま一回の複利計算の率に使ったところ、利息を半年ごとに元本へ組み入れるという条件を落としていた。確認する組合せはどれですか。

1. 年率だけでよく、組入頻度は無関係
2. 元本だけでよく、期間は無関係
3. 利息は常に元本と同じ額にする
4. 年率の表示方法、半年の期間利率、複利回数

### 問19

貸倒DCFの問題で、通常の貸付発生時の約定利率5％と、条件緩和後の利率2％が並んでいる。将来回収額の見積りと割引率の関係はどれですか。

1. 当初5％で現金回収額を作り、2％で割り引く
2. 二つの平均3.5％を根拠なく採用する
3. 緩和後の元利回収額を見積もり、発生当初約定利率5％で割り引く
4. 緩和後の利率2％を使えば当初の5％は不要

### 問20

固定資産の減損について、割引前の将来キャッシュ・フローで行う認識判定と、使用価値を計算する段階がある。「現在価値」という用語を使う段階を区別し、すべての段階を一つの割引計算に置き換えてよいか説明してください。

### 問21

売上の一部を現金で受け取った取引を、いったん全額掛売上としてから現金回収を記録する方式で伝票にする。入金伝票の相手科目として適切なのはどれですか。

1. 売掛金
2. 売上
3. 仕入
4. 前払費用

### 問22

五伝票制で、現金仕入もいったん全額掛けとして記録する方式を採る。同じ商品購入45,000円について、仕入伝票に「仕入45,000円／買掛金45,000円」、出金伝票に「買掛金45,000円／現金45,000円」を記入した。正しい判断はどれですか。

1. 両伝票が必要で、買掛金は差引0円となり、仕入と現金支払を一回ずつ記録できる
2. 同じ45,000円なので出金伝票を削除すればよい
3. 仕入伝票だけを削除すれば商品取得が正しく記録される
4. 両方の借方を仕入へ変えても損益は変わらない

### 問23

普通仕訳帳に伝票A14の備品代30,000円の支払い、特殊仕訳帳に伝票B25の消耗品代30,000円の支払いがある。証憑と支払記録を照合すると、別の購入・別の支払いをそれぞれ一回ずつ記録したものと確認できた。担当者は「同額だから重複」として30,000円を除こうとした。除くべき額と、重複という用語がこの二行に当てはまるかを理由とともに説明してください。 取引の同一性を確認する方法も一例示してください。

### 問24

銀行の入金明細に「取引先から120,000円」とだけ載っている。請求書や契約書はまだ見ていない。この証憑一つで売上・売掛金回収・借入金のどれかを確定できるか、追加で確認する資料の例を一つ以上示して説明してください。

## 解答と採点

### 問1

正答：1。

借入れでは預金と負債が増えます。現金収入と収益は同じ概念ではありません。他の案は負債の発生を落とすか、資産増加と利益を直結させています。

### 問2

正答：4。

貸借の向きだけでは勘定の性質は決まりません。累計額は資産の取得後からの配分の累積で、当期費用や支出額と区別します。

### 問3

給与は役務に係る費用になり得る一方、配当は株主への利益分配で純資産の減少として扱う。配当を費用にすると当期利益を過小にする。

資金の流出だけで費用と判定せず、取引の相手と目的を確認します。この問は配当手続の適法性や金額制限を求めていません。

- 給与に係る費用と株主への利益分配を区別する（2点）
- 誤って費用にすると当期利益が過小になると示す（1点）

### 問4

正答：2。

回収時は現金預金が増え売掛金が減ります。売上の時期と入金の時期を分けます。前受収益は既に販売済みの商品代金回収に当てはまりません。

### 問5

諸口は複数の相手科目を示す記載であり、独立勘定を作らない。元帳の参照先の仕訳帳を確認して、複数の相手科目と金額を追う。この一行だけで個別の売上・売掛金・借入金等へ断定はできない。

元帳の相手欄は参照のための記載です。内訳がないのに、180,000円を別勘定の残高や架空の相手科目へ割り当てません。

- 諸口を複数相手の記載とし、独立勘定を否定する（1点）
- 参照先の仕訳帳で内訳を確認すると示す（1点）
- 一行だけでは個別の相手科目を確定できないと示す（1点）

### 問6

正答：4。

仕訳帳と総勘定元帳は同じ取引を異なる軸で記録し、参照関係を残します。得意先元帳は預金を含むすべての取引の主要簿ではありません。

### 問7

正答：3。

総勘定元帳の総額と得意先別内訳を照合します。買掛金元帳は支払義務、固定資産台帳は資産個別情報の資料で、現金合計だけでは未払得意先を特定できません。

### 問8

当期記入合計は借方300,000円と貸方120,000円をそれぞれ示す。180,000円は当期記入の差額で、合計額そのものではない。同じ数字として転記できない。期末残高を求めるなら期首残高も必要になる。

合計試算表の借貸合計と残高の計算を区別します。与件は期首を与えていないので、180,000円を当然に期末残高としません。

- 借方合計300,000円・貸方合計120,000円を区別する（1点）
- 差額180,000円と合計額を区別し同一転記を否定する（1点）
- 期末残高には期首残高の情報が必要と示す（1点）

### 問9

正答：1。

同額の誤科目転記は試算表の一致で発見できない場合があります。他の案は勘定の意味を無視するか、試算表の検出能力を過大に見積もっています。

### 問10

正答：4。

損益勘定に収益・費用を集めます。残高勘定は資産等の繰越に関わり、諸口は独立勘定ではありません。資本金へ全収益費用を直接振り替える処理にもなりません。

### 問11

残高勘定には備品500,000円と累計額80,000円をそれぞれの残高方向で記載する。貸借対照表の正味帳簿価額は500,000−80,000＝420,000円。累計額は負債ではなく備品の控除項目。

貸方にある累計額を買掛金等の負債と合算しません。この問題は別の評価損等がない条件です。

- 残高勘定の二つの残高を区別する（1点）
- 正味備品420,000円を計算する（1点）
- 累計額を資産控除と説明する（1点）

### 問12

正答：2。

累積した純資産の残高と、一期間の損益を区別します。現金や売上予算とは別の情報です。

### 問13

正答：1。

経過勘定の前払費用は継続役務の期間配分に関する用語です。物品代金の前払いを同じ性質としません。他の案は支出と費用の時期又は前払いと未払いを混同しています。

### 問14

正答：4。

継続役務の経過分と資産の取得代金を区別します。具体的な補助科目名が違う場合も、この性質の区別を確認します。

### 問15

確定した金銭の返還請求権なので未収入金の性質。将来保障の権利がないので前払費用ではない。継続的な役務を当社が提供したことによる当期の未収収益とも異なる。

未入金という事実だけで未収収益に分類せず、権利が生じた原因を確認します。返金の税務上の処理はこの問の範囲外です。

- 確定返金請求権を未収入金とする（1点）
- 前払費用との将来役務の違いを示す（1点）
- 未収収益との発生原因の違いを示す（1点）

### 問16

正答：2。

継続役務の対価を役務提供前に受け取った部分が前受収益です。未収収益と売掛金は請求権側、未払費用は当社が受けた役務の未払側なので向きが異なります。

### 問17

再振替は前期末整理の逆仕訳を翌期首に行う記帳方法。翌期の支払い等と組み合わせることで、前期分を翌期費用へ重ねず、翌期分だけを翌期の費用に残す。前期の確定した費用帰属を翌期へ移す処理ではない。

再振替する場合としない場合で、適切な処理後の期間損益が一致することを確認します。

- 期末整理の逆仕訳という記帳方法を説明する（1点）
- 翌期支払と合わせ前期分を翌期へ重ねないと説明する（1点）
- 前期費用を翌期へ移す説明を否定する（1点）

### 問18

正答：4。

半年複利なら期間に合う率と回数が必要です。実効年率と名目年率のどちらかも確認します。他の案は金利・期間の条件を無視します。

### 問19

正答：3。

金額を決める条件と測定の率を区別します。購入債権なら取得当初の実効利率を使うなど、債権の発生形態も確認します。他の案は役割を取り違えています。

### 問20

損失認識の判定では割引前の将来CFを用い、使用価値の算定では将来CFの現在価値を用いる。測定の目的と適用条件が異なるので、両段階を一つの割引計算に置き換えない。

利息・現価講で扱う測定目的の区別を確認する問題です。この問は減損兆候の全要件や回収可能価額全体の計算は求めません。

- 認識判定が割引前であると示す（1点）
- 使用価値が現在価値であると示す（1点）
- 目的が違い一律に置換しないと説明する（1点）

### 問21

正答：1。

この方式では売上は全額掛取引の伝票で計上済みで、入金伝票は売掛金の回収です。売上にすると同じ現金部分の売上を重ねます。他の科目は与件の取引原因に合いません。

### 問22

正答：1。

全額掛け方式では仕入と、買掛金の現金決済を二段階で記録します。出金伝票を削除すると現金支払が欠け、仕入伝票を削除すると商品取得が欠けます。両方の借方を仕入にすると90,000円を仕入計上し、買掛金45,000円も残る誤りになります。

### 問23

除く額は0円。同じ30,000円でも、別の購入・別の支払いであり、それぞれ一回だけ記録されているので重複ではない。同一取引の余分な記録を見つけるために、証憑番号・取引内容・支払記録を対応させる。

重複は金額の一致だけで判定しません。この与件で一行を消すと、実在する別取引を欠落させます。

- 除く額0円を示す（1点）
- 別の実在取引を各一回記録しているので重複でないと説明する（1点）
- 証憑番号や支払記録等を対照し、取引の同一性を確認する方法を一例示す（1点）

### 問24

入金の事実は確認できるが、取引原因まで一意に確定できない。対応する請求書・売掛金元帳・契約書などを確認し、新規販売、既存債権回収、借入れ等のどれかを判断する。

証憑が示す事実の範囲と会計上の分類判断を区別します。入金元の名称だけで収益を断定しません。

- 入金だけでは原因を確定できないと説明する（1点）
- 追加資料の具体例を示す（1点）
- 収益・債権回収・負債発生の分類に結び付ける（1点）
