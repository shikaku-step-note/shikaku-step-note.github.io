設備の個別基準による当期損失はゼロと適正に判定済みだが、翌年度の主要契約更新が見積額へ重要な影響を与えるリスクがある。連結設備残高800、個別残高500。個別注記案は、金額を省き「連結参照。減損基準に従った」とだけ書く。認識測定と注記の判断、個別額、参照内容の三点から問題を示し、直接補足又は参照を使う有効な改善案を一つ述べてください。

解答例：当期損失ゼロでも翌年度の重要なリスクの説明を検討する。個別の計上額500を連結800や省略で置き換えない。参照先の「減損基準に従った」だけでは契約更新の仮定や変化の条件等を理解できない。個別500を示し、必要な企業固有情報を当該注記へ直接補足するか、それを含む別注記/連結注記を参照して所在を明らかにする。

解説：参照という形式だけで開示目的を満たすとはいえません。直接補足を選んだ答案に、不要な参照先表示を追加採点条件として課しません。

- 2点：損失ゼロとリスク注記を分ける
- 1点：個別額500を必要とする
- 1点：参照内容の不足を具体的に指摘
- 1点：直接補足又は必要情報を備えた参照という改善
