# 立木・鉱業権等の担保と公示

登記立木、採掘権、漁業権、採石権、ダム使用権には、土地や建物の抵当を読むだけでは判断できない条件があります。採掘権の取消し後に使える競売期間を、鉱業財団の6か月と答える誤りも、その一つです。まず担保の対象を特定し、設定や公示の条件、取消原因、実行の方法を順に調べます。

本講の基準日は2026年4月3日です。目的は、①五つの財産・権利の担保目的、公示の効力、処分制限を資料に適用すること、②取消し・放棄等の後の実行、供託、土地利用関係、売却残余の帰属を判断し、国税の徴収対象につなげることです。前提は、抵当権と法定納期限等の比較、個別財団、特別の先取特権の各講です。

## 公示の名前と、何に効く公示かを分ける

調査資料に登記事項証明、鉱業原簿、免許漁業原簿、ダム使用権登録簿が混在しているときは、まず資料の表題を確かめます。その公示が権利を成立させる要件なのか、第三者に主張するためのものなのか、行政庁の認可と別に必要なのかを整理します。

|対象|担保を読む入口|公示等で確認すること|
|---|---|---|
|立木法の立木|所有権保存登記を受けた樹木の集団|立木登記記録、抵当の設定登記、土地側の既存担保の転写|
|採掘権|鉱業法13条で抵当の目的となる採掘権|鉱業原簿。原則として登録が効力発生要件となる60条と例外|
|個別漁業権|団体漁業権に当たらない漁業権|抵当設定の知事認可、登記に代わる免許漁業原簿の登録|
|採石権|他人の土地で岩石・砂利を採取する物権|土地の登記。採石業者の登録や採取計画認可とは区別|
|ダム使用権|多目的ダムによる一定量の貯留を確保する権利|大臣による設定、移転等の許可、登記に代わる専用簿の登録|

採掘権は登録を原則的な効力要件とする明文があります。相続等の一般承継、担保債権の消滅による抵当権消滅、期間満了による鉱業権消滅等は、60条の例外です。「鉱業では登録前の変動は全部無効」と広げないでください。漁業権の取得は69条の免許、個別漁業権の抵当設定は78条2項の認可を確認し、117条の登録を代用品にしません。

ダム使用権では、20条の不動産規定準用と26条の登記に代わる登録を読みます。1957年の政府の逐条説明は、26条を第三者に対する対抗要件を備えさせる規定と説明しています。一方、国税庁の68条関係27には登録によって成立するとの記述があります。本講の適用例は、有効な設定と登録が完了した権利に限定します。未登録の設定・移転の効力を問う枝は、この根拠の表現差の独立確認が済むまで、本講の未確認事項として残します。

## 立木は、登記前の土地側の権利まで調べる

明治42年法律22号を、以下「立木法」と呼びます。1条の立木は、一筆の土地又はその一部に生立する樹木の集団で、同法による所有権保存登記を受けたものです。登記されている立木は不動産とみなされ、土地から分離して譲渡し、抵当権の目的にできます。土地所有権や地上権の処分の効力が、この立木に及ばないという2条3項も確認します。

保存登記ができる集団の範囲は昭和7年勅令12号によります。原則は別表の樹種のうち7種を超えない種類で組成される集団です。植栽によって生立させた集団には、この制限によらないことができる例外があります。同一の土地の集団に二つ以上の立木登記をすることもできません。「天然林は全て対象外」「8種類なら植栽でも一律不可」とは判断できません。

立木法11条は、土地又は地上権が質権の目的である場合に、その土地の樹木の保存登記を認めません。17条は土地登記簿上の利害関係人の承諾等を要求し、18条は既存の先取特権・抵当権の登記を、所定の例外を除き立木登記簿へ転写させます。先に土地抵当があったのに、後から立木登記をすれば樹木だけを無担保にできる、という読み方はできません。

### 例題1：適法な採取と、別々の所有者になった後の土地利用

甲は土地と、適法に保存登記された立木を所有しています。既存の土地担保はなく、甲は立木だけに乙の抵当権を設定・登記しました。抵当設定時、両者は登記された施業方法に従う間伐を合意しています。甲がその方法で伐採した樹木Aと、その範囲を逸脱して伐採した樹木Bについて、抵当の追及を比較します。Bには即時取得等の第三者問題はないとします。

3条の協定した施業方法による採取であれば、Aは4条1項の分離後の追及から除かれます。Bにはその除外がなく、土地から切り離された後も抵当を行うことができます。4条2項により、乙は債権の期限前でもBを競売できますが、代金は供託します。甲が相当担保を供託して競売免除を申し立てる方法、1か月以上の期間を定めて乙に競売を催告し、不実行ならBへの抵当行使を失わせる方法も、同条にあります。

Bが第三者へ譲渡されたときは、4条5項が民法192〜194条の適用を妨げない点を加えます。登記があるから善意無過失の即時取得は一切問題にならない、と結論を固定しません。第三者の取引・占有取得・善意無過失等を別に当てはめます。

次に、乙の抵当実行で丙が立木を買い、甲が土地を所有し続けたとします。設定時に土地と立木が同じ甲に属し、立木だけに抵当を設定しているため、5条1項の地上権の設定みなしを適用します。期間・地代は、請求により地方の慣習を考慮して裁判所が定めます。買受人が伐採搬出まで土地を使う法的基礎を、売却代金の配当と並んで判断する場面です。

立木が地上権者に属する場合には6条の賃貸借のみなしとなり、地上権の存続期間内という条件があります。転貸できる土地賃借人の立木には7条の準用を確認します。8条は、担保立木の所有者である地上権者・賃借人が、抵当権者の承諾なく土地の権利を放棄し又は契約を解除することを制限します。9条は既存の運搬用土地・水利用権を買受人が相当対価を払って使う規律です。どの土地利用権が元々あるかによって結論が変わります。

## 採掘権単体の30日と、鉱業財団の6か月

鉱業権は鉱業法5条の鉱区で鉱物を掘採・取得する権利です。12条は物権とみなし不動産規定を準用しますが、13条が担保の目的を制限しています。試掘権を採掘権と同じに扱って抵当設定しません。21条1項により設定された採掘権は抵当権・租鉱権の目的となり得ますが、40条3項・7項又は41条1項により設定された採掘権は、13条ただし書では抵当権の目的となるものとされています。租鉱権を一律に設定できるとしません。

通常の移転では、51条の2による取得者側の大臣許可を確認し、登録だけを調べて終えません。相続等の一般承継は51条の3の届出等の経路であり、取得から3か月以内の届出と所定の適格条件の審査があります。登録が効力要件の例外であることと、届出・適格性の確認が不要であることは別です。

採掘権の取消しによる消滅登録後は、57条の通知と競売保護を確認します。抵当権者は通知到達の日から30日以内に競売を申し立てることができます。ただし52〜54条による取消しは除かれます。錯誤訂正、公共の福祉に反する状態、他人の鉱業等の著しい妨害という取消原因を先に特定してください。

対象となる場合、30日の期間内又は競売手続が完結する日までは競売目的の範囲で採掘権が存続するとみなされます。買受人の代金納付によって、取消しは効力を生じなかったとみなされます。58条は放棄による消滅登録に57条を準用します。なお、18条が定める登録日から2年、石油・可燃性天然ガスでは4年という存続期間は試掘権の規定です。これを採掘権の期間とせず、試掘権の期間満了に57条の抵当権者保護を付け加えることもしません。

### 例題2：通知の日と、特別競売の残金

抵当設定・登録済みの採掘権について、鉱業法55条の事由により適法な取消しがされ、57条の通知が2026年6月2日の日中に抵当権者へ到達しました。競売申立期限を求めます。別に、採掘権を含む鉱業財団で、鉱業抵当法4条の対象となる取消しがあり、同日に同条の通知を受けた場合と比較します。各期間について初日不算入とし、休日その他の延長事由はないものとします。

単体採掘権では6月3日を第1日として30日を数え、7月2日までです。財団では通知を受けた日から6か月の別規定を適用し、12月2日までとなります。通知の到達前に取消日があっても、両方の起点を一律に取消日へ移しません。

単体採掘権の57条の特別競売で、売却代金500万円、競売費用10万円、同条で弁済する抵当債務320万円とします。国税差押え・交付要求等の競合、他の抵当権、追加費用はありません。残余は500−10−320＝170万円で、57条5項により国庫へ帰属します。通常の滞納処分の配当表のように、この170万円をそのまま元の権利者へ交付しません。国庫帰属したことだけで、その者の滞納国税が同額納付済みになるとも扱いません。

取消しが53条の公共福祉を理由とする場合は、57条2項ただし書により同じ競売保護を使いません。53条の2では所定損失の補償を定め、抵当付き採掘権については、抵当権者の承諾がある場合を除き補償金を供託させます。抵当権者はその供託金に権利を行使できます。競売申立てと補償金への権利行使を、取消原因に応じて選びます。

## 漁業権は個別・団体・入漁を区分する

漁業法60条の漁業権には定置・区画・共同があります。団体漁業権は、自ら漁業を営まない漁業協同組合等の区画漁業権と共同漁業権です。これ以外を62条の個別漁業権として読みます。定置・区画という名称だけを見たり、「個別だから個人所有」と読み替えたりしません。

77条は個別漁業権には民法の質権の章を、団体漁業権には先取特権・質権・抵当権の各章を適用しません。個別漁業権の抵当設定には78条2項の知事認可が効力要件です。その漁場に定着する工作物には、同条1項による民法370条の特則があります。免許・抵当認可・登録はそれぞれの資料で確認します。

移転は79条の原則制限と例外を読みます。個別漁業権の滞納処分、先取特権者・抵当権者の実行等の場合でも、所定の知事認可と取得者の適格性が必要です。相続・合併・分割による取得には80条の届出等があります。貸付けは82条で禁止され、分割・変更・放棄には83条の登録先取特権者等・登録入漁権者の同意を確認します。

75条の存続期間は、真珠養殖等の省令所定の区画漁業権と共同漁業権が免許から10年、その他は5年です。漁場計画で法定期間より短く定めた場合は、その期間になります。具体的な省令該当性や計画の短縮が資料で確定しているかを確認し、抵当の有無だけで免許の存続期間を延ばしません。

入漁権は他人の団体漁業権の漁場で所定の漁業を営む権利です。98条は許される権利目的を限定し、通常の抵当設定の対象にはしていません。譲渡には漁業権者の同意が必要です。免許漁業原簿に記載されるという共通点から、入漁権を個別漁業権の抵当と同じ表に入れないでください。

### 例題3：休業取消しと公益取消しで、次の手段を選ぶ

会社丁は有効な個別漁業権を持ち、戊の抵当設定について知事認可と登録が完了しています。場合Aは漁業法89条の休業取消し、場合Bは93条1項の水底電線敷設等の公益上の必要による取消しです。Aでは95条1項の通知が2026年6月15日の日中に戊へ到達しました。初日不算入とし、延長事由はありません。

Aでは95条2項の30日以内に競売を請求でき、期限は7月15日です。Bは同項ただし書の除外に当たり、この30日の競売保護を利用できません。錯誤による免許取消しも除外です。抵当登録が残っていたという一事実だけで、全ての取消原因へ競売期間を与えません。単なる存続期間満了にも、この取消しの仕組みをそのまま準用しません。

Aの特別競売で売却代金50万円、費用2万円、登録先取特権に係る債務30万円、登録抵当債務10万円とし、他の競合はありません。95条4項の弁済をした残金は50−2−30−10＝8万円で国庫へ帰属します。買受人の代金納付時には、同条5項の取消しの効力に関するみなしを適用します。取消し後も無期限に普通の漁業ができる、という効果ではありません。

## 採石権の登記と、採石業の登録は別の資料

採石法4条の採石権は、設定行為に従って他人の土地で岩石・砂利を採取する物権です。地上権の規定を準用し、民法369条2項により抵当の対象となります。対抗関係の公示には土地の登記を調べます。一方、採石法32条の登録は採石業者の登録であり、採石権や抵当の登記を代わりに済ませるものではありません。

存続期間は設定行為で定め、5条により20年以内です。25年と定めても20年へ短縮されます。6条の更新も更新時から20年を超えません。期間がなくても地主との契約があるから無期限、とはしません。採石権が消滅した後の土地返還では、8条の原状回復又は損失補償も確認します。

9条以下は、経済産業局長の許可を受けた協議、協議不調時の決定等の手続です。「採石権の設定は全て9条の許可だけで成立する」と要約しません。決定申請書副本の交付後は14条の処分制限があり、土地側への新権利設定や採石権の変更・消滅を無断で進められない場面があります。決定により権利が変更・消滅するときの補償と、通常の契約譲渡の代金を分けて読みます。

### 例題4：権利消滅後の金銭を、誰に支払うか

採石法12条の決定で、第三者己の土地に関する権利が消滅することとなり、己へ支払う補償金が120万円と確定しました。その権利には抵当権が存し、抵当権者は直接払いを承諾していません。25条1項により、補償金支払義務者は120万円を供託します。抵当権者は同条2項により供託金へ権利を行使でき、己へ全額を先に渡す処理はできません。

別に、庚の登録済みダム使用権が、特定多目的ダム法24条により全部取り消されました。登録抵当があり、同法28条1項に従う還付金は360万円と計算済みです。抵当権者が直接払いを承諾していないので、28条2項により国は還付金360万円を供託します。同条3項の権利行使へつなげます。採石の補償とダムの負担金等の還付では、支払義務者・発生原因・根拠条項が違います。

取消し前に、庚がダム使用権の一部を分割したい場合は、22条の大臣許可に加え、23条の登録抵当権者の同意を得て許可を申請します。大臣の許可を受ける予定だから担保同意は不要、と進めません。一般承継を除く移転にも22条の許可制限があり、法人分割の例外は設定目的の事業全部の承継という条件まで読みます。

24条は、流水占用の許可・登録を取り消し、誰にも従来どおりの占用を認められない場合の対応です。25条は、他の者へ新たに占用を認めるための譲渡命令等を定めます。ダム使用権の取消し全てに採掘権の30日競売を当てはめる規定はありません。取消しの根拠と、還付金・供託のルートを確定してください。

## 国税との比較へ戻す前に、原資を確定する

有効な抵当がある通常の国税徴収の場面では、徴収法16条の設定時点、法定納期限等、担保債権の範囲を前の講の方法で比較します。その前に、財産が納税者に属するか、担保目的となり得るか、必要な公示・認可があるかを確定します。国税の納期限より古い契約書だけでは、効力要件を満たした証明にならない場合があります。

取消し等の後は、元の権利そのもの、存続みなしのある特別競売、補償金・還付金、供託金を区分します。鉱業法57条と漁業法95条の残金国庫帰属を、通常の滞納配当の残金交付と置き換えないでください。差押えの送達・登記登録嘱託はregistered-assets、公売に伴う事業権承継や権利消滅・配当の詳細はrights-distribution、裁判所競売との競合・交付要求等はpreservationで扱う具体的な後続課題です。
