## 決算整理と帳簿の締切を分けて考える

決算では、当期に属する収益・費用を確定し、期末の資産・負債・純資産を整えます。その後、収益と費用を締め切って利益又は損失を確定し、次期へ引き継ぐ残高を整理します。この順序を逆にすると、未払給与などの整理事項を反映しない利益を振り替えてしまいます。

この講では、決算整理後の試算表から、損益勘定、利益剰余金への振替、残高勘定、翌期の開始までを追います。前提は、仕訳・転記・試算表の貸借を理解していることです。経過勘定や減価償却の細かな算定は後続講で学び、ここでは整理すべき金額と処理方法を与えます。税金、配当、増資などは別に指定した場合を除き考慮しません。

## 利益を集計する勘定と残高を集める勘定

収益・費用は、当期の経営成績を計算する勘定です。締切時には、それぞれを損益勘定へ振り替えます。収益を集めた額と費用を集めた額の差が、当期の利益又は損失です。損益勘定はこの振替計算のために用いる勘定で、現金のような保有資産ではありません。

資産・負債・純資産の勘定残高は翌期へ引き継ぎます。この講の中心は、残高勘定を使って各勘定を締め切る方式です。一般に大陸式と呼ばれる方式で、残高勘定の借方に資産等の借方残高、貸方に負債・純資産等の貸方残高を集めます。元帳を締め切る仕訳なので、集められる勘定側は残高と反対の側に記入します。

別の方式では、各勘定で次期繰越を記入して締め切り、翌期に前期繰越として開始します。一般に英米式と呼ばれる方式です。問題で残高勘定を使うのか、各元帳に次期繰越を記入するのかを確認してください。同じ資産負債を引き継ぐ処理でも、帳簿上の記入形式は異なります。この講の残高勘定の仕訳と、次期繰越の記入を一律に二重実行しません。

## 例題1：整理前試算表から損益・残高勘定まで

株式会社の決算整理前残高は次のとおりです。資本金とは別に、過年度からの繰越利益剰余金120,000円があります。借方合計・貸方合計は各2,160,000円です。

| 借方残高 | 金額 | 貸方残高 | 金額 |
| --- | ---: | --- | ---: |
| 現金 | 500,000 | 買掛金 | 140,000 |
| 売掛金 | 240,000 | 借入金 | 300,000 |
| 備品 | 600,000 | 資本金 | 700,000 |
| 給料 | 600,000 | 繰越利益剰余金 | 120,000 |
| 地代家賃 | 220,000 | 売上 | 900,000 |

決算で、当期給与の未払30,000円、地代家賃に含まれる翌期分40,000円、備品の減価償却60,000円を整理します。給与未払は未払費用、翌期家賃は前払費用、償却は減価償却累計額を使うものと指定します。

| 整理事項 | 借方 | 貸方 |
| --- | --- | --- |
| 当期給与の未払 | 給料30,000 | 未払費用30,000 |
| 翌期分家賃の除去 | 前払費用40,000 | 地代家賃40,000 |
| 備品の減価償却 | 減価償却費60,000 | 減価償却累計額60,000 |

整理後の費用は給料630,000円、地代家賃180,000円、減価償却費60,000円です。前払費用40,000円は翌期に費用となる資産なので、当期費用から除きます。未払給与は現金を支払っていなくても当期の費用へ含めます。整理後試算表は借方・貸方とも2,250,000円となります。

### 収益と費用を損益勘定へ振り替える

売上は900,000円の貸方残高です。これを0にするため売上の借方へ900,000円を記入し、相手を損益の貸方とします。仕訳は、売上900,000円／損益900,000円です。売上の取消しや顧客への返金が起きたのではなく、当期の収益を集計する締切の振替です。

費用は借方残高なので、反対の貸方へ記入して0にします。借方・損益870,000円／貸方・給料630,000円、地代家賃180,000円、減価償却費60,000円と振り替えます。過去の給与支払自体は記録に残り、費用勘定の貸方記入は当期の費用集計を示します。

損益勘定の貸方は収益900,000円、借方は費用870,000円で、貸方に30,000円が残ります。これは利益です。借方・損益30,000円／貸方・繰越利益剰余金30,000円として、損益勘定も0にします。繰越利益剰余金は120,000＋30,000＝150,000円となります。利益を借入金や売上へ振り替えることはしません。

| 損益勘定の借方 | 金額 | 損益勘定の貸方 | 金額 |
| --- | ---: | --- | ---: |
| 給料 | 630,000 | 売上 | 900,000 |
| 地代家賃 | 180,000 |  |  |
| 減価償却費 | 60,000 |  |  |
| 繰越利益剰余金への利益振替 | 30,000 |  |  |
| 合計 | 900,000 | 合計 | 900,000 |

### 残る各勘定を残高勘定へ集める

借方残高は、現金500,000円、売掛金240,000円、備品600,000円、前払費用40,000円です。借方・残高1,380,000円／貸方・各資産1,380,000円として、各資産勘定を締め切ります。期末現金500,000円を残高勘定へ集める記録で、現金の実際有高は500,000円のままです。

貸方残高は、買掛金140,000円、借入金300,000円、未払費用30,000円、資本金700,000円、繰越利益剰余金150,000円、減価償却累計額60,000円です。借方・各勘定1,380,000円／貸方・残高1,380,000円として集めます。残高勘定の左右は各1,380,000円で一致します。

減価償却累計額60,000円は貸方残高ですが、借入金などの負債とは異なり、備品の金額から控除する勘定です。残高勘定へ集める側と、貸借対照表での区分を混同しないでください。この例の備品帳簿価額は600,000−60,000＝540,000円となります。

決算書での資産合計は500,000＋240,000＋540,000＋40,000＝1,320,000円。負債は470,000円、純資産は850,000円で、合計1,320,000円です。残高勘定の合計1,380,000円と異なるのは、累計額を資産から控除する前の帳簿残高を集めたためです。累計額のある表を見たら、総額表示か控除後かを確かめて検算します。

## 例題2：損失が出るときの振替方向

別の会社で、売上180,000円、受取利息10,000円、給料140,000円、地代家賃90,000円、減価償却費20,000円が、整理後の残高として残っています。繰越利益剰余金の期首貸方残高は30,000円で、配当その他の変動はありません。

収益合計190,000円を損益勘定の貸方へ、費用合計250,000円を借方へ集めると、損益勘定は借方に60,000円残ります。借方が大きいので損失です。損益勘定を0にする仕訳は、借方・繰越利益剰余金60,000円／貸方・損益60,000円です。

利益の場合の仕訳をそのまま使うと、損失なのに繰越利益剰余金を増やしてしまいます。まず損益勘定の残高の側を確認し、それを消す側へ振り替えます。振替後の繰越利益剰余金は、貸方30,000円に対して借方60,000円なので、借方残高30,000円となります。

この借方残高は、現金などの資産が新たに生じた意味ではありません。利益剰余金が負の額になった状態です。残高勘定を作る際にも、勘定ごとに実際の残高が借方・貸方のどちらかを確認し、通常は貸方だからという理由で無理に貸方へ置かないようにします。決算書では純資産の内訳として負の利益剰余金を示すことになります。

## 翌期の開始では、同じ残高を二重に引き継がない

残高勘定を使う方式で翌期を開始するなら、借方・各資産／貸方・残高と、借方・残高／貸方・各負債・純資産等を記録して、各勘定へ期首残高を戻します。例題1の現金なら借方500,000円、借入金なら貸方300,000円です。収益・費用は、前期分を締め切っているため、前期残高をそのまま当期の収益・費用として開始しません。

各元帳へ前期繰越を記入する方式では、その繰越が開始残高に当たります。これに重ねて同じ開始仕訳を追加しないようにします。試験資料の様式を見て、どこまで処理済みかを確かめてから未知額を計算してください。期首残高が引き継がれたのか、再振替まで実施したのかで、当期の費用勘定にある数字も変わります。

## 例題3：前期未払給与を再振替する場合

前期末に、前期費用の給与24,000円を、給料24,000円／未払費用24,000円で計上済みとします。翌期首に再振替する方法を採用し、1月末に前期分24,000円と当期分56,000円の合計80,000円を現金で支払います。

再振替は、借方・未払費用24,000円／貸方・給料24,000円です。1月末の支払を給料80,000円／現金80,000円とすれば、当期の給料は80,000−24,000＝56,000円となります。未払費用は期首で消えているので、支払時に同じ24,000円をもう一度消しません。

再振替しない方法なら、支払時に借方・未払費用24,000円と給料56,000円／貸方・現金80,000円と記録します。どちらの方法でも、当期給与は56,000円、支払後の未払費用は0円、現金支出は80,000円です。再振替は記帳手順の選択で、どちらも給与を同じ帰属期間へ計上します。

期首の給料貸方24,000円は、会社が新しく収益を得たという意味ではありません。支払時に全額を費用処理する手順と合わせ、当期に負担すべき費用だけを残すための記録です。期首直後の費用勘定だけを切り取って利益を判断せず、指定された支払処理と期末整理まで追います。

再振替はすべての負債へ機械的に行う処理ではありません。借入元本や買掛金を、給与と同じように収益・費用へ戻すことはしません。どの前期末整理を当期首に戻す指定か、その後の通常記帳をどう行うかを確認します。前払・前受・未収についても、対象契約と記帳方法を後続の経過勘定講で検討します。

## 例題4：残高勘定の未知額を総額と純額で検算する

残高勘定の借方には、現金の未知額、売掛金180,000円、備品500,000円、前払費用20,000円があります。貸方には借入金260,000円、買掛金90,000円、資本金400,000円、繰越利益剰余金70,000円、減価償却累計額40,000円があります。すべて締切後の額で、他の勘定はありません。

貸方合計＝260,000＋90,000＋400,000＋70,000＋40,000＝860,000円

現金＝860,000−180,000−500,000−20,000＝160,000円

純額の貸借対照表で確かめると、資産は160,000＋180,000＋500,000＋20,000−40,000＝820,000円。負債350,000円と純資産470,000円の合計も820,000円です。累計額を貸方合計から外したまま資産の備品を総額500,000円で使うと、現金を40,000円少なく推定してしまいます。

さらに期首の繰越利益剰余金が50,000円で、増資・配当・純資産への直接計上・過年度修正等がないと指定されたなら、当期利益は70,000−50,000＝20,000円と分かります。この追加条件なしに、締切後の利益剰余金70,000円をそのまま当期利益とはできません。残高が累積額か当期発生額かを区別してください。

## 締切の各段階を別々に検算する

例題1で整理前の数字から計算すると、利益は900,000−600,000−220,000＝80,000円です。未払給与の計上で30,000円減り、翌期家賃の除去で40,000円増え、償却費で60,000円減るため、整理後は30,000円となります。純額の増減は−50,000円です。整理前利益を先に振り替えると繰越利益剰余金は200,000円となり、正しい150,000円を50,000円上回ります。繰越利益剰余金の金額に加え、利益を変えた整理事項の金額も照合します。

決算整理後の試算表では、整理仕訳が収益費用と資産負債へ反映されたかを確認します。損益勘定では、収益・費用を漏れなく集めたか、利益損失の向きが合うかを確認します。その振替後に、繰越利益剰余金の期首から期末への増減を照合し、最後に残高勘定の貸借を合わせます。

当期損益の求め方と、締切のための勘定記入を混同すると、収益費用の振替を新しい営業取引と読んだり、次期繰越を支出と読んだりします。仕訳の摘要に決算振替・開始・再振替などの段階を残し、金額が動いている理由を確認してください。

練習では、同じ資料から利益、利益剰余金、残高勘定の合計、決算書の純額を別々に求めます。それぞれが異なる額になっても、対象範囲を説明できれば誤りとは限りません。未知額を逆算する問題では、前期残高、当期損益、資本取引や評価差額の有無を確かめ、利用できる条件だけで解答します。
