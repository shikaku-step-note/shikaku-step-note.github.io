# 現金・債権の用語を事例で使い分ける26問

草稿。26問52点の用語適用問題です。独立審査はpendingで、定義一覧の再掲を問題数に含めません。

## 1問

金庫の自社振出小切手を見た係員が「他人振出小切手と同じ通貨代用証券なので現金実際有高へ足す」と説明した。適切な訂正を選んでください。

1. 会社の金庫にある証書はすべて現金である
2. 自社振出小切手は他人から受け取った通貨代用証券と区分し、金庫での保管だけでは現金有高へ加えない
3. 小切手は振出人を問わずすべて売掛金である
4. 自社小切手は必ず貸倒引当金を必要とする

解答：2

2が適切。保管場所ではなく権利の性質を読む。1は他の資産・証憑まで現金化し、3は通常の他人振出小切手を排除し、4は支払指図を貸倒対象債権と取り違える。未渡の支払記帳の訂正は、実際有高の算入とは別に行う。

## 2問

現金不足を仮処理した時点で、担当者が「現金過不足という費用が確定した」と報告した。現金過不足と最終の雑損・雑益の役割を区分し、原因が判明した後の扱いを説明してください。

解答：現金過不足は原因調査中の差を整理する仮勘定であり、その名称だけで最終費用が確定しない。原因が判明すれば対応する費用・債権等へ振り替え、決算まで不明の残額を貸借に応じて雑損又は雑益へ振り替える。

配点：原因調査中の仮勘定という位置付け（1点）／判明分と決算時不明残額の異なる振替先（1点）

## 3問

旅費の内容が確定しないまま従業員へ前渡しし、会社は仮払金を記録した。後日の精算報告が届いた時点で確かめる事項として適切なのはどれですか。

1. 返金は必ず現金過剰益にする
2. 費用の確定は会社の現金を必ず追加で減らす
3. 仮払金を全額そのまま当期旅費にすることだけ
4. 支出内容・確定費用・返金又は不足払を照合し、仮払金の残高を精算する

解答：4

4が適切。仮払金は未確定段階の支払を整理するため、実額と科目・差額を照合する。3は他科目や返金を精算に含めず、1は判明した返金を不明差額とし、2は前渡し済みの支出を二重に現金減額する。

## 4問

購入時に通信費として記帳した郵券が期末に未使用で残った。郵券の貯蔵品への振替は、現金実査で見つかった「現金の不足」を埋める処理なのか。貯蔵品と通信費の役割、購入時の現金処理との関係を説明してください。

解答：未使用郵券は将来使用する資産として貯蔵品へ移し、使用した部分と当期通信費を区分する。購入時の現金支出が正しく記帳されているなら、その資産・費用間の振替で現金を動かさない。郵券自体を現金へ含め不足を埋める処理でもない。

配点：未使用資産と使用済み費用を区分（1点）／購入記帳済みという条件から現金修正と区分（1点）

## 5問

銀行勘定調整表を作る目的について、最も適切な説明を選んでください。

1. 帳簿側と銀行側の差異原因を分け、双方の正しい残高と会社に必要な仕訳を確認するため
2. すべての差異について会社の現金過不足を計上するため
3. 会社と銀行の両方で同じ修正仕訳を作るため
4. 銀行証明額を無条件に会社の残高へ転記するため

解答：1

1が適切。銀行側の時差・誤処理にも調整がある。4は銀行誤処理等を確認せず、2は預金の照合差を現金実査の仮勘定へ一律に入れ、3は銀行側の時差まで会社が重複記帳する。

## 6問

支払小切手が銀行で決済されていないことだけが分かっている。「未取付小切手」と「未渡小切手」のどちらかを決めるために必要な追加事実と、その事実が会社の修正仕訳に及ぼす違いを説明してください。

解答：支払先へ交付済みかを確認する。交付済みで適切に支払記帳してある未取付なら、会社側の支払仕訳を戻さず銀行側の時差として扱う。未交付なのに支払記帳した未渡なら、その記帳を戻して預金と債務を復活させる。銀行未決済だけでは二つを区別できない。

配点：交付済みかという追加事実（1点）／正しい交付済記帳と未交付先行記帳の訂正差（1点）

## 7問

銀行が別口座の支払を当社口座へ誤って引き落とした。会社はその支払をしておらず、会社帳簿は正しい。担当者が「未通知の支払なので費用を計上する」と提案した。適切な対応を選んでください。

1. 銀行側の残高も会社側の残高も同額ずつ減らす
2. 会社の未通知取引として費用を計上する
3. 会社の正しい帳簿には仕訳せず、銀行側の誤引落を照合上戻して訂正を求める
4. 当座借越がなければ入金益にする

解答：3

3が適切。実際の会社取引の未通知と、銀行がした他社取引の誤処理は原因が違う。2は存在しない費用、4は存在しない利益、1は誤りを双方へ広げる処理になる。

## 8問

帳簿で当座預金が貸方残高になったとき、係員は「預金という勘定名だから、そのまま貸借対照表の資産をマイナス表示すればよい」と述べた。照合に用いる負の残高、当座借越の振替、財務諸表の表示科目を区分してください。

解答：照合では貸越を負の預金残高として扱うと双方を比較できる。決算で当座借越へ振り替えたものは、適用する表示規則に従って短期借入金等の負債へ表示する。帳簿の仮の計算上の符号や勘定名だけで、資産のマイナス表示を決めない。

配点：負の残高による照合と負債への振替の区分（1点）／帳簿勘定名と財務諸表表示科目の区分（1点）

## 9問

製造会社が商品の販売ではなく、不要となった備品の売却代金を手形で受け取った。営業上の受取手形との区分理由として適切なものを選んでください。

1. 手形である以上、取引原因による区分はしない
2. 備品売却による営業外債権の性質を踏まえ、営業外受取手形として区分する
3. 銀行を通じて決済するので貸付金とする
4. 非営業取引なので手形の有効性がなくなる

解答：2

2が適切。手形という形式だけでなく発生原因を読む。1は営業・営業外の表示区分を無視し、3は備品売却を貸付へ変え、4は表示区分と法的有効性を混同する。

## 10問

割引手形の額面が900,000円、新たな保証債務の時価が4,000円と示された。保証債務として900,000円をそのまま負債計上する説明と、保証債務を一切認識しない説明の問題を述べてください。両金額の意味も区分してください。

解答：額面は主債務の金額であり、割引に伴い新たに生じる保証債務の初期認識額は本問で与えられた時価4,000円である。額面をそのまま負債額にする説明は金額の意味を混同し、無認識の説明は譲渡に伴う新たな義務を認識していない。注記の対象額と認識負債額も同一とは限らない。

配点：額面と保証の時価認識額の区分（1点）／過大計上と無認識の両方の問題（1点）

## 11問

不渡り後、適法な遡求により前者への請求権を取得した。「不渡手形と記録するなら全額が回収できるはずだ」という説明の評価を選んでください。

1. 誤り。請求権の存在・範囲と、相手の返済能力等による回収可能性は別に検討する
2. 正しい。担保がなくても全額が直ちに現金となる
3. 誤り。不渡りになるとすべての遡求権が自動消滅する
4. 正しい。勘定科目が回収可能額を保証する

解答：1

1が適切。権利取得の認識と貸倒見積りは異なる判断である。4と2は権利を現金や回収保証と同視し、3は所与の適法な遡求を否定している。

## 12問

手形の更改で満期だけを延ばし、延長期間の利息は別に前受けした。担当者は新旧の手形を両方資産へ残し、前受利息も元本に足した。更改の元本管理と利息の期間配分から訂正してください。

解答：旧手形から新手形への入替えで同じ元本を追い、新旧を二重の債権にしない。利息を別に前受けした設定では元本へ加算せず、経過した期間分を受取利息、未経過分を前受利息として区分する。

配点：更改による同一元本の追跡と新旧の二重計上防止（1点）／前受利息を元本と区分し期間配分（1点）

## 13問

売掛債権について電子記録債権の発生記録が有効に行われたが、入金はまだない。記録の意味として適切なものを選んでください。

1. 売上が同額だけもう一度生じた
2. 現金回収が完了した
3. 債権を二つ重ねて保有することになった
4. 債権の法的・記録上の形が変わる取引であり、発生記録と現金決済を区分する

解答：4

4が適切。発生記録時の振替と、その後の決済による預金の増加は別の段階である。2は決済との混同、3は原債権との二重計上、1は同じ販売の二重収益となる。

## 14問

金融資産譲渡後も譲渡人が保証を付ける契約である。「保証があるので消滅は絶対に認められない」とする説明を、消滅要件と新たな義務の認識に分けて評価してください。個別の三要件を満たすかは未検討です。

解答：保証の存在だけで消滅の可否は確定しない。法的保全、譲受人による権利の享受、実質的な買戻し権利義務等の支配移転の条件を検討する。消滅が認められる場合でも、譲渡に伴い新たに生じる保証債務は別に認識する。

配点：保証の存在だけで消滅の可否を断定しない（1点）／支配移転の条件と保証債務の別認識を区分（1点）

## 15問

債権譲渡で、①異種の有価証券を新たな対価として受け取る場合と、②元の債権に係る回収サービス権を残存部分として留保する場合がある。両方とも適切な認識条件は満たす。測定の区分として適切な説明を選んでください。

1. ①は常に損失、②は常に利益である
2. 両方とも必ず現金額だけで処理する
3. ①は新規資産の時価、②は譲渡部分と残存部分の時価比率による原価配分を検討する
4. 両方とも旧債権の元本を同額だけ増やす

解答：3

3が適切。新たな異種資産の受領と元の資産の残存部分は測定の位置付けが違う。2は非現金の権利を認識せず、4は原債権を増やす根拠がなく、1は対価と原価を計算せず損益の方向を決めている。

## 16問

一部消滅時の「時価比率による原価配分」を、残った資産を時価評価することと同じだと説明した。時価が使われる目的と、元の帳簿価額の扱いを区分してください。

解答：この原価配分では、譲渡部分と残存部分の相対的な時価を比率に使い、元の帳簿価額を二つへ分ける。残存部分へ配分された原価とその時価は一致するとは限らない。この処理だけで元の帳簿価額全体を時価へ評価替えしない。

配点：時価の用途は相対比率であること（1点）／元の原価総額を維持した配分と再評価の区分（1点）

## 17問

債務者は経営破綻しているが、担保の処分により元本の一部を回収できる。「担保があるので一般債権に戻す」とする説明の評価を選んでください。

1. 誤り。債務者の状態による債権区分と、担保による回収可能額の測定を区分する
2. 正しい。債務者の状態は分類に関係しない
3. 誤り。破綻した債務者の担保は常に無価値である
4. 正しい。担保が1円でもあれば一般債権である

解答：1

1が適切。担保は回収見込みを変えるが、経営破綻という債務者の状態を消さない。4と2は分類条件を無視し、3は与えられた担保回収を無根拠にゼロにする。

## 18問

保証書には上限700,000円とあるが、保証人の履行能力等から実際の回収見込みは300,000円と判定された。必要引当金計算で両者を区別する理由と、採用する回収見込額を述べてください。

解答：保証の契約上限は法的に請求できる最大額であり、その全額が回収できることを意味しない。履行能力等を反映して見積もった300,000円を回収見込額に用いる。同じ回収財産を担保回収と重ねて二度控除しない。

配点：請求上限と回収見込みの違い（1点）／300,000円を採用する理由（1点）

## 19問

通常貸付金の貸倒DCFで、当初約定利子率を使う条件が満たされている。現在の市場金利だけが上がったため、担当者が割引率を現在の市場率へ変更した。最も適切な説明を選んでください。

1. 必ず適切。貸倒DCFは常に現在市場率を使う
2. 適切とはいえない。指定条件の当初約定利子率と現在市場率は別であり、取得債権の当初実効利子率等の条件も区分する
3. 利率はどれを使っても必要引当金が同じになる
4. 将来回収時期をすべてゼロと置けば率の問題はなくなる

解答：2

2が適切。本問は当初約定率を用いる条件を確定している。1は別の測定の率を一律に持ち込み、3は割引の効果を無視し、4は回収時点を改変する。

## 20問

期末必要引当金が200,000円と分かっただけで、担当者が「当期費用も200,000円」とした。必要残高と当期繰入額の違い、追加で確かめる残高資料を説明してください。

解答：必要引当金は期末に持つべき残高であり、当期繰入額は整理前の引当残高との差額である。期首残高だけでなく当期貸倒れによる取崩し等を反映した整理前残高を確認し、必要額との差で繰入れ又は戻入れを求める。

配点：期末ストックと当期増減の区分（1点）／取崩し等反映後の整理前残高が必要と示す（1点）

## 21問

ある開始時点の一般債権集団について、その後の貸倒れを追跡して実績率を算定する。分子・分母の組合せとして適切なのはどれですか。

1. その年の全貸倒額／別の年の全売上高
2. 開始集団と無関係な貸倒額／期末現金
3. その年の全貸倒額／都合のよい最小の債権残高
4. 開始集団から生じた貸倒額／その開始集団の債権額

解答：4

4が適切。同じ集団を追跡する関係を保つ。1は別の集団・時点・売上を混在させ、2は貸倒対象と現金を対応させ、3は率を恣意的に変える。期間別の平均方法と現在の信用リスクの検討も別に必要である。

## 22問

期末評価日に、債務者から「年度内に払う予定」とだけ連絡が来た。貸倒DCFで各回収額を割り引くために不足している時点の情報と、元本・利息の区分を確認する理由を説明してください。

解答：評価日から各回収日までの期間を確定する必要があり、どの年度かだけでは期末から何期間後か決まらない。回収額が元本か利息かを分ければ、受領後の元本帳簿残高や時間経過収益との対応を追える。対象となる元利金を時点別に整理して計算する。

配点：評価日から各回収日までの期間が必要（1点）／元利区分と残る帳簿・収益の対応を説明（1点）

## 23問

回収見込み不変の貸倒DCFで、期首純額に当初率を乗じた時間経過収益を計上したが、当期の現金受領はゼロだった。適切な評価を選んでください。

1. 時間経過収益は必ず新規の貸付実行である
2. 現金がゼロならDCFの純額は必ず不変である
3. 時間経過収益は直ちに現金回収を意味しない。回収日が近づく割引の戻りと現金受領を区分する
4. 収益計上額と同じだけ元本を必ず消す

解答：3

3が適切。回収日までの期間が短くなって純額が増える効果と現金の受領は別である。2は期間変化を反映せず、4は受領していない元本を消し、1は割引の戻りを資金支出と取り違える。

## 24問

回収額を減らす見積変更が期末に分かった。担当者は期首と期末の引当金残高の差だけを「見積変更損失」と呼んだ。時間経過を先に反映する手順と、この説明で混ざる損益を示してください。

解答：まず旧回収見積りのまま時間経過収益と現金回収を反映し、変更直前の純額を求める。その純額と新しい回収見積りを当初の率で割り引いた純額との差が変更の損益となる。期首から期末の引当差額だけでは、時間経過による減額と見積変更による増額が相殺されている場合がある。

配点：旧見積りで時間経過・回収を先に反映（1点）／変更前後の純額差と期首期末差の異なる意味（1点）

## 25問

回収予測不変の時間経過により貸倒引当金が減る額を、受取利息としても貸倒引当金戻入益としても同時に全額収益計上した。適切な説明を選んでください。

1. 二つの科目なので同時に全額計上してよい
2. 同一の時間経過効果を二度収益にしている。原則の利息配分と許容される戻入処理は同じ効果の別の処理として区分する
3. 引当金が減ると必ず同額の現金が増える
4. どちらの科目でも収益計上は一切許されない

解答：2

2が適切。同一効果の二重収益となる。移管指針115項の原則と許容処理の条件を読む。1は二重計上を容認し、3は引当減少と現金を混同し、4は時間経過の処理自体を否定する。

## 26問

債務者の条件変更で将来の契約利息は免除され、過去の回収不能な未収利息も修正済みである。その後、元本回収の見込みが不変のままDCFの時間経過収益が生じた。この収益は、免除した契約利息を再び債務者へ請求することなのか。法的な請求額と割引計算の時間経過を区分してください。

解答：時間経過収益は、回収見込みの元本までの期間が短くなることによる割引の戻りである。免除した契約利息を復活させたり、回収不能な過去利息を再計上したりする法的請求の追加ではない。契約上の回収額を変えずに、会計上の純額と収益の推移を計算する。

配点：元本回収までの期間短縮による割引の戻り（1点）／免除済み又は回収不能利息の請求・計上復活と区分（1点）
