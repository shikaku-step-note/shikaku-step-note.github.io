## 金庫の中身を数え、現金として計上する額を決める

現金実査は、紙幣や硬貨を数えて帳簿と比較する作業です。簿記の問題では、金庫に小切手、切手、領収書、社員の私物等が混在していることもあります。最初に、会社の現金に当たる物を選びます。その合計と現金勘定の残高を比べ、差の原因を調べて仕訳に反映します。金庫内の全ての額面を足すだけでは、会社の現金残高は求められません。

このレッスンでは、日本円の現金を扱います。外貨の換算差額や、現金同等物を含むキャッシュ・フロー計算書の範囲は別の講で学びます。現金勘定、当座預金勘定、小口現金勘定のどれを問われているかも確認してください。預金も含む「現金及び預金」と、金庫内の「現金」は集計範囲が異なります。

現金の過不足があっても、直ちに全額を損失にするとは限りません。未記帳の旅費や売掛金回収が見つかれば、その取引を正しい勘定へ記録します。資料が明らかにしている原因を処理し、最後に残った原因不明額を、指定された方法で整理します。

## 実査物は、会社への帰属と換金できる性質から分ける

ここでは、通常の他人振出小切手や、支払期日の到来した利札等を、直ちに換金できる通貨代用証券として現金に含めます。支払制限、不渡り、先日付等の別の条件がある場合は、その条件を先に読みます。書類の名前だけで、どの状態でも同じ勘定になると判断しないようにします。

| 金庫内の物 | この講での条件 | 現金実査での扱い |
| --- | --- | --- |
| 紙幣・硬貨 | 会社が所有する日本円 | 現金に含める |
| 他人振出小切手 | 会社が受領し、直ちに換金できる通常のもの | 現金に含める |
| 利札等 | 支払期日が到来し、直ちに換金できるもの | 現金に含める |
| 未使用の郵便切手・収入印紙 | 使用するために保有 | 現金には含めず、貯蔵品等の処理を確認 |
| 支払済みの領収書 | 経費の支払を証する書類 | 現金には含めず、未記帳取引を調べる資料とする |
| 社員の私金 | 会社が預かっただけで、会社の現金とは区別保管 | 会社所有の実査額には含めない |
| 自己振出しの未渡小切手 | 通常の買掛金支払用に記帳したが未交付 | 現金には含めず、当座預金と買掛金の修正を検討 |

例えば、切手を1,000円分持っていても、通常の買物代金1,000円をその切手で直ちに支払えるという意味ではありません。将来の郵便サービスに使う物として区分します。現金から切手を買った支払が未記帳なら、現金を減らす仕訳が必要です。すでに通信費へ計上した未使用分を貯蔵品へ振り替えるなら、その振替では現金は動きません。同じ切手でも、何が未処理なのかを確認します。

社員の私金についても、会社が現金を預かり、その分の返済義務を帳簿に計上すべき取引が生じている資料と、単に社員の封筒を別に保管している資料では前提が違います。本講の例題では後者を指定します。誰の物か不明な現金を、推測で会社の売上へ加えることは避けてください。

## 例題1：実際有高と、原因調査前の不足を求める

決算日の現金勘定は189,800円の借方残高です。会社の金庫を実査した結果は次のとおりでした。現金過不足勘定は使っておらず、小口現金はこの金庫に含めません。

- 会社の紙幣・硬貨128,600円。
- 会社が受領した、直ちに換金できる他人振出小切手42,000円。
- 支払期日が到来し、直ちに換金できる会社所有の利札5,400円。
- 未使用の郵便切手6,200円。
- 別の封筒で預かっている社員の私金9,000円。
- 支払済みの旅費の領収書11,800円。

現金の実際有高は128,600＋42,000＋5,400＝176,000円です。切手、私金、領収書は、この条件での会社の現金には含めません。したがって、帳簿189,800円に対して実際176,000円なので、13,800円の不足です。

不足をいったん現金過不足勘定で処理する指定なら、次の仕訳になります。

借方・現金過不足13,800円／貸方・現金13,800円

これにより現金勘定は実際有高176,000円へ合います。ただし、現金過不足の借方残高は、まだ原因の分からない仮の整理額です。13,800円が最終的な損失と決まったわけではありません。また、領収書11,800円が見つかっただけでは、その支払が未記帳かまでは分かりません。帳簿にすでに旅費として記録してあれば、再計上すると費用を二重にします。証拠書類と記帳状況を照合してから次の処理へ進みます。

## 原因判明の仕訳は、現金を修正済みかで変わる

帳簿を実際に合わせる前なら、未記帳の現金支払は、費用等を借方、現金を貸方に記録します。すでに現金過不足を使って現金を実際へ合わせた後なら、原因の勘定と現金過不足を振り替えます。ここで再び現金を減らすと、同じ支払を二度反映してしまいます。

例えば、現金不足の仮処理後に、通信費3,000円の未記帳が原因と分かれば、借方・通信費3,000円／貸方・現金過不足3,000円です。現金の実際額は新たに変わっていません。変わったのは、不足をどの費用等へ帰属させるかという説明です。

現金過不足は、借方残高なら不足、貸方残高なら過剰を表します。ただし、原因が一部判明した後には残高の側が変わることもあります。最初に不足だったから最後も雑損失、と決めないでください。原因判明の仕訳を全て転記してから、残高を確認します。

## 例題2：不足から、原因不明の過剰へ変わる

帳簿94,000円に対し実際は88,200円でした。期中に、借方・現金過不足5,800円／貸方・現金5,800円を計上済みです。決算までに、次の原因が判明しました。他の原因は調査しても分かりませんでした。

1. 消耗品費7,600円を現金で支払ったが未記帳でした。
2. 売掛金1,000円を現金で回収したが未記帳でした。

第一の原因は、本来の費用計上で不足を説明するものです。現金はすでに実際へ合わせているので、消耗品費7,600円／現金過不足7,600円とします。現金過不足の残高は、借方5,800円から貸方1,800円へ変わります。

第二の原因は、未記帳の入金です。現金過不足1,000円／売掛金1,000円とします。これで現金過不足の貸方残高は800円です。決算で原因不明の残りを雑収入とする指定なら、現金過不足800円／雑収入800円と振り替えます。

元の帳簿から直接検算してみましょう。94,000−7,600＋1,000＝87,400円です。実際88,200円との差800円は、実際の方が多いので原因不明の過剰です。最初の不足5,800円をそのまま雑損失にすれば、分かった原因も残高の逆転も無視することになります。

一連の処理後、現金は88,200円、現金過不足は零です。費用7,600円、売掛金の減少1,000円、雑収入800円は、それぞれ別の意味を持ちます。金額を一つの「差額」にまとめず、現金勘定と仮勘定の両方を検算すると、貸借の向きも確かめられます。

## 例題3：仮払金の精算と返金を結び付ける

会社は社員へ出張のため30,000円を渡し、仮払金30,000円／現金30,000円と記帳しました。社員は決算日までに戻り、交通費12,600円、宿泊費9,800円、業務用消耗品1,600円の証憑と、残金6,000円を提出しました。費用は全て当期分で、まだ精算仕訳をしていません。返された6,000円は会社の金庫に含まれています。

使用額は12,600＋9,800＋1,600＝24,000円、返金と合わせると24,000＋6,000＝30,000円で、渡した額と一致します。交通費と宿泊費を旅費交通費へまとめる指定なら、精算仕訳は次のとおりです。

| 借方 | 金額 | 貸方 | 金額 |
| --- | ---: | --- | ---: |
| 旅費交通費 | 22,400円 | 仮払金 | 30,000円 |
| 消耗品費 | 1,600円 |  |  |
| 現金 | 6,000円 |  |  |

仮払金を渡した時点の30,000円を、精算時にもう一度現金から減らしません。今回現金が増えるのは返金6,000円です。領収書24,000円分を現金実際有高へ加える処理も誤りです。領収書は、すでに使った額の内容を説明する資料です。

金庫の現金が帳簿より6,000円多く、その全額がこの返金で説明できるなら、原因不明の雑収入ではありません。仮払金の精算を通じて処理します。まだ現金過不足で調整していなければ上の仕訳、すでに調整済みならその仮勘定との振替も含め、重複しないように整理します。

逆に証憑の合計が仮払額を超え、社員が会社のために立て替えたと明示される場合は、返金ではなく会社の追加支払義務を検討します。社員自身の私的支出が混じる場合も、会社の費用とする条件を確認してください。金庫に紙があることと、会社に費用が生じたことは別です。

## 例題4：小口現金は、報告と補給の時点を分ける

小口現金は、少額の支払に備えて担当者へ渡す資金です。ここでは定額資金前渡制度を用い、定額を50,000円とします。担当者が支払うたびに本社が仕訳するのではなく、支払報告を受けた時点で費用等を計上し、使った額を補給する方法を考えます。

12月中の支払は、通信費7,600円、旅費交通費12,800円、消耗品費5,400円でした。担当者の手元には24,200円が残っています。支払額25,800円と手元24,200円の合計は定額50,000円と一致します。12月31日に報告を受け、翌年1月に補給する場合、年末には次を計上します。

通信費7,600円・旅費交通費12,800円・消耗品費5,400円／小口現金25,800円

小口現金勘定の決算残高は24,200円です。翌年の補給時に、小口現金25,800円／当座預金25,800円とすると、担当者の手元も勘定残高も50,000円へ戻ります。定額制度でも、報告から補給までの間、勘定残高が常に定額のままとは限りません。

報告と補給を同じ日に行うなら、二つの仕訳の小口現金25,800円を相殺し、各費用25,800円／当座預金25,800円とまとめることもできます。しかし、年をまたいで補給する本例でその仕訳を年末に計上すると、まだ減っていない当座預金まで減らしてしまいます。取引日が違うものを、便宜的に一日にまとめないようにします。

決算日には、支払報告が未到着でも当期中の支払が判明していることがあります。その支払をいつ費用等へ反映すべきかは、書類が届いた日だけで決めず、当期の取引であることと資料の条件から判断します。小口現金の残金と証憑を合わせて検算することは、補給額と決算残高の両方を確かめる方法です。

## 郵券の振替と、現金過不足の整理を重ねない

未使用切手を資産へ振り替える仕訳と、現金残高を直す仕訳は分けます。例えば、期中に切手4,800円を現金で買い、全額を通信費へ正しく記帳済みで、決算日に未使用1,200円が残るとします。未使用分を貯蔵品へ振り替える指定なら、貯蔵品1,200円／通信費1,200円です。この時点で現金は変わりません。

もし購入自体が未記帳なら、まず購入時の支払を反映します。その上で、費用処理した未使用分を資産へ振り替えます。実査額と帳簿の差が切手の未記帳購入で生じているときに、購入仕訳と現金過不足の損失振替を両方残すと、同じ原因を二重に処理します。

解答前に、現金を実際へ合わせた仕訳があるか、切手の購入が記帳されているか、未使用分をどう扱う指定かを整理してください。費用処理と資産処理の選択が認められる実務上の重要性判断を、資料のないまま勝手に加えず、設問で与えられた条件に従います。

## 残高の橋渡しで検算する

現金については、整理前残高に未記帳入金を加え、未記帳支払を引き、誤記の差を修正します。その結果と実際有高との差が、原因不明額です。すでに現金過不足で現金を直していれば、現金ではなく仮勘定へ原因を振り替えた仕訳も追います。どちらの方法でも、最終的な現金残高と各取引の意味は一致するはずです。

小口現金では、定額と支払額と残金を照合し、報告日と補給日を分けます。仮払金では、渡した額と、認められる支出、返金又は追加精算額を照合します。これらの残高が一致しても、費用の種類や計上期間を誤る場合があるため、合計だけで確認を終えないでください。

理解度チェックでは、実査物の選別、仮勘定の向き、費用の未記帳、仮払精算、小口現金の年末処理を自分で判断します。次の銀行勘定調整表では、会社の記録と銀行の記録の時点差を調べます。金庫の実査と預金の照合で方法は異なりますが、記録済みか、誰の取引か、いつの取引かを分ける考え方は共通です。
