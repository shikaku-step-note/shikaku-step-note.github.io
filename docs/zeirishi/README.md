# 税理士コースの全面拡充

これは制作・検証用の記録です。学習者向けの完成教材ではありません。

第76回（2026年）の公式範囲と、同回公告の2026年4月3日現在施行法令を基準に、会計学2科目・税法9科目を扱います。全11科目の受験が必要という意味ではありません。次回以降の公告が公表されたら、基準日・経過措置・出題の注意事項を改めて確認します。

- `upgrade-plan.json`：11科目を省略しない計画の分母。目標・前提・資料・独立演習の要件・未解決事項・22回分の模試設計を含みます。計画の掲載は完成を意味しません。
- `accounting-audit.md`、`national-tax-audit.md`、`other-tax-audit.md`：既存教材と公式範囲を照合した監査。取得・適用時点の制約も残しています。
- `review-log.json`：実際の本文と対応する証拠を、人が確認する手順に相当する独立レビュー工程で記録します。AIによるレビューであり、税理士など資格保有者の校閲を意味しません。
- `coverage-ledger.json`：`node scripts/audit-zeirishi-upgrade.mjs` が生成する目標別の進捗。欠けている教材を分母から外しません。`--require-complete` では未完了が一つでもあれば失敗します。

本文のハッシュが変われば、その本文に対する過去のレビューは現在版の完成証拠に数えません。レッスンを増やしたことや、文字数・ビルド検査を満たしたことだけでは、目標別の説明・例題・独立演習・累積評価・根拠照合・日本語校閲が揃った扱いにしません。

旧54講は導入教材としてURL・安定ID・保存済み記録を維持します。新しい目標には `zr2-` で始まるIDを用い、旧教材の学習済み記録を移しません。新単元の数値IDは計画に保存し、単元を挿入するときも既存の数値を振り直しません。

公開用TXTは、実装・確認済みの教材から生成します。未完成の計画を完成教材の一覧として混ぜません。旧基礎模試は履歴を維持し、今回の本試験形式の模試とは別ID・別名称にします。独自の採点を公式得点や合否へ換算しません。

累積問題が複数講の技能を評価する場合は、主要な`lesson`と`objectives`を保持し、`targetObjectives`へ実際の追加講と1始まりの目標番号を記録できます。存在しない講・目標、主要講の矛盾した対応は検証で拒否します。復習先は全対象講を表示し、問題や配点を重複して数えません。単なる参考リンクを評価済みの技能へ読み替えないでください。

## 教材を追加・改訂するとき

本文は `src/content/lessons/<安定ID>.md`、目標・例題・講末問題・出典・単元演習の正本は `src/data/zeirishi-expanded.json` です。タイトル変更でIDを変えず、既存の設問ID・履歴も保持してください。大幅に作り直した評価では、その評価のversionを改め、過去の記録を新しい採点で読み替えません。用語の解説は各講のglossaryから単元ページへ自動集約されます。

追加した単元は同データのunitsへ登録します。科目・検索・進捗・サイトマップ・TXTは実在する登録内容から生成されます。新単元の数値numberは `upgrade-plan.json` のprogressUnitと一致させ、既存値を振り直しません。目的、説明、例題、独立練習、累積確認の実際の内容を照合し、出典の版・箇所・実確認日を記録した後にreview-logへ証拠を登録してください。ハッシュだけを書き替えて未実施の確認を済んだ扱いにしないでください。

`pnpm check`、`pnpm test:storage`、`pnpm audit:zeirishi-upgrade`、`pnpm build`、`pnpm verify`を実行し、新しい演習・保存・復元・明暗テーマ・狭い画面をブラウザでも確認します。TXTはビルド時に再生成されるため、手で別の学習順を書き込まず、登録データを修正してください。法令・基準が変わったときは適用基準日と経過措置を先に確認し、本文だけでなく例題、問題、解説、採点、対応表、出典を併せて点検します。
