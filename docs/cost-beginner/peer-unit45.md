## 実際に確認した対象

次の9レッスンの本文、例題・案内付き練習・自力練習と解答、到達目標、用語定義を読みました。対応する126問の完全な設問、正答、解説と、42問の4択の全選択肢も確認しました。

- `cb2-behavior`：変動費・固定費、総額と単位当たり、関連範囲、直接・間接との区別。
- `cb2-contribution`：貢献利益、変動販売費、役割別損益との照合、貢献利益率。
- `cb2-break-even`：数量・売上高の分岐点、整数制約、正の利益との区別、貢献利益が正でない場合。
- `cb2-target-profit`：目標数量・売上高、必要売価、費用上限、丸め、能力範囲。
- `cb2-safety-changes`：補足的な安全余裕指標、独立した改善案、率一定と金額一定の違い。
- `cb2-budget`：予算・実際売上高、達成率、期間・数量・金額の単位、比較の限界。
- `cb2-sales-variance`：数量差異・価格差異、橋渡し売上高、交差部分、別方式と符号。
- `cb2-variance-cases`：複数製品、相殺、構成変化、異なる単位、サービス・返品条件。
- `cb2-integration`：配賦から仕掛品・製品・売上原価・営業利益、別期間CVP、売上差異の全体照合。

「固定費は一定」という省略に対象期間と活動範囲が添えられているか、単純CVPと在庫が動く損益を混同していないか、売上差異を利益差や責任者の行動原因へ飛躍させていないかを重点的に読みました。外部の制度・法令や給与規則を追加する問題はありません。

## 数値の別計算

設問の条件から数式を再入力し、84問すべての数値入力キーを別計算しました。執筆担当の問題生成コードや正答説明の式は取り込みません。丸めは整数切上げと正の利益の最小数量を区別し、マイナス・ゼロもそのまま照合しています。すべて一致しました。

具体的には次を確認しました。

- 変動費の数量差と固定費の相殺、同じ費用モデルからの単価・固定費の逆算。
- 変動販売費を含む貢献利益と、固定製造費を含む売上総利益の違い、最終営業利益の一致。
- 分岐点222.666…個の最小非赤字223個、分岐点250個に対する正の利益最小251個。
- 目標利益の切上げ、単位変動費の上限、費用率固定と単位金額固定の価格逆算の違い。
- 独立改善案を混ぜない増分比較、値下げで売上が増えても利益が減る計算。
- 部門の達成率の単純平均を使わず、合計金額で割る計算。
- 売上差異の数量・価格の一組の方式、交差部分の重複・漏れ、返品の純数量への調整。

## 指摘した箇所と対応

| 箇所 | 実際の問題 | 修正内容・再確認 |
| --- | --- | --- |
| `cb2-contribution-q12` | 正答が「構成変更で全体率が変わる」と断定。売価・費用額が異なる二製品でも貢献利益率が同じなら全体率が変わらない場合がある。 | 「変わり得る」へ修正。構成変更後に製品別計算を確認するという正答の趣旨を維持。 |
| `cb2-contribution` 案内付き練習末尾 | 貢献利益について「何の支払いまで終えた残りか」とあり、原価・費用の控除と現金支払いを混同しかねない。 | 「どの費用を差し引いた後の金額か」へ修正。消費・費用と現金の時期を区別。 |
| `cb2-safety-changes-q14` | 自サイトが安全余裕を補足と表示しているかを問う設問で、目標0の余裕額・率の理解を直接評価していなかった。 | 実際売上800,000円、安全余裕率25％から損益分岐点600,000円を逆算する数値問題へ差替え。800,000×75％を独立再計算。修正後は84数値・42択一。 |
| `cb2-behavior-q02` | 数量×単位変動費の計算だが分類の目標0へ対応付けられていた。 | 総額・単位当たり計算の目標1へ修正。 |
| `cb2-target-profit-q09`・`q14` | 目標売上高・追加必要数量の計算で、整数制約や活動範囲を直接確認する設問ではなかった。 | 必要数量・売上高の目標0へ修正。目標2の切上げ・活動範囲はq03・q08・q13で引き続き直接評価。 |
| `cb2-budget-q11` | 3か月合計の差異計算で、数量×単価の目標0へ対応付けられていた。 | 同じ期間と単位の差額・達成率の目標1へ修正。 |
| `cb2-sales-variance-q14` | 行動上の原因の限界を問う内容と、異なる方式・符号を区別する目標2が直接には一致していなかった。 | 外部資料の「予算−実績＝−40,000円」を「実績−予算＝＋40,000円」へ読み替える択一問題へ変更。全選択肢と符号を再確認。 |
| `cb2-variance-cases-q14` | 価格差異の解釈一般で、サービス・返品条件を読む目標2との対応が弱かった。 | 修理サービスの作業内容変更・単価上昇という条件を追加し、提供内容と費用を追加確認する説明へ変更。設問の終わりも「この判断に対する説明として適切なのはどれですか」へ修正し、4つの説明選択肢と対応することを再確認。 |

レビュー側は原稿・問題バンクへ直接修正せず、統合担当へ具体的なID・理由・修正案を伝えました。上記の内容修正と対応目標は修正後データを再読しています。設問の条件を減らして答えを合わせたり、異なる目標を一律に循環割当したりする処理は行っていません。

## 日本語・教材としての所見

読み手が式を選ぶ理由、途中式、結果の意味、誤った方法が何を落とすかを本文で説明しています。公式の範囲にない安全余裕指標は補足と区別され、標準原価計算の費用差異へ無断拡張していません。サービスの数量定義や返品条件、在庫条件を繰り返す箇所は計算上必要な条件として確認しました。
