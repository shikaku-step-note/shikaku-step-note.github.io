# 原価計算初級：42技能の証拠対応の独立レビュー

確認日：2026年10月28日。執筆・証拠付けの担当と別のAI担当による対応確認。公式の区分を教学上42技能へ分解した表を対象とし、「42項目が公式の指定数」「外部専門家が全範囲を認証した」とは扱わない。

## 確認した資料と範囲

`src/data/cost-beginner-coverage.json` の全42行を確認し、公式PDFの3領域と `competency-plan.json` の技能分解へ戻って照合した。各行の本文・例題アンカー、独立した理解度チェック、単元復習の設問本文を読み、問題IDが存在するだけでなく、技能が実際に問われているかを確認した。

ユニット1〜2の8本文・96問と模試2回は `peer-unit12-mocks.md` の全文レビューを利用。ユニット3は同担当が執筆・検算したため、それ自体を独立した第三者レビューとは数えない。ここでは親担当の対応付けが、実際の本文・設問へ正しく向いているかを別に調べた。ユニット4〜5は対応する目標・例題・設問、および統合課の本文を読み、各技能の内容と照合した。両ユニットの全文数値監査は別担当の記録も必要となる。

実在確認では全42行について、対象レッスンのファイル、stableId、資格ID、通常公開のメタデータを確認。本文・例題アンカーは各参照先に1個ずつ存在し、独立問題IDと単元復習IDもすべて実在した。参照先問題のレッスンと0始まりの目標番号も有効だった。機械検査の記録は `work/cost-coverage-link-review.json`。この実在検査だけを教学上の完全性の証明にしない。

## 全42行の確認結果

| 行の範囲 | 確認した技能と証拠の関係 |
| --- | --- |
| CB-C01〜C05 | 対象・活動・資源、購入/消費/支払、単位換算、部門と責任、収益費用の対応。C05を修正後、意味の合う説明・例題・練習・単元復習へ接続 |
| CB-C06〜C10 | 材料/労務/経費、追跡可能性、二軸分類、製造と販売管理、利益の二段階。分類する問いと原価を集計する問いを区別している |
| CB-C11〜C15 | 材料元帳、製品別の消費単価、時間×賃率、経費の消費期間、直課と二重集計。C12・C14を修正後の実際の出題へ照合 |
| CB-C16〜C20 | 配賦基準と範囲、率、配賦額の検算、製品原価と単位原価、基礎仕訳。C19・C20に関連する既存証拠を補足 |
| CB-C21〜C28 | 仕掛品、未完成原価、製品数量、製品評価、売上原価、損益表、製品別・サービス別利益。C28には原価合計だけでなく利益を求める実際のレビューを追加 |
| CB-C29〜C36 | 費用の総額/単位額、数量×単価、変動/固定の集計、貢献利益、率、営業利益、分岐数量/売上。C29・C33の比較・分母の証拠を補足 |
| CB-C37〜C42 | 予算実績の範囲、価格・数量差異、合計照合、解釈、総合問題。C38の価格差異はr13、C39の数量差異はr04が実際に該当。C41・C42を拡張 |

統合課は、製品別の当月実績から在庫を反映する損益を求め、翌月の別計画で在庫一定のCVPを計算し、当月の売上予実差異へ戻る構造である。異なる前提を一つの利益額へ無理に一致させず、何を比較するかを教えている。この説明と、q07〜q09のCVP・在庫条件、q10〜q13の売上差異・利益との区別が対応していることを確認した。

C33・C38・C39の特に指定された対応は、問題内容と一致する。材料費の `worked-3` は二製品の消費量×単価を直課し、共通補助材料を分ける実例であるため、C12の例題として適切である。

## 判定の限界と配備前の工程

確認した範囲では、指摘した証拠の不一致は具体的な問題追加と対応修正で解消された。全42行の参照は実在し、技能の意味に合う教学・練習・単元復習の証拠をたどれる。これは索引と内容の対応に関する判定で、学習者の試験準備が必ず完了するという保証ではない。

全本文の日本語・計算の別担当レビュー、模試の解答監査、ブラウザでの操作、記録保存、表示、配備はそれぞれの実施記録に基づいて確認する必要がある。レビュー時点の `evidenceStatus` は `implemented-pending-final-release-checks` としてあり、リンク検査だけを理由に配備・教学の最終確認済みへ変更していない。外部専門家による監修、学習者による難易度と時間の校正は行っていない。


統合担当の最終確認：材料受入の案内文を「1袋8kgの材料が月初に2袋あり、当月に10袋を受け入れ、月末に3袋残っています。」へ修正済みです。残っていた表現上の指摘も解消しました。
