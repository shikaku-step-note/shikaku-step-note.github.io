# 原価計算初級・ユニット3の執筆・校正記録

作業日：2026年10月28日。対象は `cb2-wip`、`cb2-finished`、`cb2-pnl`、`cb2-product-profit`、`cb2-services` と `src/data/cost-beginner-unit3-questions.json`。

## 実施した作業

5本を新しい技能IDで執筆し、各3学習目標、3つの目標アンカー、3つの例題アンカーを設置した。例題は、説明と計算結果だけで終わらず、なぜその金額を足す・引く・割るか、結果が何を意味するか、別方向の検算、条件変更、典型的な誤りを含む。本文の計算練習には解答と理由を付けた。

| ID | 主な教学上の仕事 | 条件を明示した応用 |
| --- | --- | --- |
| cb2-wip | 月初・投入・完成・月末の原価保存を、製造途中に残す理由から説明 | 未完成の仕事を個別に追跡して評価、投入額の逆算、二か月の引継ぎ |
| cb2-finished | 完成と販売、数量と金額、原価と売価を分ける | 均一原価による在庫評価、数量・完成原価の逆算、仕掛品からの連続計算 |
| cb2-pnl | 製造・販売・管理の活動を分け、二段階の利益表へ置く | 在庫付き損益、利益率の分母、営業損失、売上と利益の比較 |
| cb2-product-profit | 二製品の材料・時間・配賦・在庫・利益を共通資料で接続 | 配賦基準のみ変える比較、直接販管費と共通費、配賦後赤字の解釈 |
| cb2-services | 顧客・作業・案件という対象と単位からサービス原価を組む | 二修理メニュー、一種類のサービス、未完了案件の指定条件、小売部門 |

本文のうち前付け・出典部分を除き、空白を除いた文字数はおよそ4,500〜4,700字。表、式、見出しを含む測定であり、厳密な自然文だけの文字数ではない。分量だけで技能の完成を判断しない。各レッスンの目標・例題・独立問題を実内容で確認した。

理解度チェックは各13問、合計65問。数値入力46問、4択19問である。すべて本文の例題と異なる新しい数値・条件の問題とした。逆算、二期間・二段階の保存関係、配賦基準、在庫と利益、サービスの条件判断を含む。同じ計算技能の反復を含むため、「65種類の異なる技能」「すべてが独立した出題設計」とは数えない。問題は1問ずつ表示されても解けるよう条件を再掲し、各問に0始まりの目標番号を付けた。

選択肢はIDを種とする並替えを行い、元の正解文を保持した。0・1・2・3の周期を答えの手掛かりにしない。解説には正解の理由に加え、原価と売価、対象と全体、完成と販売、直接費と共通費など、誤った操作を選ぶ理由の違いを示した。

## 範囲・正確性の確認

公式資料は同ディレクトリの `source-register.json` のS02・S05を中心に確認。月末仕掛品、月末製品、製品・サービス別の期間損益は公式範囲である。仕掛品は評価額の指定または追跡可能な未完成の仕事を使い、完成品換算量・工程別総合原価計算・標準原価差異を必須論点として持ち込んでいない。

月初と当月で単位原価が違う場合を無断で平均せず、指定評価額・均一原価・月初在庫なし等を明示した。サービスの未完了原価の引継ぎは問題の学習条件として限定し、すべての役務会計に一般化しない。配賦後損失から撤退判断を即断することを避け、費用節約条件のある補助例で解釈を確認した。

本文の例題・練習について、与件数値を別途入力した112個の計算式を実行し、途中額・最終額・行列合計が一致することを確認。問題の46数値解答も、受入解答文字列を計算に使わず、与件から別に入力した算式を評価して照合した。作業用の記録は `work/cost-unit3-body-witnesses.json` と `work/cost-unit3-question-witnesses.json`。いずれもAIが式を再入力した検算で、人間の専門家による独立監査とは区別する。

## 日本語の編集・校正

`natural-japanese`、`humanizer`、`proofread-ja` の指示を読み、本文・設問・解説を文脈で確認した。プロジェクトの `custom-terms.md` を確認したが、宅建士・税理士固有の制度用語を原価計算初級へ転用していない。本文はです・ます体、表と式と短い定義・設問条件は簡潔な表記を許容した。

`work/japanese-tools/Scripts/python.exe` で natural-japanese の `lint.py --json --genre tech`、`calques.py`、`outline.py`、`terms.py` を5本文へ実行（20件）。設問・選択肢・解説をレッスンごとに抽出した5ファイルへも同4ツールを実行（20件）。修正後、全5本文のlint・calquesを再実行（10件）。製品別利益へ計算前の符号予測を追記した後も、同本文の2検査を追加実行。作業結果は `work/cost-unit3-ja/` に保存した。

主な判断と修正は次のとおり。

- [修正] 製品別利益の「ではなく」「だけでなく」という対比の連続を、配賦基準の比較・二重控除・条件付き解釈という具体的な説明へ整理した。計算条件と留保は保持した。
- [修正] サービスの引継ぎ説明の不要な「このように」を削除。「前月分が抜ける」を「前月分を計算へ含められない」へ具体化した。
- [修正] 出典の説明を区切るダッシュを日本語のコロンへ統一した。式の減算記号やURLは変更していない。
- [保持] 全5本文の文長変化が小さいという統計警告。短い断片文や口語を足すための書換えはせず、計算理由と条件を一文ずつ追える教育上の読みやすさを優先した。
- [保持] 損益・サービスの体言止めがないという参考情報。連続説明を名詞句へ機械的に変えて、理由のつながりを失わせないため。
- [保持] 製品の問題集合における「月初製品」等の文頭の反復。各問が独立表示されるため必要な条件を省略せず、言い換えだけを目的に正式用語を変えない。
- [保持] 製品別利益の設問集合の文長変化の弱い警告。指示する数値と単位を同じ粒度で伝えるためで、判読に問題はない。
- [保持] calquesが列挙した「足す」「引く」は実際の加減計算、「先」は計算順または集計先を指す。曖昧な動作の比喩として置き換えていない。

proofread-ja の誤字・同音異義語・送り仮名・補助動詞・数値単位・敬体・助詞・表記揺れの観点で、各本文の節と各問題を読み直した。数値や条件を文体のために削らず、原価と費用、製造原価と製品製造原価、売上総利益と営業利益、作業時間と件数の区別を保持した。
