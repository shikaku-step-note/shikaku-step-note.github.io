# 日商原価計算初級：公式範囲と旧教材の調査

確認日：2026年10月28日。AIによる公式資料照合。資格保有者や外部専門家による監修ではない。

## 対象と適用版

今回の「全て」は一つの公式区分「原価計算初級」の全範囲を意味する。簿記初級や簿記1〜3級は別区分である。公式Q&Aによると、原価計算初級の上位に独立した中級・上級を設ける予定はなく、より進んだ内容は簿記1・2級につながる。サイト内のユニットを公式級として扱わない。

出題範囲は2018年度施行開始の1ページPDF。2026年度も変更なし。2026年7月31日公表の2027年度確定案内も、原価計算初級は変更しないと明記し、同じPDFへリンクする。2026年度の学習に将来の簿記初級の改定を混ぜる必要はない。

出典：[公式概要](https://www.kentei.ne.jp/bookkeeping/ca/effect)、[出題範囲PDF](https://www.kentei.ne.jp/wp/wp-content/uploads/2018/01/h30genkashokyu.pdf)、[適用年度案内](https://www.kentei.ne.jp/bookkeeping/exam-list)、[Q&A](https://www.kentei.ne.jp/bookkeeping/ca/qa)。詳細な台帳は `source-register.json`。

## 試験形式と公開サンプルの区別

現在確認できる仕様は、認定会場のネット試験、選択式、40分、100点満点で70点以上。自宅で受けるオンライン試験ではない。形式は2026年4月1日更新の[ネット試験案内](https://www.kentei.ne.jp/33013)を優先する。古いQ&Aには2020年の予定等も残るため、ページ全体を一律に最新情報と扱わない。

[2018年公開サンプル](https://www.kentei.ne.jp/wp/wp-content/uploads/2018/03/SAMPLE_ca2018.pdf)の全6ページを確認した。出題構造は次のとおり。

| 群 | 観察できる構造 | サンプルの群別配点 |
| --- | --- | ---: |
| 第1問 | 語句選択13問と仕訳選択1問 | 44 |
| 第2問 | 一つの店舗資料からCVPを考える6設問 | 24 |
| 第3問 | 二製品の原価明細と損益表の完成。明細8空欄、損益表9空欄 | 32 |

第3問の空欄は、取得したPDFの6ページ目を画像化して数えた。明細は4行それぞれ2空欄で8。損益表は売上高2、売上原価2、売上総利益3、販管費1、営業利益1で9。したがってサンプルの解答箇所は計37である。17空欄を「8問」と数えて、全体を28問とするのは実際の作業量を過少に示す。

ただし、これはサンプルの観察結果であり、すべての実試験の固定出題数を公式が37と定めたことにはならない。公開PDFは群配点のみ示し、空欄ごとの点数や部分点は明示していない。第2・第3問には旧来の数値入力欄があるが、最新の現行案内は選択式とする。教材の本番時間モードは現行形式で作り、自由入力は学習用の練習に使う。

二つの模試は別資料・別文面・別数値・別の条件判断を持つ独立した問題として作る。37解答箇所と44/24/32を参考にするなら、その対応と独自配点を説明する。特に第3問は一つの表資料を読み、原価集計から販売原価・利益へ進む仕事を省略しない。数値の一行問題を15個並べた旧模試を本番作業量の代わりにしない。公式サンプルの文面、データ、選択肢を転載しない。

## 公式範囲の境界と教学上の注意

公式PDFの3領域は、原価の基礎概念、利益の計画と統制、製品別・サービス別の期間損益計算。基本語句だけでなく、資源の消費と対象の関係、原価の分類、CVP、売上高の価格・数量差異、直課と配賦、仕掛品と製品の在庫、損益のつながりを計算で扱う。

[公式の内容説明](https://www.kentei.ne.jp/bookkeeping/ca/point_ca)は、製造業だけでなく飲食店・小売を含むサービス業の例も出し、製品・サービスごとの利益計算を重視する。一方、個別原価計算と総合原価計算という計算形態の違い、および標準原価計算は範囲外としている。予算売上高の差異分析は明示された範囲なので、標準原価差異と混同して除外しない。

月末仕掛品原価の計算は範囲に含まれる。製品別に追跡できる未完成分の材料・作業費等、与えられた評価額、原価保存の増減関係を扱う。工程別計算、完成品換算量、先入先出法を初級の必要技能として追加しない。完成品の単位原価を計算する場合は、原価の均一性、期首在庫の有無、指定された評価方法、端数処理を明示する。

安全余裕率、目標利益、感度比較はCVP理解を助ける派生練習として妥当だが、公式PDFの独立項目と偽らない。売上数量が増えたことだけで利益も同額増加したと決めつけない。販管費の配賦基準が指示される場合、製品別損益はその前提に依存する。配賦後赤字だから即撤退という意思決定へ飛躍しない。

## 旧4レッスンの内容監査

本文4本と `src/data/boki-questions.json` の16問、`src/data/boki-mock.json` の15問を実際に読んだ。旧教材には基本式の理由、単位、簡単な検算があり、その正しい説明は維持可能。一方で、広い範囲を4本へまとめ、分野ごとの独立練習・条件変更・統合資料が少ない。公開済みという理由で十分な試験準備教材とは扱わない。

| 旧ID | 既存の有用な内容 | 拡充が必要な技能 |
| --- | --- | --- |
| cb-classify | 購入と消費、費目と直接間接の二軸、簡単な分類 | 対象/活動/責任の関係、材料帳と数量・金額、賃率と時間、経費の具体例、複数軸の判断理由 |
| cb-allocate | 時間基準の配賦率と検算、総額と単位原価 | 複数製品の直課と配賦を資料から整理、基準変更の比較、二重集計、端数・基準量の条件 |
| cb-inventory | 月初/投入/月末/完成、売上原価、簡単な製品別損益 | 仕掛原価の組立て、数量と原価の二つの保存、製品別の一貫表、サービス別の利益、原価の仕訳選択 |
| cb-cvp | 貢献利益、分岐点数量/売上、目標利益、簡単な差異 | 変動固定の単位、条件変化の推論、複数のCVP資料、価格数量の橋渡し、符号と解釈、総合問題 |

既存の16理解度チェックは単純な計算・選択で、一つのレッスンに4問。ユニット総合確認は同じ16問の再利用で、独立した出題設計ではない。累積総復習も同じ16問である。旧模試は15問の独立した短い設問で、連結した製品原価表や一店舗のCVP共通資料を完成させる構造ではない。問題の数値は基本的に正しいが、`cb-cvp-q2` は「同じ条件」として前問を参照するため、個別表示でも解けるよう条件の再掲が必要。参照先を誤って別問題に解釈させない。

旧4本を分割して新しい技能IDを設ける場合、旧ID・URL・星・完了・当時の評価履歴を保持し、新課程の完了へ自動転記しない。公開課程の学習ツリーは新しい学習順に一本化する。旧版への移行説明や作業実績をコース冒頭へ常設しない。技術的移行はリポジトリと必要な進捗ヘルプへ記す。

## 提案された22レッスンの評価

5ユニット・22本という親エージェント案は、必要な前提と標準的な統合問題を教える余地がある。公式の領域番号と教学順は異なってよい。原価の流れ・仕掛品・製品別利益を先に学び、その後にCVPと予実差異を統合する順序は自然である。

留意点は次のとおり。`cb2-cost-flow` では公開サンプルにある製品から売上原価への基礎仕訳を、簿記未学習者にも借方/貸方の役割から説明する。`cb2-wip` は上位級の計算形態へ広げない。`cb2-pnl` と `cb2-product-profit` は表の読み方と複数製品・配賦条件の技能を分け、重複説明だけの二記事にしない。`cb2-services` では製品在庫がある製造業の式をサービス全般へ一律に適用せず、与えられたサービス別売上・直接費・共通費から利益を求める。`cb2-budget` は数量/単価/売上の関係、`cb2-sales-variance` は橋渡し計算、`cb2-variance-cases` は逆方向の変化・符号・利益との違い、と技能を分ける。

`competency-plan.json` は42技能の暫定対応表で、公式の小区分を教学上分解したもの。現時点で本文・問題の完成を表すものではない。最終受入れでは各技能に実在する本文アンカー、実例、独立練習と単元復習の問題IDを付け、実内容を読んで判断する必要がある。
