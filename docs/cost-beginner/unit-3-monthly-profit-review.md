# 原価計算初級 ユニット3の範囲・教材・検索の点検

2026-11-15確認。資格全体の公式範囲を起点とし、今回の改訂は指定されたユニット3「在庫と製品・サービス別の利益」。日本商工会議所の3(2)は仕掛品と製品の月末原価、3(3)は製品別・サービス別の売上原価、販管費、売上総利益・営業利益。1の原価の分類と3(1)の直課・配賦はユニット1・2で学ぶ。公式2の利益計画と予算実績差異は後続ユニット4・5に位置付ける。2026年度の範囲と2027年度確定版について、原価計算初級の変更はない。[公式範囲](https://www.kentei.ne.jp/wp/wp-content/uploads/2018/01/h30genkashokyu.pdf) · [年度別適用表](https://www.kentei.ne.jp/bookkeeping/exam-list)

公式サンプルの第3問では、共通の資料から複数製品の原価明細と損益計算書を作る。サンプルの在庫条件や解答箇所数を固定の実試験仕様とみなさず、今回の章では公式範囲の月末原価に月初からの原価移動を組み合わせた、別の事例を作成した。現行は40分の選択式。学習モードの数値入力は復習用。評価方法の違いの比較や標準原価計算を試験必須項目として追加しない。[公開サンプル](https://www.kentei.ne.jp/bookkeeping/ca/sample) · [試験案内](https://www.kentei.ne.jp/33013) · [上位級との違い](https://www.kentei.ne.jp/bookkeeping/ca/point_ca)

## 学習順と到達目標

既存5章と理解度チェック65問を保持し、それぞれに原票や費用から判断する例題を追加した。新しい第6章は、二つの在庫の式、製造間接費と販管費の異なる配賦基準、製品別損益計算書を一続きの問題で扱う。収益や費用の範囲が分かるユニット1、原票と集計表を照合するユニット2を終えてから進む。

## 評価と学習記録

ユニット3は5章から6章、コースは27章から28章。新章の理解度チェックは6問（数値入力2・選択4）。総合確認には原票2表を読む独立の複合問題を加え、16問から20問とした。収納用品の完成原価48,000円、売上原価40,000円、修理の売上48,000円・売上原価22,000円を求め、共通管理費10,000円を売上高で配賦する。全体の営業利益は40,000円で、修理の未完了原価訂正後は41,500円。各部門を別々に計算して照合する。新章と新しいユニット総合確認だけ別の評価版を使用する。旧版の評価結果と既存の章の進捗は引き続き参照できる。用語確認と既存の40分模試2回を引き続き学習順に含める。
