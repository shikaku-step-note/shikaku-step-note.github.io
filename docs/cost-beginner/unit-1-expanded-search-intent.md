# 原価計算初級 ユニット1 追加章の検索意図

2026-11-15。日本語の公開検索結果と日本商工会議所の語彙から立てた候補で、検索数・順位の計測値ではありません。

| 調べたいこと | 日本語クエリ候補 | 章・既存ページとの関係 |
| --- | --- | --- |
| 購入額と実際の使用額 | 材料を買ったとき 使ったとき 材料費、払出し 返却 材料 | cb2-material-use。数量と時点を判断。複数単価と本格的な元帳は cb2-materials |
| 役務と原価の対象・期間 | サービスの収益と原価、案件別原価 入金 売上 違い | cb2-matched-revenue。完了日と案件番号で資料を合わせる。配賦を含む期間損益は cb2-services |
| 販管費と二つの利益 | 製造原価 販管費 違い、売上総利益 営業利益 違い | cb2-profit-boundary。用語と未販売を含む単一製品。複数期の仕掛品・損益表は cb2-pnl |
| 分類と利益をつなぐ | 原価計算初級 原価の分類 練習、製造間接費 売上原価 総合問題 | cb2-classification-case。自作資料で解法の順を教える。概念の入口は cb2-purpose と cb2-traceability、採点ランナーは検索対象外 |

公開検索では費目・活動・追跡可能性の説明が一緒に扱われる場合があります。章ごとの学習目標をタイトル・説明文に反映し、章同士を内部リンクでつなぎます。観測した検索結果は需要・順位の保証に使いません。検索サービスの管理画面の実績は今回の判定外です。[JCCIの範囲](https://www.kentei.ne.jp/wp/wp-content/uploads/2018/01/h30genkashokyu.pdf)
