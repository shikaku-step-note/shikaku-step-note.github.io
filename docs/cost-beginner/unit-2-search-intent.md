# 原価計算初級 ユニット2 検索意図

2026-11-15、日本語の公開検索結果と日本商工会議所の用語を比較。以下は検索需要の定量計測を伴わない編集用の候補。検索数・順位・難度は未計測。

| 日本語クエリ候補 | 読者が確認したいこと | 既存の正規ページと改善 |
| --- | --- | --- |
| 材料消費額 計算、材料元帳 受払、材料 返品 払出し | 購入から消費を割り出す、二種の返却と残高の違い | cb2-materials。原票を使った月次元帳と現物差異を追加 |
| 消費賃率 計算、直接労務費 間接労務費、外注加工費 直接経費 | 作業票の時間換算、製品と共通の区分、当月負担 | cb2-labor-expenses。作業票と請求書を分類して集計 |
| 製造間接費 配賦率 計算、直課 配賦 違い | どの基準量と率を使うか、重複を防ぐ | cb2-allocation。率が与えられる場合と原票で専用分を切り出す場合を説明。単語としての直課・配賦の区別は cb2-traceability |
| 原価の流れ 仕掛品 製品、売上原価 仕訳 | 各勘定への振替、販売時の費用、在庫と照合 | cb2-cost-flow。月次残高表を順につなぐ事例と訂正を追加。残高の詳細は cb2-wip と cb2-finished |
| 原価計算初級 過去問、原価計算初級 練習 | 公式サンプル、無料で使える練習 | 公式サンプル情報は coverage、学習・演習への入口はコースページ。総合確認は内部ユーザー向けのnoindex |

出題用語、初心者の言い方、同じ語に対する講義と練習の役割をページ上で整理しました。指名語・数字・同義語の違いだけでURLは増やしません。検索・AI機能に向けた確認は公開HTMLの説明、見出し、出典、画像のテキスト相当、正規URL、内部リンク、サイトマップの整合に限定。ウェブマスターの実績値が使える場合は公開後のページ・クエリ別の測定に使います。
