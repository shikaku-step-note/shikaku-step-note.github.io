# 日商原価計算初級 ユニット1の教材深度と表示の確認

確認日 2026-11-15。対象はユニット1の8章。公式の1(1) 資源の消費、1(2) 原価・収益・部門・責任、1(3) 費目と直間、1(4) 売上総利益・営業利益を、既存の学習順に対応させました。日本商工会議所は2026年度と2027年度に同じ範囲を適用します。現行は選択式40分。公開サンプルに見られる問題数や配点は、全回の固定値として扱いません。[公式範囲](https://www.kentei.ne.jp/wp/wp-content/uploads/2018/01/h30genkashokyu.pdf) · [適用年度](https://www.kentei.ne.jp/bookkeeping/exam-list) · [公開サンプル](https://www.kentei.ne.jp/bookkeeping/ca/sample) · [現行の試験案内](https://www.kentei.ne.jp/33013)

## 各章の既存教材と追加した推論

| 章 | 既存の説明・例題・独立練習 | 今回追加した説明と条件違い | 検算 |
| --- | --- | --- | --- |
| cb2-purpose | 目的・活動・資源、消費の時点と単位、販売分との対応 | 案件が使った機器時間と会社が契約した時間から、対象ごとに必要な資料を選ぶ | A 16,000円、うち機器7,200円。両案件の機器21,600円＋未使用時間相当14,400円＝契約36,000円 |
| cb2-material-use | 受入れ・払出し・返却、数量残高の照合、均一単価での換算 | 倉庫から出た後に現場で未使用のまま残った量を区別。倉庫と現場の残高を別々に追い、実際の消費へ戻る | 40kg＝倉庫20＋現場5＋消費15。@800円なら32,000円＝16,000＋4,000＋12,000 |
| cb2-elements | 費目別・機能別分類、複数用途の明細、製造と販管費 | 金額だけ確定した勤務を確認待ちとし、訂正後に用途別へ振り分ける。総額照合と分類根拠の違いを教える | 訂正後の製造13,500＋販売5,500＋管理3,000＝22,000円 |
| cb2-traceability | 対象変更で直間が変わる理由、六分類、直課と配賦 | 製品名の記載、製品別の計量、工場全体額という証拠の差を読む。後で判明した専用費を共通分から移す | A8,000＋B7,000＋共通13,000＝同じ請求28,000円 |
| cb2-departments | 部門責任、固有費・共通費、数量・単価の違い | 部門利益が同じ二つの報告を比較し、追加の支出と配賦先の変更が全社利益に及ぼす違いを追う | 両案とも部門利益24,000円。全社利益は案Aが6,000円減、案Bは不変 |
| cb2-matched-revenue | 案件と期間、平均の限界、割合と共通費 | 前月・当月・翌月にまたがる三件の入金、完了、使用した直接費を照合。締め時点が変わる場合も比較 | 5月入金24,500円。完了分26,000−12,800−3,700＝9,500円。Nも完了する条件なら26,100円 |
| cb2-profit-boundary | 製造・販売・管理、未販売分、粗利と営業利益 | 粗利の変化から誤った分類額を逆算し、売上原価と在庫へ分かれる割合を使う。全量販売とも比べる | 粗利の増加3,600÷75％＝移動4,800円、在庫と営業利益は各1,200円減 |
| cb2-classification-case | 三つの分類軸、二製品の原価、在庫と営業利益 | 読取り訂正で2製品の間に原価を移したとき、工場総額の保存と、在庫・当月費用への経路を別に検算する | 訂正後はA43,000・B21,000で計64,000円、売上原価55,400円、在庫8,600円、営業利益28,600円 |

既存の本文、例題、解答、前後関係を照合し、既存の教材アンカーは保持しました。章間の移動は行っていません。材料の簡略例の返却条件と正味消費量の定義、誤解の出やすい新規設問の前提などを明確にしました。設問と既存模試の改変は行っていません。

| traceability | #trace-evidence-map で対象単位の変更、#trace-source-strength で証拠の強さを照合 | #guided-traceability。円入力17,000。追加で判明した額を共通分から外す |
| departments | #cost-responsibility で調査順を追い、#department-cause-controls で似た利益差の照合資料を選ぶ | #guided-departments。全社利益不変を選択。部門間負担と会社への実際の支出を区別 |
| matched-revenue | #match-evidence-table で案件番号と完了月、#match-month-ledger で月をまたぐ計上額と入金を照合 | #guided-matched-revenue。円入力12,000。完成した案件の前月分と当月分をたどる |
| profit-boundary | #profit-statement-bridge で粗利・営業利益の経路、#profit-boundary-sold-share で販売・未販売割合と逆算 | #guided-profit-boundary。移動3,000円／営業利益1,200円減を選択。粗利の変化と販管費の増加を比較 |

各練習は途中で解き、正答時に途中式や判断理由を確認できます。不正解には再検討する資料や条件を表示します。練習内の「解答と考え方を読む」はJavaScriptなしと印刷でも使えます。採点つきの既存チェックやしおりとは別の、その場で試す練習です。既存画像、図、元の演習は引き続き読めます。

## 保存・維持管理・検索

ユニット1は8章、全体26章。章末チェック76問、総合確認19問と、既存の40分模試2回の版と形式は同じです。本文に途中練習8件を追加。正味消費量の定義が変わったため、ユニット1用語確認と全体の用語総復習だけを改版しました。旧版得点を履歴に残し、未提出の旧版用語確認は新しい版でやり直します。

教材は src/content/lessons/cb2-*.md。途中練習用の操作は src/scripts/guided-lesson.ts、教材の表示・印刷は共通のレッスンページで管理します。学習時間・用語等を変えた際は pnpm curriculum を実行し、TXTを更新します。新しい用語の版は cost-beginner.ts で個別に管理します。

検索は既存URLと学習順を維持。「原価と消費」「直接費・間接費」「製造原価と販管費」「売上総利益・営業利益」の用語が、それぞれ説明・図・作例と同じページにあります。前回の検索意図表と今回の本文を合わせて確認しました。順位や掲載は測定未実施。第三者専門家の監修や実際の試験難度との同等性は確認していません。
