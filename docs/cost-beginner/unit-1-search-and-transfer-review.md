# 原価計算初級 ユニット1の出題範囲・教材・検索の点検

点検日 2026-11-15。対象は「原価の考え方と分類」。日商原価計算初級は一つの試験区分で、ユニットはこのサイトの学習順を表す。

## 出題範囲と学習順

[日本商工会議所の出題区分表](https://www.kentei.ne.jp/bookkeeping/exam-list)で2026年度に適用される範囲と、2027年度確定版での扱いを確認した。原価計算初級の[出題範囲・内容](https://www.kentei.ne.jp/wp/wp-content/uploads/2018/01/h30genkashokyu.pdf)は2027年度も変更されない。対象の第1章は、(1) 原価と資源の消費、(2) 収益との対応と原価の集計対象、(3) 費目および直接・間接の分類、(4) 製造原価・販管費と段階利益。試験は40分の選択式。[ネット試験の概要](https://www.kentei.ne.jp/33013)と[公式サンプルへの案内](https://www.kentei.ne.jp/bookkeeping/ca/sample)を同日に確認した。サンプルから資料の読み取り方と問題形式を確認し、教材と問題は独自の条件で作成した。

各章を、定義、判断の根拠、途中式、誤答の理由、自力演習の順で点検した。以下の8章で出題範囲を教え、別業種の複数資料を読み合わせる練習をユニット末で追加した。学習目標の分割を要する不足は見つからなかった。

## 演習と既存記録

- ユニット1は8章のまま。独立した理解度チェック76問と入力・選択で答える章内演習8件を保持し、表付きの例題を4件追加した。
- 総合確認は19問から22問に増えた。新しい共通資料では自転車修理店の引渡し、入金、部品、作業の記録から、収益の対象月、費目と直課、店全体と案件別の差額を判断する。選択式に合わせ、金額や判断を自力で出してから選べるようにした。
- コース全体は26章。ユニット1と全コースの用語テスト、40分模試2回、章ごとのチェック問題と進捗IDを保持した。ユニット総合確認だけ版を更新し、旧版の結果は履歴に残す。旧回答を追加3問込みで採点し直すことはない。
- [出題範囲と対応表](https://shikaku-step-note.github.io/qualifications/cost-beginner/coverage/)の対応根拠を更新した。所要時間を変えた4章と追加3問は、既存のTXT出力で日程と合計に反映する。

## 検索の観測と改善

2026-11-15のGoogle Search Consoleエクスポートは過去24時間のウェブ検索。サイト全体は62表示・0クリック（日本62表示、モバイル53表示）。原価計算初級のコースURLは2表示・0クリック・平均掲載順位8.0。ユニット1のクエリとランディングページの組合せは確認できなかった。Bingの提供CSVは日別のサイト全体で28表示・3クリック。コース別・ページ別・クエリ別の値を含まない。

表の検索意図は公式用語と日本語の公開検索結果から得た候補。検索量や当サイトでの実績は未計測。比較語、学習用の計算手順、例題という目的を分けて各章に割り当てた。タイトルと説明文を本文に合わせ、コースの学習ツリーでも同じ章名からたどれるようにした。内部検索語には表記の違いと日常語を加えた。「原価計算初級 原価の分類 例題」では、コース紹介の本文よりも具体的な章名が先に出るよう、完全一致の章名と見出し中の語の一致を優先した。同じ優先度の結果は従来の並び順を保つ。40分の試験形式や全範囲の演習を探す意図は、コース概要・模試一覧が受け持つ。
