# 原価計算初級 40分模試の資料・計算確認（2026-11-18）

日本商工会議所の[現行のネット試験案内](https://www.kentei.ne.jp/33013)は、原価計算初級を40分の選択式としています。[公式の試験概要](https://www.kentei.ne.jp/bookkeeping/ca/effect)では100点満点で70点以上が合格基準です。独自模試2回は各37小問・100点です。44・24・32点の3群は[2018年公開サンプル](https://www.kentei.ne.jp/wp/wp-content/uploads/2018/03/SAMPLE_ca2018.pdf)の構成を参考にしています。本試験の固定小問数、固定配点、部分点や難易度の根拠にはしていません。問題、資料の会社・数値・文面、選択肢は独自に用意しています。

## 第1回 第2群の費用資料

ケータリングの資料は、1件増えるごとに発生する食材費560円・配送外注料340円と、月額で発生する賃料72,000円・固定給48,000円・減価償却費60,000円を区別します。単位変動費は900円、月間固定費は180,000円です。

- 予算の貢献利益率は (1,500−900)÷1,500＝40％。予算500件で固定費も引いた営業利益率は 120,000÷750,000＝16％。変動費率60％や、この二つの利益率を使い分けます。
- 予算条件の分岐は180,000÷600＝300件。実際の売価なら1件当たり貢献利益540円。333件で179,820円、334件で180,360円を回収するので、赤字にならない最小整数は334件です。実際550件の営業利益は117,000円。
- 売上高は予算750,000円、実際792,000円。予算単価で数量差異＋75,000円、実際数量で価格差異−33,000円を求め、その和＋42,000円を売上高の差と照合しました。

## 第1回 第3群の製品原価・損益資料

月初・月末の仕掛品はともにゼロ。月初の製品もありません。直接作業時間を賃金の計算に使い、別に記録した機械作業時間を製造間接費の配賦に使います。二つの材料・時間記録を読み、完成数量と販売数量を分けて利益まで計算します。

| 確認欄 | 製品A | 製品B |
| --- | ---: | ---: |
| 直接材料費（600円／kg） | 300kgで180,000円 | 200kgで120,000円 |
| 直接労務費（500円／直接作業時間） | 180時間で90,000円 | 140時間で70,000円 |
| 直接経費 | 12,000円 | 8,000円 |
| 機械作業時間と配賦額（240円／時間） | 300時間で72,000円 | 200時間で48,000円 |
| 完成品原価・完成数量 | 354,000円・354個 | 246,000円・410個 |
| 完成品1個当たり原価 | 1,000円 | 600円 |
| 販売数量・売上原価 | 300個・300,000円 | 350個・210,000円 |
| 月末製品数量と原価 | 54個・54,000円 | 60個・36,000円 |
| 売上高と売上総利益 | 540,000円・240,000円 | 350,000円・140,000円 |

完成品原価合計600,000円は売上原価510,000円と未販売製品原価90,000円へ分かれます。売上高合計890,000円から売上原価510,000円、販管費90,000円を順に引き、290,000円となります。第2回は仕掛品と製品の金額を前後から逆算する別資料です。第1回の数量・単価の読取りと、第2回の金額の受払をそれぞれ練習できます。
