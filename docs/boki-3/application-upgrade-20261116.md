## 教材・採点・記録

- 既存55レッスンに、異なる金額や資料を使う数値入力と途中式を追加。本文の定義を残し、科目の初出付近に3～4語の用語カードを置いた。追加3章も同一画面内の用語、複数の表、入力して確かめられる練習付き。
- レッスン末の採点対象は667問から693問へ、単元総合確認は148問から157問へ。章内の即時フィードバックはこの数と学習記録から独立。
- 60分の独立模試2回を維持。既存の答案・採点キーと配点は共通のまま、利息勘定と固定資産台帳で誤った際の説明と復習先を更新した。単元5・6の総合確認は、新しい問題が増えたため評価版を分けた。旧成績・完了・ブックマークは引き続き保存される。
- 日本語資料の参照では、パブロフ簿記の無料教材と、出版社・会計教育事業者が公開している資料を、説明の進め方だけ比較した。取引の言葉から権利・義務や帳簿の列へつなげる順を参考にした。本文・図表・設問は当サイト用の独自例。確認は内容照合、計算の別検算、日本語の読み直し。外部の人による監修や受験者による模試の難度校正は実施していない。
- 2027年4月以降は、紙の手形・小切手、販売時の売上原価、除却・廃棄、定率法などの適用に変更がある。確定した改定事項の概要を現行課程から分けて表示し、2027年度課程・計算例・新配点模試の実装は次回の年度更新とする。

## 表示と操作の確認

1,440pxの固定資産台帳レッスンで、用語をその場で読む操作と、2語を右側に固定して比較する操作を検証。1語ずつ解除できることを確認した。768pxでは右側を非表示にし、同じ位置で読める小さな説明を使う。360pxのダーク表示では全58レッスンを開き、横にはみ出さず、各ページの用語をタップで開閉できることを確認した。キーボードのEscape、スクリプトを無効にした場合の解説、印刷での用語の表示も点検した。
