# 日商簿記3級：現金預金・日常収支・商品売買の執筆記録

対象：`b3x-cash`〜`b3x-payroll`、`b3x-purchases`〜`b3x-moving-average`の新規12レッスン。2026年10月28日作成。

## 教える内容と順序

仕訳の基礎を前提に、現金の分類→現金過不足→小口現金→預金→経費と収益→給料へ進みます。商品売買は3分法の仕入れ→販売→諸掛と立替え→返品→先入先出法→移動平均法です。売価・原価、発生・決済、費用・負債の減少などを混同する箇所では、元の取引と残高の変化を具体的に比較します。

各レッスンに測定可能な3目標と`objective-1`〜`objective-3`、解法と検算を伴う4例題と`worked-1`〜`worked-4`、誘導付きの練習、条件の違う自力演習と解答があります。仕訳だけを暗記させず、相手科目を決める理由、現金・預金・債権債務のどれが変わるか、残高や純額のつながりを説明しています。狭い科目の定義だけで分量を増やさず、逆算、混合取引、誤記修正、時点の違いで応用を補いました。

文字数は本文・例題・表を含み、メタデータと末尾の公式資料欄、別データの採点問題を除いた非空白文字数です。概ね4,500〜5,100字ですが、これは説明の十分さを証明する基準ではありません。数値と記号も含みます。具体的な目標・問題数・検算の実行結果は`daily-author-validation.json`を参照してください。

銀行勘定調整表、棚卸減耗・評価損、上位の割引・割戻等を3級の必須手続に追加していません。現行の小切手処理は残しています。経費レッスンの初稿に含めた`役務収益`・`役務原価`は、区分表の級別確認により2級範囲と分かったため公開前に除去しました。該当例題・目標・用語・設問を、3級の受取手数料・受取利息と元本回収の区分へ置換済みです。

給料は指定された控除額・会社負担額で記帳します。税率・保険料率、個人別税額計算を推測していません。商品有高帳では返品の原価・再平均・戻入順序・端数処理を問題ごとに明示し、唯一の処理を曖昧な条件から決めていません。3分法の販売仕訳へ、商品有高帳の払出原価を重ねて記録しないよう説明しています。

## 日本語編集の工程と所見

`natural-japanese`、`humanizer`、`proofread-ja`の指示と校正資料を読み、自然な敬体、公式用語、因果関係、費用と決済の区分を保って編集しました。単語をむやみに言い換えて用語の一貫性を崩す処理はしていません。

本文、メタ説明、用語、理解度チェック、ユニット復習を合わせて、各12ファイルに対し`lint.py --genre tech --reading-load`、`calques.py`、`outline.py`、`terms.py`を実行しました。合計48ジョブの終了コードはすべて0です。初回の検出を確認し、「このように」の不要な接続、強調だけの否定、長い数値条件の一文などを9レッスンで修正しました。数値・科目・前提を変えない編集です。修正前後の`newfacts.py`は12ファイルとも新規項目なしでした。

再実行後も語彙多様性、文長の均一性、同じ専門用語での文頭反復などが残ります。これらは用語や問題文まで含めた検出であり、検出数をゼロにするための不自然な同義語置換はしていません。否定文は、二重記帳、売価と原価、支払いと費用を取り違える実際の誤りを説明する箇所に必要なものを残しました。`まとめると`の1件は「雑費にまとめると」という実際の集約操作の説明です。翻訳調候補の多くは文字どおりの算術の「足す・引く」、時点の「先」、正式用語の「小口現金」です。漢字連続も仕訳の科目名や小切手の正式名称が中心で、初出の意味を本文で確認しています。

最後に4件の短い数値解説へ式の意味・資産回収・原価配分の理由を補いました。追加の新しい前提や正解変更はありません。文章のリズムを変えるためだけに説明や計算過程を省いていません。
