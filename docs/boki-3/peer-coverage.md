# 日商簿記3級・技能別カバレッジの独立レビュー

確認日：2026年10月28日。対象は `src/data/boki3-coverage.json` の現行61行と `docs/boki-3/competency-plan.json`。2026年度に適用される商業簿記区分表の3級欄を、保存済みの4ページの配置を保った抽出資料と公式原本で確認した。2027年度からの変更4行を現行61行の分母へ入れない扱いは適切である。61は教材側で手続を分解した数であり、公式が定めた技能数とは扱わない。

確認では、全61行の技能文と実際のアンカー・問題IDを読み、執筆時と別レビュー時に読んだ本文・問題内容に対応づけた。手形貸借、当座借越の決算振替、税金、補助簿締切など、見出しが似ていても手続が違う箇所は本文を再読し、全コースの該当語検索と問題文の照合で裏づけた。IDの存在や問題数だけで教育的カバレッジを認定していない。

## 現行範囲の構成

2026年度では2級欄にある役務収益・役務原価、未決算、固定資産の除却・廃棄、直接法・定率法、正式な区分表示・報告式、割引・裏書・不渡、銀行勘定調整表等を現行の必須技能へ加えていないことも確認した。独自練習の仕訳・表の作成量と、公式の試験形式が固定されているという主張は区別されている。

## 修正が必要な具体的な証拠

### b3c-24：手形貸付金・手形借入金へのリンクが通常の貸借へ向いている

初回の対応は `b3x-loans` のobjective-1・2、worked-1・2だった。これらは普通の貸付金・借入金と利息天引きであり、手形貸借を教える箇所は同ページのobjective-3・worked-3である。実際の末問q10〜q14、ユニット確認 `b3x-u4-review-15` はこの第三目標へ属するため、初回の行から漏れていた。

本文には手形貸付の発生→回収、相手の手形借入→返済までの両側の仕訳と、商品代金の受取手形・支払手形との区別がある。教材が不足しているのではなく、実在する適切な説明・独立練習を行へ結び直す修正である。

### b3c-46：日常の借越処理が、決算振替の証拠になっている

公式第三3は「当座借越の振替」を明示している。初回のリンクは `b3x-bank` objective-2・worked-2とq04・q05・q08・q10・q11、review-2だった。これらは日常の二勘定制で借越を発生・解消する取引や一勘定制の残高計算であり、期末に貸方残高を借入金へ振り替え、翌期首に戻す処理ではない。

当初の `b3x-bank` 本文は決算時の振替を後で扱うと述べるだけだった。全b3本文検索では `b3-cash` に期末振替の短い例はあるが、翌期首への連続例と新条件の独立問題は見つからなかった。したがってこの初回対応は単なるリンク修正では足りず、期末・翌期首・その後の入出金をつなぐ例題、理由、独立仕訳と解説、レビューを補う必要がある。二勘定制の日常返済をもう一問増やすだけでは当該技能を満たさない。

### b3c-40：租税公課のうち固定資産税の説明・練習が薄い

初回は `b3x-expenses` objective-2・worked-2と `b3x-supplies` objective-3を参照していた。前者の実体は未払広告代と銀行手数料、後者は未使用切手・印紙の資産振替である。第二21アの固定資産税は `b3x-corporate-tax` の本文で租税公課との区別に触れる一文だけだった。全boki3末問では固定資産税を実際に仕訳する独立問題は見つからなかった。

未使用印紙の整理と、固定資産税の支払処理は両方租税公課に関係しても、同じ手続ではない。既存ページ内へ固定資産税等の費用計上と支払を教える小さな例、法人税等・消費税との区別、新しい仕訳練習を補い、適切なアンカーを行へ追加するのが妥当である。税率や課税計算の解説を無断で増やす必要はない。

### b3c-16・b3c-56：技能文と例示の精度

初回b3c-16は「月割または指定日割」と書くが、対応するloans本文と14末問はすべて月割の具体例であり、日割は指示に従う旨に触れるだけだった。日割も実装済みという主張は避け、教示・新条件の独立練習を追加するか、技能文を実際に教えた範囲へ正す必要がある。

b3c-56の英米式の総勘定元帳締切はclosing-booksの実例に対応する。一方、bills objective-3の実例は手形の未決済明細と元帳照合が主で、補助簿を期間で締める実例へのリンクとしては弱い。cash・petty-cashの出納帳と残高繰越の実例も参照する方が適切である。また、公式第三8アが仕訳帳と総勘定元帳の両方を挙げるため、仕訳帳の期間合計・区切りと次期開始を簡潔に具体化すれば、T勘定だけで帳簿締切全体を教えたと見なす誤解を防げる。

## 総合演習と独立練習の扱い

b3c-58は二つの総合演習の各技能をつなぎ、Aの別会社の損失ケース、Bの別条件の自力演習を参照する。主問題と同じ数値を採点する43欄は `guidedCheckQuestionIds` へ分離され、独立問題へ数えていないことを確認した。独立資料の模試A・Bの第3問46欄は、46の別会社の問題ではなく、二つの総合資料に対する採点欄である。独立した二つの資料を実際に全科目で処理する課題として、単なる短い定義問題とは区別できる。

各行に同じ技能の練習が複数回登場することは復習のため妥当だが、行別のリンク数の総和をユニーク問題数とは呼ばない。用語確認299問や別名は、仕訳・帳簿作成の実技を満たす証拠へ使われていない。

## 結論の範囲

初回監査では、課程の大分類そのものの欠落は認めなかったが、上記の決算時当座借越・固定資産税の実技と対応関係を、そのまま完了扱いすることはできなかった。修正後は追加した実際の説明・問題と対応行を読み直して判定する。これは現行の公式3級範囲と教材の関連を検証する独立AIレビューであり、有資格者による監修や本試験の難易度較正ではない。
