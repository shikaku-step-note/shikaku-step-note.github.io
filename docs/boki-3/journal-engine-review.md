# 仕訳入力エンジンの検証

確認日：2026年10月28日。

- `Question.input="journal"` と `journal:{accounts,debits,credits}` を追加。各側4行の入力欄を常に表示し、正解の行数を示さない。
- 保存解答は借貸の行配列を含むJSON文字列。バックアップv5、IndexedDB v1を維持。
- 勘定科目は指定リストから選択。金額は全角数字・適切な桁区切り・通常の正の小数に対応。指数表記、負数、円などの単位、壊れた桁区切りを正解扱いしない。
- 完全な空行は無視。同一科目の複数行を合計し、行順に依存せず貸借両側を完全照合。小数合計は整数の桁合わせにより正確に比較する。
- 科目のみ・金額のみの途中解答、貸借不一致、未選択は保存・復元できるが正解にならない。不正なJSON構造は現行形式との互換性を認めない。既存記録自体は削除しない。
- 採点結果は借方・貸方・科目・金額を読みやすい文字列で表示し、JSONを直接見せない。保存済みの入力は移動・再読込時に全行へ反映し、クリアでは全行を空欄へ戻す。
- 選択欄・金額欄にラベルと固有名を付与。狭い画面は借方と貸方を縦に配置。既存の明暗テーマ変数とフォーカス表示を使用。
