# 宅建業法ユニットの学習順と改修判断

確認日 2026年11月21日。法令の学習基準は2026年4月1日。公式の第7分野を、事業者の体制、依頼関係、情報提供、契約条件、資金保護、履行後の責任へ分けて検討した。RETIO令和7年度公開問題の問26〜45では、一つの数字の再生だけでなく、物件類型、業者の立場、名目と金額、複数条項の併用を読み取る課題がある。公開問題の文面は転載せず、独自の条件で教材と設問を作成した。

| 順に獲得する技能 | 章 | 判断と練習の位置 |
| --- | --- | --- |
| 取引の役割から宅建業と免許権者を判断する | tk-license | transaction-map、role-grid、notification-grid、三つの例題、guided-tk-license |
| 個人の登録・証・勤務先を分け、事務所ごとの人数を計算する | tk-practitioner | registration-route、change-map、proof-handling、3例、人数入力 |
| 場所の業務から人的体制・表示・届出・記録を確認する | tk-office | duty-comparison、location-matrix、retention-axis、3例、開始前日数入力 |
| 金銭の行先と時点から二つの保証制度を使い分ける | tk-guarantee | money-route、routes、deadlines、証券評価と支店追加・還付の3例、現金不足入力 |
| 売買以前の依頼関係と、登録・報告の時計を整理する | tk-brokerage | contract-record、two-contracts、time-grid、3例、登録期限比較 |
| 契約の判断へ必要な情報を、取得者と取引類型に応じて提供する | tk-disclosure | information-groups、purpose-map、contract-axis、vs-contract-items、3例、業者間の残存義務 |
| 成立した契約の書面を読み、合意内容と実際の履行を分ける | tk-document | contract-sequence、party-flow、cash-timeline、3例、残代金入力 |
| 売主・買主の属性を先に決め、八つの規制を横断して照合する | tk-protection | eight-rules、eight-map、money-ledger、3例、合算超過入力 |
| 申込み・契約の場所と告知・履行の時系列を追う | **新設 tk-cooling** | decision-procedure、place-matrix、stage-drawing、notice-timeline、worked-cases、告知日入力、独立混合問題 |
| 累計額から二つの金額条件と保全内容を選ぶ | **新設 tk-advance-payments** | contract-status、threshold-grid、running-bars、worked-cases、running-ledger、残る受領枠入力 |
| 価格区分から通常の報酬額を計算し、片側と合計を照合する | tk-reward | bracket-reasoning、rate-trace、cap-check、3例、税込上限入力 |
| 取引の変更に応じて基礎額と特例を選び、複数の上限を同時に満たす | **新設 tk-reward-cases** | method-choice、method-map、3例、low-price、vacant-rental、vacant-cap、代理受領枠入力 |
| 許可・確認と広告・契約の行為を分け、禁止行為・監督の対象を選ぶ | tk-conduct | permission-stage、stage-grid、bait-advertising、supervision-grid、3例、処分期間入力 |
| 対象住宅・契約時点・部位・引渡し後の責任と備えを整理する | **新設 tk-housing-warranty** | target、newness、house-parts、security、three-securities、3例、report、届出期限入力 |

元の10章は、既存の説明・例と学習目標を維持した上で、冒頭の前提、条件から結論へ至る理由、数値や当事者を変えた適用、独立問題を詳しくした。新設4章は、クーリングオフの日付・場所判定、累計支払の条件論理、複合報酬の計算方法、住宅引渡し後の資力確保という異なる手続きを、独立して練習するために設けた。元の章を読まずに例外だけを当てる学習順にはしない。新設章にも、それぞれ仕組みの説明、完全な例題、意味のある変形、二つ以上の図表、途中演習と独立問題がある。

保存する章末問題を61問追加し、既存章の4問と組み合わせる。新設章は各7問。ユニット末には、章末と重複しない10問を別に用意した。複数の制度のどちらを先に調べるか、独立した要件を両方満たすか、正しい数値を別制度へ使っていないかを確認する。

章別のアンカー、数式の再計算、情報源と残る限界は business-teaching-evidence-20261121.json に記録した。既存の全法定書式欄、すべての判例・但書、罰則額を一件ずつ独立評価した記録ではない。公式の級や科目の数を増やしたものではなく、第7分野の学習ステップの増設である。
