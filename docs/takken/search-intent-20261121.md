# 宅建士の検索意図と教材の案内先

確認日2026年11月21日。日本語の公開検索結果の見出しと公式の用語を比較し、既存の正規URLへ対応させた。現時点のSearch Console・Bingのアカウント内レポートは取得していない。検索量、人気順、順位やクリック率の改善幅は推定していない。検索の掲載例は需要を考える定性的な手掛かりとして扱う。

| 公開検索で調べた表現・質問 | 学習者の目的 | 対応する教材 |
| --- | --- | --- |
| 宅建 建ぺい率 容積率 計算 違い | どちらの面積を計算し、道路幅員や加重平均をどう使うか | tk-densityとtk-area-exclusions。二つの比率を分け、計算過程と条件変更を示す |
| 宅建 クーリングオフ 8日 数え方 | 告知日・申込み場所・発信と到達を判定したい | tk-cooling。日付の図と場所の比較、数え方の入力練習へ直接案内 |
| 宅建 不動産取得税 40平米 2026 | 2026年4月前後の面積要件と軽減計算を確認したい | tk-acquisition-tax。取得日と面積を先に読み、価格控除と土地税額減額を自分で導く |
| 宅建 相続 共有 保証 借家 の条件 | 原則だけでは判断しにくい人物関係や別手続を学びたい | 新しい権利関係の章。詳細はprivate-search-intent.mdに記録 |

コースページは全体の学習順と七分野、章ページは具体的な判断や計算の目的を持たせる。新章は別の学習成果が必要な場合に作り、単なる表記違いの検索語ごとにページを増やしていない。本文にある内容に合わせて題名・説明・導入を整え、数字、単位、適用日を明示する。サイト内の検索・ディレクトリ・HTML/XMLサイトマップは共有コンテンツから生成する。

今回参照した現行の公式ガイドはGoogleの[タイトルリンク](https://developers.google.com/search/docs/appearance/title-link)、[スニペット](https://developers.google.com/search/docs/appearance/snippet)、[有用なコンテンツ](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)、[AI機能](https://developers.google.com/search/docs/appearance/ai-features)、[サイト名](https://developers.google.com/search/docs/appearance/site-names)。Bingのガイド入口はJavaScript必須表示であり、追加の本文を取得できたと扱わない。静的HTML、正規URL、意味のある見出し、一次資料、本文と一致する既存構造化データを優先した。

公開・IndexNow通知・クロール・索引登録・順位・AI引用は別の確認事項である。公開後に同じ条件のレポートが得られた際、端末、検索語、ページ、掲載順位をそろえ、十分な再クロール後の期間で評価する。今回の公開検査から検索上の成果を推定しない。
