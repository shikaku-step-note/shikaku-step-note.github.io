# 権利関係の学習順と拡充方針

確認日 2026-11-21。基準は2026年度試験の2026年4月1日施行法令。RETIOの直近の公式公開問題は2025年度を使用し、問題文は転載しない。

## 入口から応用への候補技能

1. tk-contract 契約成立、意思能力、制限行為能力、無効・取消しの基本。
2. tk-capacity-followup【追加、tk-contractの後】取消権者と相手方の催告、追認、期間、返還を時系列から判断する。行為の効力を分類できても、その後どの意思表示で確定するかは別の技能。
3. tk-intent 意思表示の瑕疵、第三者を含む保護要件、取消し前後の時系列。
4. tk-agency 本人・代理人・相手方を図示し、権限、顕名、無権代理、相手方保護の根拠を順に選ぶ。
5. tk-prescription 権利の種類から期間と起算点を選び、完成猶予・更新、援用、第三者との前後関係を整理。
6. tk-title 当事者間の権利取得と第三者への対抗、二重譲渡、登記の公信力の有無。
7. tk-shared-land【追加、tk-titleの後】共有の持分と行為の分類、意思決定、相隣関係・通行を扱う。第三者への対抗とは別の判断手順が必要。
8. tk-mortgage 抵当権の範囲・順位・配当・物上代位・法定地上権・根抵当を比較。
9. tk-performance 弁済、受領権者、供託、相殺、債権譲渡の対抗要件。
10. tk-joint-guarantee【追加、tk-performanceの後】債権者からの請求と内部負担、連帯の効力、保証と連帯保証、個人根保証を判別する。2025年度公式問2・9の判断要求を参照。
11. tk-remedies 履行請求・損害賠償・解除・契約不適合・手付の要件を選ぶ。
12. tk-services-tort【追加、tk-remediesの後】請負・委任の義務と終了、契約関係がない被害者への不法行為責任を扱う。契約当事者を確定した後で法的根拠を選ぶ技能。
13. tk-lease 賃貸借の使用収益・修繕・賃料・敷金・譲渡転貸と借地借家法の入口。
14. tk-land-lease【追加、tk-leaseの後】土地を借り建物を所有する権利、普通借地の更新・再築・対抗と定期の方式を比較。
15. tk-building-lease【追加、tk-land-leaseの後】普通借家の期間・正当事由と、定期借家の契約前説明・終了通知・中途解約を別々の時点で判断する。
16. tk-inheritance 相続人、順位、割合、承認放棄、遺言、遺留分、登記を時系列に統合。
17. tk-condo 専有・共用・敷地利用権、管理の分類と集会の二つの母数、2026年改正と経過措置。

既存11章の基礎説明と正しい例題は保持し、独立した追加章はその後に進む応用技能を担当する。章数の増加は既存本文の移動や要約によって行わない。
